## Problem (문제)

### 핵심 문제

> **정보 우선순위가 시간 긴급도와 일치하지 않아, 사용자가 "지금 해야 할 것"을 즉시 파악하기 어렵다.**

### 세부 문제

#### P-1. 선생님: "오늘 레슨" 이 수강권보다 먼저여야 하는가?

현재: 오늘 레슨(5) → 수강권(6) → 이벤트(7,8)

**문제**: 이벤트(레슨 요청, 스케줄 변경)는 "지금 대응 필요"한데 6번째에 위치. 스크롤해야 보임.

**토스 참고**: 토스 홈은 "알림/이벤트 → 잔액(상태) → 최근 거래(일별)" 순서. 대응 필요한 것을 가장 위에.

**네이버 예약 참고**: "대기 중 예약 → 다가오는 예약 → 지난 예약" 순서. 액션 필요한 것 우선.

#### P-2. 학생: 이벤트가 너무 위에, 수강권이 너무 아래

현재: 레슨 요청(4) → 배너(5) → 다음 레슨(7) → 수강권(8)

**문제**: 학생에게 레슨 요청은 드문 이벤트(한 달에 1-2회). 매일 보는 "다음 레슨"과 "수강권 잔여"가 더 중요한데 아래에.

#### P-3. 이벤트와 상태 정보가 시각적으로 구분 안 됨

모든 섹션이 같은 스타일(제목 + 카드)로 표시되어, "지금 액션이 필요한 것"과 "참고 정보"를 한눈에 구분하기 어려움.

---

## Solution (솔루션)

### 정보 우선순위 원칙 (벤치마크 기반)

| 순서 | 원칙 | 참고 |
|:----:|------|------|
| 1 | **긴급 알림** (미수금, 확인 필요) | 토스: 연체 알림 최상단 |
| 2 | **오늘/다음 레슨** (시간 한정) | 네이버 예약: 다가오는 예약 상단 |
| 3 | **이벤트** (대응 필요) | 카카오뱅크: 알림 배너 |
| 4 | **수강권** (장기 상태) | 토스: 계좌 잔액 |
| 5 | **과제/연습** (진행 중) | 하단 보조 |

### 제안: 선생님 홈 재배치

```
AS-IS                          TO-BE
────────────────               ────────────────
1. Header                      1. Header
2. GettingStarted              2. GettingStarted
3. UrgentAlert                 3. UrgentAlert
4. StatsRow                    4. ★ 오늘의 레슨 (시간 한정 → 최상단)
5. 오늘의 레슨                 5. StatsRow
6. 수강권                      6. ★ 이벤트 존 (레슨요청 + 스케줄변경 합침)
7. 레슨 요청                   7. ★ 수강권 현황
8. 스케줄 변경 요청             8. 과제
9. 과제                        9. 통계 링크
10. 통계 링크
```

**변경 포인트:**
- 오늘의 레슨을 StatsRow 위로 (가장 시간 긴급)
- 레슨 요청 + 스케줄 변경을 "이벤트 존"으로 통합 (같은 성격)
- 수강권은 이벤트 아래 (장기 상태)

### 제안: 학생 홈 재배치

```
AS-IS                          TO-BE
────────────────               ────────────────
1. Header + Gamification       1. Header + Gamification
2. GettingStarted              2. GettingStarted
3. 레슨 요청                   3. ★ 다음 레슨 (가장 궁금한 것)
4. 갱신/제안 배너              4. ★ 수강권 요약 (잔여 횟수)
5. 스케줄 확인 카드            5. ★ 이벤트 배너 (제안/갱신/요청)
6. 다음 레슨                   6. 연습 요약
7. 수강권 요약                 7. 선생님 피드백
8. 체험 예약
9. 연습 요약
10. 선생님 피드백
```

**변경 포인트:**
- 다음 레슨을 최상단 (학생이 가장 궁금한 "다음 레슨 언제?")
- 수강권을 다음 레슨 바로 아래 (잔여 횟수 확인)
- 이벤트 배너(갱신/제안/요청)를 하나의 존으로 통합
- 체험 예약은 제거 또는 이벤트 존에 통합 (드문 이벤트)

### 시각적 구분 패턴

| 카테고리 | 시각 스타일 | 참고 |
|----------|-----------|------|
| 긴급 알림 | 빨간/주황 배경 + 아이콘 | 토스: 연체 배너 |
| 오늘/다음 레슨 | 큰 카드 + primary 악센트 | 네이버: 예약 카드 |
| 이벤트 | 컴팩트 리스트 + 빨간 dot | 카카오톡: 읽지 않은 메시지 |
| 수강권 | 티켓 카드 + 프로그레스바 | 토스: 계좌 카드 |
| 과제/연습 | 미니 카드 + 회색 톤 | 하단 보조 정보 |

## 점검 결과

| # | 현재 문제 | 개선안 | 우선순위 |
|---|----------|--------|:--------:|
| 1 | 선생님: 이벤트(레슨요청/변경)가 스크롤 아래에 위치 | 이벤트를 오늘 레슨 바로 아래로 이동 | Must |

| 4 | 학생: 수강권이 8번째에 위치 | 다음 레슨 바로 아래로 이동 | Must |

| 6 | 양쪽: 섹션 간 시각 구분 없음 | 카테고리별 다른 스타일 적용 | Could |
