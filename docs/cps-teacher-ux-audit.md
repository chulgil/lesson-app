# CPS: 선생님 홈 + 수강관리 UX 감사

> 작성일: 2026-04-16
> 버전: 1.0
> 상태: 확정

---

## Context

선생님이 홈 화면과 수강관리 화면을 일상적으로 사용할 때, "3초 안에 현재 상태를 파악하고 필요한 액션을 취할 수 있는가?"를 검증.

### 현재 구현

**선생님 홈**:
- 긴급 알림 5종 동시 표시 (미수금/만료/갱신/확인/예약대기)
- 오늘 레슨 최대 3개
- 레슨 요청/스케줄 변경 각각 별도 섹션
- 과제 요약 하단 배치

**수강관리**:
- 클래스 중심 그룹 (학원/개인)
- 필터 칩 2줄 (수업유형 + 연습상태)
- 연습 점 그래프 (7일 점)
- 같은 학생 2행 표시 가능

---

## Problem

### P-1. 긴급 알림 과부하
5종 동시 표시 → 우선순위 혼란

### P-2. 오늘 레슨 3개 제한
초과 건은 "전체보기"로만 → 4~5개 가르치는 선생님 불편

### P-3. 필터 칩 2줄
공간 차지 큼, 다중 필터 불명확

### P-4. 연습 점 그래프 해석 어려움
점의 의미가 한눈에 안 보임

### P-5. 같은 학생 2행 (학원+개인)
시각적 중복감

---

## Solution

### 결정 (Q&A)

| 질문 | 선택 | 근거 |
|------|:---:|------|
| **Q1. 정보 아키텍처** | A. 클래스 중심 (현재 유지) | 수업 유형 분리 관리 편함, 네이버 예약 패턴 |
| **Q2. 연습 추이 시각화** | B. Mock 데이터 스파크라인 | 추이 정보 유지, 실데이터 전환 용이 |
| **Q3. 긴급 알림 범위** | A. Top 1 + Expandable | 토스 패턴, 인지 부하 감소 |

### 변경 요약

| 영역 | AS-IS | TO-BE |
|------|-------|-------|
| 홈: 긴급 알림 | 5종 동시 | Top 1 + Expandable |
| 홈: 오늘 레슨 | 최대 3개 | 최대 5개 + 전체보기 |
| 수강관리: 필터 | 칩 2줄 (8개) | 세그먼트 1줄 + 필터 바텀시트 |
| 수강관리: 연습 시각화 | 7일 점 | 7일 스파크라인 |
| 수강관리: 복수 과목 학생 | 중복감 | `[2]` 배지 힌트 |

### 제외 (향후 Phase)

- 레슨요청 + 스케줄변경 통합 (큰 리팩토링)
- 시간대 인식 홈 (10x Vision)
- 선택 모드 액션 확장 (일괄 피드백 등)
- StatsRow 과제 완료율 추가 (백엔드 필요)
