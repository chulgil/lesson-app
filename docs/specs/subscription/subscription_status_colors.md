# 수강권 상태별 색상 체계

> 작성일: 2026-01-25
> 상태: ✅ 구현 완료

---

## 개요

수강권의 상태별 시각적 표현 가이드. 브랜드 색상과 UX 원칙에 기반한 설계.

---

## 브랜드 팔레트

| 색상 | 코드 | 용도 |
|------|------|------|
| **Primary (보라)** | #6B5B95 | 브랜드 핵심, 성취 |
| **Success (녹색)** | #2E8B57 | 성공, 활성 |
| **Warning (주황)** | #F4A460 | 주의, 행동 유도 |
| **Tertiary (회색)** | #999999 | 비활성, 만료 |

---

## 상태 정의

| 상태 | 조건 | 의미 |
|------|------|------|
| **이용중** | 잔여 횟수 > 1, 유효기간 > 7일 | 정상 사용 중 |
| **갱신 필요** | 잔여 횟수 = 1 또는 유효기간 ≤ 7일 | 곧 만료 예정 |
| **사용 완료** | 잔여 횟수 = 0 | 모든 레슨 사용 완료 (긍정적) |
| **만료됨** | 유효기간 경과 | 기간 만료 (미사용분 있을 수 있음) |
| **일시정지** | 수동 정지 상태 | 임시 중단 |

## UX 설계 원칙

### 1. 성취 = 브랜드 컬러

"사용 완료"는 목표 달성 → Primary 보라로 긍정 강조

```
❌ 빨강/주황: "문제가 있다"는 부정적 인상
✅ 보라: "완료했다"는 성취감, 브랜드 일관성
```

### 2. 경고 ≠ 실패

"만료 임박"은 행동 유도, "만료됨"은 중립적 표현

```
갱신 필요: 주황 (Warning) - 행동 유도
만료됨: 회색 - 지나간 것, 비난하지 않음
```

### 3. 비활성 = 페이드아웃

만료된 카드는 opacity 낮춰 시각적 우선순위 ↓

```
활성 수강권: 100% opacity
만료 수강권: 70% opacity
→ 현재 사용 가능한 것에 집중 유도
```

### 4. 빨강 미사용 이유

```
❌ 빨강 사용 시 문제:
   - "내가 뭔가 잘못했다"는 부정적 인상
   - 앱에 대한 거부감 증가
   - 음악 앱의 따뜻한 분위기 훼손

✅ 회색 사용 시 장점:
   - "지나간 것"이라는 중립적 표현
   - 현재 활성 수강권에 집중 유도
   - 부담 없이 갱신 고려 가능
```

## 구현 세부사항

### 판정 우선순위

```dart
// 상태 판정 순서 (subscription_card.dart)
if (subscription.isDepleted) {
  // 사용 완료 (보라)
} else if (subscription.isExpired) {
  // 기간 만료 (회색)
} else if (subscription.isExpiringSoon) {
  // 갱신 필요 (주황)
} else if (subscription.status == SubscriptionStatus.paused) {
  // 일시정지 (회색)
} else {
  // 이용중 (녹색)
}
```

### 관련 속성

| 속성 | 타입 | 설명 |
|------|------|------|
| `isDepleted` | bool | 잔여 횟수 ≤ 0 |
| `isExpired` | bool | 유효기간 경과 |
| `isExpiringSoon` | bool | 잔여 1회 또는 D-7 이내 |

### 요약 텍스트 (summaryText)

| 상태 | 텍스트 예시 |
|------|------------|
| 이용중 | "3/4회 남음 (D-25)" |
| 갱신 필요 | "1/4회 남음 (D-3)" |
| 사용 완료 | "4회 모두 사용" |
| 만료됨 (미사용분) | "2회 미사용 (만료됨)" |
