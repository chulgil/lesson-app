## 1. 전체 구조 변경

### 1.1 레슨 요청 → 4단계 마무리

```
레슨 요청 라이프사이클 (변경 없음):
  신청 → 확정 → 결제 → 완료(수강권 발급)

수강권 발급 후 → 별도 "수강권 관리" 화면으로 전환
```

### 1.2 홈 화면 재구성

```
[변경 전]                          [변경 후]
홈:                                홈:
├── 레슨 요청 섹션                  ├── 레슨 요청 섹션 (유지)
├── 수강권 섹션 ← 제거              ├── 스케줄 변경요청 섹션 ← NEW
└── 과제 요약                      └── 과제 요약

수강권 리스트 → 학생 상세 화면의 "수강권 현황"으로 이동
```

### 1.3 네비게이션 플로우

```
선생님 홈
├── 레슨 요청 (N) ─── 탭 → 레슨 요청 상세 (기존)
│
├── 스케줄 변경요청 (N) ─── 탭 → 스케줄 변경 상세 (NEW)
│   └── [전체보기] → 스케줄 변경요청 전체 목록
│
└── 학생 탭 → 학생 상세
    └── 수강권 현황
        └── 수강권 카드 탭 → 스케줄 변경 상세 (동일 화면)
```

### 2.2 회차 프로그레스 바 상세

#### 배치 규칙
- **8개/줄** — 8회차 이하: 1줄, 9~16: 2줄, 17~24: 3줄
- 각 회차는 원형 인디케이터 (지름 32px)
- **[전체]** 버튼: 프로그레스 바 우측 끝

#### 상태별 표시

| 상태 | 아이콘 | 색상 | 탭 가능 |
|------|--------|------|---------|
| 완료 | ✅ | success (green) | ✅ (접힌 챗으로 스크롤) |
| 다음 예정 (자동 선택) | 📅 | primary (blue), 테두리 강조 | ✅ |
| 미래 | ⏳ (숫자만) | grey | ✅ |
| 변경 요청 중 | 🔴 dot | warning (amber dot 오버레이) | ✅ |

#### 자동 선택 규칙
- 화면 진입 시, **현재 일자 기준 다음에 진행할 회차**가 자동 선택
- 자동 선택된 회차의 챗 영역이 펼쳐지고 스크롤 위치 조정

#### [전체] 버튼 동작
```
[전체] 탭 시:
1. 현재~마지막 미완료 회차 전체 선택 (하이라이트)
2. 하단 버튼 라벨: "일정 변경" → "전체 스케줄 변경"
3. 일정 제안 시 말풍선: "전체 회차(4~10) 일정 변경을 제안했습니다"
4. 정규권에서만 활성화 (회차권은 비활성)
```

### 2.3 챗 영역 상세

#### 회차별 접기/펼치기

```
접힌 상태 (과거 완료):
  ── 1회차 · 4/5(토) 14:00 완료 ──     ← 한 줄 요약, 탭하면 펼침

펼쳐진 상태:
  ══ 4회차 · 4/26(토) 14:00 예정 ══    ← 강조 헤더
  │                                     │
  │  [학생 버블]                        │  챗 이벤트들
  │  "시간 변경 요청..."               │
  │                                     │
  │  [선생님 버블]                      │
  │  "가능한 시간..."                  │
  │                                     │
  ══════════════════════════════════     ← 회차 끝 구분선
```

#### 프로그레스 바 ↔ 챗 영역 연동
- 프로그레스 바에서 회차 탭 → 해당 회차 **펼침 + 자동 스크롤**
- 펼쳐진 회차가 있으면 기존 펼침 닫힘 (아코디언 방식)
- 과거 완료 회차도 탭하면 펼침 가능 (읽기 전용, 변경 불가)

#### 첫 회차 수강권 발급 카드

```
[선생님 말풍선 — ProposalChatCard 스타일]
┌─────────────────────────────────┐
│  🎵 수강권이 발급되었습니다       │
│  ─────────────────────────────  │
│  바이올린 정규 10회               │
│  매주 토 14:00 · 60분            │
│  유효기간: 4/1 ~ 6/30            │
│  변경취소권: 2회                  │
│  기준시간: 12시간                 │
└─────────────────────────────────┘
```

### 2.4 하단 입력 바

레슨 요청 상세와 동일한 구조:

```
┌──────────────────────────────────────┐
│  [메시지 입력...]     [일정 변경 📅] │
└──────────────────────────────────────┘
```

- **메시지 입력**: 텍스트 메시지 전송 (챗 이벤트로 기록)
- **일정 변경 버튼**:
  - 학생: 변경 요청 (변경취소권 체크 → 선생님에게 전송)
  - 선생님: AlternativeTimeGrid 열기 → 시간 제안 (최대 3개)

### 2.5 일정 변경 말풍선 구조

#### 학생 → 선생님 (변경 요청)
```
[학생 버블]
"4회차 시간 변경을 요청합니다"
변경취소권 1회 사용 (잔여 1회)
───────────
사유: 개인 일정 변경
```

#### 선생님 → 학생 (시간 제안)
```
[선생님 버블]
"4회차 일정 변경을 제안했습니다"
┌────────────────────────┐
│ 1순위 일 10:00~11:00   │
│ 2순위 월 14:00~15:00   │
│ 3순위 화 10:00~11:00   │
└────────────────────────┘
메시지: "일요일 오전이 가장 여유있습니다"
```

#### 전체 회차 변경 시
```
[선생님 버블]
"전체 회차(4~10) 일정 변경을 제안했습니다"
┌────────────────────────┐
│ 매주 일 10:00~11:00    │  ← 고정 스케줄 1개
└────────────────────────┘
```

#### 학생 수락
```
[학생 버블]
"1순위 일 10:00~11:00을 선택했습니다"

✅ 4회차 → 4/27(일) 10:00 확정
```

## 4. 정규권 vs 회차권 차이

| | 정규권 (monthly) | 회차권 (package) |
|---|---|---|
| 프로그레스 바 | 전체 회차 표시 (예정 시간 포함) | 완료 + 예약 필요 + 미정 |
| [전체] 버튼 | ✅ 활성화 | ❌ 비활성 (회색) |
| 미래 회차 | 자동 생성된 시간 표시 | "예약 필요" 표시 |
| 변경 말풍선 | "4회차" 또는 "전체 회차(4~10)" | "3회차" (개별만) |
| 빈 회차 (예약 필요) | 해당 없음 | 학생이 빈 시간대 선택 UI |

## 7. 데이터 플로우

```
[이벤트 저장]
  학생/선생님 액션 → RequestEvent 생성
    - subscriptionId
    - sessionNumber (또는 null = 전체)
    - eventType (scheduleChangeRequested / Proposed / Accepted / Countered)
    - suggestedSlots (시간 제안 시)
    - message (텍스트 메시지)

[화면 로딩]
  subscriptionSessionEventsProvider(subscriptionId) → 전체 이벤트
  → sessionNumber별 그룹핑 → 회차별 챗 렌더링
```

## 8. 구현 Phase (확정)

| Phase | 내용 |
|-------|------|
| D-1 | 홈 화면 수강권 섹션 → 스케줄 변경요청 섹션 교체 |
| D-2 | 회차 프로그레스 바 위젯 (상태 색상 + [전체] 버튼) |
| D-3 | 수강권 상세 리디자인 (프로그레스 + 챗 + 하단 입력) |
| D-4 | 수강권 발급 카드 말풍선 (ProposalChatCard 스타일) |
| D-5 | 일정 변경 챗 이벤트 (말풍선 구조 + 슬롯 카드) |
| D-6 | 스케줄 변경요청 전체보기 화면 |
| D-7 | 가이드 메시지 + 인포박스 |
