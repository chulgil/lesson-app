# 레슨 취소/변경 시 수강권 처리 정책

> 작성일: 2026-01-25
> 상태: 📋 설계 완료, 구현 대기

---

## 개요

레슨 스케줄 변경, 취소, 미진행 발생 시 수강권(이용횟수) 처리 정책을 정의합니다.

---

## 0. 레슨 완료 확인 방식

### 0.1 기본 플로우

```
레슨 예정 시간 종료
    │
    ├── 선생님이 레슨 노트 작성 → ✅ 자동 완료 처리 (횟수 차감)
    │
    ├── 30분 경과 후 노트 없음 → ⚠️ "레슨 확인" 알림 발송
    │       │
    │       └── 선생님이 확인 버튼 클릭
    │
    └── 24시간 경과 (미확인) → 자동 완료 처리 (횟수 차감)
```

### 0.2 레슨 확인 UI (선생님)

```
┌─────────────────────────────────────────┐
│ 📋 레슨 확인                             │

│                                         │
│  ┌─────────────────────────────────┐   │
│  │ ✅ 레슨 완료                     │   │
│  │    → 횟수 1회 차감               │   │
│  └─────────────────────────────────┘   │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ ❌ 레슨 미진행                   │   │

│  └─────────────────────────────────┘   │
```

### 0.4 처리 결과 요약

| 선택 | 수강권 처리 | 설명 |
|------|------------|------|
| **레슨 완료** | ⚠️ 횟수 1회 차감 | 정상 레슨 완료 |
| **학생 사정으로 불참** | ⚠️ 횟수 1회 차감 | 학생 귀책 (당일 취소, 미출석 등) |
| **선생님 사정으로 취소** | 📅 다른 날짜로 변경 | 선생님 귀책, 횟수 유지 |
| **상호 합의로 취소** | 📅 다른 날짜로 변경 | 사전 협의된 취소/변경 |

## 1. 기본 원칙

| 원칙 | 설명 |
|------|------|
| **선생님 시간 보호** | 선생님이 시간을 확보한 경우, 학생 사유 취소는 횟수 차감 |

| **명확한 기록** | 모든 취소/변경 이력을 SubscriptionUsage에 기록 |

## 2. 취소 유형 및 처리

### 2.1 취소 주체별 정책

| 취소 주체 | 사전 취소 (24h+) | 당일 취소 (24h 이내) | 미출석 |
|----------|:---------------:|:------------------:|:----:|
| **학생** | ✅ 횟수 유지 | ⚠️ 횟수 차감 | ❌ 횟수 차감 |
| **선생님** | 📅 날짜 변경 | 📅 날짜 변경 | - |
| **상호 합의** | 📅 날짜 변경 | 📅 날짜 변경 | - |

### 2.2 상세 시나리오

#### 학생 취소

## 3. 수강권 타입별 차이

### 3.1 월정액 (Monthly)

| 상황 | 처리 |
|------|------|
| 사전 취소/변경 | 같은 달 내 날짜 변경 가능 |
| 당일 취소/미출석 | 횟수 차감, 복구 불가 |
| 선생님 취소 | 같은 달 내 다른 날짜로 변경 |
| 월말 취소 | 다음 달 초로 변경 가능 (예외) |

### 3.2 회차권 (Package)

| 상황 | 처리 |
|------|------|
| 사전 취소/변경 | 유효기간 내 자유롭게 날짜 변경 |
| 당일 취소/미출석 | 횟수 차감 |
| 선생님 취소 | 유효기간 내 다른 날짜로 변경 |

## 5. 레슨 상태 확장

### 5.1 LessonStatus 값

```dart
enum LessonStatus {
  // 기본 상태
  scheduled,                    // 예약됨
  completed,                    // 완료 (횟수 차감)

  // 취소/변경 상태
  cancelledByStudentAdvance,    // 학생 사전 취소 (24h+, 날짜 변경)
  cancelledByStudentLate,       // 학생 당일 취소 (횟수 차감)
  cancelledByTeacher,           // 선생님 취소 (날짜 변경)
  cancelledMutual,              // 상호 합의 취소 (날짜 변경)
  studentAbsent,                // 미출석 (횟수 차감)

  // 변경 진행 중
  reschedulePending,            // 일정 변경 요청 중 (학생 확인 대기)
}
```

### 5.2 레슨 변경 이력

```dart
@HiveType(typeId: 64)
@JsonSerializable()
class LessonReschedule {
  final String lessonId;
  final DateTime originalDate;       // 원래 날짜
  final DateTime newDate;            // 변경된 날짜
  final String reason;               // 변경 사유
  final String requestedBy;          // 요청자 (teacherId 또는 studentId)
  final DateTime requestedAt;        // 요청 시간
  final bool approved;               // 승인 여부
}
```

## 6. SubscriptionUsage 확장

### 6.1 UsageType

```dart
enum UsageType {
  normal,           // 정상 레슨 (차감)
  lateCancellation, // 당일 취소 (차감)
  studentAbsent,    // 미출석 (차감)
  rescheduled,      // 일정 변경됨 (차감 안 함)
}
```

### 6.2 SubscriptionUsage 수정

```dart
@HiveType(typeId: 63)
@JsonSerializable()
class SubscriptionUsage extends HiveObject {
  // 기존 필드...

  @HiveField(8)
  final UsageType usageType;  // 🆕 사용 유형

  @HiveField(9)
  final bool deducted;        // 🆕 횟수 차감 여부
}
```
