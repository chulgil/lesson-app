# 레슨 취소/변경 시 수강권 처리 정책

> 작성일: 2026-01-25
> 상태: 📋 설계 완료, 구현 대기

---

## 개요

레슨 스케줄 변경, 취소, 미진행 발생 시 수강권(이용횟수) 처리 정책을 정의합니다.

---

## 0. 레슨 완료 확인 방식

### 0.1 기본 플로우

```
레슨 예정 시간 종료
    │
    ├── 선생님이 레슨 노트 작성 → ✅ 자동 완료 처리 (횟수 차감)
    │
    ├── 30분 경과 후 노트 없음 → ⚠️ "레슨 확인" 알림 발송
    │       │
    │       └── 선생님이 확인 버튼 클릭
    │
    └── 24시간 경과 (미확인) → 자동 완료 처리 (횟수 차감)
```

### 0.4 처리 결과 요약

| 선택 | 수강권 처리 | 설명 |
|------|------------|------|
| **레슨 완료** | ⚠️ 횟수 1회 차감 | 정상 레슨 완료 |
| **학생 사정으로 불참** | ⚠️ 횟수 1회 차감 | 학생 귀책 (당일 취소, 미출석 등) |
| **선생님 사정으로 취소** | 🔄 보강 1회 생성 | 선생님 귀책, 횟수 유지 |
| **상호 합의로 취소** | ✅ 횟수 유지 | 사전 협의된 취소/변경 |

## 2. 취소 유형 및 처리

### 2.1 취소 주체별 정책

| 취소 주체 | 사전 취소 (24h+) | 당일 취소 (24h 이내) | 미출석 |
|----------|:---------------:|:------------------:|:----:|
| **학생** | ✅ 횟수 유지 | ⚠️ 횟수 차감 | ❌ 횟수 차감 |
| **선생님** | ✅ 횟수 유지 + 보강 | ✅ 횟수 유지 + 보강 | - |
| **상호 합의** | ✅ 횟수 유지 | ✅ 횟수 유지 | - |

## 3. 수강권 타입별 차이

### 3.1 월정액 (Monthly)

| 상황 | 처리 |
|------|------|
| 사전 취소 | 같은 달 내 변경 가능, 다음 달 이월 불가 |
| 당일 취소/미출석 | 횟수 차감, 복구 불가 |
| 선생님 취소 | 보강 생성, 같은 달 내 사용 권장 |
| 월말 취소 | 다음 달로 보강 이월 가능 (예외) |

### 3.2 회차권 (Package)

| 상황 | 처리 |
|------|------|
| 사전 취소 | 유효기간 내 자유롭게 변경 |
| 당일 취소/미출석 | 횟수 차감 |
| 선생님 취소 | 보강 생성, 유효기간 내 사용 |
| 유효기간 임박 | 보강은 유효기간 자동 연장 (해당 보강분만) |

## 4. 보강 레슨 (MakeupLesson)

### 4.1 보강 생성 조건

| 조건 | 보강 생성 |
|------|:--------:|
| 선생님 취소 | ✅ 자동 생성 |
| 천재지변/긴급상황 | ✅ 선생님 재량 |
| 학생 당일 취소 | ❌ 생성 안 함 |
| 학생 미출석 | ❌ 생성 안 함 |

### 4.2 보강 엔티티

```dart
@HiveType(typeId: 64)
@JsonSerializable()
class MakeupLesson extends HiveObject {
  @HiveField(0)
  final String id;

  @HiveField(1)
  final String subscriptionId;       // 원본 수강권

  @HiveField(2)
  final String originalLessonId;     // 취소된 원본 레슨

  @HiveField(3)
  final String? scheduledLessonId;   // 예약된 보강 레슨 (null이면 미예약)

  @HiveField(4)
  final DateTime createdAt;          // 보강 생성일

  @HiveField(5)
  final DateTime expiresAt;          // 보강 유효기간 (생성일 + 30일)

  @HiveField(6)
  final MakeupStatus status;         // pending, scheduled, completed, expired

  @HiveField(7)
  final String reason;               // 보강 사유 (선생님 취소, 긴급상황 등)
}

enum MakeupStatus {
  pending,    // 일정 미정
  scheduled,  // 일정 확정
  completed,  // 보강 완료
  expired,    // 유효기간 만료
}
```

## 5. 레슨 상태 확장

### 5.1 LessonStatus 추가 값

```dart
enum LessonStatus {
  // 기존
  scheduled,          // 예약됨
  completed,          // 완료
  cancelled,          // 취소됨 (기존 - deprecated)

  // 🆕 상세 취소 상태
  cancelledByStudentAdvance,  // 학생 사전 취소 (24h+)
  cancelledByStudentLate,     // 학생 당일 취소 (24h 이내)
  cancelledByTeacher,         // 선생님 취소
  cancelledMutual,            // 상호 합의 취소
  studentAbsent,                     // 미출석

  // 보강
  makeup,                     // 보강 레슨
}
```

### 5.2 취소 사유 기록

```dart
@HiveType(typeId: 65)
@JsonSerializable()
class LessonCancellation {
  final String lessonId;
  final LessonStatus cancelType;
  final String? reason;              // 취소 사유 (선택)
  final DateTime cancelledAt;
  final String cancelledBy;          // 취소 주체 (studentId 또는 teacherId)
  final bool subscriptionDeducted;   // 수강권 차감 여부
}
```

## 8. 선생님 설정

### 8.1 취소 정책 설정

```dart
@HiveType(typeId: 66)
class CancellationPolicy {
  final int advanceCancelHours;      // 사전 취소 기준 (기본: 24시간)
```
