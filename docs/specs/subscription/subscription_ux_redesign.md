# 수강권 발급 UX 재설계 스펙

> 작성일: 2026-03-30
> 상태: APPROVED
> 버전: v1.0

## Context — 현재 문제점

### 현재 화면 구조 (3개 분리)
```
1. ProposalCreateScreen   — 템플릿 선택 → 제안 (학생 1명씩)
2. IssueSubscriptionScreen — 10+필드 폼 → 즉시 발급 (템플릿 미연동)
3. 학생측 수락 화면         — 존재하지 않음 (bottom sheet만 부분 구현)
```

### 핵심 문제 5가지
| # | 문제 | 상세 |
|---|------|------|
| 1 | **발급 화면이 너무 복잡** | 10+ 필드 폼 (타입, 회차, 유효기간, 금액, 할인, 보너스, 시작일, 변경횟수, 결제, 장소) |
| 2 | **템플릿 ↔ 발급 단절** | IssueScreen은 템플릿을 불러오지 않음. 매번 수동 입력 |
| 3 | **스마트 입력 없음** | 숫자 입력만 존재. 태그 제안, 자동완성 없음 |
| 4 | **학생 복수선택 UI 없음** | 배치 모드는 있으나 진입점(학생 목록에서 선택)이 없음 |
| 5 | **학생 수락 화면 미구현** | 3가지 선택지를 학생이 보는 전용 화면 없음 |

---

## 재설계 원칙

> **"한 화면, 스마트 기본값, 점진적 노출"**

1. **Template-First**: 템플릿이 있으면 탭 한 번으로 발급. 폼은 예외적 편집용
2. **Progressive Disclosure**: 초기에는 최소 정보만 노출. 세부 설정은 "수정" 탭 시 펼침
3. **Smart Chips**: 숫자 입력 대신 태그 칩으로 빠른 선택 (4회/8회/12회)
4. **Context-Aware Defaults**: 학생 월례비, 이전 수강권, 템플릿에서 자동 추론
5. **Unified Flow**: 제안과 발급을 하나의 플로우로 통합

## 신규 화면 설계

### 화면 A: 통합 수강권 발급 (`UnifiedSubscriptionSheet`)

> 기존 ProposalCreateScreen + IssueSubscriptionScreen을 **바텀시트**로 통합

```
+-------------------------------------------+
|  x                수강권 발급              |
+-------------------------------------------+
|                                           |
|  [학생] 김소연 . 바이올린                  |  <- 학생 1명 (또는 "3명 선택됨")
|  ---------------------------------------- |
|                                           |
|  [템플릿 선택]                             |
|  +----------+ +----------+ +----------+   |
|  | 4회권     | |*8회권    | | 12회권    |   |  <- 가로 스크롤 카드
|  | 20만원    | | 38만원   | | 54만원    |   |     * = 추천 뱃지
|  | 60일      | | 90일     | | 120일     |   |
|  +----------+ +----------+ +----------+   |
|                                           |
|  -- 또는 직접 입력 ----------------------- |  <- 접힘 상태 (탭하면 펼침)
|                                           |
|  +-------------------------------------+  |
|  |  [바로 발급]     [제안 보내기]        |  |  <- 2개 버튼
|  +-------------------------------------+  |
+-------------------------------------------+
```

**동작 규칙:**
- 템플릿 탭 -> 즉시 선택 (파란 테두리)
- 선택 카드 위 "수정" 아이콘 -> 인라인 편집 (금액, 회차만)
- "직접 입력" 탭 -> 아래 폼 펼침 (스마트 칩 방식)
- "바로 발급" -> 즉시 Subscription 생성
- "제안 보내기" -> 최대 3개 선택 후 Proposal 생성

### 화면 A-1: 직접 입력 폼 (펼침 시)

```
+-------------------------------------------+
|  -- 직접 입력 ------------------ [접기]    |
|                                           |
|  회차  [ 4 ] [ 8 ] [12 ] [  직접입력  ]   |  <- 칩 태그 (탭으로 선택)
|                                           |
|  금액  [     380,000원                ]   |  <- 입력 포커스 시 추천 태그 표시
|        [20만] [32만] [38만] [54만]         |  <- 이전 이력 + 템플릿 기반 추천
|                                           |
|  유효기간  자동: 90일                      |  <- 회차 기반 자동 계산, 변경 가능
|            [ 60일 ] [ 90일 ] [120일]       |
|                                           |
|  [+ 할인/보너스 설정]                      |  <- 접힌 상태, 탭 시 펼침
|                                           |
+-------------------------------------------+
```

**스마트 칩 패턴:**
- 입력 필드 포커스 시 -> 관련 태그 칩이 아래에 나타남
- 칩 탭 -> 값 자동 입력 + 포커스 해제
- 직접 타이핑도 가능
- 포커스 해제 시 -> 칩 사라짐 (깔끔)

### 화면 A-2: 제안 모드 (최대 3개 선택)

```
+-------------------------------------------+
|  x          수강권 제안 (2/3)              |
+-------------------------------------------+
|                                           |
|  학생에게 보낼 선택지를 고르세요             |
|                                           |
|  [v] 4회권  20만원  60일                   |  <- 체크 표시
|  [v] 8회권  38만원  90일  [추천]           |  <- 롱프레스로 추천 설정
|  [ ] 12회권 54만원 120일                   |
|                                           |
|  한줄 메시지 (선택)                        |
|  [  초보자 특가 할인 적용했어요!       ]    |
|                                           |
|  +-------------------------------------+  |
|  |         [제안 보내기]                 |  |
|  +-------------------------------------+  |
+-------------------------------------------+
```

### 화면 B: 학생 수강권 수락 (`StudentProposalAcceptScreen`)

> 학생 전용 전체 화면. 푸시 알림 탭 시 진입.

```
+-------------------------------------------+
|            박미연 선생님                    |
|         수강권을 제안했어요                  |
+-------------------------------------------+
|                                           |
|  "초보자 특가 할인 적용했어요!"             |  <- 선생님 메시지
|                                           |
|  +-------------------------------------+  |
|  |  4회권                               |  |
|  |  200,000원 . 유효 60일                |  |
|  |  주 1회 기준 약 1.5개월                |  |
|  |                    [선택하기]          |  |
|  +-------------------------------------+  |
|                                           |
|  +=====================================+  |
|  | [추천]  8회권                         |  |  <- 추천 뱃지 + 하이라이트 테두리
|  |  380,000원 . 유효 90일                |  |
|  |  주 1회 기준 약 2개월                  |  |
|  |  회당 47,500원 (가장 경제적)           |  |  <- 회당 단가 표시
|  |                    [선택하기]          |  |
|  +=====================================+  |
|                                           |
|  +-------------------------------------+  |
|  |  12회권                              |  |
|  |  540,000원 . 유효 120일               |  |
|  |  주 1회 기준 약 3개월                  |  |
|  |                    [선택하기]          |  |
|  +-------------------------------------+  |
|                                           |
|  [다음에 할게요]                           |  <- 하단 텍스트 버튼
|                                           |
|  -- 결제 안내 ---------------------------  |
|  [복사] 국민은행 123-456-789 (박미연)      |  <- 계좌 복사 버튼
|  선택 후 위 계좌로 입금해 주세요            |
|                                           |
+-------------------------------------------+
```

**학생 UX 포인트:**
- 추천 카드 시각적 강조 (두꺼운 테두리 + [추천] 뱃지)
- 회당 단가 자동 계산 -> 가격 비교 용이
- "주 N회 기준 약 N개월" -> 기간 감각 제공
- 계좌정보 항상 하단 노출 (복사 버튼)
- 선택 즉시 -> "입금 완료했어요" 버튼 노출

### 화면 C: 학생 목록 복수 선택 모드

> 기존 학생 리스트에 "선택" 모드 추가

```
학생 리스트 AppBar: [선택] 버튼 추가
  -> 탭 시 체크박스 모드 활성화
  -> 1명 이상 선택 시 하단 바: "N명에게 수강권 발급"
  -> 탭 -> UnifiedSubscriptionSheet 진입 (배치 모드)
```

## 구현 Phase

### Phase 1: UnifiedSubscriptionSheet (바텀시트 통합)
- 기존 2개 화면을 1개 바텀시트로 통합
- 템플릿 카드 가로 스크롤 + 선택
- "바로 발급" / "제안 보내기" 분기
- 파일: `features/subscription/presentation/widgets/unified_subscription_sheet.dart`

### Phase 2: 스마트 칩 입력 위젯
- ChipInputField 공통 위젯 (포커스 시 칩 표시, 블러 시 숨김)
- 회차/금액/유효기간 각각의 추천 칩 데이터
- 파일: `core/widgets/chip_input_field.dart`

### Phase 3: StudentProposalAcceptScreen
- 학생 전용 전체 화면 (제안 수락)
- 회당 단가 계산, 추천 하이라이트
- 계좌 복사, 결제 알림 플로우
- 파일: `features/subscription/presentation/screens/student_proposal_accept_screen.dart`

### Phase 4: 학생 목록 복수 선택
- StudentsPage에 선택 모드 추가
- 선택 후 -> UnifiedSubscriptionSheet 연결
- 라우팅 파라미터로 studentIds 전달
