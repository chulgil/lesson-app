## 1. 개요

### 1.1 배경

정기레슨 시작 전, 선생님이 학생에게 수강권을 제안하고 결제를 받은 후 수강권을 발급하는 플로우가 필요합니다.

### 1.2 기존 문제점

| 문제 | 설명 |
|------|------|
| 복잡한 제안 플로우 | 시간 3개 제안 → 선택 → 승인 (왕복 3회) |
| 결제 시점 불명확 | 시간 먼저 잡고 결제? 결제 먼저? |
| 반복 작업 | 선생님이 매번 금액/회차 설정 |

### 1.3 해결책: 수강권 템플릿 + 리드 관리 시스템

```
[핵심 아이디어]
1. 선생님이 수강권 템플릿을 미리 만들어둠 (1회성)
2. 템플릿이 선생님 프로필에 메뉴판처럼 공개 표시
3. 체험레슨 완료 시 → 앱이 자동으로 리드 생성 + 골든타임 할인 제안
4. 24h/48h/72h 자동 리마인더 발송 (앱이 선생님 대신)
5. 학생이 입금 후 알림 → 선생님이 확인 → 수강권 발급
6. 선생님 대시보드에서 리드 현황 한눈에 파악
```

### 1.4 v2 추가 기능

| 기능 | 설명 | 효과 |
|------|------|------|
| **리드 관리** | 체험 후 전환되지 않은 학생 추적 | 학생 이탈 방지 |
| **골든타임 전환** | 체험 직후 24시간 한정 할인 | 전환율 70%↑ |
| **자동 리마인더** | 앱이 선생님 대신 알림 발송 | 선생님 부담↓ |
| **대시보드** | 리드 상태 한눈에 파악 | 관리 효율↑ |

## 2. 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **수강권 우선** | 수강권이 있어야만 레슨 예약 가능 |
| **템플릿 재사용** | 선생님은 한 번 설정, 무한 재사용 |
| **메뉴판 공개** | 템플릿이 프로필에 공개되어 학생이 미리 확인 가능 |
| **앱 대리 알림** | 선생님이 트리거, 앱이 대신 알림 발송 (선생님 부담↓) |
| **단일 예약 화면** | 예약은 LessonBookingScreen 하나로 통일 |
| **자연스러운 순서** | 결제 → 수강권 발급 → 시간 예약 |
| **최소 클릭** | 선생님 제안: 2~3클릭, 학생 수락: 2클릭 |

### 2.1 학원 vs 개인 선생님 구분

| 유형 | 가격 설정 | 템플릿 소유 |
|------|----------|------------|
| **학원 소속** | 학원이 설정한 가격 사용 | 학원 템플릿 상속 |
| **개인 선생님** | 선생님 본인이 설정 | 본인 템플릿 관리 |

```
학원 소속 선생님:
├── 학원 관리자가 수강권 템플릿 설정
├── 소속 선생님들이 학원 템플릿 사용
└── 학원 계좌로 입금 안내

개인 선생님:
├── 본인이 직접 수강권 템플릿 설정
├── 본인 계좌로 입금 안내
└── 자유롭게 가격 조정 가능
```

### 3.3 시나리오별 분기

| 시나리오 | 수강권 상태 | 플로우 |
|----------|------------|--------|
| **신규 학생** | 없음 | 프로필 메뉴판 확인 → 체험레슨 → 리드 생성 |
| **체험레슨 후** | 없음 | 골든타임 제안 → (자동 리마인더) → 입금 → 발급 → 예약 |
| **수강권 만료** | 만료됨 | 갱신 제안 → 입금 → 발급 → 예약 |
| **수강권 보유** | 유효 | 바로 예약 (LessonBookingScreen) |
| **수강권 소진 임박** | 1~2회 남음 | 선생님이 갱신 제안 |

## 4. 수강권 템플릿

### 4.1 개념

선생님이 자주 사용하는 수강권 구성을 미리 저장해두고 재사용합니다.

### 4.2 템플릿 예시

| 템플릿명 | 횟수 | 금액 | 시간 | 유효기간 | 변경 |
|----------|:----:|-----:|:----:|:--------:|:----:|
| 바이올린 8회권 | 8회 | 380,000원 | 60분 | 2개월 | 2회 |
| 바이올린 4회권 | 4회 | 200,000원 | 60분 | 1개월 | 1회 |
| 체험레슨 | 1회 | 30,000원 | 45분 | 2주 | 0회 |
| 첼로 8회권 | 8회 | 400,000원 | 60분 | 2개월 | 2회 |

### 4.3 템플릿 필드

| 필드 | 필수 | 설명 | 예시 |
|------|:----:|------|------|
| name | ✅ | 템플릿 이름 | "바이올린 8회권" |
| instrument | ✅ | 악기 | "바이올린" |
| totalLessons | ✅ | 총 횟수 | 8 |
| amount | ✅ | 금액 (원) | 380000 |
| lessonDuration | ✅ | 레슨 시간 (분) | 60 |
| validityDays | ✅ | 유효 기간 (일) | 60 |
| rescheduleLimit | ✅ | 변경 가능 횟수 | 2 |
| description | ❌ | 설명 | "주 1회 권장" |
| isActive | ✅ | 활성화 여부 | true |

### 4.4 기본 템플릿 제공

선생님 가입 시 기본 템플릿 3개 자동 생성:

```dart
// 기본 템플릿 (선생님이 수정 가능)
- 체험레슨: 1회, 30,000원, 45분
- 4회권: 4회, 200,000원, 60분, 1개월
- 8회권: 8회, 380,000원, 60분, 2개월
```

## 5. 리드 관리 시스템

### 5.1 개요

체험레슨을 완료했지만 정규레슨으로 전환하지 않은 잠재 학생을 추적합니다.

### 5.2 리드 상태

| 상태 | 조건 | 설명 | 색상 |
|------|------|------|:----:|
| `hot` | 체험 후 24시간 이내 | 전환 가능성 높음, 즉시 접근 필요 | 🔴 |
| `warm` | 체험 후 24~72시간 | 관심은 있으나 고민 중 | 🟠 |
| `cold` | 체험 후 72시간 이상 | 관심 식어감, 적극적 접근 필요 | ⚪ |
| `converted` | 정규레슨 시작 | 전환 완료 | 🟢 |
| `lost` | 거절 또는 7일 초과 무응답 | 이탈 | ⚫ |

### 5.3 리드 상태 전이

```
체험레슨 완료
      │
      ▼
┌─────────────┐
│    hot      │ ← 0~24시간
│    🔴       │
└──────┬──────┘
       │
       │ 24시간 경과
       ▼
┌─────────────┐
│    warm     │ ← 24~72시간
│    🟠       │
└──────┬──────┘
       │
       │ 72시간 경과
       ▼
┌─────────────┐
│    cold     │ ← 72시간+
│    ⚪       │
└──────┬──────┘
       │
       │ 7일 경과 (무응답)
       ▼
┌─────────────┐
│    lost     │
│    ⚫       │
└─────────────┘

[어느 단계에서든]
       │
       │ 입금 완료
       ▼
┌─────────────┐
│  converted  │
│    🟢       │
└─────────────┘
```

| **적시 개입** | hot 상태에서 선생님 개인 메시지 권장 |

## 6. 골든타임 전환

### 6.1 개요

체험레슨 직후가 전환 가능성이 가장 높은 "골든타임"입니다.
24시간 한정 할인을 제공하여 즉시 전환을 유도합니다.

### 6.2 골든타임 할인 정책

| 항목 | 값 | 설정 |
|------|-----|------|
| 기본 할인율 | 10% | 선생님 설정 가능 (0~20%) |
| 유효 시간 | 24시간 | 체험 완료 시점 기준 |
| 적용 대상 | 첫 수강권 | 체험레슨 제외 |

### 6.3 골든타임 UI - 체험 완료 직후 (학생)

```
┌─────────────────────────────────────┐
│                                     │
│            🎉                       │
```

## 7. 자동 리마인더

### 7.1 개요

체험 후 "다음에 할게요"를 선택한 학생에게 앱이 자동으로 리마인더를 발송합니다.

### 7.2 리마인더 스케줄

| 단계 | 발송 시점 | 리드 상태 | 메시지 톤 |
|:----:|----------|:--------:|----------|
| 1 | 24시간 후 | hot → warm | 부드러운 리마인드 |
| 2 | 48시간 후 | warm | 혜택 강조 |
| 3 | 72시간 후 | warm → cold | 마감 임박 긴급성 |
| 4 | 7일 후 | cold | 마지막 기회 |

## 8. 수강권 제안 플로우

### 8.1 제안 생성 (선생님)

**진입점:**
- 학생 상세 화면 → [수강권 제안] 버튼
- 학생 목록 → 학생 길게 누르기 → "수강권 제안"
- 체험레슨 완료 후 → "정규레슨 제안하기" 안내

**제안 과정:**
1. 템플릿 선택 (라디오 버튼)
2. 메시지 입력 (선택사항)
3. [제안 보내기] 클릭

### 8.2 제안 상태

| 상태 | 설명 | 다음 액션 |
|------|------|----------|
| `pending` | 제안됨, 학생 확인 대기 | 학생: 입금 후 알림 or 거절 |
| `paymentNotified` | 학생이 입금 완료 알림 | 선생님: 입금 확인 |
| `confirmed` | 입금 확인, 수강권 발급됨 | 학생: 레슨 예약 |
| `rejected` | 학생이 거절 | 종료 |
| `expired` | 7일 경과 자동 만료 | 재제안 가능 |
| `cancelled` | 선생님이 취소 | 재제안 가능 |

### 8.3 상태 전이

```
            ┌──────────────────┐
            │     pending      │
            └────────┬─────────┘
                     │
      ┌──────────────┼──────────────┬────────────┐
      │              │              │            │
      ▼              ▼              ▼            ▼
┌──────────┐  ┌────────────┐  ┌─────────┐  ┌─────────┐
│ rejected │  │paymentNoti │  │ expired │  │cancelled│
│ (학생거절)│  │   fied     │  │(7일경과)│  │(선생취소)│
└──────────┘  └─────┬──────┘  └─────────┘  └─────────┘
                    │
         ┌──────────┴──────────┐
         │                     │
         ▼                     ▼
   ┌───────────┐        ┌───────────┐
   │ confirmed │        │ 입금미확인 │
   │(수강권발급)│        │  (문의)    │
   └───────────┘        └───────────┘
```

### 8.4 입금 확인 프로세스

**학생 측:**
1. 제안 상세에서 계좌 정보 확인
2. 외부 앱(뱅킹)으로 입금
3. 앱으로 돌아와 [입금 완료했어요] 클릭

**선생님 측:**
1. 입금 알림 수신
2. 실제 입금 확인 (뱅킹 앱 확인)
3. [입금 확인 완료] 클릭 → 수강권 자동 발급

**입금 미확인 시:**
- [입금 미확인] 버튼 → 학생에게 메시지 전송
- "입금 내역을 확인할 수 없습니다. 확인 부탁드립니다."

### 11.3 StudentLead (학생 리드)

```dart
@HiveType(typeId: 83)
enum LeadStatus {
  @HiveField(0)
  hot,        // 체험 후 24시간 이내

  @HiveField(1)
  warm,       // 체험 후 24~72시간

  @HiveField(2)
  cold,       // 체험 후 72시간 이상

  @HiveField(3)
  converted,  // 전환 완료 (정규레슨 시작)

  @HiveField(4)
  lost,       // 포기/거절
}

@HiveType(typeId: 84)
@JsonSerializable()
class StudentLead {
  @HiveField(0)
  final String id;

  @HiveField(1)
  final String teacherId;

  @HiveField(2)
  final String studentId;

  @HiveField(3)
  final String? trialLessonId;      // 체험레슨 ID (있는 경우)

  @HiveField(4)
  final LeadStatus status;

  @HiveField(5)
  final DateTime createdAt;         // 리드 생성 시점 (체험 완료 시점)

  @HiveField(6)
  final DateTime? convertedAt;      // 전환 시점

  @HiveField(7)
  final DateTime? lostAt;           // 포기/이탈 시점

  @HiveField(8)
  final int remindersSent;          // 발송된 리마인더 수

  @HiveField(9)
  final DateTime? lastReminderAt;   // 마지막 리마인더 발송 시점

  @HiveField(10)
  final bool discountOffered;       // 골든타임 할인 제안 여부

  @HiveField(11)
  final int? discountPercent;       // 제안된 할인율 (%)

  @HiveField(12)
  final DateTime? discountExpiresAt; // 할인 만료 시점

  @HiveField(13)
  final String? trialFeedback;      // 체험 후 학생 피드백 (선택)

  @HiveField(14)
  final String? lostReason;         // 이탈 사유 (선택)

  const StudentLead({
    required this.id,
    required this.teacherId,
    required this.studentId,
    this.trialLessonId,
    this.status = LeadStatus.hot,
    required this.createdAt,
    this.convertedAt,
    this.lostAt,
    this.remindersSent = 0,
    this.lastReminderAt,
    this.discountOffered = false,
    this.discountPercent,
    this.discountExpiresAt,
    this.trialFeedback,
    this.lostReason,
  });

  /// 현재 리드 상태 계산 (시간 기반)
  LeadStatus get currentStatus {
    if (status == LeadStatus.converted || status == LeadStatus.lost) {
      return status;
    }

    final hoursSinceCreation = DateTime.now().difference(createdAt).inHours;

    if (hoursSinceCreation < 24) {
      return LeadStatus.hot;
    } else if (hoursSinceCreation < 72) {
      return LeadStatus.warm;
    } else {
      return LeadStatus.cold;
    }
  }

  /// 할인 유효 여부
  bool get isDiscountValid {
    if (!discountOffered || discountExpiresAt == null) return false;
    return DateTime.now().isBefore(discountExpiresAt!);
  }

  /// 할인 남은 시간 (초 단위)
  int get discountRemainingSeconds {
    if (!isDiscountValid) return 0;
    return discountExpiresAt!.difference(DateTime.now()).inSeconds;
  }
}
```
