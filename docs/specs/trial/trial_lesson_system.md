## 개요

체험 레슨은 새로운 학생이 선생님과의 첫 레슨을 경험해보는 시스템입니다.
본 문서는 선생님과 학생 각각의 관점에서 체험 레슨 시스템을 정리합니다.

## 핵심 개념

### 체험 레슨이란?

| 항목 | 내용 |
|------|------|
| 정의 | 1회성 레슨으로 선생님과 학생이 서로를 알아가는 시간 |
| 목적 | 정규 레슨 전 레슨 스타일 맞춤 확인 |
| 비용 | 30,000원 (기본) |
| 시간 | 불특정 시간, 선생님이 시간을 내서 진행 |

### 역할별 목표

| 역할 | 목표 |
|------|------|
| **선생님** | 새 학생 확보, 레슨 스타일 소개, 정규 레슨 전환 |
| **학생** | 선생님 수업 방식 경험, 악기/레슨 적합성 확인 |

## 👩‍🏫 선생님 관점

### 1. 체험 레슨 준비

#### 가용 시간 등록
> 📍 프로필 > 레슨 시간 설정

| 설정 항목 | 설명 | 필수 |
|----------|------|------|
| 요일별 가용 시간 | 월~일, 시작~종료 시간 | ⭕ |
| 체험 레슨 가능 여부 | ON/OFF 토글 | ⭕ |
| 체험 레슨 금액 | 기본 30,000원 (커스텀 가능) | ⭕ |

#### ✅ 가용 시간 관리 시스템

> 상세 스펙: [가용시간 관리 시스템](#가용시간-관리-시스템-상세) 섹션 참조

**3계층 구조:**
```
Layer 1: 주간 템플릿 (기본 스케줄)
    ↓
Layer 2: 예외 (오버라이드)
    ↓
Layer 3: 구글 캘린더 연동 (수동 블로킹)
```

| 계층 | 역할 | 예시 |
|------|------|------|
| 주간 템플릿 | 기본 가용 시간 설정 | 월~금 14:00-20:00 |
| 예외 | 특정 날짜/시간 오버라이드 | 12/25 휴무, 매주 수요일 불가 |
| 구글 연동 | 외부 일정 확인 후 블로킹 | 병원 예약 → 해당 시간 블로킹 |

### 2. 신청 수신 및 관리

#### 신청 알림
> 참조: [레슨 스케줄 시스템 - 예약 상태](./lesson_schedule.md#예약-상태)

| 알림 경로 | 내용 | 구현 상태 |
|----------|------|----------|
| 앱 푸시 알림 | "새로운 체험레슨 신청" | 🔴 미구현 |
| 앱 내 알림 | 알림 센터에 표시 | 🔴 미구현 |
| 이메일 | 신청 상세 정보 | 🔴 미구현 |

#### 승인 대기 화면
> 📍 홈 > 승인 대기 (또는 캘린더에서 진입)

```
┌─────────────────────────────────────┐
│  📋 승인 대기                        │
├─────────────────────────────────────┤
│  홍길동 (1년 미만, 취미)             │
│  12/28(토) 14:00 - 15:00            │
│  "바이올린 처음 배우고 싶어요"        │
│                                      │
│     [승인]        [일정 조율]        │
└─────────────────────────────────────┘
```

| 표시 정보 | 설명 |
|----------|------|
| 학생명 | 신청자 이름 |
| 경험/목표 | 악기 경험 + 레슨 목표 |
| 희망 일시 | 학생이 선택한 시간 |
| 메시지 | 학생이 전달한 메시지 (선택) |

### 3. 신청 처리

#### 승인 플로우
```
[승인] 클릭 → 확인 다이얼로그 → 학생에게 알림 전송 → 캘린더에 레슨 표시
```

#### 일정 조율 플로우 (구 거절)
> ⚠️ "거절"이 아닌 "일정 조율"로 부드럽게 표현

```
[일정 조율] 클릭 → 사유 선택 → (선택) 대안 시간 제안 → 학생에게 안내
```

| 사유 옵션 | 학생에게 표시되는 메시지 |
|----------|------------------------|
| 해당 시간 마감 | "요청하신 시간이 마감되었어요" |
| 일정 조율 필요 | "해당 시간 조율이 필요해요" |
| 잠시 레슨 쉬는 중 | "선생님이 잠시 쉬고 계세요" |

**대안 시간 제안 (선택)**
- 선생님의 가용 시간 중 선택
- 직접 시간 추가 (날짜/시간 직접 입력)
- 최대 3개까지 제안 가능

### 4. 체험 레슨 진행

#### 레슨 당일
| 항목 | 내용 |
|------|------|
| 레슨 시작 | 캘린더에서 레슨 카드 탭 → 레슨 시작 |
| 레슨 노트 | 레슨 중/후 메모 작성 |
| 녹음 | 레슨 녹음 (학생 동의 필요) |
| 레슨 완료 | 레슨 종료 → 완료 처리 |

#### 🔴 기획 필요: 체험 레슨 전용 노트
- [ ] 체험 레슨용 간단 평가 폼
  - 악기 상태 (본인 악기, 대여 필요 등)
  - 학생 레벨 평가
  - 추천 레슨 횟수
  - 선생님 메모
- [ ] 정규 레슨 전환 시 체험 노트 연동

### 5. 정규 레슨 전환

#### 전환 권유 타이밍
```
레슨 완료 후 → "정규 레슨 등록하기" 버튼 활성화
```

> 참조: [레슨 스케줄 시스템 - 정규레슨 전환 플로우](./lesson_schedule.md#정규레슨-전환-플로우)

#### 🔴 기획 필요: 전환 유도
- [ ] 체험 레슨 후 자동 알림 (n일 후)
- [ ] 정규 레슨 할인 쿠폰 (첫 달)
- [ ] 전환율 통계 대시보드

### 6. 수강료 정산

> 참조: [수강료 관리 시스템 - 2단계 입금확인](./payment_system.md#2단계-입금확인-시스템)

#### 체험 레슨 결제 플로우
```
1. 학생: 계좌 이체 (선생님 계좌)
2. 학생: 앱에서 "입금 완료" 표시
3. 선생님: 계좌 확인 후 "입금 확인" 처리
```

#### 🔴 기획 필요: 선결제/후결제 정책
- [ ] 체험 레슨 선결제 여부 결정
  - 선결제: 승인 후 입금 → 레슨
  - 후결제: 레슨 후 입금
- [ ] 노쇼(No-show) 정책

#### 상태별 가능 액션
> 참조: [레슨 스케줄 시스템 - 예약 상태](./lesson_schedule.md#예약-상태)

| 완료 (completed) | "레슨 완료" | - |
| 취소 (cancelled) | "취소되었습니다" | - |

## 가용시간 관리 시스템 상세

> 작성일: 2025-12-27
> 상태: ✅ 설계 완료

### 개요

선생님의 레슨 가능 시간을 효율적으로 관리하는 시스템입니다.
체험 레슨과 정규 레슨 모두에서 공통으로 사용됩니다.

### 설계 원칙

| 원칙 | 설명 |
|------|------|
| **3계층 구조** | 주간 템플릿 → 예외 → 구글 연동 순으로 적용 |
| **개인별 커스텀** | 슬롯 단위(30/45/60분) 선생님별 설정 |
| **수동 블로킹** | 구글 일정 자동 블로킹 아닌 수동 확인 후 블로킹 |

### 데이터 모델

```dart
/// 선생님 가용시간 설정
class TeacherAvailability {
  final String teacherId;
  final int slotDurationMinutes;        // 30, 45, 60 (개인별 설정)
  final List<WeeklySchedule> weeklySchedules;
  final List<TimeException> exceptions;
  final GoogleCalendarSync? googleSync;
}

/// 주간 스케줄 (Layer 1)
class WeeklySchedule {
  final int dayOfWeek;                  // 1(월) ~ 7(일)
  final bool isAvailable;               // 해당 요일 가용 여부
  final TimeOfDay? startTime;           // 시작 시간
  final TimeOfDay? endTime;             // 종료 시간
  final List<TimeRange> excludedRanges; // 제외 시간대 (점심 등)
}

/// 시간 예외 (Layer 2)
class TimeException {
  final String id;
  final ExceptionType type;
  final DateTime? startDate;            // 시작일 (periodOff, temporaryAddition)
  final DateTime? endDate;              // 종료일 (시작일=종료일이면 하루)
  final int? dayOfWeek;                 // 요일 (recurringOff)
  final TimeRange? timeRange;           // 시간대 (timeBlocking, temporaryAddition)
  final String? reason;                 // 사유 (선택)
  final bool isAddition;                // true=추가, false=제외
}

/// 예외 유형
enum ExceptionType {
  periodOff,          // 기간 휴무 (하루~여러 날)
  timeBlocking,       // 특정 시간대 블로킹
  recurringOff,       // 반복 휴무 (매주 특정 요일)
  temporaryAddition,  // 임시 가용시간 추가
}

/// 구글 캘린더 연동 (Layer 3)
class GoogleCalendarSync {
  final bool isConnected;
  final String? calendarId;
  final DateTime? lastSyncTime;
  final List<GoogleEvent> pendingEvents;  // 블로킹 대기 이벤트
  final List<GoogleEvent> blockedEvents;  // 블로킹 완료 이벤트
}
```

## 노쇼/취소 정책 시스템 상세

> 작성일: 2025-12-27
> 상태: ✅ 설계 완료

### 개요

레슨 취소 및 노쇼(무단결석) 상황을 처리하는 정책 시스템입니다.
체험 레슨과 정규 레슨에 각각 다른 정책을 적용합니다.

### 설계 원칙

| 원칙 | 설명 |
|------|------|
| **선생님 재량** | 페널티 수준은 선생님이 설정 |
| **체험레슨 관대** | 첫 인상 중요, 취소→일정변경 유도 |
| **결제방식 연동** | 선결제/후결제에 따라 처리 방식 다름 |
| **긴급상황 유연** | 선생님 재량으로 예외 허용 (문서화 안함) |

### 데이터 모델

```dart
/// 선생님별 취소/노쇼 정책 설정
class CancellationPolicy {
  final String teacherId;
  final int cancellationDeadlineHours;    // 취소 마감 (기본 24시간)
  final CancellationPenaltyType penaltyType;
  final int? freeCancellationsPerMonth;   // 무료 취소 횟수 (옵션 C)
  final NoShowPolicy noShowPolicy;
  final TeacherNoShowCompensation teacherNoShowCompensation; // 선생님 노쇼 시 보상
}

/// 취소 페널티 유형
enum CancellationPenaltyType {
  fullCharge,         // A: 100% 과금
  halfCharge,         // B: 50% 과금
  freeThenCharge,     // C: 월 n회 무료 후 100% 과금
  rescheduleOnly,     // D: 취소 불가, 일정변경만 허용
}

/// 노쇼 정책
class NoShowPolicy {
  final int graceMinutes;                 // 노쇼 판정 대기 시간 (기본 15분)
  final bool chargeFullAmount;            // 100% 과금 여부
  final int? warningsBeforeBlacklist;     // 블랙리스트 전 경고 횟수 (null=사용안함)
}

/// 선생님 노쇼 시 학생 보상 설정
class TeacherNoShowCompensation {
  final TeacherNoShowOption regularLessonOption;   // 정규레슨 기본 보상
  final TeacherNoShowOption trialLessonOption;     // 체험레슨 기본 보상
  final int? extraMinutes;                         // 시간 연장 시 추가 분 (기본 15분)
}

/// 선생님 노쇼 보상 옵션
enum TeacherNoShowOption {
  // 정규 레슨용
  addLesson,              // A: 레슨 1회 추가
  extendNextLesson,       // D: 다음 레슨 시간 연장

  // 체험 레슨용
  freeRebooking,          // A: 무료 재예약
  freeRebookingWithCoupon, // C: 무료 재예약 + 정규레슨 할인 쿠폰
}

/// 취소/노쇼 기록
class CancellationRecord {
  final String id;
  final String lessonId;
  final String studentId;
  final CancellationType type;            // 취소 or 노쇼
  final DateTime requestedAt;
  final int hoursBeforeLesson;            // 레슨 몇 시간 전 취소
  final bool withinDeadline;              // 마감 내 취소 여부
  final PenaltyResult? penalty;           // 페널티 결과
  final bool isEmergencyException;        // 긴급상황 예외 처리 여부
}

enum CancellationType {
  cancelled,          // 학생이 취소
  noShow,             // 학생 노쇼
  teacherCancelled,   // 선생님이 취소
  teacherNoShow,      // 선생님 노쇼
}

/// 페널티 처리 결과
class PenaltyResult {
  final PaymentMethod paymentMethod;      // 선결제/후결제
  final int chargeAmount;                 // 과금 금액
  final bool lessonDeducted;              // 레슨 차감 여부 (선결제)
  final String? invoiceId;                // 청구서 ID (후결제)
}

enum PaymentMethod {
  prepaid,            // 선결제 (무통장입금 등)
  postpaid,           // 후결제
}
```

### 취소 정책 상세

#### 취소 마감 시간

| 설정 | 기본값 | 비고 |
|------|--------|------|
| 취소 마감 | 레슨 24시간 전 | 선생님 설정 가능 |

```
예시: 12/28(토) 14:00 레슨
→ 12/27(금) 14:00까지 무료 취소 가능
→ 12/27(금) 14:01 이후 취소 시 페널티
```

#### 페널티 옵션 (선생님 설정)

| 옵션 | 설명 | 적용 |
|------|------|------|
| **A. 100% 과금** (기본) | 마감 후 취소 시 전액 과금 | 가장 엄격 |
| **B. 50% 과금** | 마감 후 취소 시 절반 과금 | 중간 |
| **C. 월 n회 무료** | 무료 취소 소진 후 100% 과금 | 유연함 |
| **D. 일정변경만** | 취소 불가, 변경만 허용 | 노쇼 방지 |

#### 결제 방식별 처리

| 결제 방식 | 마감 전 취소 | 마감 후 취소 | 노쇼 |
|----------|-------------|-------------|------|
| **선결제** | 전액 환불 | 레슨 1회 차감 | 레슨 1회 차감 |
| **후결제** | 무료 | 100% 청구 | 100% 청구 |

### 체험레슨 특별 정책

#### 관대한 정책 적용

| 항목 | 정규레슨 | 체험레슨 |
|------|---------|---------|
| 취소 | 페널티 적용 | **일정변경으로 유도** |
| 마감 후 취소 | 과금 | 1회에 한해 일정변경 허용 |
| 노쇼 | 100% 과금 | 100% 과금 (동일) |

#### 체험레슨 취소 플로우

```

    ↓

    ↓

```

### 선생님 취소/노쇼 정책

#### 선생님 취소

| 상황 | 처리 |
|------|------|
| 24시간 전 취소 | 학생에게 알림 + 대안 시간 제안 |
| 24시간 내 취소 | 학생에게 알림 + 사과 메시지 + 대안 제안 |
| 잦은 취소 | 플랫폼 경고 (추후) |

#### 선생님 노쇼 - 학생 보상

> **원칙**: 선생님 노쇼 시 학생에게 어드벤티지 제공 (선생님이 보상 방식 선택)

**정규 레슨 - 선생님 선택 옵션:**

| 옵션 | 보상 내용 | 설명 |
|------|----------|------|
| **A. 레슨 추가** | 해당 레슨 무료 (선결제 시 1회 추가) | 기본 옵션 |
| **D. 시간 연장** | 해당 레슨 무료 + 다음 레슨 시간 연장 | 예: 15분 추가 |

**체험 레슨 - 선생님 선택 옵션:**

| 옵션 | 보상 내용 | 설명 |
|------|----------|------|
| **A. 무료 재예약** | 체험레슨 무료로 다시 예약 | 기본 옵션 |
| **C. 무료 재예약 + 쿠폰** | 무료 재예약 + 정규레슨 할인 쿠폰 | 정규 전환 유도 |

**반복 노쇼 시:**
- 매번 동일한 보상 적용 (증가 없음)
- 플랫폼 경고/제재 (추후 구현)

#### 선생님 노쇼 처리 플로우

```
레슨 시작 시간
    ↓
학생: 선생님 미출석 (15분 대기)
    ↓
학생: [선생님 노쇼 신고] 버튼 클릭
    ↓
시스템: 선생님에게 확인 알림 발송
    ↓
(5분 내 응답 없음)
    ↓
시스템: 노쇼 확정 → 학생에게 보상 자동 적용
    ↓
선생님: 다음 접속 시 보상 방식 선택 요청
```
