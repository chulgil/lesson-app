## 0. 현황 진단

### 현재 (v1) 문제점

| 문제 | 심각도 | 설명 |
|------|--------|------|
| 학생 전용 | CRITICAL | 선생님/학부모 도움말 없음 |
| FAQ 6개 고정 | HIGH | 하드코딩, 확장 불가, 상황별 안내 없음 |
| 컨텍스트 도움말 없음 | HIGH | 화면별 도움말 제공 안 됨 |
| 튜토리얼 재접근 불가 | MEDIUM | 건너뛴 튜토리얼을 다시 볼 수 없음 |
| 검색 없음 | MEDIUM | 원하는 도움말을 찾을 수 없음 |
| 신규 기능 안내 없음 | LOW | What's New / 변경 로그 없음 |

### 벤치마크

| 앱 | 도움말 구성 |
|----|-----------|
| **Notion** | 인앱 가이드 + 템플릿 + 커뮤니티 + 검색 |
| **Slack** | 봇 안내 + 컨텍스트 도움말 + 키보드 단축키 가이드 |
| **Figma** | 인터랙티브 튜토리얼 + 팁 카드 + 유튜브 링크 |
| **Discord** | 서버 설정 마법사 + FAQ + 지원 봇 |

## 2. 기능 가이드 (Feature Guide)

### 2.1 역할별 가이드 구조

각 가이드 항목:
```
┌─────────────────────────────┐
│  📖 레슨 등록 및 관리         │
│                             │
│  레슨을 등록하고 관리하는      │
│  방법을 알아보세요.           │
│                             │
│  ① 캘린더에서 날짜를 선택     │
│     [스크린샷/일러스트]       │
│                             │
│  ② 레슨 정보를 입력          │
│     • 학생 선택              │
│     • 시간 설정              │
│     • 레슨 타입 선택          │
│     [스크린샷/일러스트]       │
│                             │
│  ③ 저장하면 완료!            │
│                             │
│  💡 Tip: 정기 레슨을 설정하면  │
│  매주 자동으로 등록됩니다.     │
│                             │
│  [관련 퀘스트: 첫 레슨 등록]   │
└─────────────────────────────┘
```

### 2.2 선생님 가이드 목록

| # | 가이드 | 관련 퀘스트 | 핵심 내용 |
|---|--------|-----------|----------|
| 1 | 학생 관리 | 첫 학생 추가 | 학생 추가/수정/삭제, 초대 코드 |
| 2 | 레슨 등록 및 관리 | 첫 레슨 등록 | 단일/정기 레슨, 취소/변경, 출결 |
| 3 | 레슨 노트 작성 | 첫 레슨 노트 | 피드백, 레슨 노트, 과제 부여 |
| 4 | 수강권 발급 | 첫 수강권 발급 | 수강권 생성/관리/갱신 |
| 5 | 스케줄 관리 | — | 주간/월간 뷰, 변경 요청 처리 |
| 6 | 프로필 설정 | 프로필 사진, 자기소개 | 프로필 편집, 악기 추가 |
| 7 | 연습 관리 | — | 학생 연습 현황 확인, 레퍼토리 |
| 8 | 알림 설정 | — | 레슨 알림, 연습 리마인더 |

### 2.3 학생 가이드 목록

> 학생이 가장 많이 사용하는 기능 순서로 배치: 연습 도구 → 레슨 노트 → 스케줄

| # | 가이드 | 관련 퀘스트 | 핵심 내용 | 사용 빈도 |
|---|--------|-----------|----------|----------|
| **연습 도구 (매일)** | | | | |
| 1 | 메트로놈 완전 정복 | 메트로놈 사용 | BPM 조절, 박자 설정, 세분화, 센터 버튼 접근법 | 매일 |
| 2 | 튜너 사용법 | 튜너 사용 | 음 감지, 센트 표시, 롱프레스 접근법, 설정 | 매일 |
| 3 | 스마트 녹음 가이드 | 첫 녹음 | 녹음 시작/정지, 자동 트리밍, 무음 감지, 녹음 비교 | 매일 |
| 4 | 레퍼토리 관리 | 레퍼토리 추가 | 곡 추가, 섹션 분할, 연습 완료 체크 | 매일 |
| **레슨 & 피드백 (주간)** | | | | |
| 5 | 레슨 노트 확인 | 레슨 노트 확인 | 대시보드 피드백 섹션, 노트 히스토리, 검색 | 주 1-2회 |
| 6 | 레슨 일정 확인 | 첫 레슨 확인 | 캘린더, 예정 레슨, 변경 요청 | 주 1-2회 |
| 7 | 선생님과 소통 | 선생님 연결 | 초대 코드, 연결 방법, 피드백 확인 | 월 1-2회 |
| **관리 (가끔)** | | | | |
| 8 | 녹음 백업 | — | 전체 백업 생성, 클라우드 저장 | 월 1회 |
| 9 | 프로필 설정 | 프로필 사진 | 이름, 악기, 사진 변경 | 최초 1회 |

### 2.4 학부모 가이드 목록

| # | 가이드 | 핵심 내용 |

## 3. FAQ 시스템 (확장)

### 3.1 v1 → v2 변경

| 항목 | v1 | v2 |
|------|----|----|
| 대상 | 학생만 | **모든 역할** |
| 개수 | 6개 고정 | **카테고리별 확장 가능** |
| 저장 | 하드코딩 | **AppStrings 상수** (Phase 1), CMS/백엔드 (Phase 2) |
| 검색 | 없음 | **키워드 검색** |

### 3.2 FAQ 카테고리 + 항목

#### 계정 및 로그인 (공통)
- 비밀번호를 잊어버렸어요
- 소셜 로그인은 어떻게 하나요?
- 계정을 삭제하고 싶어요
- 역할을 변경할 수 있나요?

#### 레슨 관련 (선생님)
- 정기 레슨은 어떻게 설정하나요?
- 레슨을 취소/변경하려면?
- 보강 레슨은 어떻게 등록하나요?
- 그룹 레슨은 지원하나요?

#### 레슨 관련 (학생)
- 레슨은 어떻게 예약하나요?
- 레슨 변경을 요청하려면?
- 레슨 일정 알림은 어떻게 받나요?

#### 결제/수강권 (공통)
- 수강권이 만료되면 어떻게 되나요?
- 수강권 잔여 횟수는 어디서 확인하나요?
- 환불은 어떻게 하나요?

#### 연습 도구 (학생) — 가장 많이 묻는 질문
- 메트로놈은 어떻게 켜나요? (센터 버튼 탭)
- 튜너는 어떻게 사용하나요? (센터 버튼 길게 누르기)
- 메트로놈 BPM을 바꾸려면? (슬라이더 또는 +/- 버튼)
- 박자를 4/4에서 3/4로 바꾸려면?
- 녹음은 어떻게 시작하나요?
- 녹음이 자동으로 잘리는 이유는? (스마트 트리밍 설정)
- 이전 녹음과 비교하려면?
- 녹음 파일은 어떻게 백업하나요?
- 레퍼토리에 새 곡을 추가하려면?
- 연습 기록은 어떻게 남기나요?
- 선생님 피드백은 어디서 보나요? (대시보드 또는 레슨 상세)

#### 기술 문제 (공통)
- 앱이 느려요 / 크래시가 나요
- 알림이 오지 않아요
- 데이터가 동기화되지 않아요

## 4. 컨텍스트 도움말 (Contextual Help)

### 4.1 개요

각 화면의 빈 상태(Empty State)에 관련 도움말 링크를 제공.

```
┌─────────────────────────────┐
│  [캘린더 - 빈 상태]          │
│                             │
│     아직 등록된 레슨이 없어요  │
│                             │
│  💡 레슨을 등록하려면 날짜를   │
│     탭하세요.                │
│                             │
│  [레슨 등록 가이드 보기 →]    │
│  [첫 레슨 등록 퀘스트 →]      │
│                             │
└─────────────────────────────┘
```

### 4.2 화면별 컨텍스트 도움말 매핑

| 화면 | 빈 상태 메시지 | 연결 가이드 | 연결 퀘스트 |
|------|--------------|-----------|-----------|
| **선생님** | | | |
| 학생 목록 | "아직 학생이 없어요" | 학생 관리 가이드 | 첫 학생 추가 |
| 캘린더 | "등록된 레슨이 없어요" | 레슨 등록 가이드 | 첫 레슨 등록 |
| 수강권 | "발급한 수강권이 없어요" | 수강권 가이드 | 첫 수강권 발급 |
| **학생** | | | |
| 연습 탭 (레퍼토리 없음) | "연습할 곡을 추가해보세요" | 레퍼토리 관리 가이드 | 레퍼토리 추가 |
| 연습 탭 (녹음 없음) | "녹음 버튼으로 연습을 기록해보세요" | 스마트 녹음 가이드 | 첫 녹음 |
| 메트로놈 모달 (첫 사용) | "BPM을 조절해서 연습해보세요" | 메트로놈 완전 정복 | 메트로놈 사용 |
| 튜너 화면 (첫 사용) | "악기로 소리를 내보세요" | 튜너 사용법 | 튜너 사용 |
| 대시보드 (피드백 없음) | "선생님 피드백이 여기에 표시돼요" | 레슨 노트 확인 | 레슨 노트 확인 |
| 스케줄 (학생) | "예정된 레슨이 없어요" | 레슨 확인 가이드 | — |

### 4.3 도움말 아이콘 (?)

주요 화면의 AppBar에 `?` 아이콘 배치:
- 탭 시 해당 화면의 기능 가이드로 이동
- 또는 인라인 팁 바텀시트 표시

## 5. 퀘스트 재시작

### 5.1 접근 경로

```
설정 > 도움말 > 🎯 퀘스트 다시하기
```

### 5.2 화면 구조

```
┌─────────────────────────────┐
│  🎯 퀘스트 다시하기           │
│                             │
│  [미완료 퀘스트]             │
│  → 전화번호 인증              │
│  → 프로필 사진 등록           │
│  → 자기소개 작성              │
│                             │
│  [보너스 퀘스트]             │
│  → 학생 3명 추가              │
│  → 첫 수강권 발급             │
│                             │
│  [완료된 퀘스트]             │
│  ✓ 프로필 생성                │
│  ✓ 첫 학생 추가               │
│  ✓ 첫 레슨 등록               │
│  ✓ 첫 레슨 노트 작성           │
│                             │
│  [워크스루 다시 보기 →]       │
└─────────────────────────────┘
```

- 미완료 퀘스트 탭 → 해당 기능 화면으로 이동
- "워크스루 다시 보기" → 인터랙티브 워크스루 재실행 (샘플 데이터 없이)

## 7. 데이터 모델

### 7.1 가이드 항목

```dart
class GuideItem {
  final String id;
  final String title;
  final String summary;
  final UserRole targetRole;     // teacher, student, parent
  final String category;
  final List<GuideStep> steps;
  final String? relatedQuestId;

class GuideStep {
  final int order;
  final String instruction;
  final String? imageAsset;      // 스크린샷/일러스트

}
```

```dart
class FaqItem {
```

## 8. UI 규칙

- **Notebook × Score** 디자인 일관성 유지
- 가이드 헤더: `NotebookTypography.sectionTitle`
- FAQ 아코디언: 기존 `HelpScreen` 패턴 확장
- 가이드 스텝: 번호 + 텍스트 + 선택적 이미지
- 색상: `AppColors` 토큰만 사용
- 텍스트: `AppStrings` 상수 사용
- 빈 상태 연결: 기존 `EmptyStateWidget` 패턴 확장
