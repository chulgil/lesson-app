## 0. 설계 철학

### 왜 재설계하는가?

v1 온보딩은 **읽는 슬라이드쇼** — 5장의 정적 페이지를 넘기면 끝. 업계 최고 수준의 온보딩(Duolingo, Notion, Figma, Superhuman)과 비교하면:

| 기준 | v1 (현재) | v2 (재설계) | 벤치마크 앱 |
|------|----------|------------|------------|
| 학습 방식 | 읽기 (passive) | **하면서 배우기** (active) | Duolingo, Figma |
| 진행 동기 | 없음 | **퀘스트 + 축하 + 진행률** | Duolingo, Forest |
| 첫 가치 도달 | 온보딩 후 | **온보딩 중에 첫 가치** 경험 | Notion, Superhuman |
| 개인화 | 없음 | **악기별 + 역할별** 맞춤 | Spotify, Netflix |
| 도움말 연계 | 별도 FAQ 6개 | **인앱 코치마크 + 퀘스트 + 매뉴얼** | Slack, Discord |

### 핵심 원칙

1. **Do, Don't Read** — 설명 대신 직접 해보게 한다 (Interactive Tutorial)
2. **5분 안에 아하** — 선생님: 첫 레슨 노트 작성까지, 학생: 첫 연습 기록까지
3. **퀘스트 = 실제 사용** — 튜토리얼 미션이 아니라 실제 데이터를 만드는 행동
4. **축하하고 보상** — 각 단계 완료마다 마이크로 셀레브레이션
5. **언제든 돌아올 수 있다** — 건너뛴 퀘스트는 대시보드에서 재시작 가능

## 1. 온보딩 전체 플로우

### 1.1 선생님 (Teacher) 플로우

```
[1] 가입/로그인
    ↓
[2] 역할 선택 (선생님/학생/학부모)
    ↓
[3] 프로필 설정 (Quick Start — 최소 입력)
    │  이름 + 주 악기 1개 (30초 완료)
    │  ※ 사진/소개글/전화번호는 퀘스트로 이동
    ↓
[4] 인터랙티브 워크스루 (3단계, 각 30초)
    │  ① "학생 추가해보기" — 샘플 학생 자동 생성, 추가 플로우 체험
    │  ② "첫 레슨 만들기" — 샘플 학생에게 레슨 등록 체험
    │  ③ "레슨 노트 남기기" — 방금 만든 레슨에 피드백 작성
    │  ※ 각 단계: 코치마크 → 직접 탭 → 축하 애니메이션
    │  ※ "나중에 하기" 가능 → 퀘스트 보드로 이동
    ↓
[5] 홈 화면 진입 + 퀘스트 보드 활성화
```

### 1.2 학생 (Student) 플로우

```
[1] 가입/로그인
    ↓
[2] 역할 선택
    ↓
[3] 초대 코드 입력 (선택) / 선생님 찾기
    ↓
[4] 프로필 설정 (Quick Start — 이름 + 악기)
    ↓
[5] 인터랙티브 워크스루 (4단계 — 연습 도구 중심)
    │  ① "메트로놈 켜보기" — 센터 버튼 탭 → BPM 조절 체험
    │  ② "튜너로 음 맞춰보기" — 길게 누르기 → 음 감지 체험
    │  ③ "첫 녹음 해보기" — 샘플 곡으로 5초 녹음 체험
    │  ④ "선생님 피드백 확인하기" — 대시보드 피드백 섹션 안내
    │  ※ 각 단계: 코치마크 → 직접 탭 → 축하
    │  ※ "나중에 하기" 가능 → 퀘스트 보드로 이동
    ↓
[6] 홈 화면 진입 + 퀘스트 보드 활성화 (연습 도구 퀘스트 우선)
```

> **설계 의도**: 학생의 핵심 가치는 **연습 도구**(메트로놈, 튜너, 녹음)와 **레슨 노트 확인**.
> 스케줄 확인은 선생님이 레슨을 등록하면 자동으로 보이므로 워크스루에서 별도 안내하지 않는다.
> 연습 도구를 먼저 체험시켜 "이 앱은 매일 쓸 수 있는 연습 동반자"라는 인식을 심는다.

### 1.3 학부모 (Parent) 플로우

```
[1] 가입/로그인
    ↓
[2] 역할 선택
    ↓
[3] 자녀 연결 (초대 코드 또는 자녀 프로필 생성)
    ↓
[4] 간단 워크스루 (1단계)
    │  ① "자녀 레슨 현황 보기" — 대시보드 탐색
    ↓
[5] 홈 화면 진입
```

## 2. 프로필 설정 (Quick Start)

### v1 → v2 변경 핵심

| 항목 | v1 | v2 |
|------|----|----|
| 필수 입력 | 이름+사진+악기+소개글(20자) | **이름+악기만** (30초 완료) |
| 전화번호 인증 | 온보딩 필수 단계 | **퀘스트로 이동** (나중에 해도 됨) |
| 프로필 사진 | 온보딩 필수 | **퀘스트로 이동** |
| 소개글 | 온보딩 필수 (20자+) | **퀘스트로 이동** |
| 목표 | 진입 장벽 최소화 | **30초 안에 앱 진입** |

### 2.1 선생님 Quick Start

```
┌─────────────────────────────┐
│  선생님 프로필을 만들어볼까요?  │
│                             │
│  이름 [_______________]     │
│                             │
│  주 악기 (1개 선택)           │
│  ┌────┐ ┌────┐ ┌────┐      │
│  │바이올린│ │피아노│ │첼로 │      │
│  └────┘ └────┘ └────┘      │
│  ┌────┐ ┌────┐ ┌────┐      │
│  │플루트│ │기타 │ │성악 │      │
│  └────┘ └────┘ └────┘      │
│                             │
│  [    시작하기 →   ]         │
└─────────────────────────────┘
```

- 이름 + 악기 1개만 → 즉시 앱 사용 가능
- 나머지(사진, 소개글, 추가 악기, 전화번호)는 "프로필 완성 퀘스트"로

### 2.2 학생 Quick Start

- 이름 + 악기 1개만 (기존과 동일하지만 더 간결한 UI)
- 초대 코드는 선택 — "코드 없이도 시작할 수 있어요"

## 3. 인터랙티브 워크스루 (Interactive Walkthrough)

### v1 → v2 핵심 변경

| 항목 | v1 (슬라이드쇼) | v2 (인터랙티브) |
|------|---------------|---------------|
| 방식 | PageView 넘기기 | **실제 화면에서 코치마크** |
| 콘텐츠 | 아이콘 + 텍스트 | **실제 UI + 하이라이트 + 안내 말풍선** |
| 행동 | 읽기만 | **직접 탭하고 입력** |
| 데이터 | 없음 | **샘플 데이터 자동 생성** |
| 완료 느낌 | 없음 | **축하 애니메이션 + 진행률** |

### 3.1 선생님 워크스루 상세

#### Step 1: "첫 학생 추가하기" (30초)

```
┌─────────────────────────────┐
│  🎯 미션: 첫 학생을 추가해보세요  │
│                             │
│  [학생 관리 화면]             │
│  ┌─── 코치마크 ────────┐    │
│  │ 여기를 탭하면         │    │
│  │ 학생을 추가할 수 있어요 │    │
│  │    [+ 학생 추가] ←───│    │
│  └─────────────────────┘    │
│                             │
│      "연습용 학생"으로         │
│      자동 완성 가능            │
│                             │
│  ─── 하단 ──────────         │
│  진행률: ■□□  (1/3)          │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 코치마크(반투명 오버레이 + 포인터)로 "학생 추가" 버튼 하이라이트
- "연습용 학생으로 시작하기" 원탭 옵션 (이름: "연습용 학생", 악기: 선생님 악기와 동일)
- 학생 추가 완료 → 컨페티 애니메이션 + "첫 학생이 추가되었어요!"
- ※ 연습용 학생은 나중에 삭제하거나 실제 학생으로 변경 가능

#### Step 2: "첫 레슨 만들기" (30초)

```
┌─────────────────────────────┐
│  🎯 미션: 레슨 일정을 등록해보세요 │
│                             │
│  [캘린더 화면]               │
│  ┌─── 코치마크 ────────┐    │
│  │ 날짜를 탭하고         │    │
│  │ 레슨을 등록해보세요    │    │
│  │    [오늘 날짜] ←─────│    │
│  └─────────────────────┘    │
│                             │
│  자동 완성:                   │
│  학생: 연습용 학생             │
│  시간: 지금 (체험 레슨)        │
│                             │
│  진행률: ■■□  (2/3)          │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 캘린더 화면에서 오늘 날짜 하이라이트
- "빠른 등록" — 학생/시간 자동 완성, 한 번 탭으로 레슨 생성
- 레슨 생성 완료 → 축하 + "첫 레슨이 등록되었어요!"

#### Step 3: "첫 레슨 노트 남기기" (30초)

```
┌─────────────────────────────┐
│  🎯 미션: 레슨 노트를 작성해보세요 │
│                             │
│  [레슨 상세 화면]             │
│  ┌─── 코치마크 ────────┐    │
│  │ 레슨 후 피드백을       │    │
│  │ 남겨보세요            │    │
│  │  [피드백 작성] ←─────│    │
│  └─────────────────────┘    │
│                             │
│  예시 텍스트 제공:             │
│  "오늘 스케일 연습을 했습니다.   │
│   다음 시간에는..."           │
│                             │
│  진행률: ■■■  (3/3)          │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 방금 만든 레슨의 상세 화면으로 자동 이동
- 피드백 작성 영역 하이라이트 + 예시 텍스트 제공
- 피드백 저장 → 최종 축하 + "온보딩 완료!" 셀레브레이션

### 3.2 학생 워크스루 상세

> **핵심 원칙**: 학생의 핵심 가치는 스케줄 확인이 아니다.
> 학생이 가장 많이 사용하는 기능: **레슨 노트 확인 > 스마트 녹음 > 메트로놈 > 튜너**.
> 워크스루는 이 4가지 핵심 도구를 직접 체험하게 설계한다.

#### Step 1: "메트로놈 켜보기" (20초)

```
┌─────────────────────────────┐
│  🎯 미션: 메트로놈을 켜보세요    │
│                             │
│  [하단 네비게이션 바]           │
│  ┌─── 코치마크 ────────┐    │
│  │ 가운데 버튼을 탭하면    │    │
│  │ 연습 도구가 열려요      │    │
│  │    [♪ 버튼] ←────────│    │
│  └─────────────────────┘    │
│                             │
│  → 메트로놈 모달 열림          │
│  → BPM 조절 체험              │
│  → "탭탭탭" 3초 재생           │
│                             │
│  진행률: ■□□□  (1/4)         │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 하단 센터 버튼(연습 도구) 코치마크
- 탭 → 메트로놈 모달 자동 열림
- BPM 조절 하이라이트 → "템포를 조절해보세요" 안내
- 3초 재생 체험 → "메트로놈으로 정확한 박자를 연습할 수 있어요!"

#### Step 2: "튜너로 음 맞춰보기" (20초)

```
┌─────────────────────────────┐
│  🎯 미션: 튜너를 사용해보세요    │
│                             │
│  [메트로놈 모달에서]           │
│  ┌─── 코치마크 ────────┐    │
│  │ 길게 누르면 튜너가      │    │
│  │ 열려요                │    │
│  │    [♪ 버튼] ←────────│    │
│  └─────────────────────┘    │
│                             │
│  → 튜너 화면 열림              │
│  → 마이크 권한 요청            │
│  → "아무 소리를 내보세요" 안내   │
│                             │
│  진행률: ■■□□  (2/4)         │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 센터 버튼 길게 누르기 안내 (또는 튜너 탭 전환 안내)
- 튜너 화면에서 마이크 권한 승인 → 소리 감지 체험
- 음이 감지되면 → "튜너로 정확한 음을 맞출 수 있어요!"

#### Step 3: "첫 녹음 해보기" (30초)

```
┌─────────────────────────────┐
│  🎯 미션: 연습을 녹음해보세요    │
│                             │
│  [연습 탭]                   │
│  ┌─── 코치마크 ────────┐    │
│  │ 레퍼토리를 선택하고     │    │
│  │ 녹음을 시작해보세요     │    │
│  │    [🔴 녹음] ←────────│    │
│  └─────────────────────┘    │
│                             │
│  → 샘플 레퍼토리 자동 추가     │
│    (악기에 맞는 기본 연습곡)    │
│  → 5초 녹음 체험               │
│  → 스마트 녹음 자동 트리밍 확인  │
│                             │
│  진행률: ■■■□  (3/4)         │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 연습 탭 → 샘플 레퍼토리 자동 생성 (악기별: 바이올린→"스케일 연습", 피아노→"하논 1번" 등)
- 녹음 버튼 코치마크 → 5초 간단 녹음
- 녹음 완료 → 스마트 트리밍 결과 확인 → "녹음으로 연습을 기록하고 비교할 수 있어요!"

#### Step 4: "선생님 피드백 확인하기" (20초)

```
┌─────────────────────────────┐
│  🎯 미션: 레슨 노트를 확인해보세요│
│                             │
│  [대시보드]                   │
│  ┌─── 코치마크 ────────┐    │
│  │ 선생님이 남긴 피드백을   │    │
│  │ 여기서 확인할 수 있어요  │    │
│  │  [피드백 섹션] ←──────│    │
│  └─────────────────────┘    │
│                             │
│  → 피드백 섹션 하이라이트       │
│  → 샘플 피드백 표시            │
│  → "더보기" 탭 안내            │
│                             │
│  진행률: ■■■■  (4/4)         │
│  [나중에 하기]                │
└─────────────────────────────┘
```

- 대시보드의 "선생님 피드백" 섹션 코치마크
- 샘플 피드백 표시 (선생님 연결 전이라도 체험용 데이터)
- "레슨 노트에서 선생님의 피드백과 과제를 확인할 수 있어요!"
- 최종 축하 → "모든 연습 도구를 알아봤어요!"

### 3.3 학생 워크스루 설계 근거

> **왜 스케줄 확인이 아닌 연습 도구를 먼저?**

| 관점 | 스케줄 우선 (v1) | 연습 도구 우선 (v2) |
|------|----------------|-------------------|
| 사용 빈도 | 주 1-2회 확인 | **매일** 사용 |
| 아하 모먼트 | "일정이 보이네" (약함) | **"메트로놈 편하다!"** (강함) |
| 재방문 동기 | 수동적 확인 | **능동적 연습 도구** |
| 차별화 | 캘린더 앱과 동일 | **음악 특화 앱의 핵심** |
| Duolingo 패턴 | 대시보드 먼저 보여줌 | **첫 레슨을 바로 시작** |

학생이 온보딩 직후 "이 앱 쓸 만하다"라고 느끼려면, 매일 쓰는 **연습 도구의 편리함**을 먼저 체험해야 한다. 스케줄은 선생님이 등록하면 자동으로 보이므로 별도 안내 불필요.

### 4.3.1 학생 퀘스트 설계 근거

```
[아하 모먼트 순서]

1. 메트로놈 → "와 편하다" (즉시 가치, 10초)
2. 튜너 → "음 맞추기 쉽네" (즉시 가치, 10초)
3. 녹음 → "내 연주를 다시 들을 수 있다" (핵심 가치, 30초)
4. 레슨 노트 → "선생님이 뭐라고 했더라" (관계 가치)
5. 선생님 연결 → "레슨 시작" (관계 가치)

↓ 위에서 아래로 갈수록 외부 의존도 증가 (선생님 필요)
  메트로놈/튜너/녹음은 혼자서도 즉시 가치를 느낌
```

**왜 메트로놈이 첫 퀘스트인가?**
- 진입 장벽 최저 (탭 1번 → 소리 남)
- 모든 악기 학생이 사용
- 10초 안에 "이 앱 쓸 만하다" 판단 가능
- 선생님 연결 없이도 작동

**왜 선생님 연결이 필수인데 후순위인가?**
- 선생님이 아직 앱에 없을 수 있음 (초대 대기)
- 연결 전에도 연습 도구는 사용 가능
- 연결 실패가 첫 경험이 되면 이탈률 급증

### 4.4 퀘스트 보드 UI 규칙

- **Notebook × Score** 디자인: 종이 위의 체크리스트 메타포
- 완료 항목: `paperOk` 색상 + ✓ 글리프 + ~~취소선~~
- 현재 진행 항목: `paperAccent` 하이라이트 + → 화살표 + [하기] CTA
- 미해금 항목: `inkTertiary` + ○ 빈 원
- 카테고리별 접이식: 필수(기본 펼침), 권장(접힘), 보너스(접힘)
- 모든 퀘스트 완료 시 퀘스트 보드 숨김 + "모든 퀘스트 완료!" 최종 축하

### 4.5 프로필 완성도 (Profile Completeness)

퀘스트와 연동되는 프로필 완성도 게이지:

```
프로필 완성도: ████████░░ 80%

부족한 항목:
- 프로필 사진 (+10%)
- 자기소개 (+10%)
```

- 프로필 화면 상단에 표시
- 100% 달성 시 "완벽한 프로필" 축하
- 학생/학부모에게 프로필 노출 시 완성도가 신뢰도에 영향

enum OnboardingPhase {

## 8. 워크스루 ↔ 퀘스트 관계

```
[워크스루]                    [퀘스트 보드]
Step 1: 학생 추가 체험  ───→  Quest 2: 첫 학생 추가 ✓ (자동 완료)
Step 2: 레슨 등록 체험  ───→  Quest 3: 첫 레슨 등록 ✓ (자동 완료)
Step 3: 노트 작성 체험  ───→  Quest 4: 첫 레슨 노트 ✓ (자동 완료)

워크스루 건너뛰기 ───→ Quest 2,3,4 미완료 상태로 퀘스트 보드에 표시
```

- 워크스루에서 한 행동은 실제 데이터로 저장 → 퀘스트 자동 완료
- 워크스루를 건너뛰면 퀘스트가 미완료 상태로 남아 대시보드에서 안내

### 12.2 학생 온보딩 벤치마크 — 연습 도구 중심

| 앱/게임 | 패턴 | 우리 적용 |
|---------|------|----------|
| **Duolingo** | 가입 전 첫 레슨 체험 → 손실 회피 | 프로필 설정 직후 메트로놈 즉시 체험 (가입 후 10초 안에 소리) |
| **GarageBand** | 악기 선택 → 즉시 연주 (빈 화면 없음) | 악기 선택 → 즉시 메트로놈/튜너 (빈 캘린더 아님) |
| **Yousician** | 첫 곡을 튜토리얼에서 연주 + 점수 | 첫 녹음을 워크스루에서 직접 체험 + 스마트 트리밍 확인 |
| **Forest (뽀모도로)** | 나무 심기 = 집중 시작 | 연습 기록 = 연습 스트릭 → 보너스 퀘스트 |
| **Slack** | 봇이 채널에서 직접 안내 | 코치마크가 실제 화면에서 직접 안내 |
| **게임 퀘스트** | 쉬운 퀘스트 → 어려운 퀘스트 (난이도 곡선) | 메트로놈(탭1번) → 튜너(소리내기) → 녹음(5초) → 피드백(읽기) |
