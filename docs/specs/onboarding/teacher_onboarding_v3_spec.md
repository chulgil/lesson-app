# 선생님 온보딩 v3 — 게임형 튜토리얼 + 프로필 보상 시스템

> 작성일: 2026-05-31
> 상태: 스펙 초안
> 선행: [onboarding_quest_v2.md](onboarding_quest_v2.md) (미구현), 현재 v1 (3단계 슬라이드)

## 1. 문제 정의

### 현재 온보딩 (v1)

```
전화인증(필수) → 프로필(이름+악기+소개글) → 3페이지 슬라이드 → 홈
                                          ↑ 스킵 가능
```

| 문제 | 심각도 |
|------|--------|
| 레슨 시간/가용 시간 설정이 온보딩에 없음 → 학생이 예약 불가 | CRITICAL |
| 프로필이 이름만 → 학생 검색에 노출 안 됨 (`canBeSearched` 60%+ 필요) | HIGH |
| 튜토리얼이 패시브 슬라이드 → 기억에 안 남음 | HIGH |
| Getting Started 5단계가 온보딩과 중복 (학생 추가, 레슨 추가 등) | MEDIUM |
| 전화인증이 첫 단계 → 진입 마찰 큼 | MEDIUM |

### 게임 튜토리얼이 잘 되는 이유

| 게임 패턴 | 효과 | Lessonaza 적용 |
|-----------|------|----------------|
| **강제 첫 미션** | "이것만 하면 시작" 확실한 목표 | 첫 학생 초대 = 강제 미션 |
| **코치마크 (하이라이트 + 말풍선)** | 어디를 눌러야 하는지 정확히 안내 | 각 단계마다 UI 하이라이트 |
| **즉시 보상** | 완료 시 축하 애니메이션 + 잠금 해제 | 프로필 완성도 → 학생 노출 증가 |
| **점진적 난이도** | 쉬운 것 먼저, 복잡한 것 나중 | 이름 → 악기 → 시간 설정 → 수강권 |
| **스킵 불가 핵심 + 스킵 가능 선택** | 핵심은 반드시 경험 | 3가지 필수 + 나머지 선택 |
| **진행률 시각화** | "80% 완료!" → 완성 욕구 자극 | 프로필 완성도 게이지 |

### 경쟁 서비스 온보딩 비교

| 서비스 | 온보딩 단계 | 소요 시간 | 핵심 차별점 |
|--------|-----------|----------|-----------|
| **TakeLessons** | 악기 → 경력 → 가격 → 가용시간 → 소개영상 → 검토 | 15분 | 프로필 완성도가 검색 랭킹에 직접 영향 |
| **Lessonface** | 악기 → 가격 → Bio → 교육이력 → 시간대 → 프로필 사진 | 10분 | "Complete your profile to get found" 배너 |
| **Calendly** | 이름 → 가용시간 설정 → 첫 이벤트 생성 → 링크 공유 | 5분 | 코치마크로 단계별 안내, 첫 이벤트 강제 생성 |
| **Duolingo** | 목표 선택 → 레벨 테스트 → 첫 레슨 강제 완료 → 스트릭 시작 | 3분 | 절대 스킵 불가, 즉시 보상(XP) |
| **Notion** | 템플릿 선택 → 첫 페이지 생성 → 공유 안내 | 2분 | 인터랙티브 체크리스트 |
| **숨고 (전문가)** | 전문분야 → 활동지역 → 경력 → 가격 → 소개글 → 포트폴리오 | 10분 | "프로필 90%+ → 매칭 확률 3배" 표시 |

## 2. 설계 원칙

> **"30초 안에 첫 성공을 경험하고, 5분 안에 핵심 설정을 완료한다."**

1. **강제 최소화** — 필수 3단계(이름/악기/가용시간)만 강제, 나머지는 보상으로 유도
2. **즉시 보상** — 각 단계 완료 시 "잠금 해제" 피드백 (학생 노출, 웹 공유 등)
3. **코치마크** — 실제 화면에서 하이라이트로 안내 (별도 튜토리얼 화면 제거)
4. **프로필 = 화폐** — 프로필 완성도가 높을수록 학생에게 더 많이 노출
5. **웹 공유** — 프로필 완성 시 공유 가능한 웹 프로필 URL 제공

## 3. 온보딩 플로우 (v3)

### 3.1 전체 흐름

```
[Phase A: 즉시 시작 (30초)]
  로그인 → 역할 선택 → 이름 + 악기 1개 선택
  → 홈 화면 즉시 진입
  → 코치마크: "첫 학생을 초대해보세요" (하이라이트)

[Phase B: 핵심 설정 (5분, 코치마크 가이드)]
  퀘스트 보드 표시 (홈 상단 카드)
  ├─ 필수 퀘스트 1: 레슨 가능 시간 설정 (★ 신규)
  ├─ 필수 퀘스트 2: 첫 학생 초대
  └─ 필수 퀘스트 3: 첫 레슨 등록

[Phase C: 프로필 강화 (선택, 보상 유도)]
  ├─ 보상 퀘스트: 프로필 사진 추가     → "학생 검색 노출 ON"
  ├─ 보상 퀘스트: 소개글 작성 (20자+)  → "웹 프로필 공유 가능"
  ├─ 보상 퀘스트: 레슨비 설정          → "학생에게 가격 표시"
  ├─ 보상 퀘스트: 경력/학력 추가       → "프로필 신뢰도 배지"
  └─ 보상 퀘스트: 전화번호 인증        → "인증 선생님 배지"
```

### 3.2 Phase A: 즉시 시작 (30초)

```
┌────────────────────────────────────────┐
│         Lessonaza에 오신 것을           │
│            환영합니다!                  │
│                                        │
│  이름: [___________________]           │
│                                        │
│  주 악기 선택:                          │
│  ┌──────┐ ┌──────┐ ┌──────┐           │
│  │바이올린│ │ 피아노│ │ 첼로 │ ...      │
│  └──────┘ └──────┘ └──────┘           │
│                                        │
│  ┌──────────────────────────────┐      │
│  │         시작하기              │      │
│  └──────────────────────────────┘      │

- 이름 + 악기 1개만 필수 (2개 필드)
- 소개글, 전화인증, 프로필 사진 → Phase C로 이동
- "시작하기" 탭 → 홈 화면 즉시 진입

> **코드 반영 노트 (2026-06-10 — _audits/2026-06-10-teacher-flow-ux-audit.md §4.1 A1)**:
> Phase A 에서 소개글 입력 섹션을 완전 제거함 (이전 코드는 화면=선택, 검증=필수 20자 충돌 → 가입 차단 가능). `TeacherOnboardingProfile.isValid` 도 `name.isNotEmpty && instruments.isNotEmpty` 로 정렬.
> 소개글은 Phase C 보상 퀘스트(`profileIntroduction`, §3.4) 로 이관됨.

```

## 4. 프로필 보상 시스템

### 4.1 프로필 완성도 → 학생 노출 연동

| 완성도 | 레벨 | 학생에게 보이는 것 | 검색 노출 |
|--------|------|-------------------|----------|
| 0-29% | 시작 | 이름만 표시 | 검색 불가 |
| 30-49% | 기본 | 이름 + 악기 | 검색 가능 (하단) |
| 50-69% | 표준 | 이름 + 악기 + 소개 | 검색 가능 (중간) |
| 70-89% | 우수 | 전체 프로필 + "경험 있는 선생님" 배지 | 검색 상단 |
| 90-100% | 완벽 | 전체 + "인증 선생님" 배지 + 프로필 영상 | 검색 최상단 + 추천 |

### 4.2 보상 잠금 해제 목록

> **현행 구현 기준 (2026-06-06 업데이트)**: 스펙 초안의 8-퀘스트 체계에서 Action Phase를 포함한 10-퀘스트 체계로 확장됨.
> 코드 SSOT: `frontend/lib/features/home/presentation/providers/teacher_profile_completion_provider.dart`

#### Setup Phase (40%)

| 퀘스트 | 보상 | 완성도 기여 |
|--------|------|-----------|
| 레슨 가능 시간 설정 (blocker) | 학생 예약 가능 | +10% |
| 프로필 사진 | 검색 노출 활성화 | +8% |
| 소개글 (20자+) | **웹 프로필 URL** 생성 + 공유 가능 | +8% |
| 레슨비 설정 | 학생에게 가격 자동 표시 | +7% |
| 은행 계좌 등록 | 학생에게 결제 정보 제공 | +7% |

#### Action Phase (60%)

| 퀘스트 | 보상 | 완성도 기여 |
|--------|------|-----------|
| 첫 학생 초대 | 선생님-학생 연결 | +12% |
| 첫 수강권 발급 | 레슨 관리 시작 | +15% |
| 첫 레슨 완료 | 전체 워크플로우 완성 | +13% |
| 첫 레슨 메모 작성 | 학생에게 피드백 전달 | +10% |
| 첫 연습 과제 등록 | 학생 연습 관리 시작 | +10% |

#### Phase C — 보상 퀘스트 (가중치 0, 배지 부여)

| 퀘스트 | 보상 |
|--------|------|
| 전화번호 인증 | "인증된 선생님" 배지 |

> 미구현 (스펙 초안 기준 항목): 경력/학력 배지, 프로필 영상 노출 — Phase C 보상으로 향후 추가 예정.

### 4.3 웹 프로필 공유

소개글 작성 완료 시 웹 프로필이 활성화됩니다:

```
https://lessonaza.app/t/{teacher-slug}
```

선생님이 카카오톡/인스타그램/명함에 이 링크를 공유하면:
- 학생/학부모가 웹에서 프로필 확인
- "레슨 신청하기" 버튼 → 앱 다운로드 유도 or 웹에서 초대 코드 입력
- Open Graph 메타 태그로 SNS 미리보기 (사진 + 이름 + 악기 + 소개)

### 4.4 프로필 완성 유도 알림 (리마인더)

| 시점 | 메시지 | 조건 |
|------|--------|------|
| 가입 후 24시간 | "프로필을 완성하면 학생에게 노출돼요!" | 완성도 < 50% |
| 가입 후 3일 | "프로필 사진만 추가하면 검색에 노출됩니다" | 프로필 사진 없음 |
| 가입 후 7일 | "웹 프로필 링크를 만들어 카톡에 공유해보세요" | 소개글 미작성 |
| 첫 학생 연결 시 | "축하해요! 레슨비를 설정하면 학생에게 자동 표시돼요" | 레슨비 미설정 |

## 5. 코치마크 시스템 설계

> **폐기 (2026-08-20, #1287 UXC-3)**: 홈 화면의 3-step 코치마크 배선은 프로덕션 경로에서 `start()` 호출 0회의 죽은 코드로 확인되어 제거됨. 설명 카피는 QuestBoardCard 퀘스트 행 부제(풀 방식 컨텍스트 도움말)로 이식. `core/widgets/coach_mark/` 라이브러리는 향후 재사용을 위해 보존. 근거: NN/g push vs pull — 시퀀스형 코치마크는 읽히지 않음.

### 5.1 컴포넌트

```dart
/// Semi-transparent overlay with spotlight on target widget
class CoachMarkOverlay extends StatelessWidget {
  final GlobalKey targetKey;     // 하이라이트할 위젯의 키
  final String title;            // 말풍선 제목
  final String description;      // 말풍선 설명
  final String actionLabel;      // CTA 버튼 텍스트
  final VoidCallback onAction;   // CTA 탭 시 동작
  final VoidCallback onDismiss;  // 닫기
  final CoachMarkPosition position; // 말풍선 위치 (위/아래/좌/우)
}
```

### 5.2 코치마크 시퀀스

```
[홈 화면 첫 진입]
  ↓ 자동
CoachMark 1: 설정 탭 하이라이트
  "레슨 가능 시간을 설정하세요"
  [설정하러 가기] → 설정 화면 이동
  ↓ 완료 후 홈 복귀
CoachMark 2: 학생 탭 하이라이트
  "첫 학생을 초대해보세요"
  [학생 추가하기] → 학생 추가 화면
  ↓ 완료 후 홈 복귀
CoachMark 3: + 버튼 하이라이트
  "첫 레슨을 등록해보세요"
  [레슨 추가하기] → 레슨 추가 화면
  ↓ 완료 후
CelebrationSheet: "기본 설정 완료! 🎉"
  → 퀘스트 보드로 전환 (Phase C)
```

## 6. 학생 온보딩 개선

### 현재 문제

- 4페이지 패시브 슬라이드 → 기억에 남지 않음
- 프로필 완성 단계가 항상 `true`로 하드코딩

### 개선안

```
[Phase A: 즉시 시작]
  로그인 → 이름 + 악기 → 홈 즉시 진입

[Phase B: 코치마크 가이드]
  CoachMark 1: "선생님과 연결하기" → 초대 코드 입력 or 검색
  CoachMark 2: "연습 기록하기" → 연습 타이머 시작
  CoachMark 3: "메트로놈 사용하기" → 메트로놈 화면

[Phase C: 보상 퀘스트]
  ○ 첫 연습 완료 → 연습 스트릭 시작
  ○ 첫 녹음 → 선생님에게 공유 가능
  ○ 프로필 사진 → 선생님 화면에서 아이콘 표시
```

## 7. 기존 v1 vs v3 비교

| 항목 | v1 (현재) | v3 (제안) |
|------|----------|----------|
