## 개요

연습 시스템에 메트로놈 기능을 통합하여:
1. **연습 중 메트로놈 사용** - 별도 앱 전환 없이 인앱 메트로놈
2. **녹음 시 메트로놈 적용** - 이어폰으로 듣고 녹음에는 포함 안 됨
3. **BPM 기록 관리** - 선생님/학생 모두 확인 가능

### 핵심 사용자 스토리

```
선생님: "스즈키6권 라폴리아 1~10 메트로놈:60으로 연습해오세요"
         → 섹션에 목표 BPM 60 설정

학생:   "메트로놈 60으로 4번 연습했어요"
         → BPM 60 사용 기록 4회 저장
         → 녹음 시 메트로놈 ON 상태로 녹음 (이어폰 필수)

선생님: 레슨 시 학생의 연습 기록 확인
         → "BPM 60 x 4회" 표시 확인
         → 녹음 재생하여 템포 확인
```

## 데이터 모델 변경

### MetronomeSettings (신규)

```dart
class MetronomeSettings {
  final int bpm;                    // 40~208
  final TimeSignature timeSignature; // 박자표
  final MetronomeSound sound;        // 소리 종류
  final bool visualFlash;            // 시각 플래시 여부

  const MetronomeSettings({
    this.bpm = 60,
    this.timeSignature = TimeSignature.fourFour,
    this.sound = MetronomeSound.click,
    this.visualFlash = false,
  });
}

enum TimeSignature {
  twoFour,   // 2/4
  threeFour, // 3/4
  fourFour,  // 4/4 (기본)
  sixEight,  // 6/8
}

enum MetronomeSound {
  click,      // 기본 클릭
  woodblock,  // 우드블록
  cowbell,    // 카우벨
  digital,    // 디지털
  silent,     // 무음 (시각만)
}
```

## UI 설계

### 디자인 컨셉: "고양이 메트로놈"

어린이 사용자를 고려한 친근한 비주얼:
- **비트 시각화**: 고양이 두 마리가 눈을 감았다 뜨는 애니메이션
- **박자별 표현**:
  - 4/4박: 🐱🐱 두 마리가 번갈아 눈 깜빡
  - 3/4박: 🐱 한 마리가 한쪽 눈만 깜빡 (윙크)
  - 2/4박: 🐱🐱 두 마리가 동시에 깜빡

```
4/4 박자 예시:
    1박       2박       3박       4박
  😺 😸    😸 😺    😺 😸    😸 😺
  (왼쪽뜸) (오른쪽뜸) (왼쪽뜸) (오른쪽뜸)

3/4 박자 예시 (윙크 고양이):
    1박       2박       3박
   😉        😺        😉
  (왼눈윙크)  (양눈뜸)  (오른눈윙크)
```

### 1. 메트로놈 컨트롤러 위젯 (하단 고정 바)

연습 화면 하단에 컴팩트하게 고정:

```
┌─────────────────────────────────────────────────────────┐
│  😺😸  │  60 BPM  │  [-5] ━━●━━━ [+5]  │  ▶  │  ⚙️     │
│ 고양이   숫자탭     슬라이더+버튼      재생   설정      │
└─────────────────────────────────────────────────────────┘
```

**구성 요소:**
- 고양이 비트 인디케이터 (작은 크기)
- BPM 숫자 (탭하면 직접 입력)
- 슬라이더 + -5/+5 버튼
- 재생/정지 버튼
- 설정 버튼 (풀스크린 모달 열기)

## 기술 구현

### 오디오 엔진

| 옵션 | 장점 | 단점 |
|------|------|------|
| `audioplayers` | 간단, 크로스플랫폼 | 정밀도 낮음 |
| `just_audio` | 고품질, 스트리밍 | 오버헤드 |
| `flutter_soloud` | 저지연, 게임용 | 복잡도 |
| **네이티브 (추천)** | 최고 정밀도 | 플랫폼별 구현 |

**권장**: Phase 1은 `audioplayers`, Phase 2에서 필요시 네이티브 전환

### 정밀 타이밍

```dart
class MetronomeEngine {
  Timer? _timer;
  int _bpm = 60;

  void start() {
    final interval = Duration(milliseconds: (60000 / _bpm).round());
    _timer = Timer.periodic(interval, (_) => _playClick());
  }

  void _playClick() {
    // 오디오 재생 + 시각 피드백
    HapticFeedback.lightImpact(); // 진동
    _audioPlayer.play(AssetSource('sounds/click.mp3'));
  }
}
```

### 녹음 시 메트로놈 분리

```dart
// 이어폰 감지
bool get hasHeadphones => // Platform-specific check

// 녹음 시작 전 체크
if (metronomeEnabled && !hasHeadphones) {

    title: '이어폰을 연결해주세요',
    message: '메트로놈 소리가 녹음에 포함되지 않도록 이어폰이 필요합니다.',
  );
  return;
}

// 녹음은 마이크만, 메트로놈은 이어폰으로만 출력
```

## 학생 → 선생님 템플릿 플로우

```
선생님 앱                              학생 앱
───────────                          ─────────
과제 등록                              과제 확인
├─ 라폴리아 1~10                       ↓
├─ 목표 BPM: 60           ───→      "연습으로 등록"
└─ 박자: 4/4                          ↓
                                    연습 레퍼토리에 추가
                                    ├─ 라폴리아 1~10
                                    ├─ 기본 BPM: 60 (선생님 설정에서 복사)
                                    └─ 박자: 4/4
                                        ↓
                                    학생이 자유롭게 BPM 조절하며 연습
                                    (55 → 58 → 60 점진적 증가)
                                        ↓
                                    연습 기록 저장
                                    ├─ 12/25: BPM 55
                                    ├─ 12/26: BPM 58
                                    └─ 12/27: BPM 60 ✓ 목표 달성
```

## 고양이 비트 인디케이터 상세 스펙

### 발바닥 애니메이션 (Paw Animation)

"툭 올려놓기" 모션으로 비트를 시각적으로 표현합니다.

#### 드롭 애니메이션
| 파라미터 | 값 |
|----------|-----|
| Duration | 140ms |
| Easing | cubic-bezier(0.22, 0.61, 0.36, 1) |

#### BPM별 기본 드롭 거리
| BPM 범위 | 기본 거리 |
|----------|-----------|
| < 90 | 12px |
| 90~119 | 8px |
| ≥ 120 | 5px |

#### 박자별 드롭 배수
| 박자 유형 | 배수 | 설명 |
|----------|------|------|
| 강박 (1박) | 3.0x | 가장 큰 움직임 |
| 중간박 (3박, 4/4에서) | 2.0x | 중간 움직임 |
| 약박 (2, 4박) | 1.4x | 작은 움직임 |

#### 스케일 애니메이션
| 파라미터 | 값 |
|----------|-----|
| Duration | 120ms |
| Curve | easeOut |

| 박자 유형 | 스케일 피크 | 조건 |
|----------|------------|------|
| 강박 | 1.06 | BPM < 120 |
| 중간박 | 1.03 | BPM < 120 |
| 약박 | 1.0 (없음) | - |
| 고속 (≥120 BPM) | 1.0 (없음) | 모든 박자 |

#### 투명도 (Opacity)
| 상태 | 투명도 |
|------|--------|
| 비활성 | 0.4 (40%) |
| 활성 - 강박/중간박 | 1.0 (100%) |
| 활성 - 약박 (strongMediumWeak 패턴) | 0.85 (85%) |

### Compact 모드 (하단 컨트롤러 바)

하단 바의 고양이는 발바닥 대신 **깜박임 효과**로 박자 표현:

| 파라미터 | 값 |
|----------|-----|
| Duration | 100ms |
| 스케일 피크 | 1.15 |
| Curve | easeOut |
