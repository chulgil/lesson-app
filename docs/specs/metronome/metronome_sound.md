# 사운드 컨셉

성인들이 메트로놈 용도로 사용할 수 있는 안정적인 사운드 이펙트를 제작하려고 합니다.
총 4개의 버전으로 구성될 예정이며, 각각은 다음과 같은 박자 강약 패턴을 담고 있어야 합니다:
	1.	강 (Strong Beat Only)
	2.	약 (Weak Beat Only)
	3.	중간 (Medium Beat Only)
	4.	전체 (4박자 패턴: 강 - 약 - 중간 - 약)

요청 조건:
	•	전자음이 아닌 자연스러운 음색을 사용해주세요.
	•	악기 연습 시 사용하기 때문에 거슬리지 않고 명료한 소리여야 합니다.
	•	반복 재생에 적합하도록 톤의 일관성과 심플한 디자인을 유지해주세요.

이런 사운드는 집중을 방해하지 않으면서도 박자를 명확하게 인지할 수 있어야 합니다. 편안한 연습 환경을 돕는 메트로놈 효과음으로 완성되길 바랍니다.

컨셉은 나무가 부딪히는 느낌으로 중후한 소리로 탁탁탁탁 소리가 나도록 


## 기쁜고양이 

> 좋은 음악을 실컷 듣고 아주 기쁜 고양이 버전이에요. 
> 밝고 통통 튀는 “냐!”(nya!) 느낌, 짧게 위로 스쿱해서 올라간 뒤 살짝 안정되는 피치, 
> 그리고 **1박에만 아주 조그만 ‘딩’(토이벨)**을 얹어 아이들도 박을 쉽게 잡도록 했어요. 
> 특정 캐릭터 IP를 그대로 베끼지 않고, 고전 카툰풍의 기분 좋은 에너지만 담았습니다.

### 사운드 포인트
	•	밝은 미드~하이 톤(기쁜 표정처럼 F2가 높은 “ny” 질감 → 후반엔 살짝 “a”).
	•	스쿱 업(↑) + 짧은 홀드 + 가벼운 안정(↘): 활짝 웃는 “냐!” 제스처.
	•	짧은 트윙클(sparkle): 1박만 살짝 반짝여서 따라치기 쉬움.
	•	길이: 약 0.25s (빠른 템포도 부담 없이 사용 가능).

### 사운드파일

	•	강(1박) – happy_kitten_strong.wav
	•	중간(3박) – happy_kitten_medium.wav
	•	약(2·4박) – happy_kitten_weak.wav
	•	1마디 루프(120BPM, 강-약-중간-약) – happy_kitten_bar_120bpm.wav￼

### 튜닝 팁
	•	더 발랄하게: 1박 벨을 +1dB 올리거나, 업 스쿱을 280–320 cents로 확장.
	•	더 차분하게: 트윙클 제거, 스쿱을 150–180 cents로 축소.
	•	수업용: 강박만 중앙, 약박은 ±8% 팬 분산 → 재미 + 구분감 ↑.
