## 개요

### 설계 원칙

| 원칙 | 설명 |
|------|------|
| **심플** | 학생 앱과 동일한 심플한 디자인 톤 유지 |
| **재사용** | 캘린더, 카드, 배지 등 공통 컴포넌트 재사용 |
| **일관성** | 3앱 (선생님/학생/학부모) 동일한 UX 패턴 |

### 공통 재사용 컴포넌트

| 컴포넌트 | 위치 | 사용처 |
|----------|------|--------|
| `WeekCalendarWidget` | `core/widgets/` | 스케줄 탭 (주간/월간 토글 내장) |
| `StudentSubscriptionBadge` | `features/students/` | 학생 카드, 상세 화면 |
| `StudentClassBadge` | `features/students/` | 학원/개인 구분 배지 |
| `LessonCard` | `features/lessons/` | 레슨 목록 |
| `StatCard` | `core/widgets/` | 통계 카드 (홈, 학생 상세) |

## 네비게이션 구조

```
BottomNavigationBar (4탭)
├── [0] 홈 (HomeTab)           ← 대시보드 형태 (캘린더 없음)
├── [1] 스케줄 (CalendarTab)   ← WeekCalendarWidget (월간/주간 토글 내장)
├── [2] 학생 (StudentsTab)
└── [3] 프로필 (ProfileTab)
```

### 1.2 주요 기능

| 영역 | 기능 | 탭/네비게이션 |
|------|------|--------------|
| AppBar 알림 | 알림 목록 | → `/notifications` |
| AppBar 예약 | 승인 대기 목록 | → `/pending-bookings` |
| 핵심 통계 | 오늘 레슨, 미수금, 이번 달 완료 | - |
| 즉시 확인 필요 | 레슨 요청, 미수금 | → 해당 화면으로 이동 |
| 오늘의 레슨 | 레슨 카드 탭 (최대 3개) | → `/lessons/{id}` |
| 전체보기 | 3개 초과 시 스케줄 탭 전환 | → 스케줄 탭 |

## 2. 스케줄 탭

> **변경 (2026-03-02)**: WeekCalendarWidget 월간/주간 토글 기반으로 스펙 정리

### 2.1 화면 구성

```
┌─────────────────────────────────────────┐
│ 스케줄                          [+ 추가]│  ← AppBar
├─────────────────────────────────────────┤
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │  [<]    2026년 2월    [오늘]  [>]  │ │  ← WeekCalendarWidget 헤더
│ │  일  월  화  수  목  금  토         │ │     헤더 탭: 월간 ↔ 주간 토글
│ │   2   3   4  [5]  6   7   8        │ │     주간 뷰 (기본)
│ └─────────────────────────────────────┘ │
│                                         │
│ 2월 5일 (수) · 3개 레슨  [정렬 ▼]      │  ← 날짜 + 레슨 수 + 정렬
│ ┌─────────────────────────────────────┐ │
│ │ 14:00  김민수 🎻  🏫 ○○음악학원     │ │  ← LessonCard (재사용)
│ │ 15:00  박철수 🎻  👤 개인레슨       │ │
│ │ 16:00  이수진 🎹  👤 개인레슨       │ │
│ └─────────────────────────────────────┘ │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 캘린더 뷰 모드

`WeekCalendarWidget`의 내장 토글로 전환 (월/년 헤더 탭으로 확장/축소)

| 뷰 | 동작 | 레슨 표시 |
|----|------|-----------|
| **주간** (기본) | 한 주 날짜 표시, 좌우 화살표로 주 이동 | 선택 날짜의 레슨 |
| **월간** (확장) | 월 헤더 탭으로 전체 달력 확장 | 선택 날짜의 레슨 |

### 2.3 헤더 구성

| 요소 | 설명 |
|------|------|
| 이전/다음 화살표 | 주간/월간 단위 이동 |
| 월/년 텍스트 | 탭하면 월간 ↔ 주간 토글 |
| [오늘] 버튼 | 오늘 날짜로 이동 |
| + 추가 버튼 | 레슨 추가 화면으로 이동 |
| 정렬 드롭다운 | 시간순 / 이름순 선택 |
