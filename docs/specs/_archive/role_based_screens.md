## 플랫폼 구분

| 플랫폼 | 역할 | 설명 |
|--------|------|------|
| **앱 (iOS/Android)** | 선생님 | 레슨/학생 관리, 개인레슨 수강권 발급 |
| **앱 (iOS/Android)** | 학생 | 연습, 레슨 확인, 과제 수행 |
| **앱 (iOS/Android)** | 학부모 | 자녀 모니터링, 결제 관리 |
| **웹** | 학원 매니저 | 학원 운영, 강사/학생 관리, 수강권 발급 |

> **Note**: 이 문서는 **앱** 화면만 다룹니다. 웹 관리자 화면은 별도 스펙으로 관리됩니다.

## 1. 선생님 앱 (Teacher App)

> **상세 화면 설계**: [teacher_app_screens.md](teacher_app_screens.md) 참조

### 1.1 화면 목록

| 탭 | 경로 | 설명 |
|----|------|------|
| 홈 | `/` | 핵심 통계, 긴급 알림, 오늘의 레슨 (캘린더 없음) |
| 스케줄 | `/lessons` | 뷰 선택 (전체/주간/일간) + 캘린더 + 레슨 목록 |
| 학생 | `/students` | 클래스별 그룹화된 학생 목록 |
| 프로필 | `/profile` | 내 정보, 가용 시간, 설정 |

### 1.2 핵심 기능

| 기능 | 화면 | 연관 스펙 |
|------|------|----------|
| 다중 옵션 제안 | 프로필 > 가용 시간 설정 | [Multi_Option_Schedule_Spec.md Part B](../lesson/Multi_Option_Schedule_Spec.md) |
| 수강권 발급 | 학생 상세 > 수강권 | [subscription_system_spec.md](../subscription/subscription_system_spec.md) |
| 미수금 관리 | 프로필 > 미수금 관리 | [subscription_system_spec.md 섹션 5.7](../subscription/subscription_system_spec.md) |

### 1.3 재사용 컴포넌트

| 컴포넌트 | 사용처 |
|----------|--------|
| `WeekCalendarWidget` | 스케줄 탭 주간 뷰 |
| `CollapsibleCalendar` | 스케줄 탭 월간 뷰 |
| `StudentSubscriptionBadge` | 학생 카드, 레슨 카드 |
| `StudentClassBadge` | 학원/개인 구분 |
| `StatCard` | 홈 통계, 학생 상세 |

## 4. 공통 컴포넌트

### 4.1 컨텍스트 배지

모든 화면에서 일관되게 사용하는 컨텍스트 배지입니다.

| 배지 | 의미 | 사용 위치 |
|------|------|----------|
| 🏫 학원명 | 학원 소속 | 학생 목록, 레슨 일정, 수강권 |
| 👤 개인레슨 | 선생님 직접 연결 | 학생 목록, 레슨 일정, 수강권 |
| 💻 온라인 | 온라인 레슨 | 레슨 장소, 레슨 일정 |
| 🎟️ N회 | 회차제 수강권 | 수강권 현황 |
| 📅 월정액 | 기간제 수강권 | 수강권 현황 |
| 🆓 체험 | 체험 레슨 | 수강권 현황, 학생 목록 |

### 4.2 수강권 상태 표시

| 상태 | 표시 | 색상 |
|------|------|------|
| 정상 | 잔여 N회 / 총 N회 | 기본색 |
| 임박 (잔여 2회 이하) | ⚠️ 잔여 N회 | 주황색 |
| 만료 임박 (D-7 이내) | ⚠️ D-N | 주황색 |
| 만료됨 | ❌ 만료됨 | 빨간색 |
| 미결제 | ⚠️ 미수금 | 빨간색 |

### 4.3 알림 우선순위

| 우선순위 | 알림 종류 | 표시 방식 |
|----------|----------|----------|
| 1 (긴급) | 결제 기한 D-day, 미수금 | 빨간 배지 + 상단 고정 |
| 2 (높음) | 결제 요청, 수강권 임박 | 주황 배지 |
| 3 (보통) | 새 과제, 레슨 변경 | 기본 알림 |
| 4 (낮음) | 연습 완료, 스트릭 달성 | 선택적 알림 |
