# 일괄 피드백 전송 스펙

> 작성일: 2026-03-12
> 상태: 미구현

---

## 1. 개요

레슨 종료 후 선생님이 학생 한 명씩 피드백을 작성하는 것은 시간 소모가 크다. 같은 반·같은 과제를 진행한 학생들에게 공통 피드백을 한 번에 전송하고, 개별 코멘트만 추가하는 "일괄 피드백" 기능을 제공한다.

**비유**: 학교 선생님이 시험지 채점 후 공통 총평을 칠판에 쓰고, 개별 코멘트만 시험지에 적는 것과 같다.

**핵심 가치**: 5명 학생 피드백을 5분 → 1분으로 단축

---

## 2. 현재 상태 (AS-IS)

| 항목 | 상태 |
|------|------|
| 피드백 작성 | 레슨 상세 → 1명씩 개별 작성 |
| QuickFeedback | 레슨 1건 전용 (개별) |
| 일괄 전송 | 미지원 |
| 공통 피드백 | 개념 없음 |

---

## 3. 목표 상태 (TO-BE)

### 3.1 UX 원칙

- **공통 → 개별 순서**: 공통 피드백 먼저 작성 → 학생별 개별 추가 (선택)
- **학생 선택 간편성**: 오늘 레슨 학생 자동 선택, 체크박스로 제외
- **미리보기**: 전송 전 각 학생에게 전달될 최종 피드백 확인

### 3.2 기능 범위

| 기능 | 우선순위 | 설명 |
|------|----------|------|
| 학생 다중 선택 | HIGH | 오늘 레슨 학생 중 선택 |
| 공통 피드백 작성 | HIGH | 프리셋 칩 + 자유 텍스트 |
| 개별 추가 코멘트 | MEDIUM | 학생별 한 줄 추가 (선택) |
| 전송 미리보기 | MEDIUM | 최종 결과 확인 후 전송 |
| 과제 일괄 지정 | LOW | 공통 과제 + 개별 과제 |
| 템플릿 저장 | LOW | 자주 쓰는 일괄 피드백 저장 |

## 4. 상세 설계

### 4.1 진입점

```
스케줄 탭 → 오늘 레슨 요약 바 → [일괄 피드백] 버튼
또는
레슨 목록 → 상단 [📝 일괄 피드백] FAB
```

- 오늘 완료된 레슨이 2개 이상일 때만 버튼 노출
- 미완료 레슨도 선택 가능 (사전 준비 피드백)

### 4.2 UI 플로우

#### Step 1: 학생 선택

```
┌─────────────────────────────────┐
│ 일괄 피드백                      │
│                                 │
│ 오늘의 레슨 (5명)                │
│ ☑ 김하은  바이올린  14:00  ✓완료  │
│ ☑ 이서준  첼로      15:00  ✓완료  │
│ ☑ 박지민  바이올린  16:00  진행중 │
│ ☐ 최우진  비올라    17:00  예정   │
│ ☑ 정수아  바이올린  18:00  ✓완료  │
│                                 │
│ 3명 선택됨                       │
│                                 │
│          [다음: 피드백 작성 →]    │
└─────────────────────────────────┘
```

- 완료 상태 레슨은 기본 선택
- 악기별 필터 탭 (전체 / 바이올린 / 첼로 ...)

#### Step 2: 공통 피드백 작성

```
┌─────────────────────────────────┐
│ 공통 피드백 (3명에게 전송)        │
│                                 │
│ [+] [음정 주의] [활 주법] [진도↑] │
│ ┌──────────────────────────────┐│
│ │ 오늘 수업에서 비브라토 연습을  ││
│ │ 집중적으로 했습니다.          ││
│ │ 다음 주까지 연습곡 2번 반복   ││
│ │ 연습 부탁드립니다.           ││
│ └──────────────────────────────┘│
│                                 │
│ ── 개별 추가 (선택) ──           │
│ 김하은: [포지션 이동 연습 추가]   │
│ 이서준: [                    ]   │
│ 정수아: [보잉 속도 주의]         │
│                                 │
│    [← 이전]    [미리보기 →]      │
└─────────────────────────────────┘
```

- 프리셋 칩은 커스텀 프리셋 Provider 연동
- 개별 추가는 접힌 상태 (탭하면 펼침) — 필수 아님

#### Step 3: 미리보기 & 전송

```
┌─────────────────────────────────┐
│ 피드백 미리보기                   │
│                                 │
│ ┌─ 김하은 ─────────────────────┐│
│ │ 오늘 수업에서 비브라토 연습을  ││
│ │ 집중적으로 했습니다.          ││
│ │ 다음 주까지 연습곡 2번 반복   ││
│ │ ---                          ││
│ │ 📌 포지션 이동 연습 추가      ││
│ └──────────────────────────────┘│
│                                 │
│ ┌─ 이서준 ─────────────────────┐│
│ │ (공통 피드백만)               ││
│ └──────────────────────────────┘│
│                                 │
│ ┌─ 정수아 ─────────────────────┐│
│ │ (공통 + 📌 보잉 속도 주의)    ││
│ └──────────────────────────────┘│
│                                 │
│      [← 수정]   [✓ 전송 (3명)]  │
└─────────────────────────────────┘
```

### 4.3 데이터 플로우

```
1. 학생 선택 → lessonIds 수집
2. 공통 피드백 텍스트 + 개별 추가 Map<lessonId, String>
3. 전송 시: 각 Lesson의 feedback 필드에 병합 저장
   - lesson.feedback = "$commonFeedback\n---\n$individualNote"
   - lesson.keyPoints += 공통 핵심포인트
4. LessonsNotifier.updateLesson() 반복 호출 (batch)
```

## 6. 예외 처리

| 상황 | 처리 |
|------|------|
| 선택 학생 0명 | "최소 1명 이상 선택하세요" + 다음 버튼 비활성화 |
| 공통 피드백 비어있음 | 전송 불가 + "피드백을 입력하세요" 안내 |
| 이미 피드백 존재 | "기존 피드백에 추가할까요?" 확인 다이얼로그 |
| 전송 중 일부 실패 | 성공/실패 수 표시 + 실패 건 재시도 버튼 |
| 오늘 레슨 없음 | 진입점 버튼 숨김 |
