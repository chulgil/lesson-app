# 수강료 관리 요구사항

## 개요

음악 레슨 선생님을 위한 수강료 관리 시스템

---

## 배경

- 선생님은 무통장입금(계좌이체)으로 수강료를 받음
- 앱 내 결제 시스템이 아닌 수동 입금 확인 방식
- 학생마다 레벨에 따라 수강료가 다름
- 체험 레슨과 정규 레슨 금액이 다름
- 월 4회가 기본이지만, 중간에 시작하면 2~3주만 결제하는 경우도 있음

---

## 사용자 시나리오

### 시나리오 1: 신규 학생 체험 레슨
1. 신규 학생 등록 (체험 예정)
2. 체험 레슨 결제 추가 (30,000원, 12월 2주)
3. 학생이 입금 완료
4. 선생님이 입금 확인 버튼 클릭 → 완료 처리

### 시나리오 2: 체험 후 정규 레슨 시작
1. 12월 2주 체험 → 완료
2. 12월 3~4주 정규 레슨 결제 추가 (2회, 100,000원)
3. 1월부터 월 4회 정규 결제

### 시나리오 3: 기존 학생 월별 결제
1. 매월 초 자동 결제 생성 (예정)
2. 선생님이 입금 확인
3. 미납 시 알림 표시

---

## 기능 요구사항

### 1. 학생 레벨 시스템

| 레벨 | 기본 월 수강료 |
|------|----------------|
| 입문 | 160,000원 |
| 초급 | 180,000원 |
| 중급 | 200,000원 |
| 고급 | 240,000원 |

- 레벨별 기본 금액 설정
- 학생별 커스텀 금액 설정 가능

### 2. 결제 유형

#### 체험 레슨
- 1회성 레슨
- 기본 30,000원 (수정 가능)
- 특정 날짜 지정

#### 정규 레슨
- 월/주 단위 결제
- 주차 범위 선택 (1~4주, 또는 3~4주 등)
- 레슨 횟수 표시 (기본 주당 1회)

### 3. 결제 상태

| 상태 | 설명 |
|------|------|
| 대기 | 입금 대기 중 |
| 완료 | 입금 확인됨 |
| 연체 | 납부기한 초과 |
| 취소 | 결제 취소 |
| 환불 | 환불 처리됨 |

### 4. 입금 확인 프로세스

#### Phase 1 (현재 구현)
- 선생님이 직접 입금 확인 후 버튼 클릭

#### Phase 2 (향후 계획)
1. 학생이 앱에서 "입금완료" 체크
2. 선생님 화면에 "학생 입금완료 알림" 표시
3. 선생님이 실제 계좌 확인 후 "입금확인" 클릭
4. 최종 완료 처리

### 5. 알림 시스템 (향후)

#### 선생님 → 학생
- 결제 요청 알림
- 미납 알림

#### 학생 → 선생님
- 입금 완료 알림
