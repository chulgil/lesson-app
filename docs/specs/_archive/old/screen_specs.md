## 1. 로그인/회원가입

### 1.1 화면 개요

| 항목 | 내용 |
|------|------|
| **화면 ID** | AUTH-001, AUTH-002 |
| **템플릿 참조** | 05 Login, 06 Signup |
| **사용자** | 모든 사용자 (비로그인) |
| **목적** | 앱 진입을 위한 인증 |

### 1.2 사용자 스토리

```
선생님으로서, 빠르게 로그인하여 오늘 레슨 일정을 확인하고 싶다.
학생으로서, 간편하게 가입하여 선생님이 등록해준 레슨을 확인하고 싶다.
```

```yaml
  response: [Lesson]

  response: [{ student, practice_status }]
```
