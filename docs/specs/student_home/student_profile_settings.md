# 학생 프로필 설정 화면 스펙

> Last updated: 2026-03-08

## 1. 개요

학생 프로필 탭(`StudentProfileTab`)의 설정 섹션에서 접근하는 5개 하위 화면의 상세 스펙.
스마트폰의 '설정' 앱처럼, 각 메뉴를 탭하면 해당 설정 화면으로 이동한다.

**대상 화면:**

| # | 이슈 | 화면 | 복잡도 |
|---|------|------|:------:|
| 1 | #77 | 도움말 화면 | S |
| 2 | #78 | 앱 정보 화면 | S |
| 3 | #79 | 다크 모드 토글 | S |
| 4 | #80 | 언어 설정 | S |
| 5 | #81 | 알림 설정 화면 | S |

---

## 2. 화면별 상세

### 2.1 도움말 화면 (#77)

**진입**: 프로필 탭 > 설정 > 도움말

**기능:**
- 자주 묻는 질문(FAQ) 목록을 아코디언(ExpansionTile)으로 표시
- 각 항목: 질문(제목) + 답변(본문)
- 하단에 고객 지원 연락처 표시

**UI 구조:**
```
/settings/help
┌──────────────────────────────────┐
│  <- 도움말                        │
├──────────────────────────────────┤
│                                  │
│  자주 묻는 질문                    │
│                                  │
│  ┌─ Q. 레슨은 어떻게 예약하나요? ─┐│
│  │ 홈 화면에서 스케줄 탭을 선택... ││
│  └──────────────────────────────┘│
│                                  │
│  ┌─ Q. 연습 기록은 어떻게... ────┐│
│  │  (접힌 상태)             >   ││
│  └──────────────────────────────┘│
│                                  │
│  ┌─ Q. 녹음 파일 백업은... ─────┐│
│  │  (접힌 상태)             >   ││
│  └──────────────────────────────┘│
│                                  │
│  ┌─ Q. 메트로놈 사용법... ──────┐│
│  │  (접힌 상태)             >   ││
│  └──────────────────────────────┘│
│                                  │
│  ┌─ Q. 수강권이 만료되면... ────┐│
│  │  (접힌 상태)             >   ││
│  └──────────────────────────────┘│
│                                  │
│  ──────────────────────────────  │
│                                  │
│  도움이 필요하신가요?              │
│  📧 support@lessonaza.com        │
│  [문의하기] 버튼                   │
│                                  │
└──────────────────────────────────┘
```

**데이터**: 정적 FAQ 목록 (하드코딩). 향후 서버에서 가져올 수 있도록 리스트 구조 사용.

**FAQ 항목 (초기):**

| 질문 | 답변 |
|------|------|
| 레슨은 어떻게 예약하나요? | 홈 화면에서 스케줄 탭을 선택한 후, 우측 상단의 '예약' 버튼을 탭하세요. 선생님을 선택하고 원하는 시간을 골라 예약할 수 있습니다. |
| 연습 기록은 어떻게 확인하나요? | 하단 네비게이션의 '연습' 탭에서 날짜별 연습 기록을 확인할 수 있습니다. 레퍼토리별로 섹션을 관리하고 완료 여부를 체크할 수 있습니다. |
| 녹음 파일은 어떻게 백업하나요? | 프로필 > 녹음 백업에서 전체 백업을 생성할 수 있습니다. 백업 파일은 공유 기능으로 클라우드에 저장하세요. |
| 메트로놈은 어떻게 사용하나요? | 연습 화면에서 중앙 하단의 연습 도구 버튼을 탭하면 메트로놈, 튜너 등의 도구를 사용할 수 있습니다. |
| 수강권이 만료되면 어떻게 되나요? | 수강권이 만료되면 레슨 예약이 제한됩니다. 선생님에게 새 수강권 발급을 요청하거나, 홈 화면의 수강권 섹션에서 상태를 확인하세요. |
| 학부모님을 어떻게 초대하나요? | 프로필 탭에서 '학부모 초대'를 탭하면 초대 코드가 생성됩니다. 코드를 학부모님께 공유하면 앱에서 연결됩니다. |

**"문의하기" 버튼**: `url_launcher`로 이메일 앱 열기 (`mailto:support@lessonaza.com`)

### 2.2 앱 정보 화면 (#78)

**진입**: 프로필 탭 > 설정 > 앱 정보

**기능:**
- 앱 이름, 버전, 빌드 번호 표시
- 이용약관 / 개인정보처리방침 링크
- 오픈소스 라이선스 보기 (`showLicensePage`)

**UI 구조:**
```
/settings/app-info
┌──────────────────────────────────┐
│  <- 앱 정보                       │
├──────────────────────────────────┤
│                                  │
│         [앱 아이콘]                │
│         Lessonaza                │
│         버전 1.0.0 (1)           │
│                                  │
│  ──────────────────────────────  │
│                                  │
│  ┌ 이용약관                   > ┐│
│  └──────────────────────────────┘│
│  ┌ 개인정보처리방침            > ┐│
│  └──────────────────────────────┘│
│  ┌ 오픈소스 라이선스           > ┐│
│  └──────────────────────────────┘│
│                                  │
│  ──────────────────────────────  │
│                                  │
│      © 2026 Lessonaza            │
│      Made with ♥                 │
│                                  │
└──────────────────────────────────┘
```

**패키지 의존성**: `package_info_plus` (이미 pubspec에 있는지 확인 필요)

**동작:**
- 이용약관/개인정보처리방침: 현재 URL이 없으므로 "준비 중입니다" SnackBar 표시
- 오픈소스 라이선스: Flutter 기본 `showLicensePage()` 호출
- 버전/빌드: `PackageInfo.fromPlatform()`에서 가져오되, 실패 시 하드코딩 폴백

### 2.3 다크 모드 토글 (#79)

**진입**: 프로필 탭 > 설정 > 다크 모드 Switch

**현재 상태**: 앱이 라이트 모드만 지원. 다크 테마 미구현.

**Phase A 구현 범위:**
- Switch 토글 시 "다크 모드는 준비 중입니다" SnackBar 표시
- Switch는 항상 `false` 상태 유지 (비활성)

**향후 계획 (Phase 4+):**
- Hive에 `isDarkMode` 저장
- `ThemeMode.dark` / `ThemeMode.light` 전환
- `AppColors`를 다크 테마 대응으로 확장

**UI 변경**: 기존 `student_profile_tab.dart`의 다크 모드 Switch에 SnackBar 콜백 추가. 별도 화면 불필요.

### 2.4 언어 설정 (#80)

**진입**: 프로필 탭 > 설정 > 언어

**현재 상태**: 한국어만 지원. 다국어(i18n) 미구현.

**Phase A 구현 범위:**
- 탭 시 "현재 한국어만 지원됩니다. 다른 언어는 준비 중입니다." SnackBar 표시
- 별도 화면 불필요

**향후 계획 (Phase 4+):**
- `flutter_localizations` + `intl` 패키지 활용
- 한국어(ko), 영어(en) 지원
- Hive에 `locale` 저장
- 언어 선택 화면 (라디오 버튼 리스트)

### 2.5 알림 설정 화면 (#81)

**진입**: 프로필 탭 > 설정 > 알림 설정

**현재 상태**: FCM 미연동. 푸시 알림 미구현.

**Phase A 구현 범위:**
- 별도 알림 설정 화면으로 이동
- 카테고리별 알림 ON/OFF 스위치 (로컬 상태만, Hive 저장)
- 실제 푸시 알림 발송은 하지 않음 (UI 선행 구현)

**UI 구조:**
```
/settings/notifications
┌──────────────────────────────────┐
│  <- 알림 설정                     │
├──────────────────────────────────┤
│                                  │
│  전체 알림                        │
│  ┌ 알림 받기               [ON] ┐│
│  │ 모든 알림을 켜거나 끕니다     ││
│  └──────────────────────────────┘│
│                                  │
│  ──────────────────────────────  │
│                                  │
│  레슨 알림                        │
│  ┌ 레슨 시작 알림          [ON] ┐│
│  │ 레슨 30분 전 알림             ││
│  └──────────────────────────────┘│
│  ┌ 레슨 변경 알림          [ON] ┐│
│  │ 레슨 시간/일정 변경 시        ││
│  └──────────────────────────────┘│
│                                  │
│  수강권 알림                      │
│  ┌ 수강권 제안 알림        [ON] ┐│
│  │ 선생님이 수강권을 제안할 때    ││
│  └──────────────────────────────┘│
│  ┌ 수강권 만료 알림        [ON] ┐│
│  │ 수강권 만료 7일 전 알림       ││
│  └──────────────────────────────┘│
│                                  │
│  연습 알림                        │
│  ┌ 연습 리마인더           [ON] ┐│
│  │ 매일 설정한 시간에 알림       ││
│  └──────────────────────────────┘│
│  ┌ 선생님 피드백           [ON] ┐│
│  │ 선생님이 피드백을 남길 때     ││
│  └──────────────────────────────┘│
│                                  │
│  ⓘ 푸시 알림은 준비 중입니다.     │
│    알림 설정은 저장되며, 기능이    │
│    활성화되면 자동 적용됩니다.     │
│                                  │
└──────────────────────────────────┘
```

**데이터 모델:**

```dart
// Hive에 저장할 알림 설정
class NotificationSettings {
  bool allNotifications;       // 전체 알림
  bool lessonReminder;         // 레슨 시작 알림
  bool lessonChange;           // 레슨 변경 알림
  bool subscriptionProposal;   // 수강권 제안 알림
  bool subscriptionExpiry;     // 수강권 만료 알림
  bool practiceReminder;       // 연습 리마인더
  bool teacherFeedback;        // 선생님 피드백
}
```

**동작:**
- "전체 알림" OFF → 모든 개별 스위치 비활성화 (greyed out)
- "전체 알림" ON → 개별 스위치 활성화
- 변경 즉시 Hive에 저장 (별도 저장 버튼 없음)

## 3. 공통 사항

### 라우트

| 화면 | 라우트 경로 | 비고 |
|------|------------|------|
| 도움말 | `/settings/help` | 새 화면 |
| 앱 정보 | `/settings/app-info` | 새 화면 |
| 알림 설정 | `/settings/notifications` | 새 화면 |
| 다크 모드 | - | 인라인 Switch (화면 없음) |
| 언어 | - | 인라인 SnackBar (화면 없음) |

### 파일 위치

| 파일 | 위치 |
|------|------|
| HelpScreen | `features/student_home/presentation/screens/help_screen.dart` |
| AppInfoScreen | `features/student_home/presentation/screens/app_info_screen.dart` |
| NotificationSettingsScreen | `features/student_home/presentation/screens/notification_settings_screen.dart` |
| NotificationSettings entity | `features/student_home/domain/entities/notification_settings.dart` |
| NotificationSettings provider | `features/student_home/presentation/providers/notification_settings_provider.dart` |

### student_profile_tab.dart 변경 사항

| 메뉴 | 현재 | 변경 |
|------|------|------|
| 알림 설정 | Switch 스텁 + `onTap: () {}` | Switch 제거, `onTap` → 알림 설정 화면 이동 |
| 다크 모드 | Switch 스텁 `onChanged: (v) {}` | `onChanged` → "준비 중" SnackBar |
| 언어 | `onTap: () {}` | `onTap` → "준비 중" SnackBar |
| 도움말 | `onTap: () {}` | `onTap` → 도움말 화면 이동 |
| 앱 정보 | `onTap: () {}` | `onTap` → 앱 정보 화면 이동 |
