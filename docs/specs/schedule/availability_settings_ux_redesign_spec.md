# 가용시간 설정 UX 재설계 스펙

> 작성일: 2026-03-12
> 도메인: schedule
> 상태: 스펙 작성 (구현 전)

## 문제점

현재 가용시간 관리 화면(`TeacherAvailabilityScreen`)이 직관적이지 않아 선생님이 어떤 기능인지 이해하기 어려움.

### 현재 UX 문제

1. **용어 모호성**: "가용시간", "시간 예외", "슬롯" 등 기술적 용어 사용
2. **적용 기준 불명확**: 설정한 가용시간이 어디에 어떻게 반영되는지 안내 없음
3. **진입 경로 깊음**: 프로필 → 레슨 시간 설정 → 가용시간 관리 (3단계)
4. **시각적 피드백 부족**: 설정 후 실제 스케줄에 어떻게 반영되는지 미리보기 없음
5. **설정 항목 분산**: 슬롯 길이, 쉬는시간, 요일별 시간이 별도 화면

## 설계 원칙

1. **한눈에 이해**: 화면을 보자마자 "내 레슨 시간을 설정하는 곳"임을 인지
2. **실시간 미리보기**: 설정 변경 시 주간 스케줄 미리보기 즉시 반영
3. **가이드 텍스트**: 각 설정이 어디에 영향을 미치는지 안내

## UI 설계

### 화면 제목 변경

```
Before: 가용시간 관리
After:  레슨 운영 시간 설정
```

### 섹션 1: 주간 레슨 시간

**헤더**: "레슨하는 요일과 시간을 설정하세요"
**부제**: "설정한 시간이 스케줄과 학생 예약 화면에 반영됩니다"

| 요일 | 시작 | ~ | 종료 | 토글 |
|------|------|---|------|------|
| 월요일 | 14:00 | ~ | 18:00 | ON/OFF |
| 화요일 | 14:00 | ~ | 18:00 | ON |
| 수요일 | - | | - | OFF (쉬는날) |
| ... | | | | |

- 각 요일에 ON/OFF 토글
- OFF = 쉬는날 (스케줄에 회색 배경으로 표시)
- ON 시 시작/종료 시간 선택 (TimePicker)
- 같은 요일에 복수 시간대 지원 (예: 오전 10-12, 오후 14-18)
- "+ 시간대 추가" 버튼으로 복수 시간대 추가

### 섹션 2: 레슨 설정

**헤더**: "레슨 기본 설정"

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 레슨 길이 | 한 레슨의 기본 시간 | 50분 |
| 쉬는 시간 | 레슨 사이 휴식 | 10분 |
| 시작 간격 | 레슨 시작 가능 시간 간격 | 30분 |

각 항목에 도움말 텍스트:
- 레슨 길이: "학생이 예약 시 이 길이로 예약됩니다"
- 쉬는 시간: "연속 레슨 사이에 자동으로 쉬는 시간이 추가됩니다"
- 시작 간격: "30분이면 10:00, 10:30, 11:00 시작 가능"

### 섹션 3: 미리보기

**헤더**: "이번 주 예상 스케줄"

설정한 시간을 기반으로 한 주간 미니 그리드 미리보기:
- 가용시간 = 밝은 보라색 영역
- 쉬는날 = 회색 영역
- 기존 레슨 = 작은 색상 블록

### 섹션 4: 임시 휴무/추가 오픈

**헤더**: "특별 일정"
**부제**: "휴가, 공휴일, 추가 오픈 등을 관리합니다"

- 휴무 추가: 날짜 선택 + 사유 입력
- 추가 오픈: 평소 쉬는 날에 레슨 추가
- 리스트로 표시 (다가오는 것부터)

## 진입 경로 개선

### 현재

```
프로필 탭 → 레슨 시간 설정 → 가용시간 관리
```

### 개선안

```
프로필 탭 → "레슨 운영 시간" (직접 진입, 한 단계 줄임)
```

추가 진입:
- 스케줄 탭 빈 상태 → "레슨 시간을 먼저 설정하세요" CTA
- 온보딩 → 초기 시간 설정 안내

## 반영 범위

가용시간 설정이 영향을 미치는 곳:

| 화면 | 영향 |
|------|------|
| 타임라인 (일간) | 가용시간 범위만 표시 |
| 주간 그리드 | 쉬는날 진한 회색 배경 |
| 학생 예약 화면 | 가용 슬롯만 표시 |
| 레슨 추가 | 시간 선택 시 가용시간 우선 표시 |

## 관련 엔티티

- `TeacherAvailability` — 루트 엔티티
- `WeeklySchedule` — 요일별 시간 (dayOfWeek, startTime, endTime, isActive)
- `TimeException` — 임시 휴무/추가 오픈

## 관련 파일

| 파일 | 용도 |
|------|------|
| `teacher_availability_screen.dart` | 현재 메인 화면 (재설계 대상) |
| `weekly_schedule_screen.dart` | 주간 스케줄 설정 |
| `lesson_time_settings_widgets.dart` | 레슨 시간 설정 위젯 |
| `teacher_availability_providers.dart` | Provider |
