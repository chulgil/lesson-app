# 챗 화면 상태별 가이드 메시지 스펙

> 마지막 업데이트: 2026-04-04

## 설계 원칙

1. **상단 가이드 = 나에게 주는 가이드라인** — 내가 지금 해야 할 일 또는 대기 상태 안내
2. **title = 리스트 actionLabel과 동일** — 리스트 → 챗 화면 진입 시 일관된 상태 인지
3. **학생의 행동은 학생 말풍선에서** — 가이드에 반복하지 않음
4. **모든 상태에서 가이드 표시** — 빈 상단 금지

## 3레이어 구조

```
┌─────────────────────────────────────┐
│ [title chip] situation text         │  ← 상단 가이드 (정보창)
├─────────────────────────────────────┤
│ 🧑 학생 말풍선  |  선생님 말풍선 🧑‍🏫 │  ← 채팅 히스토리 (이벤트 기록)
├─────────────────────────────────────┤
│ [액션 버튼]                          │  ← 하단 액션 박스 (CTA)
└─────────────────────────────────────┘
```

- 상단 가이드와 하단 액션은 **같은 내용을 반복하지 않음**
- 채팅 말풍선은 과거 이벤트 사실만 표시
- 과거 챕터 펼칠 때 가이드 숨김 (`showGuide: false`)
- 색상: action(내 차례)=primary, wait(대기/종료)=grey (2색 원칙)

## 선생님 시점 전체 매트릭스

| 상태 | 리스트 라벨 | 상단 가이드 | 하단 액션 |
|------|-----------|-----------|----------|
| pending | 확인 필요 | 희망 시간을 확인하고 수락 또는 다른 시간을 제안해주세요 | 수락/역제안 버튼 |
| approved/negotiating | 응답 필요 / 응답 대기 | 시간을 수락하거나 다른 시간을 역제안해주세요 | 수락/역제안 버튼 |
| timeConfirmed | 제안 작성 | 수강권 종류와 결제 방법을 선택해 발급해주세요 | 발급 방법 선택 버튼 |
| proposalSent | 수락 대기 | 학생이 수락하면 알림을 드립니다 | 대기 메시지 |
| proposalAccepted | **입금 대기** | 학생이 입금하면 알림을 드립니다 | 대기 메시지 |
| paymentNotified | **입금 확인** | 입금을 확인하고 수강권을 발급해주세요 | 입금 확인 버튼 |
| subscriptionIssued | 수강권 발행 | 레슨을 시작할 준비가 완료되었습니다 | 수강권 요약 카드 + 상세 링크 |
| inProgress | 레슨 진행 | 레슨 후 출석 처리와 기록을 남겨주세요 | 수강권 요약 카드 + 상세 링크 |
| completed | 완료 | 모든 레슨 수강이 완료되었습니다 | 수강권 요약 카드 + 상세 링크 |
| rejected | 거절 | 이 레슨 요청을 거절했습니다 | - |
| cancelled | 취소 | 이 레슨 요청이 취소되었습니다 | - |
| expired | 기간만료 | 응답 기간이 지나 자동 종료되었습니다 | - |

## 학생 시점 전체 매트릭스

| 상태 | 리스트 라벨 | 상단 가이드 | 하단 액션 |
|------|-----------|-----------|----------|
| pending | 요청 전송됨 | 선생님의 응답을 기다리고 있습니다 | - |
| approved/negotiating | 응답 필요 / 선생님 응답 대기 | 제안된 시간을 확인하고 수락해주세요 | 수락/역제안 버튼 |
| timeConfirmed | 수강권 대기 | 선생님이 수강권 안내를 보내면 알림을 드립니다 | - |
| proposalSent | 수강권 도착 | 수강권 안내를 확인하고 수락 또는 거절해주세요 | 수락/거절 버튼 |
| proposalAccepted | **결제 필요** | 결제를 완료해주세요 | 입금 완료 버튼 |
| paymentNotified | 입금 확인 중 | 선생님이 확인하면 수강권이 발급됩니다 | 대기 메시지 |
| subscriptionIssued | 수강권발행 | 레슨을 시작할 준비가 완료되었습니다 | - |
| inProgress | 레슨진행 | 레슨 일정에 맞춰 참석해주세요 | - |
| completed | 완료 | 모든 레슨 수강이 완료되었습니다 | - |
| rejected | 거절 | 다른 선생님이나 시간을 변경해 다시 신청할 수 있습니다 | - |
| cancelled | 취소 | 이 레슨 요청이 취소되었습니다 | - |
| expired | 기간만료 | 다시 신청하시면 선생님에게 알림이 전송됩니다 | - |

## 채팅 말풍선 메시지 (이벤트별)

| 이벤트 | 말풍선 텍스트 | 발신자 |
|--------|-------------|--------|
| initialRequest | 레슨을 요청했습니다 | 학생 |
| approve | 요청을 수락했습니다 | 선생님 |
| reject | 레슨 요청을 거절했습니다 | 선생님 |
| proposeAlternative | 다른 시간을 제안했습니다 | 선생님 |
| acceptAlternative | 제안한 시간을 수락했습니다 | 학생/선생님 |
| proposalSent | 수강권 안내를 보냈습니다 | 선생님 |
| proposalAccepted | 수강권을 수락했습니다 | 학생 |
| paymentNotified | 입금했습니다 | 학생 |
| paymentConfirmed | 입금을 확인했습니다 | 선생님 |
| subscriptionIssued | 수강권이 발행되었습니다 | 시스템 |
| cancel | 요청을 취소했습니다 | 학생/선생님 |
| expire | 요청이 만료되었습니다 | 시스템 |
