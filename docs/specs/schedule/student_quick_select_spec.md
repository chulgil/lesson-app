# 스케줄 레슨추가 학생 퀵셀렉트 스펙

> 이슈: [#123](https://github.com/chulgil/lesson-app/issues/123)
> 작성일: 2026-03-11
> 상태: 구현 완료

---

## 1. 개요

레슨 추가 화면에서 학생 선택 영역 위에 최근 레슨한 학생 상위 5명을 아바타 칩으로 표시하여 빠른 선택을 지원한다.

---

## 2. UI 설계

### 2.1 퀵셀렉트 칩 영역

```
학생 선택

최근 레슨한 학생:
[🟣민수] [🟠지영] [🟢서연] [🔵현우] [🟡하나]

┌──────────────────────────────────┐
│ 🔘 학생을 선택하세요         >    │
└──────────────────────────────────┘
```

- 아바타(이니셜) + 이름 칩
- 칩 터치 시 해당 학생 즉시 선택 + 자동 채움
- 학생이 5명 미만이면 있는 만큼만 표시
- 학생이 0명이면 칩 영역 숨김

### 2.2 정렬 기준

최근 레슨 날짜(내림차순) 기준 상위 5명
