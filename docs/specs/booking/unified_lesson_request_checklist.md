# 통합 레슨 신청 — 유저 테스트 체크리스트

> **스펙 버전**: v2.0 (2026-03-28)
> **용도**: 구현 완료 후 수용 기준 검증 + QA 체크리스트
> **사용법**: 각 항목을 실제 기기에서 테스트하며 `[ ]` → `[x]`로 체크

---

## 1. 진입점

### 1-1. 새 학생 → 레슨 신청

- [ ] 선생님 검색 → 프로필 → [레슨 신청] 버튼이 표시된다
- [ ] [레슨 신청] 탭 시 통합 신청 폼으로 이동한다
- [ ] 폼 상단에 선생님 이름, 악기, 경력이 표시된다

### 1-2. 재수강 학생 → 다시 시작하기

- [ ] 이전 선생님 프로필에 [다시 시작하기] 버튼이 표시된다
- [ ] "이전 레슨: YYYY.MM ~ YYYY.MM" 배너가 표시된다
- [ ] 탭 시 통합 신청 폼으로 이동한다
- [ ] 레슨 유형이 "정규레슨"으로 프리필된다 (변경 가능)
- [ ] 악기가 이전 레슨 악기로 프리필된다
- [ ] 이전 고정일자가 캘린더에 자동 선택된다 (가용한 경우)
- [ ] 이전 시간이 불가한 경우 "이전 시간(X요일 Y시)은 현재 불가합니다" 안내가 표시된다

---

## 2. 선생님 안내 메시지

- [ ] 레슨유형 선택 **위에** 안내 메시지가 표시된다
- [ ] 선생님이 커스텀 메시지를 설정하지 않은 경우 디폴트 표시: "희망레슨시간은 상담가능하니 편하게 메시지 주세요"
- [ ] 선생님이 커스텀 메시지를 설정한 경우 해당 메시지가 표시된다

---

## 3. 레슨 유형 선택 (3타입)

- [ ] SegmentedButton으로 "체험레슨 / 정규레슨 / 회차권" 3개 표시된다
- [ ] 새 학생 기본값: 체험레슨
- [ ] 재수강 학생 기본값: 정규레슨 (변경 가능)
- [ ] 타입 전환 시 아래 캘린더 UI가 즉시 변경된다
- [ ] 체험 → 정규 전환 시 기존 선택 초기화된다

---

## 4. 악기 선택

### 4-1. 악기 2개 이상

- [ ] ChoiceChip으로 선생님 악기 목록이 표시된다
- [ ] 하나를 선택해야 다음 진행 가능하다
- [ ] 선택 시 참고 가격이 자동 매칭된다

### 4-2. 악기 1개

- [ ] 악기 선택 UI가 **표시되지 않는다**
- [ ] 해당 악기가 자동 선택된다
- [ ] 참고 가격이 자동 매칭된다
- [ ] 선생님 프로필 화면에서는 악기 정보가 그대로 표시된다

---

## 5. 레슨 목적 + 경험 수준

- [ ] 레슨 목적: Dropdown (취미/입시/연주/기타)
- [ ] 경험 수준: SegmentedButton (초급/중급/고급)
- [ ] 기본값: 취미, 초급

---

## 6. 예상 레슨 시간

- [ ] 읽기 전용으로 "60분" 표시된다
- [ ] 편집 불가하다

---

## 7. 주간 캘린더 — 기본 동작

### 7-1. 캘린더 표시

- [ ] 현재 주가 기본 표시된다
- [ ] ◀ 이전 / 다음 ▶ 버튼으로 주 이동 가능하다
- [ ] 최대 4주 앞까지 이동 가능하다 (그 이상은 ▶ 비활성)
- [ ] 과거 날짜는 비활성 (회색, 터치 불가)이다
- [ ] 선생님 운영시간 범위 내의 슬롯만 표시된다

### 7-2. 슬롯 상태

- [ ] 가용 슬롯: 연한 primary 색상, 터치 가능
- [ ] 예약됨 슬롯: 회색, 터치 불가
- [ ] 가용/예약됨 구분이 시각적으로 명확하다

---

## 8. 3안 선택 — 클릭 순환

### 8-1. 기본 동작

- [ ] 첫 번째 가용 슬롯 클릭 → ❶ 표시, 리스트에 1순위 추가
- [ ] 두 번째 다른 슬롯 클릭 → ❷ 표시, 리스트에 2순위 추가
- [ ] 세 번째 다른 슬롯 클릭 → ❸ 표시, 리스트에 3순위 추가
- [ ] 네 번째 다른 슬롯 클릭 → 전부 초기화 → ❶ (1순위부터 다시)
- [ ] 같은 슬롯 재클릭 → 해당 슬롯 해제, 나머지 번호 재정렬

### 8-2. 중복 방지

- [ ] 같은 요일+시간 조합을 2번 선택할 수 없다
- [ ] 체험/회차권: 서로 다른 주의 같은 요일+시간은 **허용** (날짜가 다르므로)
- [ ] 정규: 같은 요일+시간은 어떤 주에서 클릭해도 **중복 불가**

### 8-3. 선택 리스트 (캘린더 아래)

- [ ] 캘린더 아래에 선택한 희망 시간 리스트가 항상 표시된다
- [ ] 각 항목에 [× 삭제] 버튼이 있다
- [ ] 삭제 클릭 시 해당 슬롯 해제 + 캘린더에서 번호 제거
- [ ] 아무것도 선택 안 한 상태에서는 "희망 시간을 선택해주세요" 안내 표시

### 8-4. 체험/회차권 리스트 표시

- [ ] "1순위: 3/26(수) 10:00" 형식으로 **날짜 포함** 표시
- [ ] 다른 주의 슬롯을 선택해도 정확한 날짜가 표시된다

### 8-5. 정규레슨 리스트 표시

- [ ] "1순위: 매주 수요일 10:00" 형식으로 **요일만** 표시
- [ ] 날짜는 표시되지 않는다 (시작일은 선생님이 결정)

---

## 9. 취소/변경 안내

- [ ] 메모 위에 "레슨 24시간 전까지 변경 가능" 안내가 표시된다
- [ ] 읽기 전용이다

---

## 10. 메모

- [ ] 자유 텍스트 입력 가능하다
- [ ] 최대 200자 제한이 동작한다 (201자 이상 입력 불가)
- [ ] 선택 사항이다 (비워도 제출 가능)

---

## 11. 참고 가격

- [ ] 악기 + 경험 수준 선택 시 가격표에서 매칭된 금액이 표시된다
- [ ] 가격표가 없으면 섹션이 표시되지 않는다
- [ ] "바이올린 초급 기준: 40,000원/회" 형식으로 표시된다
- [ ] 읽기 전용이다

---

## 12. 제출 검증

### 12-1. 필수 항목 검증

- [ ] 레슨 유형 미선택 시 제출 불가 (기본값 있으므로 실제로 발생하지 않음)
- [ ] 악기 미선택 시 (2개 이상일 때) 에러 메시지 표시
- [ ] 희망 시간 0개 선택 시 에러 메시지: "희망 시간을 1개 이상 선택해주세요"
- [ ] 모든 필수 항목 입력 시 [레슨 신청하기] 버튼 활성화

### 12-2. 제출 동작

- [ ] [레슨 신청하기] 탭 시 로딩 표시
- [ ] 제출 성공 시 완료 페이지로 이동 (뒤로가기 불가)
- [ ] 제출 실패 시 에러 메시지 표시 + 폼 유지

---

## 13. 레슨 신청 완료 페이지

### 13-1. 스텝 가이드

- [ ] "✅ 레슨 신청 완료!" 헤더가 표시된다
- [ ] 5단계 수직 리스트가 표시된다:
  - [ ] Step 1: "레슨 신청 완료" — ● 활성 (현재 단계)
  - [ ] Step 2: "선생님이 시간 확인" — ○ 비활성
  - [ ] Step 3: "시간 확정 후 입금" — ○ 비활성
  - [ ] Step 4: "선생님이 수강권 발급" — ○ 비활성
  - [ ] Step 5: "레슨 시작!" — ○ 비활성

### 13-2. 신청 정보 요약

- [ ] 선생님 이름이 표시된다
- [ ] 악기가 표시된다
- [ ] 레슨 유형 (체험/정규/회차권)이 표시된다
- [ ] 레슨 시간 (60분)이 표시된다
- [ ] 선택한 희망 시간이 순위별로 표시된다

### 13-3. 네비게이션

- [ ] [메인으로 가기] 버튼이 표시된다
- [ ] 탭 시 메인 화면(홈)으로 이동한다
- [ ] 뒤로가기(스와이프/버튼)로 신청 폼으로 돌아가지 않는다

---

## 14. 시간 협상 (선생님 응답 후)

### 14-1. 선생님이 3안 중 1개 수락

- [ ] 학생에게 "시간이 확정되었습니다" 알림이 온다
- [ ] 확정된 시간이 표시된다
- [ ] 수강권 제안 대기 상태로 전환된다

### 14-2. 선생님이 역제안 (3안 모두 불가)

- [ ] 학생에게 "다른 시간을 제안했습니다" 알림이 온다
- [ ] 선생님이 제안한 최대 3개 시간이 표시된다
- [ ] 선생님 메모가 있으면 함께 표시된다
- [ ] 학생이 역제안 중 1개를 선택하면 시간 확정된다
- [ ] 학생이 모두 불가 시 취소할 수 있다

### 14-3. 선생님이 거절

- [ ] 학생에게 "레슨 신청이 거절되었습니다" 알림이 온다
- [ ] 거절 사유가 표시된다 (선생님이 입력한 경우)

### 14-4. 2라운드 제한

- [ ] 학생의 재역제안은 불가하다 (선생님 역제안에서 선택 또는 취소만)
- [ ] 2라운드 미합의 시 "시간 협의가 어렵습니다" 메시지 표시

---

## 15. 선생님 화면 — 요청 수신 및 응답

### 15-1. 요청 수신

- [ ] 새 레슨 신청 알림이 온다
- [ ] 학생 이름, 레슨 유형, 악기, 희망 시간 3안이 표시된다
- [ ] 학생 메모가 있으면 표시된다

### 15-2. 응답 옵션

- [ ] 학생 3안 중 하나를 선택하여 [수락] 가능하다
- [ ] [대안 제안] 선택 시 주간 캘린더가 열린다
- [ ] 캘린더에서 최대 3개 대안 시간을 선택할 수 있다 (동일 클릭 순환)
- [ ] 메모를 작성할 수 있다
- [ ] [거절] 시 거절 사유 입력란이 표시된다

---

## 16. 선생님 설정 — 안내 메시지

- [ ] 프로필 > 레슨 운영에 "레슨 신청 안내 메시지" 필드가 있다
- [ ] 최대 100자 입력 가능하다
- [ ] 비우면 디폴트 메시지로 폴백된다
- [ ] 저장 후 학생 신청 폼에 반영된다

---

## 17. 타입별 시나리오 통합 테스트

### 17-1. 체험레슨 시나리오 (신규 학생)

- [ ] 선생님 검색 → 프로필 → [레슨 신청]
- [ ] 체험레슨 선택 → 악기 선택 → 취미/초급
- [ ] 주간 캘린더에서 특정 날짜+시간 1~3안 선택
- [ ] 리스트에 날짜 포함 표시 확인
- [ ] 메모 작성 (선택)
- [ ] [레슨 신청하기] → 완료 페이지
- [ ] 5단계 가이드 + 요약 정보 확인
- [ ] [메인으로 가기] → 홈

### 17-2. 정규레슨 시나리오 (재수강 학생)

- [ ] 이전 선생님 프로필 → [다시 시작하기]
- [ ] 정규레슨 프리필 확인
- [ ] 이전 악기 프리필 확인
- [ ] 이전 고정일자 자동 선택 확인 (가용한 경우)
- [ ] 또는 불가 안내 메시지 확인
- [ ] 캘린더에서 요일+시간 1~3안 선택
- [ ] 리스트에 "매주 X요일 Y시" 형식 확인
- [ ] [레슨 신청하기] → 완료 페이지

### 17-3. 회차권 시나리오

- [ ] 회차권 선택 → 캘린더 UI가 체험과 동일하게 표시
- [ ] 특정 날짜+시간 선택
- [ ] 리스트에 날짜 포함 표시 확인
- [ ] [레슨 신청하기] → 완료 페이지

### 17-4. 악기 1개 선생님 시나리오

- [ ] 악기 선택 UI가 표시되지 않는다
- [ ] 참고 가격이 자동 매칭된다
- [ ] 나머지 플로우 정상 동작

### 17-5. 선생님 수락 → 수강권 → 레슨 시작 (E2E)

- [ ] 학생 3안 제출
- [ ] 선생님이 1안 수락
- [ ] 시간 확정 알림 수신
- [ ] 선생님이 수강권 제안 발송
- [ ] 학생이 수강권 수락 + "입금했어요" 탭
- [ ] 선생님이 입금 확인 → 수강권 발급
- [ ] 학생 화면에 수강권 표시

---

## 18. 엣지케이스

- [ ] 선생님 가용 슬롯이 0개인 경우: "현재 예약 가능한 시간이 없습니다" 안내
- [ ] 4주 이내 모든 슬롯이 예약됨: 동일 안내 + 메모로 문의 유도
- [ ] 캘린더 이전 버튼: 과거 주로는 이동 불가
- [ ] 캘린더 다음 버튼: 4주 초과 시 비활성
- [ ] 네트워크 끊김 시 제출: 에러 메시지 + 재시도 유도
- [ ] 3안 모두 선택 후 타입 변경: 선택 초기화 확인
- [ ] 안내 메시지가 매우 긴 경우 (100자): 레이아웃 깨지지 않는지
- [ ] 메모 200자 정확히 입력: 더 이상 입력 불가 확인
