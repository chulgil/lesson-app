# 선생님 화면 UX 개선 PAD

> 작성일: 2026-03-28
> 출처: /grill-me 인터뷰 결과
> 상태: 초안

## 문제 정의

선생님 대시보드의 "즉시 확인 필요" 섹션과 레슨 요청 처리 플로우에 다음 문제가 있다:

1. **항목 과다**: 4개 항목(레슨 요청, 예약 승인, 입금 확인, 수강권 확인)이 선생님에게 불필요한 복잡성을 노출
2. **내부 시스템 노출**: "레슨 요청"(Unified)과 "예약 승인"(Legacy)은 선생님 관점에서 같은 행위인데 별도 표시
3. **용어 혼재**: "신청/요청", "승인/수락/확인", "거절" 등이 화면마다 다르게 사용
4. **체험레슨 분기 누락**: 유료 체험레슨이 무조건 무료로 처리됨
5. **다국어 미준비**: 모든 UI 텍스트가 하드코딩되어 향후 다국어 지원 불가

### 벤치마크 비교

| 서비스 | 선생님 처리 단계 | 항목 수 |
|--------|----------------|---------|
| 네이버 예약 | 예약 카드 → 확인 1탭 | 2개 화면 |
| 숨고 | 요청서 → 견적 보내기 1탭 | 2개 화면 |
| **Lessonaza (현재)** | 대시보드 → 목록 → 바텀시트 → (수강권 화면) | 4~6개 화면 |

## 솔루션 개요

"즉시 확인 필요"를 2개 항목으로 축소하고, 용어를 통일하며, 체험레슨 무료/유료 분기를 구현한다.

### 변경 후 "즉시 확인 필요"

```
⚠️ 즉시 확인 필요  [2]
├── 👤 레슨 요청 2건 대기      → 통합 요청 목록
└── 💰 입금 확인 1건 대기      → 입금 확인 화면
```

- "예약 승인" 항목 → "레슨 요청"에 통합 (레거시 데이터 포함)
- "수강권 확인" 항목 → 별도 메뉴로 이동 (학생 탭 또는 프로필 > 수강권·결제)

## 유저 스토리

### 선생님으로서

- 대시보드에서 **처리해야 할 일이 2가지 이내**로 표시되어, 즉시 무엇을 해야 하는지 파악할 수 있다
- "레슨 요청"을 탭하면 **신규/기존 구분 없이** 모든 대기 중인 요청을 한 곳에서 볼 수 있다
- 요청 카드에서 "**수락**"을 누르면 시간이 확정된다 (학생 별도 확인 불필요)
- 체험레슨(무료)을 수락하면 **즉시 예약 완료**된다
- 체험레슨(유료)을 수락하면 학생에게 **입금 요청 알림**이 간다
- 정규레슨을 수락하면 학생에게 **입금 요청 알림**이 간다
- "**레슨 불가**"를 선택하면 학생에게 부드러운 톤으로 안내가 간다
- 모든 버튼과 안내 문구가 **일관된 용어**를 사용한다
- 수강권 만료 알림은 **별도 메뉴**에서 확인할 수 있다

### 학생으로서

- 선생님이 "레슨 불가" 선택 시 **"선생님이 현재 레슨이 어렵다고 알려주셨어요"** 라는 부드러운 안내를 받는다
- "거절당했다"는 느낌이 들지 않는다

## 수용 기준

### Must Have

- [ ] "즉시 확인 필요" 항목이 2개(레슨 요청, 입금 확인)로 줄어든다
- [ ] "예약 승인" 항목이 "레슨 요청"에 통합된다
- [ ] "수강권 확인"이 즉시 확인 섹션에서 제거되고 별도 위치로 이동한다
- [ ] 모든 화면에서 "레슨 신청" → "레슨 요청"으로 통일된다
- [ ] 모든 수락 버튼이 "수락"으로 통일된다 ("승인", "확인" 혼용 제거)
- [ ] "거절" → "레슨 불가"로 변경된다
- [ ] 체험레슨 수락 시 선생님의 "체험레슨 무료" 설정을 참조하여 분기 처리된다
  - 무료: 수락 → 즉시 완료
  - 유료: 수락 → 학생에게 입금 요청 알림
- [ ] UI 텍스트가 상수 파일(또는 l10n)로 추출되어 하드코딩이 제거된다

### Should Have

- [ ] "수강권 확인"의 새 위치가 선생님에게 자연스럽다 (학생 탭 배너 또는 프로필 > 수강권)
- [ ] 학생에게 가는 "레슨 불가" 알림 문구가 부드럽다
- [ ] "확인하기" 범용 CTA를 컨텍스트별 CTA로 변경 ("요청 보기", "입금 확인" 등)

### Nice to Have

- [ ] 정규레슨 수락 후 수강권 발급 화면으로 자동 이동 (중간 "제안 전달" 단계 제거)
- [ ] 다국어(영어) 리소스 파일 초안

## 구현 결정 사항

### 용어 사전

앱 전체에서 사용하는 핵심 용어를 상수로 관리한다. 향후 다국어(l10n) 전환의 기반이 된다.

| 키 | 한국어 | 영어 (향후) | 일본어 (향후) |
|----|--------|------------|-------------|
| `lesson_request` | 레슨 요청 | Lesson Request | レッスンリクエスト |
| `accept` | 수락 | Accept | 承諾 |
| `unavailable` | 레슨 불가 | Unavailable | レッスン不可 |
| `counter_propose` | 다른 시간 제안 | Suggest Alternative | 別の時間を提案 |
| `payment_confirm` | 입금 확인 | Payment Confirmed | 入金確認 |
| `subscription` | 수강권 | Lesson Package | レッスンパッケージ |

### 체험레슨 무료/유료 분기

선생님 설정(`TeacherSettings.freeTrialLesson`)을 참조하여 분기:
- `true` (무료): `completeRequest()` 직접 호출
- `false` (유료): 학생에게 입금 요청 알림 전송 → 입금 확인 플로우

### 수락 = 확정

선생님이 학생의 3안 중 1개를 수락하면 바로 `timeConfirmed` 상태로 전환.
학생 별도 확정 단계는 없다 (학생이 제출한 3안 중 선생님이 골랐으므로 동의 간주).

### "수강권 확인" 이동 위치

즉시 확인 필요에서 제거 후, 다음 중 선택 필요:
- 옵션 A: 학생 탭 상단 배너 ("수강권 만료 임박 N명")
- 옵션 B: 프로필 > 수강권·결제 메뉴 내 배지
- 옵션 C: 대시보드 하단 (즉시 확인과 분리된 별도 영역)

→ 구현 시 결정.
