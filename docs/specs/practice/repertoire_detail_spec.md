## 2. 레퍼토리 상세 화면

### 2.1 레이아웃

```
┌─────────────────────────────────────────┐
│ ← 스즈키 6권                       [⋮] │
├─────────────────────────────────────────┤
│                                         │
│ 📋 기본 정보                            │
│ ┌─────────────────────────────────────┐ │
│ │ 이름: 스즈키 6권                    │ │
│ │ 설명: 바이올린 교본                  │ │
│ │ 기간: 2026.01.01 ~ 진행중       [X] │ │  ← 종료일 삭제
│ └─────────────────────────────────────┘ │
│                                         │
│ 📊 통계                                 │
│ ┌─────────────────────────────────────┐ │
│ │ 섹션 4개 | 완료 3개 | 연습 12시간   │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 섹션 목록                          [+]  │
│ ┌─────────────────────────────────────┐ │
│ │ 라폴리아 1~8 마디         🔁   [>] │ │
│ │ 라폴리아 9~16 마디    🐾 3/5   [>] │ │
│ │ 가보트 전체                    [>] │ │
│ └─────────────────────────────────────┘ │
│                                         │
└─────────────────────────────────────────┘
```

### 2.2 기본 정보 카드

| 필드 | 설명 | 편집 |
|------|------|:----:|
| 이름 | 레퍼토리 이름 (필수) | ✅ |
| 설명 | 부가 설명 (선택) | ✅ |
| 시작일 | 연습 시작일 | ✅ |
| 종료일 | 연습 종료일 (미지정 시 "진행중") | ✅ |

#### 종료일 삭제 동작
- [X] 버튼 탭 → 종료일 null로 설정
- "진행중"으로 표시 변경
- 매일 반복 섹션 활성화

```dart
/// 기간 표시 로직
String get periodText {
  final startStr = startDate != null
      ? DateFormat('yyyy.MM.dd').format(startDate!)
      : '시작일 미정';

  if (endDate == null) {
    return '$startStr ~ 진행중';
  }

  return '$startStr ~ ${DateFormat('yyyy.MM.dd').format(endDate!)}';
}
```

### 2.3 섹션 목록

| 표시 요소 | 설명 |
|----------|------|
| 곡명 | 섹션의 곡명 (pieceName) |
| 범위 | "1~8 마디" 또는 "1~3 줄" 또는 "전체" |
| 반복 아이콘 | 🔁 (매일 반복) / 🐾 N/M (N회 반복) |
| 화살표 | 섹션 상세로 이동 |

## 3. 레퍼토리 추가 화면

### 3.1 현재 vs 개선

| 항목 | 현재 | 개선 |
|------|------|------|
| 기본 정보 | ✅ 이름/설명 | ✅ 이름/설명 |
| 기간 설정 | ❌ 없음 | ✅ 시작일/종료일 추가 |
| 섹션 연속 추가 | ❌ 없음 | ✅ "저장 후 섹션 추가" 버튼 |
| 빠른 선택 | ✅ | ✅ |

### 3.2 개선된 레이아웃 (예정)

```
┌─────────────────────────────────────────┐
│ ← 레퍼토리 추가                    [저장]│
├─────────────────────────────────────────┤
│                                         │
│ 📋 기본 정보                            │
│ ─────────────────────────────────────   │
│                                         │
│ 레퍼토리 이름 *                          │
│ ┌─────────────────────────────────────┐ │
│ │ 스즈키 6권                          │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 설명 (선택)                              │
│ ┌─────────────────────────────────────┐ │
│ │ 바이올린 교본                       │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 📅 기간 설정                            │
│ ─────────────────────────────────────   │
│                                         │
│ 활성 기간                                │
│ ┌─────────────┐  ┌─────────────┐       │
│ │ 2026-01-05  │→ │ 미지정      │       │
│ └─────────────┘  └─────────────┘       │
│                                         │
│ 🔁 종료일 미설정 시 매일 반복됩니다       │
│                                         │
│ ─────────────────────────────────────   │
│                                         │
│ 빠른 선택                               │
│ ┌────────┐ ┌────────┐ ┌────────┐       │
│ │스즈키1 │ │스즈키2 │ │스즈키3 │       │
│ └────────┘ └────────┘ └────────┘       │
│ ┌────────┐ ┌────────┐ ┌────────────┐   │
│ │스즈키4 │ │스즈키5 │ │크로이처    │   │
│ └────────┘ └────────┘ └────────────┘   │
│                                         │
│ ─────────────────────────────────────   │
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │     📝 저장 후 섹션 추가하기 →       │ │
│ └─────────────────────────────────────┘ │
│ 💡 레퍼토리 저장 후 섹션 추가 화면으로   │
│    이동합니다                           │
│                                         │
└─────────────────────────────────────────┘
```

### 3.3 동작 설명

| 버튼 | 동작 |
|------|------|
| [저장] | 레퍼토리만 저장 → 목록으로 이동 |
| [저장 후 섹션 추가하기] | 레퍼토리 저장 → 섹션 추가 화면으로 이동 |

> 섹션 추가 화면에서는 방금 생성한 레퍼토리가 자동 선택됨

### 3.4 입력 필드

| 필드 | 필수 | 설명 | 현재 | 개선 |
|------|:----:|------|:----:|:----:|
| 이름 | ✅ | 레퍼토리 이름 | ✅ | ✅ |
| 설명 | ❌ | 부가 설명 | ✅ | ✅ |
| 시작일 | ❌ | 연습 시작일 | ❌ | ✅ |
| 종료일 | ❌ | 연습 종료일 | ❌ | ✅ |

### 3.5 빠른 선택 (Suggestions)
자주 사용하는 레퍼토리 목록:
- 스즈키 1~6권
- 크로이처 에튀드
- 세브시크
- 바흐 파르티타/소나타
- 스케일/아르페지오

## 5. 아카이브 시스템 (예정)

### 5.1 개념
- **아카이브**: 완료된 레퍼토리를 숨김 처리 (삭제 X)
- **복원**: 아카이브에서 다시 활성화
- **영구 삭제**: 아카이브에서 완전 삭제

### 5.2 데이터 모델

```dart
class PracticeRepertoire {
  // ... 기존 필드
  final bool isArchived;
  final DateTime? archivedAt;

  bool get isActive => !isArchived;
}
```

### 5.3 아카이브 화면

```
┌─────────────────────────────────────────┐
│ ← 아카이브                              │

│ 영구 삭제할 수 있습니다.                │
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ 🗄️ 스즈키 5권                  [⋮] │ │
```
