## 1. 개요

### 1.1 목적
학생이 일별 연습 현황을 확인하고, 레퍼토리/섹션별 연습을 관리하는 메인 화면

### 1.2 핵심 기능
| 기능 | 설명 | 상태 |
|------|------|:----:|
| 날짜 선택 | 오늘/과거 날짜 선택하여 연습 기록 조회 | ✅ |
| 레퍼토리 목록 | 활성 레퍼토리 카드 형태로 표시 | ✅ |
| 섹션 리스트 | 레퍼토리별 섹션 목록 (접기/펼치기) | ✅ |
| 레퍼토리 추가 | FAB 버튼으로 새 레퍼토리 추가 | ✅ |
| 섹션 추가 | 레퍼토리 카드에서 + 버튼으로 섹션 추가 | ✅ |

## 2. 화면 구조

### 2.1 전체 레이아웃

```
┌─────────────────────────────────────────┐
│ 연습                               [설정]│
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ ◀ 2026년 1월 5일 (일)           ▶  │ │  ← 날짜 선택
│ └─────────────────────────────────────┘ │
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │ 📚 스즈키 6권              [+] [▼] │ │  ← 레퍼토리 카드
│ ├─────────────────────────────────────┤ │
│ │ ☐ 라폴리아 1~8 마디    🔁      [>] │ │  ← 섹션 아이템
│ │ ☑ 라폴리아 9~16 마디   2/4     [>] │ │
│ │ ☐ 가보트 전체                  [>] │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │ 📚 바흐 파르티타           [+] [▼] │ │
│ ├─────────────────────────────────────┤ │
│ │ ☐ 사라방드 1~16 마디   🔁     [>] │ │
│ └─────────────────────────────────────┘ │
│                                         │
│                               [+ 추가]  │  ← FAB
└─────────────────────────────────────────┘
```

### 2.2 날짜 선택 바

```
┌─────────────────────────────────────────┐
│ ◀  2026년 1월 5일 (일)  오늘        ▶  │
└─────────────────────────────────────────┘
```

| 요소 | 동작 |
|------|------|
| ◀ / ▶ | 전날/다음날로 이동 |
| 날짜 텍스트 | 탭 시 달력 팝업 (Material DatePicker) |
| "오늘" 배지 | 오늘 날짜일 때만 표시 |

### 2.3 레퍼토리 카드

```
┌─────────────────────────────────────────┐
│ 🎵 스즈키 6권                  [+] [▼] │
│ ─────────────────────────────────────── │
│ 진행률: 75% ████████████░░░░           │
│ 섹션: 4개 | 연습: 3시간 20분            │
└─────────────────────────────────────────┘
```

| 요소 | 동작 |
|------|------|
| 카드 탭 | 레퍼토리 상세 화면으로 이동 |
| [+] 버튼 | 섹션 추가 화면으로 이동 |
| [▼] 버튼 | 섹션 목록 접기/펼치기 토글 |
| 롱프레스 | 편집/삭제 메뉴 표시 |

### 2.4 섹션 아이템

```
┌─────────────────────────────────────────┐
│ ☐ 라폴리아 1~8 마디   🔁  🐾 3/5   [>] │
└─────────────────────────────────────────┘
  ↑                      ↑    ↑
  완료 체크              반복  N회 반복 진행률
```

| 아이콘 | 의미 |
|--------|------|
| ☐ / ☑ | 연습 완료 여부 (일반 섹션) |
| ⭐ | 과제 섹션 (선생님 지정) |
| 🔁 | 매일 반복 (isRepeat) |
| 🐾 3/5 | N회 반복 진행률 (repeatCount) |

## 3. 날짜별 표시 로직

### 3.1 오늘 선택 시
- 활성 레퍼토리의 모든 섹션 표시
- 완료 여부 실시간 반영
- 섹션 추가/편집 가능

### 3.2 과거 날짜 선택 시
- 해당 날짜에 연습한 섹션만 표시
- 완료 체크 기록 표시 (수정 불가)
- 녹음 기록 조회 가능

```dart
/// 날짜별 섹션 필터링
List<PracticeSection> getSectionsForDate(DateTime date) {
  if (isToday(date)) {
    // 오늘: 모든 활성 섹션
    return activeSections;
  } else {
    // 과거: 해당 날짜에 완료 기록이 있는 섹션만
    return sections.where((s) =>
      s.completionHistory.any((c) => isSameDay(c.date, date))
    ).toList();
  }
}
```

## 4. 섹션 표시 규칙

### 4.1 반복 아이콘 표시

| 조건 | 표시 |
|------|------|
| `isRepeat == true` | 🔁 매일 반복 |
| `repeatCount > 0` | 🐾 2/5 (진행률) |
| 둘 다 있음 | 🔁 🐾 2/5 |

### 4.2 완료 상태 표시

| 조건 | 표시 |
|------|------|
| 일반 섹션 미완료 | ☐ (빈 체크박스) |
| 일반 섹션 완료 | ☑ (체크됨) |
| 과제 섹션 미완료 | ☆ (빈 별) |
| 과제 섹션 완료 | ⭐ (채워진 별) |

### 4.3 섹션 정렬 순서
1. 생성순 (기본) - 최신이 위
2. 이름순 (가나다)
3. 마디순 (시작 마디)
4. 사용자 지정 (드래그앤드롭)
