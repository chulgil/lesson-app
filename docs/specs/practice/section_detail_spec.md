### 2.2 섹션 정보 카드

| 항목 | 표시 | 조건 | 구현 |
|------|------|------|:----:|
| 곡명 | `section.pieceName` | 항상 표시 | ✅ |
| 별칭 | `section.sectionName` (선택) | 값이 있을 때 | ✅ |
| 범위 | "1~8 마디" / "1~3 줄" | **"전체"일 때 숨김** | ✅ |
| N회 반복 | 🐾 5회 반복 (`repeatCount`) | repeatCount > 0 | ✅ |
| 기간 | 시작일 ~ 종료일/진행중 (매일반복) | 항상 표시 | ✅ |

> **편집 버튼 제거**: 편집은 AppBar의 [⋮] 메뉴에서 접근

#### 기간 표시 규칙

| 시작일 | 종료일 | 매일반복 | 표시 |
|--------|--------|:--------:|------|
| 섹션 startDate | 있음 | - | `2026.01.05 ~ 2026.06.30` |
| 섹션 startDate | null | ✅ | `2026.01.05 ~ 진행중 (매일반복)` |
| null (레퍼토리 startDate 사용) | null | ✅ | `2026.01.01 ~ 진행중 (매일반복)` |

> **시작일 미정 대신**: 섹션의 시작일이 없으면 레퍼토리의 시작일을 사용

### 2.3 녹음 기록 필터

```
녹음 기록 (8)                    [당일 ▼]
                                 ┌─────────┐
                                 │ 전체    │
                                 │ 주간    │
                                 │✓당일    │ ← 기본값
                                 └─────────┘
```

| 필터 | 설명 | 기준 |
|------|------|------|
| **전체** | 해당 섹션의 모든 녹음 | - |
| **주간** | 선택 날짜가 포함된 월~일 | selectedDate |
| **당일** | 선택 날짜의 녹음만 | selectedDate |

```dart
enum RecordingFilterType {
  all,     // 전체
  weekly,  // 주간 (월~일)
  daily,   // 당일
}

/// 주간 범위 계산
DateTimeRange getWeekRange(DateTime date) {
  final weekday = date.weekday; // 월=1, 일=7
  final monday = date.subtract(Duration(days: weekday - 1));
  final sunday = monday.add(const Duration(days: 6));
  return DateTimeRange(
    start: DateTime(monday.year, monday.month, monday.day),
    end: DateTime(sunday.year, sunday.month, sunday.day, 23, 59, 59),
  );
}
```

### 2.4 연습 완료 처리

#### 일반 완료 (repeatCount 없음)
```
┌─────────────────────────────────────────┐
│ ☐ 연습 완료                             │
└─────────────────────────────────────────┘
          ↓ 탭
┌─────────────────────────────────────────┐
│ ✓ 연습 완료                      12:30 │
│ 🎉 대표녹음을 선생님께 공유해보세요!   │ ← 과제인 경우만
└─────────────────────────────────────────┘
```

#### N회 반복 완료 (repeatCount > 0)
```
┌─────────────────────────────────────────┐
│ 🐾 연습 반복 (3/5회)                    │
│                                         │
│ 🐾 🐾 🐾 🐾 🐾                           │
│ ✓  ✓  ✓  ○  ○                          │
│                                         │
│ ☐ 전체 완료 처리                        │
└─────────────────────────────────────────┘
```

| 동작 | 설명 |
|------|------|
| 🐾 탭 | 해당 스탬프 완료 토글 |
| 모든 스탬프 완료 | 자동으로 연습 완료 |
| "전체 완료 처리" | 남은 스탬프 무시하고 완료 |

## 5. 데이터 모델

### 5.1 PracticeSection

```dart
class PracticeSection {
  final String id;
  final String repertoireId;
  final String pieceName;          // 곡명 (필수)
  final String? sectionName;       // 별칭 (선택)
  final RangeType rangeType;       // 범위 유형
  final int startMeasure;          // 시작 범위
  final int endMeasure;            // 종료 범위
  final DateTime? startDate;       // 시작일
  final DateTime? endDate;         // 종료일 (null = 진행중)
  final bool isRepeat;             // 매일 반복 (endDate == null)
  final int repeatCount;           // N회 반복 (0 = 없음)
  final List<PracticeRecording> recordings;
  final DateTime createdAt;

  /// 범위 텍스트
  String get measureRangeText {
    switch (rangeType) {
      case RangeType.measure:
        return '$startMeasure~$endMeasure 마디';
      case RangeType.line:
        return '$startMeasure~$endMeasure 줄';
      case RangeType.all:
        return '전체';
    }
  }

  /// N회 반복 여부
  bool get hasRepeatCount => repeatCount > 0;
}
```
