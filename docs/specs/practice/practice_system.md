# 연습 시스템 스펙

> 작성일: 2025-12-25
> 상태: Phase 1-2 완료, Phase 3 진행 중

---

## 개요

"과제" 대신 "이번 주 연습"으로 명명하여 심리적 부담 완화. 레슨 후 학생에게 할당되는 연습 과제 관리 시스템.

### 핵심 원칙
- **원클릭 체크**: 연습할 시간도 부족하므로 최소한의 입력
- **레퍼토리 중심**: 책/곡 > 섹션 2단계 구조
- **선생님 과제 연동**: 과제 → 원클릭 레퍼토리 추가

---

## 데이터 모델

### PracticeItem

```dart
class PracticeItem {
  String id;
  String lessonId;
  String title;
  String? description;
  PracticeType type;
  PracticePriority priority;
  bool isCompleted;
  int practiceCount;
  bool hasLike;
  DateTime createdAt;
  DateTime? completedAt;
}
```

### Enums

| Enum | 값 | 설명 |
|------|-----|------|
| PracticePriority | must, should, could | 🔴필수, 🟡추천, 🟢도전 |
| PracticeType | repertoire, technique, theory, custom | 레퍼토리, 테크닉, 이론, 기타 |

## 레퍼토리 구조 (2단계)

```
📚 레퍼토리 (책 or 곡)
 └── 📝 섹션 (마디 범위)
```

### UI 레이아웃

```
┌─────────────────────────────────────────────────────┐
│ 📚 레퍼토리 [스즈키6권]                        [+] │
├─────────────────────────────────────────────────────┤
│ 라폴리아  │ 1~4 마디   │ 🎙️ │ ☐ 완료 │  [상세 >] │
│ 라폴리아  │ 11~14 마디 │ 🎙️ │ ☑ 완료 │  [상세 >] │
└─────────────────────────────────────────────────────┘
```

---

## 마디 선택 UI

| 항목 | 결정 |
|------|------|
| UI 방식 | iOS 휠 피커 + 오선지 미리보기 |
| 최대 마디 | 100마디 |
| 입력 방식 | 시작 휠피커 + 종료 휠피커 |
| 다중 구간 | RangeType (마디/줄) + 여러 구간 추가 가능 |
| 섹션 이름 | 선택사항 (미입력시 "1~4마디" 자동 생성) |

## 녹음 기능

### 버튼 상태 플로우
```
🎙️ (대기) → 🔴 (녹음중) → ⏸️ (정지) → 🔴 (재개) → ✅ (완료)
```

### 녹음 팝업 UI
```
┌─────────────────────────────────────┐
│       라폴리아 1~4 마디             │
├─────────────────────────────────────┤
│   ∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿        │  ← 오디오 웨이브폼
```

### 녹음 관리

| 항목 | 설명 |
|------|------|
| 대표 녹음 | 1개 지정, 선생님에게 공유 |
| 히스토리 | 모든 녹음 보관, 상세 화면에서 관리 |
| 삭제/지정 | 상세 화면에서 삭제 및 대표 지정 가능 |

## 과제 → 연습 연동 플로우

```
선생님 앱                        학생 앱
───────────                    ─────────
레슨탭 → 과제 등록    ───→    레슨탭 → 과제 확인
                              ↓
                         "연습으로 등록" 클릭
                              ↓
                         연습 레퍼토리에 추가
```

---

## 선생님 뷰

| 항목 | 내용 |
|------|------|
| 대표 녹음 | 학생이 지정한 대표 녹음 재생 가능 |
| 연습 통계 | 연습 횟수, 총 연습 시간 |
| 완료 체크 | 학생이 직접 관리 (선생님은 레슨 시 확인 후 피드백) |
| 좋아요 | 완료된 연습에 ❤️ 피드백 가능 |

## 연습 스트릭 규칙

```
✅ 하루 1회 이상 연습 기록 → 스트릭 유지
❌ 평일에 연습 기록 없음 → 스트릭 리셋
✨ 1-6일 연속 → 스파클 이모지
🔥 7-29일 연속 → 불꽃 이모지
🔥🔥 30일 이상 연속 → 더블 불꽃
```

### 주말 제외 정책

| 상황 | 스트릭 |
|------|--------|
| 금요일 연습 → 월요일 연습 | ✅ 유지 (주말은 카운트 안 함) |
| 금요일 연습 → 화요일 연습 | ❌ 리셋 (월요일에 연습 안 함) |
| 토요일 연습 | ✅ 스트릭에 포함 (보너스) |
