## 1. 개요

### 1.1 목적
학생이 연습 레퍼토리와 섹션을 효율적으로 추가, 수정, 삭제할 수 있도록 사용자 친화적인 CRUD 인터페이스 제공

### 1.2 핵심 원칙
- **원클릭 등록**: 최소한의 입력으로 빠른 등록
- **직관적 수정**: 롱프레스 + 편집 버튼 이중 접근
- **시각적 피드백**: 반복 아이콘(🔁), 과제 표시(⭐) 등

### 1.3 경쟁사 참고
| 앱 | 강점 | 적용 사항 |
|---|------|----------|
| [Modacity](https://www.modacity.co/) | 직관적 UX, 플레이리스트 | 레퍼토리+섹션 동시 등록 |
| [Tonara](https://www.tonara.com/) | 게이미피케이션 | 반복 스탬프 UI |
| [Yousician](https://yousician.com/) | 구간 연습, 진행률 | 마디 범위 설정 |

## 2. 현재 구현 상태

### 2.1 CRUD 현황

| 기능 | 레퍼토리 | 섹션 | 비고 |
|------|:-------:|:----:|------|
| **Create** | ✅ | ✅ | 화면 구현 완료 |
| **Read** | ✅ | ✅ | 목록/상세 완료 |
| **Update** | ⚠️ | ⚠️ | Repository만 존재, UI 미구현 |
| **Delete** | ✅ | ✅ | 삭제 다이얼로그 포함 |

### 2.2 누락 기능
1. ❌ 섹션 수정 화면
2. ❌ 레퍼토리 수정 화면
3. ❌ 반복 아이콘 표시
4. ❌ 레퍼토리 생성 시 첫 섹션 동시 등록
5. ❌ 섹션 반복 횟수 UI (스탬프)

## 3. UX 결정 사항

### 3.1 브레인스토밍 결과

| 항목 | 결정 | 상세 |
|------|------|------|
| **섹션 등록 위치** | 레퍼토리 저장 후 별도 화면 | "저장 후 섹션 추가" 버튼으로 이동 |
| **반복 설정 위치** | 섹션 상세 화면 | 토글 스위치로 ON/OFF |
| **반복 아이콘** | 🔁 표시 | 섹션 카드 우측에 표시 |
| **수정 접근 방식** | 롱프레스 + 편집 버튼 | 두 가지 방식 모두 지원 |
| **반복 동작** | 매일 미완료 리셋 | 다음날 자동으로 미완료 상태 |
| **섹션 수정 항목** | 확장 | 곡명/마디/이름/반복/우선순위 |
| **레퍼토리 수정 항목** | 전체 | 이름/설명/기간/아카이브 |

## 4. 화면 설계

### 4.1 레퍼토리 추가 화면 (개선)

**현재**: 이름/설명만 입력
**개선**: 이름/설명 입력 + 저장 후 섹션 추가 버튼

```
┌─────────────────────────────────────────┐
│ ← 레퍼토리 추가                    [저장]│
├─────────────────────────────────────────┤
│                                         │
│ 📋 기본 정보 (이름, 설명 설정)           │
│ ─────────────────────────────────────   │
│                                         │
│ 레퍼토리 이름 *                          │
│ ┌─────────────────────────────────────┐ │
│ │ 스즈키 6권                          │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 설명 (선택)                              │
│ ┌─────────────────────────────────────┐ │
│ │ 바이올린 교본                       │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 📅 기간 설정 (활성 기간, 반복 여부)      │
│ ─────────────────────────────────────   │
│                                         │
│ 활성 기간                                │
│ ┌─────────────┐  ┌─────────────┐       │
│ │ 2026-01-04  │→ │ 2026-03-04  │       │
│ └─────────────┘  └─────────────┘       │
│                                         │
│ ☑ 매일 반복 (종료일 없이 계속)      🔁  │
│ ※ 체크 시 종료일 무시                   │
│                                         │
│ ─────────────────────────────────────   │
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │     📝 저장 후 섹션 추가하기 →       │ │  ← 버튼
│ └─────────────────────────────────────┘ │
│ 💡 레퍼토리 저장 후 섹션 추가 화면으로   │
│    이동합니다                           │
│                                         │
└─────────────────────────────────────────┘
```

**동작:**
1. 레퍼토리 이름은 필수
2. [저장] 버튼: 레퍼토리만 저장 후 목록으로 이동
3. [저장 후 섹션 추가하기] 버튼: 레퍼토리 저장 후 섹션 추가 화면으로 이동
4. 섹션 추가 화면에서는 방금 생성한 레퍼토리가 자동 선택됨

---

### 4.2 섹션 추가 버튼 (레퍼토리 목록)

**현재**: 접기/펼치기 버튼
**개선**: + 버튼으로 섹션 추가

```
┌─────────────────────────────────────────┐
│ 📚 스즈키 6권                      [⋮] │
│ 완료: 2/4 (50%)                   [+]  │ ← 섹션 추가 버튼
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ 라폴리아 (전체)       ⭐ 과제 🔁  │ │ ← 선생님 과제 (전체)
│ │ 🎙️ 3회 연습 · 15분                │ │
│ │                            ☑ 완료 │ │
│ └─────────────────────────────────────┘ │
│ ┌─────────────────────────────────────┐ │
│ │ 라폴리아 2~3줄                🔁  │ │ ← 학생 자체 연습 (줄/마디)
│ │ 🎙️ 1회 연습 · 5분                 │ │
│ │                            ☐ 미완료│ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

> **참고:** 학생이 직접 추가하는 섹션은 **줄 또는 마디** 범위만 선택 가능합니다.
> "전체"는 선생님 과제에서만 사용됩니다.

---

### 4.3 섹션 추가 화면 (학생 자체 연습)

**진입 방식:**
1. 레퍼토리 카드 [+] 버튼 탭
2. "저장 후 섹션 추가하기" 버튼 탭

```
┌─────────────────────────────────────────┐
│ ← 섹션 추가                       [저장]│
├─────────────────────────────────────────┤
│                                         │
│ 📋 기본 정보 (곡명, 범위, 별칭 설정)     │
│ ─────────────────────────────────────   │
│                                         │
│ 곡명 *                                  │
│ ┌─────────────────────────────────────┐ │
│ │ 곡 이름을 입력하세요                 │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 범위 유형                               │
│ ┌─────────────────────────────────────┐ │
│ │ [●전체] [줄] [마디]                 │ │  ← 전체가 기본값
│ └─────────────────────────────────────┘ │
│                                         │
│ (전체 선택 시 범위 입력 섹션 숨김)        │
│                                         │
│ (줄 선택 시)                            │
│ ┌─────────┐     ┌─────────┐            │
│ │    1    │ 줄  │    4    │ 줄         │
│ └─────────┘     └─────────┘            │
│                                         │
│ 구간 별칭 (선택)                         │
│ ┌─────────────────────────────────────┐ │
│ │ 예: 도입부, 클라이막스                │ │
│ └─────────────────────────────────────┘ │
│ 💡 미입력 시 범위로 표시 (예: 1~4줄)     │
│                                         │
│ 📅 연습 기간 (레퍼토리와 동일 UI)        │
│ ─────────────────────────────────────   │
│                                         │
│ 시작일   레퍼토리 시작일 사용    [>]     │ ← DateRow
│ ─────────────────────────────────────   │
│ 종료일   설정 안함 (계속 진행)   [>]     │ ← DateRow
│ ─────────────────────────────────────   │
│ 🔁 종료일 미설정 시 매일 반복됩니다       │ ← 안내 메시지
│                                         │
│ 🐾 N회 반복 (선택)                       │
│ ─────────────────────────────────────   │
│                                         │
│ 하루에 여러 번 연습해야 하는 경우 설정   │
│ ┌─────────────────────────────────────┐ │
│ │ [없음 ▼]                            │ │ ← 드롭다운
│ └─────────────────────────────────────┘ │
│ 💡 고양이 발바닥 스탬프로 체크           │
│                                         │
└─────────────────────────────────────────┘
```

**입력 항목:**
- 곡명 (필수)
- 범위 유형 (전체/줄/마디 선택) - **전체가 기본값**, 전체 선택 시 범위 입력 숨김
- 시작/끝 줄 또는 마디 (줄/마디 선택 시에만)
- 구간 별칭 (선택)
- 연습 기간 (시작일/종료일) - 레퍼토리 기간 내로 제한
  - **종료일 없음 = 매일 반복** (isRepeat 자동 파생)
- 반복 횟수 (선택, 2~10회) - 🐾 스탬프 UI

## 5. 반복(Repeat) 시스템 상세

### 5.1 반복 유형

| 유형 | 설명 | 현재 상태 |
|------|------|:---------:|
| **매일 반복** | 다음날 자동 미완료 리셋 | ✅ 구현됨 (`isRepeat`) |
| **섹션 반복** | N회 반복 (스탬프 UI) | ❌ 미구현 |

### 5.2 매일 반복 동작

> **핵심 로직**: `isRepeat`는 `endDate`에서 자동 파생됩니다.
> - `endDate == null` → `isRepeat = true` (매일 반복)
> - `endDate != null` → `isRepeat = false` (종료일까지만)

```dart
// isRepeat은 endDate에서 파생

if (section.endDate == null) {

  // 오늘 완료해도 내일 다시 미완료로 표시
} else {
  // 종료일까지만 표시
  // 종료일 이후 목록에서 숨김
}
```

#### 5.3.5 반복 완료 로직

```dart
// 오늘 반복 진행률
int get todayRepeatProgress {
  final today = DateTime.now().dateOnly;
  return dailyRepeatCounts[today] ?? 0;
}

// 반복 전체 완료 여부
bool get isRepeatComplete {
  if (repeatCount == null) return true; // 반복 없음
  return todayRepeatProgress >= repeatCount!;
}

// 스탬프 탭 시
void toggleRepeat(int index) {
  final today = DateTime.now().dateOnly;
  final current = dailyRepeatCounts[today] ?? 0;

  if (index < current) {
    // 이미 완료된 것 클릭 → 취소 (해당 이후 모두 취소)
    dailyRepeatCounts[today] = index;
  } else if (index == current) {
    // 다음 미완료 클릭 → 완료
    dailyRepeatCounts[today] = index + 1;
  }
  // index > current 는 무시 (순서대로만 체크)
}
```

#### 5.3.6 매일 반복과 N회 반복의 관계

| 조합 | 동작 |
|------|------|
| 매일반복 OFF + N회반복 없음 | 기간 내 1회 완료하면 끝 |
| 매일반복 OFF + N회반복 5회 | 기간 내 5회 스탬프 완료하면 끝 |
| 매일반복 ON + N회반복 없음 | 매일 완료 체크박스만 표시 |
| 매일반복 ON + N회반복 5회 | 매일 5회 스탬프 리셋, 매일 5회 완료 필요 |

### 5.4 선생님 과제 vs 학생 자체 연습

#### 5.4.1 개요

섹션은 두 가지 유형으로 구분됩니다:

| 구분 | 선생님 과제 | 학생 자체 연습 |
|------|------------|---------------|
| 생성자 | 선생님 | 학생 본인 |
| 범위 유형 | **전체만** 가능 | **전체/줄/마디** 모두 가능 (전체가 기본값) |
| 중복 섹션 | ❌ 불가 | ❌ 불가 |
| 줄/마디 입력 | 레슨노트로 대체 | 전체 선택 시 숨김, 줄/마디 시 직접 입력 |
| 대표녹음 | ✅ 자동 지정 | ❌ 없음 |
| 녹음 공유 | ✅ 완료 시 선생님께 공유 | ❌ 없음 |
| 목록 표시 | ⭐ 과제 마크 | 일반 표시 |

**중복 방지 규칙:**

| 유형 | 고유 키 | 예시 |
|------|---------|------|
| 과제 | 레퍼토리 + 곡명 + 전체 | "스즈키6권/라폴리아(전체)" - 1개만 가능 |
| 일반 | 레퍼토리 + 곡명 + 범위 | "스즈키6권/라폴리아(2~3줄)" - 1개만 가능 |

```
✅ 허용되는 조합:
- 라폴리아 (전체)     ← 과제
- 라폴리아 (2~3줄)    ← 일반
- 라폴리아 (1~8마디)  ← 일반

❌ 허용되지 않는 조합:
- 라폴리아 (전체) x 2개     ← 중복 불가
- 라폴리아 (2~3줄) x 2개    ← 중복 불가
```

**설계 이유:** 향후 녹음 파일 공유 시 저장 공간 문제 해소

```dart
class PracticeSection {
  // 기존 필드들...

  /// 곡명 (필수)
  final String pieceName;

  /// 구간 별칭 (선택) - 기존 sectionName에서 명칭 변경
  final String? sectionLabel;

  /// 범위 유형 (신규)
  final RangeType rangeType;  // 전체, 줄, 마디

  /// 줄 범위 (신규 - rangeType이 line일 때)
  final int? startLine;
  final int? endLine;

  /// 마디 범위 (기존 - rangeType이 measure일 때)
  final int? startMeasure;  // null 가능으로 변경
  final int? endMeasure;    // null 가능으로 변경

  /// 섹션 활성 기간 (신규)
  final DateTime startDate;     // 레퍼토리 startDate 이상
  final DateTime? endDate;      // 레퍼토리 endDate 이하

  /// 매일 반복 여부 (저장됨)
  final bool isRepeat;  // true면 endDate 무시하고 매일 반복

  /// 실제 종료일 계산
  DateTime? get effectiveEndDate => isRepeat ? null : endDate;

  /// 섹션 반복 횟수 (2~10회, null이면 반복 없음)
  final int? repeatCount;

  /// 날짜별 반복 완료 횟수 (key: 날짜, value: 완료 횟수)
  final Map<DateTime, int> dailyRepeatCounts;

  /// 오늘 반복 진행률
  int get todayRepeatProgress {
    final today = DateTime.now().dateOnly;
    return dailyRepeatCounts[today] ?? 0;
  }

  /// 오늘 반복 전체 완료 여부
  bool get isTodayRepeatComplete {
    if (repeatCount == null) return true;
    return todayRepeatProgress >= repeatCount!;
  }

  /// 우선순위 (신규)
  final SectionPriority? priority;

  // ─── 선생님 과제 관련 필드 ───

  /// 과제 여부 (선생님이 생성한 섹션인지)
  final bool isAssignment;

  /// 과제 생성 선생님 ID (isAssignment=true일 때)
  final String? assignedByTeacherId;

  /// 레슨노트 목록 (선생님별 최근 1개씩)
  final List<LessonNote> lessonNotes;

  /// 과제 여부 확인
  bool get isTeacherAssignment => isAssignment && assignedByTeacherId != null;

  /// 대표녹음 지정 가능 여부
  bool get canHaveRepresentativeRecording => isAssignment;

  /// 범위 표시 텍스트 (신규)
  String get rangeDisplayText {
    switch (rangeType) {
      case RangeType.all:
        return '전체';
      case RangeType.line:
        return '$startLine~$endLine줄';
      case RangeType.measure:
        return '$startMeasure~$endMeasure마디';
    }
  }

  /// 상세 화면 타이틀 (신규) - 곡명 + 범위 단위 표시
  String get displayTitle {
    final range = rangeDisplayText;

    if (sectionLabel != null && sectionLabel!.isNotEmpty) {
      // 구간 별칭이 있으면: "곡명 · 별칭" + 줄바꿈 + "(범위)"
      return '$pieceName · $sectionLabel\n($range)';
    }

    // 구간 별칭 없으면: "곡명 (범위)"
    return '$pieceName ($range)';
  }

  /// 섹션이 특정 날짜에 활성 상태인지 확인
  bool isActiveForDate(DateTime date) {
    final dateOnly = DateTime(date.year, date.month, date.day);
    final start = DateTime(startDate.year, startDate.month, startDate.day);

    if (dateOnly.isBefore(start)) return false;
    if (isRepeat) return true;  // 매일반복 체크됨
    if (effectiveEndDate == null) return true;

    final end = DateTime(effectiveEndDate!.year, effectiveEndDate!.month, effectiveEndDate!.day);
    return !dateOnly.isAfter(end);
  }

  /// 날짜 범위 검증 (레퍼토리 범위 내인지)
  bool isValidDateRange(PracticeRepertoire repertoire) {
    // 시작일이 레퍼토리 시작일 이상인지
    if (startDate.isBefore(repertoire.startDate)) return false;

    // 종료일이 있고 레퍼토리 종료일이 있으면 그 이하인지
    if (endDate != null && repertoire.endDate != null) {
      if (endDate!.isAfter(repertoire.endDate!)) return false;
    }

    return true;
  }
}

/// 범위 유형 enum (신규)
enum RangeType {
  all,      // 전체
  line,     // 줄만
  measure,  // 마디만
}

enum SectionPriority {
  must,    // 🔴 필수
  should,  // 🟡 추천
  could,   // 🟢 도전
}

/// 레슨노트 (선생님 메모)
class LessonNote {
  final String id;
  final String teacherId;
  final String teacherName;
  final String content;
  final DateTime createdAt;
  final bool isVisible;  // 선생님 링크 해제 시 false

  /// 표시 형식: "2026-01-04 김선생님"
  String get displayHeader => '${createdAt.format('yyyy-MM-dd')} $teacherName';

4. 폼 필드에 기존 값 채우기
5. 로딩 완료 → 폼 표시
```

#### 7.5.2 저장 흐름

```
1. [저장] 버튼 탭
2. 폼 유효성 검사
   ├── 실패 → 에러 표시, 첫 에러 필드로 스크롤
   └── 성공 → 다음 단계
3. 로딩 상태 표시 (버튼 스피너)
4. API 호출 (updateSection)
   ├── 실패 → 에러 스낵바, 폼 유지
   └── 성공 → 다음 단계
5. 리스트 갱신 (invalidate providers)
6. 화면 닫기 (context.pop)
7. 성공 스낵바 표시
```

#### 7.5.3 삭제 흐름

```
1. [섹션 삭제] 버튼 탭
2. 확인 다이얼로그 표시
   ├── 취소 → 다이얼로그 닫기
   └── 확인 → 다음 단계
3. 로딩 상태 표시
4. API 호출 (deleteSection)
   ├── 실패 → 에러 스낵바
   └── 성공 → 다음 단계
5. 리스트 갱신
6. 2단계 뒤로가기 (편집 → 상세 → 리스트)
7. 성공 스낵바 "'{섹션명}' 삭제됨"
```

#### 7.5.4 뒤로가기 (변경사항 있을 때)

```
1. ← 버튼 또는 시스템 뒤로가기
2. 변경사항 확인 (hasChanges)
   ├── 없음 → 바로 나가기
   └── 있음 → 확인 다이얼로그
3. 다이얼로그: "저장하지 않은 변경사항이 있습니다"
   ├── [저장] → 저장 흐름 실행
   ├── [삭제] → 변경사항 버리고 나가기
   └── [취소] → 다이얼로그 닫기, 편집 계속
```

### 7.6 유효성 검사

#### 7.6.1 필드별 검증

| 필드 | 규칙 | 에러 메시지 |
|------|------|------------|
| 곡명 | 필수, 1-100자 | "곡명을 입력해주세요" |
| 범위 유형 | 필수 | - |
| 시작 줄/마디 | rangeType 따라 필수, ≥1 | "시작 값을 선택해주세요" |
| 끝 줄/마디 | rangeType 따라 필수, ≥시작값 | "시작 값이 끝 값보다 클 수 없습니다" |
| 시작일 | 필수, ≥레퍼토리 시작일 | "레퍼토리 기간 내에서 선택해주세요" |
| 종료일 | 선택, ≤레퍼토리 종료일 | "레퍼토리 기간 내에서 선택해주세요" |

#### 7.6.2 크로스 필드 검증

```dart
bool validateForm() {
  // 1. 개별 필드 검증
  if (pieceName.isEmpty) return false;

  // 2. 범위 검증
  if (rangeType == RangeType.line) {
    if (startLine == null || endLine == null) return false;
    if (startLine! > endLine!) return false;
  }
  if (rangeType == RangeType.measure) {
    if (startMeasure == null || endMeasure == null) return false;
    if (startMeasure! > endMeasure!) return false;
  }

  // 3. 날짜 검증
  if (startDate.isBefore(repertoire.startDate)) return false;
  if (!isRepeat && endDate != null) {
    if (repertoire.endDate != null && endDate!.isAfter(repertoire.endDate!)) {
      return false;
    }
  }

  return true;
}
```

## 8. 공통 위젯 (section_form/)

> **UI 일관성 원칙**: 레퍼토리/섹션 추가/편집 화면에서 동일한 공통 위젯을 사용합니다.

### 8.1 공통 위젯 목록

| 위젯 | 파일 | 용도 |
|------|------|------|
| `DateRow` | `date_row.dart` | 날짜 선택 행 (시작일/종료일) |
| `RangePickerButton` | `range_picker_button.dart` | 범위 값 표시 버튼 (줄/마디) |
| `RangePickerSheet` | `range_picker_sheet.dart` | 범위 선택 바텀시트 (iOS 휠 피커) |

### 8.2 DateRow 위젯

레퍼토리 상세 화면(`repertoire_detail_screen.dart`)의 `_buildDateRow` 패턴과 동일한 스타일을 사용합니다.

```dart
DateRow(
  label: '시작일',
  date: startDate,
  onTap: () => _showDatePicker(context, isStart: true),
)

DateRow(
  label: '종료일',
  date: endDate,
  placeholder: '설정 안함 (계속 진행)',  // 종료일 미지정 시
  canClear: endDate != null,
  onClear: () => setState(() => endDate = null),
  onTap: () => _showDatePicker(context, isStart: false),
)
```

**스타일:**
- 가로 Row 레이아웃 (라벨 왼쪽, 날짜 오른쪽)
- 배경: `AppColors.surfaceSecondaryLight`
- 날짜 포맷: `YYYY년 M월 D일`
- 미설정 시: 연한 색상 + placeholder 텍스트
- 우측 아이콘: 설정됨 → ✕ (삭제), 미설정 → > (선택)

### 8.3 RangePickerButton 위젯

줄/마디 범위 값을 표시하는 버튼입니다.

```dart
RangePickerButton(
  label: '시작',
  value: startLine,
  unit: '줄',
  onTap: () => _showRangePicker(context, isStart: true),
)
```

**스타일:**
- 세로 Column 레이아웃 (라벨 위, 값 아래)
- 값: 큰 숫자 + 단위 (예: "2 줄")
- 보더: `AppColors.borderLight`

### 8.4 RangePickerSheet 위젯

iOS 스타일 휠 피커 바텀시트입니다.

```dart
showModalBottomSheet(
  context: context,
  builder: (_) => RangePickerSheet(
    title: '시작 줄',
    unit: '줄',
    initialValue: startLine,
    maxValue: 99,
    onSelected: (value) => setState(() => startLine = value),
  ),
);
```

**구성:**
- 헤더: 취소/확인 버튼 + 제목
- CupertinoPicker: 1 ~ maxValue 범위
