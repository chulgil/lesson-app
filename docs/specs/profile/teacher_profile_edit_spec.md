# 선생님 프로필 편집 시스템 — 종합 스펙

> v1.0 | 2026-03-15 | 경쟁사 8개사 분석 기반

## 1. 개요

### 1.1 문제

선생님 프로필 탭에서 "수정" 버튼을 누르면 ExtendedProfileScreen으로 이동하지만, 이 화면은 **전문 경력 관리** 중심이지 선생님이 일상적으로 편집하고 싶은 기본 정보(교수 스타일, 한 줄 소개, 활동 지역 등)를 직관적으로 수정할 수 없습니다.

비유: 이력서 편집 화면은 있는데, 명함 수정 화면이 없는 상태. 선생님이 학부모에게 보여줄 "첫인상"을 관리할 곳이 없습니다.

### 1.2 경쟁사 벤치마크

| 패턴 | 앱 | 핵심 |
|------|-----|------|
| **공개/비공개 분리** | Calendly, Square, Fresha | 학생이 보는 정보 vs 내부 설정을 분리 |
| **섹션별 Edit** | Square, Fresha, 숨고 | 한 화면에 보여주고 섹션별 편집 |
| **포트폴리오 갤러리** | Fresha, 숨고 | 작업물 사진이 신뢰 구축의 핵심 |
| **자격 인증** | Lessonface, 숨고 | 자격증 사진이 전환율 결정 |
| **한 줄 소개** | 숨고, 당근 | 목록에서 첫인상 결정 |

### 1.3 현재 상태 (v2.0 — 2026-03-26 재설계 완료)

```
ProfileTab (선생님 프로필) — 1탭 접근 원칙
├── 헤더: 아바타 + 이름 + 이메일 (간결)
├── 통계: 학생 수, 완료 레슨, 완료율
│
├── [내 소개]
│   ├── 기본 정보 수정      → BasicInfoEditScreen (이름, 사진, 소개, 교수스타일, 전문분야)
│   ├── 악기 관리           → InstrumentManagementScreen (1탭 직접 접근)
│   ├── 학력·경력·자격증    → ExtendedProfileScreen (교육/경력/자격증 전용)
│   └── 프로필 미리보기     → ProfilePreviewScreen
│
├── [레슨 운영]
│   ├── 레슨 시간 설정      → LessonTimeSettingsScreen
│   ├── 가용 시간 관리      → TeacherAvailabilityScreen
│   ├── 취소/노쇼 정책      → LessonPolicyScreen
│   ├── 레퍼토리 관리       → RepertoireManagementScreen
│   └── 피드백 템플릿       → TipTemplateManagementScreen
│
├── [수강권·입금 상태]
│   ├── 수강권 템플릿       → SubscriptionTemplateListScreen
│   └── 입금 확인 상태      → Subscription status views
│
├── [설정] — 알림, 녹음, 공개 설정
├── [지원] — 도움말, 앱 정보
└── [계정] — 이용약관, 개인정보, 로그아웃
```

**v2.0 개선사항** (2026-03-26):
1. 악기 관리를 3탭→1탭으로 승격 (ExtendedProfile 경유 제거)
2. 숨겨진 화면 메뉴 노출 (입금 확인 상태, 피드백 템플릿, 프로필 미리보기)
3. 레슨 관련 설정 통합 (레퍼토리, 피드백 템플릿을 "레슨 운영"에 그룹핑)
4. 수강권·입금 섹션 신설
5. 사진 편집 진입점 단일화 (BasicInfoEdit에서만)
6. 프로필 탭 헤더 간소화 (중복 소개글/배지 제거)

## 2. 설계 원칙

### 2.1 Fresha + 숨고 하이브리드 모델

```
프로필 탭 (읽기 모드)
├── 공개 프로필 카드 (학생이 보는 정보)
│   ├── 사진 + 이름 + 한 줄 소개
│   ├── 악기 + 경력 + 지역
│   ├── 교수 스타일
│   └── "프로필 미리보기" 버튼
└── 계정 설정 (비공개)
    ├── 연락처, 알림, 백업
    └── 결제, 약관
```

### 2.2 핵심 UX 규칙

1. **섹션별 Edit**: 전체 편집 모드가 아니라 각 섹션의 편집 아이콘으로 해당 섹션만 수정
2. **Progressive Disclosure**: 필수 정보 먼저, 선택 정보는 "더보기"로
3. **한 줄 소개 강조**: 숨고 연구 — 고객 80%가 프로필 보고 결정, 한 줄 소개가 첫인상
4. **인라인 편집 우선**: 한 줄 소개, 교수 스타일 같은 짧은 텍스트는 다이얼로그로 즉시 편집
