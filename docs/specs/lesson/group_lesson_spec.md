## 1. 개요

### 1.1 배경

기존 lesson-app은 1:1 개인 레슨 중심으로 설계되어 있습니다.
음악 학원에서는 앙상블, 합주, 이론 수업 등 **그룹 레슨**이 필요하며,
GX(Group Exercise) 방식을 참고하여 그룹레슨 시스템을 설계합니다.

### 1.2 핵심 목표

| 목표 | 설명 |
|------|------|
| 정기 + 예약형 | 정기 클래스와 예약형 클래스 모두 지원 |
| 정원 관리 | 최대 인원 제한 + 대기자 명단 |
| 유연한 차감 | 참여 시 차감, 사전 변경 시 미차감 |
| 학생 자율 예약 | 원하는 클래스에 자유롭게 예약 |

### 1.3 GX 방식 핵심 특징

```
┌─────────────────────────────────────────────────────────────┐
│                      GX 방식 특징                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 클래스 중심                                              │
│     - "이 시간에 이 클래스가 열린다" → 학생이 선택 예약       │
│     - 선생님이 개별 학생마다 일정 조율 불필요                 │
│                                                             │
│  2. 정원 관리                                                │
│     - 클래스별 최대 인원 설정                                │
│     - 정원 초과 시 대기자 자동 등록                          │
│     - 취소 발생 시 대기자 순서대로 자동 승급                  │
│                                                             │
│  3. 수강권 차감 = 출석 시                                    │
│     - 예약만으로는 차감 안 됨                                │
│     - 실제 참여(체크인) 시 1회 차감                          │
│     - 노쇼도 차감 (정책에 따라)                              │
│                                                             │
│  4. 자유로운 예약/변경                                       │
│     - 클래스 시작 N시간 전까지 자유롭게 예약/취소             │
│     - 수강권 변경 횟수와 별개 (그룹레슨용 별도 정책)          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 클래스 유형

### 2.1 정기 클래스 (Regular Class)

매주 고정 시간에 열리는 클래스

```
[정기 클래스 예시]
┌─────────────────────────────────────┐
│  🎻 앙상블 클래스                    │
│  매주 토요일 14:00 (60분)            │
│  김선생님 · 정원 6명                 │
├─────────────────────────────────────┤
│                                     │
│  2월 스케줄                          │
│  • 2/1(토) 14:00 - 4/6명 예약       │
│  • 2/8(토) 14:00 - 6/6명 만석 🔴     │
│  • 2/15(토) 14:00 - 2/6명 예약      │
│  • 2/22(토) 14:00 - 0/6명 오픈      │
│                                     │
└─────────────────────────────────────┘
```

**특징:**
- 한 번 등록하면 매주 자동 생성
- 학생은 원하는 날짜에 예약
- 휴강 설정 가능 (휴일, 선생님 부재 등)

### 2.2 예약형 클래스 (Drop-in Class)

선생님이 필요에 따라 스케줄을 오픈하는 클래스

```
[예약형 클래스 예시]
┌─────────────────────────────────────┐
│  🎼 이론 특강                        │
│  비정기 · 스케줄 오픈 시 예약 가능   │
│  박선생님 · 정원 10명                │
├─────────────────────────────────────┤
│                                     │
│  오픈된 스케줄                       │
│  • 2/5(수) 19:00 - 8/10명 예약      │
│  • 2/20(목) 19:00 - 3/10명 예약     │
│                                     │
│  ℹ️ 새 스케줄 오픈 시 알림 받기      │
│                                     │
└─────────────────────────────────────┘
```

**특징:**
- 선생님이 수동으로 스케줄 오픈
- 특강, 워크샵, 마스터클래스 등에 적합
- 알림 구독 기능

### 2.3 유형 비교

| 구분 | 정기 클래스 | 예약형 클래스 |
|------|-----------|-------------|
| **스케줄 생성** | 자동 (매주) | 수동 (오픈) |
| **반복 패턴** | 요일/시간 고정 | 없음 |
| **적합 용도** | 앙상블, 합주, 정기 이론 | 특강, 워크샵 |
| **알림** | 예약 가능 알림 | 새 스케줄 오픈 알림 |

## 3. 정원 관리

### 3.1 정원 설정

```dart
/// 그룹 클래스 정의
class GroupClass {
  final String id;
  final String name;              // "앙상블 클래스"
  final String teacherId;
  final GroupClassType type;      // regular, dropIn
  final int maxCapacity;          // 최대 정원 (예: 6명)
  final int? waitlistCapacity;    // 대기자 최대 (null = 무제한)
  final Duration duration;        // 수업 시간
  final String? description;
  // ... 반복 패턴, 가격 등
}
```

### 3.2 예약 상태

| 상태 | 설명 | 아이콘 |
|------|------|:------:|
| **available** | 예약 가능 | 🟢 |
| **almostFull** | 거의 만석 (80% 이상) | 🟡 |
| **full** | 만석 (대기 가능) | 🟠 |
| **waitlist** | 대기 중 | ⏳ |
| **closed** | 예약 마감 | 🔴 |

### 3.3 대기자 명단 (Waitlist)

```
[대기자 플로우]

1. 만석인 클래스에 예약 시도
   │
   ▼
2. "대기자로 등록하시겠습니까?" 안내
   │
   ▼
3. 대기자 등록 (대기 순번 부여)
   │
   ├── 취소 발생 ──▶ 순서대로 자동 승급
   │                    │
   │                    ▼
   │               푸시 알림 + 앱 알림
   │               "2/8 앙상블 예약이 확정되었습니다!"
   │
   └── 클래스 시작 ──▶ 대기자 자동 취소 (차감 없음)
```

**대기자 UI:**
```

┌─────────────────────────────────────┐
│  🎻 앙상블 클래스                    │
│  2/8(토) 14:00                      │
│  김선생님                            │
├─────────────────────────────────────┤
│                                     │
│  🔴 만석 (6/6명)                     │
│                                     │
│  대기자 현황: 2명                    │
│                                     │
│  [대기자로 등록하기]                  │
│                                     │
│  ℹ️ 취소 발생 시 순서대로 예약됩니다  │
│                                     │

## 4. 수강권 차감 정책

### 4.1 핵심 원칙

```
┌─────────────────────────────────────────────────────────────┐
│                    수강권 차감 = 참여 시                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ❌ 예약 시 차감 안 함                                       │
│  ✅ 실제 참여 (출석 체크) 시 1회 차감                         │
│                                                             │
│  변경/취소:                                                  │
│  • 클래스 시작 전: 자유롭게 취소 가능 (차감 없음)            │
│  • 클래스 시작 후: 취소 불가 (노쇼 처리)                     │
│                                                             │
│  노쇼 정책:                                                  │
│  • 예약 후 미참석 → 수강권 1회 차감 (선생님 설정)           │
│  • 또는 노쇼 패널티 없음 (선생님 설정)                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 차감 타이밍

| 상황 | 차감 시점 | 차감 여부 |
|------|----------|:--------:|
| **예약** | - | ❌ |
| **예약 후 사전 취소** | - | ❌ |
| **클래스 참여 (출석)** | 출석 체크 시 | ✅ 1회 |
| **노쇼 (미참석)** | 클래스 종료 시 | ⚙️ 설정에 따름 |

### 4.3 출석 체크 방식

```
[클래스 시작 - 선생님 화면]

│  2/8(토) 14:00 · 진행 중            │
├─────────────────────────────────────┤
│                                     │
│  출석 체크                           │
│  ┌─────────────────────────────────┐│
│  │ ✅ 김서연   [참여] ■□□□□□□□ -1회 ││
│  │ ✅ 이도현   [참여] ■□□□□□□□ -1회 ││
│  │ ⬜ 박민지   [미참]               ││
│  │ ✅ 최유진   [참여] ■□□□□□□□ -1회 ││
│  │ ⬜ 정하늘   [미참]               ││

## 6. 데이터 모델

### 6.1 그룹 클래스 (GroupClass)

```dart
/// 그룹 클래스 유형
enum GroupClassType {
  regular,    // 정기 클래스
  dropIn,     // 예약형 클래스
}

/// 노쇼 정책
enum NoShowPolicy {
  deduct,     // 노쇼 시 수강권 차감
  noDeduct,   // 노쇼 시 차감 없음
}

/// 그룹 클래스 정의
@HiveType(typeId: 70)
@JsonSerializable()
class GroupClass {
  @HiveField(0)
  final String id;

  @HiveField(1)
  final String teacherId;

  @HiveField(2)
  final String? organizationId;     // 학원 ID (null = 개인)

  @HiveField(3)
  final String name;                // "앙상블 클래스"

  @HiveField(4)
  final String? description;

  @HiveField(5)
  final GroupClassType type;        // regular, dropIn

  @HiveField(6)
  final int maxCapacity;            // 최대 정원

  @HiveField(7)
  final int? waitlistCapacity;      // 대기자 최대 (null = 무제한)

  @HiveField(8)
  final int durationMinutes;        // 수업 시간 (분)

  @HiveField(9)
  final int? bookingDeadlineMinutes; // 예약 마감 (시작 N분 전, null = 직전까지)

  @HiveField(10)
  final int? cancelDeadlineMinutes;  // 취소 마감 (시작 N분 전)

  @HiveField(11)
  final NoShowPolicy noShowPolicy;   // 노쇼 정책

  @HiveField(12)
  final int? maxNoShowCount;         // 노쇼 허용 횟수 (초과 시 제한)

  // 정기 클래스용 반복 설정
  @HiveField(13)
  final List<int>? repeatDaysOfWeek; // [6] = 매주 토요일

  @HiveField(14)
  final String? repeatTimeOfDay;     // "14:00"

  @HiveField(15)
  final bool isActive;

  @HiveField(16)
  final DateTime createdAt;

  @HiveField(17)
  final DateTime? updatedAt;

  const GroupClass({
    required this.id,
    required this.teacherId,
    this.organizationId,
    required this.name,
    this.description,
    required this.type,
    required this.maxCapacity,
    this.waitlistCapacity,
    required this.durationMinutes,
    this.bookingDeadlineMinutes,
    this.cancelDeadlineMinutes = 120, // 기본 2시간 전
    this.noShowPolicy = NoShowPolicy.noDeduct,
    this.maxNoShowCount,
    this.repeatDaysOfWeek,
    this.repeatTimeOfDay,
    this.isActive = true,
    required this.createdAt,
    this.updatedAt,
  });
}
```

### 6.2 그룹 클래스 스케줄 (GroupClassSchedule)

```dart
/// 스케줄 상태
enum ScheduleStatus {
  open,       // 예약 가능
  full,       // 만석 (대기 가능)
  closed,     // 예약 마감
  cancelled,  // 휴강
  completed,  // 종료됨
}

/// 그룹 클래스 스케줄 (개별 회차)
@HiveType(typeId: 71)
@JsonSerializable()
class GroupClassSchedule {
  @HiveField(0)
  final String id;

  @HiveField(1)
  final String groupClassId;        // FK → GroupClass

  @HiveField(2)
  final DateTime startTime;         // 시작 시간

  @HiveField(3)
  final DateTime endTime;           // 종료 시간

  @HiveField(4)
  final ScheduleStatus status;

  @HiveField(5)
  final int currentBookings;        // 현재 예약 수

  @HiveField(6)
  final int waitlistCount;          // 대기자 수

  @HiveField(7)
  final String? cancelReason;       // 휴강 사유

  @HiveField(8)
  final DateTime createdAt;

  const GroupClassSchedule({
    required this.id,
    required this.groupClassId,
    required this.startTime,
    required this.endTime,
    this.status = ScheduleStatus.open,
    this.currentBookings = 0,
    this.waitlistCount = 0,
    this.cancelReason,
    required this.createdAt,
  });

  /// 예약 가능 여부
  bool get canBook => status == ScheduleStatus.open;

  /// 대기 등록 가능 여부
  bool get canWaitlist => status == ScheduleStatus.full;
}
```

### 7.3 선생님 화면 - 출석 체크 (단순화)

> 설계 원칙: **"생각없이 출석 체크"** - 기본값 자동 적용, 예외만 수정
> 참고: [ux_guidelines.md](../design/ux_guidelines.md) 섹션 13 - 레슨 유형별 UI

**핵심 원칙:**
1. **기본값**: 예약자 전원 참석 (수업 시작 시 자동 체크)
2. **역방향 처리**: 미참석자만 선택 해제
3. **원탭 완료**: [수업 종료] 한 번에 차감 + 완료

```
[클래스 진행 - 선생님 (단순화)]
┌─────────────────────────────────────┐
│  🎵 앙상블 클래스                    │
│  2/8(토) 14:00 · 진행 중 ⏱️         │
│                                     │
│  참석: 5/6명                        │  ← 실시간 표시
├─────────────────────────────────────┤
│                                     │
│  미참석자만 탭하세요                  │  ← 명확한 안내
│                                     │
│  ┌─────────────────────────────────┐│
│  │ ☑️ 김서연  ☑️ 이도현  ⬜ 박민지 ││  ← 기본 체크
│  │ ☑️ 최유진  ☑️ 정하늘  ☑️ 한소율 ││     미참석만 해제
│  └─────────────────────────────────┘│
│                                     │
│  차감 예정: 5명                      │
│  ⚠️ 한소율: 2회 → 1회 (마지막!)     │  ← 경고만 표시
│                                     │
│  ┌─────────────────────────────────┐│
│  │       수업 종료하기              ││  ← 원탭 완료
│  └─────────────────────────────────┘│
│                                     │
└─────────────────────────────────────┘
```

**개선 포인트:**
| 이전 | 개선 | 이유 |
|------|------|------|
| [전체 참석] [전체 미참석] 버튼 | 제거 | 불필요한 선택지 |
| 개별 차감 내역 전체 표시 | 경고 케이스만 표시 | 정보 과부하 감소 |
| "개별 체크 (탭하여 토글)" | "미참석자만 탭하세요" | 명확한 가이드 |

**인터랙션:**
- 수업 시작: 예약자 전원 자동 체크 ✅
- 칩 탭: 참석 ↔ 미참석 토글
- [수업 종료하기]: 출석 확정 + 수강권 차감 + 토스트 "5명 출석 완료!"
