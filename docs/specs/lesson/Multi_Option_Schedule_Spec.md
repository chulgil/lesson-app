# 다중 옵션 스케줄 제안 시스템 스펙

> 작성일: 2025-12-29
> 업데이트: 2026-01-26 (선생님 → 학생 제안 시스템 추가)

## 개요

**양방향** 다중 옵션 스케줄 제안 시스템:

| 방향 | 사용 케이스 | 설명 |
|------|------------|------|
| **학생 → 선생님** | 체험레슨, 1회 레슨 신청 | 학생이 1~3개 옵션 제안 → 선생님 선택 |
| **선생님 → 학생** | 정기레슨 등록, 스케줄 변경 | 선생님이 1~3개 옵션 제안 → 학생/학부모 선택 |

기존 단일 선택 → 거절 → 재신청 왕복을 줄여 스케줄 조정 효율성을 크게 향상.

---

## 배경

### 기존 시스템의 문제점

```
[기존 플로우 - 평균 2-3회 왕복]
학생: 12/30 14시 신청
  → 선생님: 거절 (다른 학생 예약됨)
  → 학생: 12/31 15시 재신청
  → 선생님: 거절 (개인 일정)
  → 학생: 1/2 16시 재신청
  → 선생님: 승인
```

### 개선된 시스템

```
[개선 플로우 - 1회로 완료]
학생: 1순위 12/30 14시, 2순위 12/31 15시, 3순위 1/2 16시
  → 선생님: 3순위 선택 (1/2 16시 확정)
```

## 상태 관리

### 신청 상태 (BookingStatus)

```dart
enum BookingStatus {
  pending,    // 대기중 - 선생님 응답 대기
  confirmed,  // 확정됨 - 선생님이 옵션 선택하여 승인
  rejected,   // 거절됨 - 선생님이 모든 옵션 거절
}
```

### 상태 흐름

```
┌─────────┐     선생님 선택      ┌──────────┐
│ 대기중   │ ─────────────────→ │  확정됨   │
│ pending │                     │ confirmed│
└────┬────┘                     └──────────┘
     │
     │ 전체 거절 + 메시지
     ↓
┌──────────┐
│  거절됨   │ → 메시지로 조율 → 학생 재신청
│ rejected │
└──────────┘
```

```dart
Future<void> approveBooking({
  required String bookingId,
  required String selectedOptionId,
}) async {
  final booking = await getBooking(bookingId);
  final selectedOption = booking.scheduleOptions
      .firstWhere((o) => o.id == selectedOptionId);

  // 1. 상태 업데이트
  await updateBooking(
    bookingId,
    status: BookingStatus.confirmed,
    selectedOptionId: selectedOptionId,
    confirmedDate: selectedOption.date,
    confirmedStartTime: selectedOption.startTime,
    confirmedEndTime: selectedOption.endTime,

  );
}
```

## 엣지 케이스

### 1. 옵션 충돌 발생 시

**시나리오**: 학생 A가 1순위로 12/30 14시 신청, 학생 B도 같은 시간 신청

**처리**:
- 먼저 신청한 학생의 옵션이 우선
- 나중에 신청하는 학생에게는 해당 시간 선택 불가
- 대기중인 다른 신청의 옵션과도 충돌 검사 (선택적)

### 2. 승인 전 옵션 수정 시

**시나리오**: 학생이 옵션 수정 중에 선생님이 승인 시도

**처리**:
- 낙관적 잠금 사용
- 수정 중이면 승인 실패 → 새로고침 후 재시도 안내

### 3. 정규레슨 주2회 조합

**시나리오**: 요일 조합별로 시간대가 다를 수 있음

**처리**:
- 각 조합별로 두 요일의 시간을 함께 저장
- 예: 1안(화16시+목16시), 2안(수15시+토10시)

## Part B: 선생님 → 학생 제안 시스템

> 추가일: 2026-01-26

---

### B.1 개요

선생님이 정기 레슨 등록이나 스케줄 변경 시, 학생(또는 학부모)에게 다중 옵션을 제안하는 시스템.

#### 사용 케이스

| 케이스 | 설명 |
|--------|------|
| **정기레슨 등록** | 체험레슨 후 정기 등록 제안 |
| **스케줄 변경 제안** | 기존 레슨 시간 변경 필요 시 |
| **추가 레슨 제안** | 주 1회 → 주 2회 확대 등 |

---

```dart
class LessonProposal {
  final String id;
  final String teacherId;
  final String studentId;
  final String? parentId;         // 학부모에게 발송 시

  final LessonType type;          // 정규(주1회), 정규(주2회)

  final DateTime proposedStartDate;

  // 다중 옵션
  final List<ScheduleOption> scheduleOptions;
  final String? selectedOptionId;

  final int? subscriptionAmount;  // 금액

  final DateTime createdAt;

}

  pending,    // 대기중
  accepted,   // 수락됨
  rejected,   // 거절됨
  expired,    // 만료됨 (7일 무응답)
```

### B.7 비즈니스 로직

#### 1. 제안 발송

```dart
Future<void> sendProposal(LessonProposal proposal) async {
  // 1. 옵션 유효성 검사 (가용시간 내인지)
  for (final option in proposal.scheduleOptions) {
    if (!isWithinAvailability(option, proposal.teacherId)) {
      throw InvalidSlotException('가용시간 외 슬롯입니다');
    }
  }

  // 2. 제안 저장
  await proposalRepository.save(proposal);

  // 3. 학생/학부모에게 알림
  await notificationService.send(
    userId: proposal.parentId ?? proposal.studentId,
    title: '새로운 레슨 제안',
    body: '${proposal.teacherName}님이 정기레슨을 제안했습니다',
  );

  // 4. 7일 후 만료 스케줄링
  await scheduleExpiration(proposal.id, Duration(days: 7));
}
```

#### 2. 제안 응답 (수락)

```dart
Future<void> acceptProposal({
  required String proposalId,
  required String selectedOptionId,
}) async {
  final proposal = await proposalRepository.get(proposalId);
  final selectedOption = proposal.scheduleOptions
      .firstWhere((o) => o.id == selectedOptionId);

  // 1. 제안 상태 업데이트
  await proposalRepository.update(
    proposalId,
    status: ProposalStatus.accepted,
    selectedOptionId: selectedOptionId,
    respondedAt: DateTime.now(),
  );

  // 2. 정기 레슨 스케줄 생성
  await lessonScheduleService.createRecurring(
    teacherId: proposal.teacherId,
    studentId: proposal.studentId,
    dayOfWeek: selectedOption.dayOfWeek,
    startTime: selectedOption.startTime,
    startDate: proposal.proposedStartDate,
  );

  // 3. 수강권 생성 (미수금 상태)
  if (proposal.subscriptionCount != null) {
    await subscriptionService.create(
      studentId: proposal.studentId,
      count: proposal.subscriptionCount!,
      amount: proposal.subscriptionAmount!,
      validMonths: proposal.subscriptionValidMonths!,
      paymentStatus: PaymentStatus.pending,  // 미수금
    );
  }

  // 4. 선생님에게 알림
  await notificationService.send(
    userId: proposal.teacherId,
    title: '제안 수락됨',
    body: '${proposal.studentName}님이 정기레슨을 수락했습니다',
  );
}
```

#### 3. 제안 응답 (거절)

```dart
Future<void> rejectProposal({
  required String proposalId,
  String? message,
}) async {
  // 1. 상태 업데이트
  await proposalRepository.update(
    proposalId,
    status: ProposalStatus.rejected,
    responseMessage: message,
    respondedAt: DateTime.now(),
  );

  // 2. 선생님에게 알림
  await notificationService.send(
    userId: proposal.teacherId,
    title: '제안 거절됨',
    body: message != null
        ? '${proposal.studentName}님: "$message"'
        : '${proposal.studentName}님이 제안을 거절했습니다',
  );
}
```
