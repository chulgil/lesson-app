# 빠른 피드백 스펙

> Last updated: 2026-03-08
> Issue: #88

## 1. 개요

선생님이 학생에게 피드백을 보내는 과정을 카카오톡 수준으로 단순화한다.
카톡: 앱 열기 → 대화방 선택 → 메시지 작성. 총 3단계.
우리 앱도: 피드백 버튼 → 학생 선택 → 피드백 작성. 총 3단계.

**핵심**: 5명 이상 학생을 고려한 UX 설계

---

## 2. 현재 문제

### 2.1 피드백 저장 버그 (CRITICAL)

`lesson_detail_screen.dart` 249줄:
```dart
LessonNoteEditor(initialText: lesson.feedback),  // ⚠️ onChanged 없음!
```
- `onChanged` 핸들러가 연결되지 않아 피드백이 **저장되지 않음**
- 선생님이 피드백을 작성해도 화면을 나가면 사라짐

### 2.2 접근 경로가 복잡 (5단계)

```
현재: 홈 → 레슨 카드 탭 → 레슨 상세 → 노트 탭 → 텍스트 입력
목표: 홈 → 피드백 버튼 → 학생 선택 + 피드백 작성
```

---

## 3. 구현 범위

### Phase A: 피드백 저장 버그 수정 (긴급)

`LessonNoteEditor`에 `onChanged` + debounce 자동 저장 연결

### Phase B: 빠른 피드백 UI

홈 대시보드에서 3단계로 피드백 전달 가능하게 함

---

## 4. 빠른 피드백 UI 설계

### 4.1 진입점

**홈 대시보드 "오늘 레슨" 섹션** 하단에 "피드백 보내기" 버튼 추가:

```
┌─ 오늘 레슨 ─────────────────────────────┐
│                                          │
│  10:00  김민준 · 바이올린         완료    │
│  14:00  이서연 · 피아노           예정    │
│  16:00  정다은 · 바이올린         예정    │
│                                          │
│  ┌──────────────────────────────────┐    │
│  │  ✏️  피드백 보내기               │    │
│  └──────────────────────────────────┘    │
└──────────────────────────────────────────┘
```

### 4.2 학생 선택 화면 (5명 이상 대응)

"피드백 보내기" 탭 → 풀스크린 모달 또는 바텀시트:

```
┌──────────────────────────────────┐
│  <- 피드백 보내기                  │
├──────────────────────────────────┤
│  🔍 학생 검색...                  │
│                                  │
│  오늘 레슨                        │
│  ┌─────────────────────────────┐ │
│  │ [🟢] 김민준 · 바이올린       │ │
│  │      10:00 레슨 (완료)       │ │
│  ├─────────────────────────────┤ │
│  │ [⏳] 이서연 · 피아노         │ │
│  │      14:00 레슨 (예정)       │ │
│  ├─────────────────────────────┤ │
│  │ [⏳] 정다은 · 바이올린       │ │
│  │      16:00 레슨 (예정)       │ │
│  └─────────────────────────────┘ │
│                                  │
│  최근 레슨                        │
│  ┌─────────────────────────────┐ │
│  │ [👤] 박지호 · 첼로           │ │
│  │      3월 7일 마지막 레슨      │ │
│  ├─────────────────────────────┤ │
│  │ [👤] 최유진 · 플루트         │ │
│  │      3월 5일 마지막 레슨      │ │
│  └─────────────────────────────┘ │
└──────────────────────────────────┘
```

**5명 이상 학생 대응:**
- 상단 검색 바로 이름/악기 검색
- "오늘 레슨" 섹션: 오늘 레슨이 있는 학생 우선 표시 (가장 피드백 필요)
- "최근 레슨" 섹션: 나머지 학생 (마지막 레슨 날짜 기준 정렬)
- 10명 이상이면 스크롤, 검색이 주요 탐색 수단

### 4.3 피드백 작성 (학생 선택 후)

학생을 탭하면 해당 학생의 **가장 최근 레슨**에 연결된 피드백 입력:

```
┌──────────────────────────────────┐
│  <- 김민준 피드백                  │
│                                  │
│  3월 8일 (오늘) 10:00 레슨        │
│  바이올린 · 50분                  │
│                                  │
│  ┌──────────────────────────────┐│
│  │                              ││
│  │  피드백을 작성하세요...        ││
│  │                              ││
│  │                              ││
│  │                              ││
│  │                              ││
│  └──────────────────────────────┘│
│                                  │
│  주요 포인트                      │
│  [+ 추가]                        │
│  • 보잉 각도 개선됨               │
│                                  │
│  ──────────────────────────────  │
│                                  │
│          [저장하기]               │
│                                  │
└──────────────────────────────────┘
```

**동작:**
- 기존 `lesson.feedback`에 저장
- "저장하기" 버튼 → 저장 + 이전 화면 복귀 + SnackBar
- 주요 포인트는 기존 `AddTipBottomSheet` 재사용
- 피드백이 이미 있으면 기존 내용 표시 (수정 가능)

---

## 5. 데이터 흐름

```
1. 홈 → "피드백 보내기" 탭
2. 오늘 레슨 학생 목록 로드 (lessonsProvider + 날짜 필터)
3. 학생 탭 → 해당 학생의 최신 레슨 조회
4. 피드백 입력 → lesson.copyWith(feedback: text)
5. lessonsNotifier.updateLesson(lesson) 호출
6. 저장 완료 SnackBar + 이전 화면
```
