## 1. 개인 레슨: 선생님이 초대 (신규)

> **QR 스캔 = 자동 연결**: 추가 버튼 탭 없이 스캔 즉시 연결됩니다.

```mermaid
sequenceDiagram
    autonumber
    participant S as 🎓 학생/학부모
    participant P as 📱 외부 플랫폼<br/>(숨고/크몽/블로그)
    participant K as 💬 카카오톡
    participant T as 🎻 선생님
    participant App as 📱 Lesson App

    Note over S,App: 🔍 Phase 1: 선생님 발굴 (외부 플랫폼)

    S->>P: 검색 "강남 바이올린 레슨"
    P-->>S: 숨고, 크몽, 블로그 결과

    S->>P: 선생님 A 연락처 확인
    S->>K: "바이올린 레슨 문의드립니다"
    K->>T: 메시지

    Note over K,T: 💬 카카오톡으로 상담 진행<br/>(기존과 동일)

    T->>K: "체험 레슨 진행해보시겠어요?"
    K->>S: 체험 제안

    Note over S,App: 🎻 Phase 2: 체험 레슨 (대면)

    Note over T,S: 체험 레슨 진행

    S->>T: "등록하고 싶어요"
    T->>T: 정기 레슨 결정

    Note over S,App: 📱 Phase 3: QR 스캔 = 자동 연결

    T->>App: 앱에서 QR 코드 표시
    App-->>T: 선생님 고유 QR 코드

    T->>S: "이 QR 스캔해주세요"

    S->>App: QR 스캔 → 앱 설치/로그인

    App->>App: 자동 연결 (trialBooked)

    App-->>S: 연결 완료 + 환영 화면
    Note over App: ✅ 홍선생님과 연결되었습니다!<br/>🎻 바이올린 · 15년 경력

    App-->>T: "🔔 김민수 학생이 연결되었습니다"

    Note over S,App: ✅ 해결: 제로 탭 연결<br/>QR 스캔만으로 즉시 연결 (버튼 탭 불필요)
```

#### QR 연결 완료 화면 (학생 앱)

```
┌─────────────────────────────────────┐
│                                     │
│         ✅ 연결 완료!               │
│                                     │
│    ┌───────────────────────────┐    │
│    │        👤                 │    │
│    │    홍선생님               │    │
│    │  🎻 바이올린 · 15년 경력   │    │
│    └───────────────────────────┘    │
│                                     │
│    체험 레슨 후 수강권을 받으면     │
│    정기 레슨을 시작할 수 있어요     │
│                                     │
│         [프로필 보기]               │
│         [홈으로 가기]               │
│                                     │
│  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    │
│  잘못 연결되었나요? [연결 해제]     │
│                                     │
└─────────────────────────────────────┘
```

#### 왜 자동 연결인가?

| 관점 | 이유 |
|------|------|
| **UX** | QR 스캔 자체가 명시적 동의, 추가 탭은 마찰 |
| **상황** | 체험 후 대면 상황에서 확인 단계는 과잉 |
| **선생님** | 어색한 대기 시간 없이 프로페셔널한 경험 |
| **학생** | "뭘 눌러야 하지?" 혼란 없이 간단명료 |

## 2. 개인 레슨: 학생이 초대 (역방향)

> **URL 클릭 = 자동 연결**: 선생님이 초대 링크로 가입하면 즉시 연결됩니다.

```mermaid
sequenceDiagram
    autonumber
    participant S as 🎓 학생/학부모
    participant P as 📱 외부 플랫폼
    participant K as 💬 카카오톡
    participant T as 🎻 선생님
    participant App as 📱 Lesson App

    Note over S,App: 🔍 Phase 1: 선생님 발굴 (외부)

    S->>P: 선생님 검색
    S->>K: 선생님에게 연락
    K->>T: 레슨 문의

    Note over K,T: 💬 상담 진행

    Note over S,App: 📱 Phase 2: 학생이 앱 소개

    S->>K: "레슨앱 쓰시면 관리가 편해요!<br/>이 링크로 가입해보세요"
    S->>App: 앱에서 초대 URL 복사
    App-->>S: https://lessonapp.link/invite/student123
    S->>K: URL 전송
    K->>T: 초대 링크

    T->>App: 링크 클릭 → 앱 설치/로그인

    Note over T,App: 선생님 프로필 설정 (첫 사용 시)

    T->>App: 프로필 작성 (이름, 악기, 소개글)

    App->>App: 자동 연결 (trialBooked)

    App-->>T: 연결 완료 + 학생 정보 표시
    Note over App: ✅ 김민수 학생과 연결되었습니다!

    App-->>S: "🔔 홍선생님이 연결되었습니다"

    Note over S,App: ✅ 해결: 선생님 온보딩 + 자동 연결<br/>프로필 작성 완료 시 즉시 연결
```

## 3. 학원 레슨

```mermaid
sequenceDiagram
    autonumber
    participant S as 🎓 학생/학부모
    participant A as 🏫 학원
    participant App as 📱 Lesson App
    participant T as 🎻 담당 선생님

    Note over S,T: 🏫 Phase 1: 학원 등록

    S->>A: 학원 방문/전화
    A->>S: "앱으로 레슨 관리해요"

    A->>App: 학원 QR 코드 제공
    S->>App: QR 스캔 → 학원 페이지

    Note over S,App: 📱 Phase 2: 학원 내 선생님 조회

    App-->>S: 학원 소속 선생님 목록

    Note over App: 🏫 OO음악학원<br/>├── 김바이올린 선생님 (바이올린)<br/>├── 박피아노 선생님 (피아노)<br/>└── 이첼로 선생님 (첼로)

    S->>App: 김바이올린 선생님 선택

    App-->>S: 선생님 프로필<br/>(경력, 소개, 가능 시간)

    S->>App: "체험 신청" 탭

    App->>T: "🔔 체험 레슨 신청\n학생: 김민수"

    T->>App: 신청 확인 → 승인

    App-->>S: "✅ 체험 레슨 승인\n토요일 14:00"

    Note over S,T: ✅ 해결: 선생님 선택권<br/>학원 배정이 아닌 학생이 직접 선택

    Note over S,T: 🎻 Phase 3: 체험 후 정기 등록

    Note over T,S: 체험 레슨 진행

    T->>App: 정기 레슨 제안 발송

    App->>S: "📋 정기 레슨 제안\n토요일 14:00 / 월 4회"

    S->>App: 수락

    App->>App: 관계 active + 스케줄 자동 생성

    Note over App: ✅ 해결: 학원 Context 유지<br/>레슨 기록이 학원에 귀속
```

## 4. 휴식 후 재등록 (past 상태)

> ⚠️ **이전 선생님 재연결은 "레슨 요청" 버튼 사용** (신규 QR 자동 연결과 다름)
>
> 이전 선생님은 이미 체험을 했으므로, **수강권 제안 → 발급**까지 완결되는 플로우
>
> 상세: [lesson_request_system.md](../subscription/lesson_request_system.md)
>
> **📋 구현 현황**: 기본 플로우 구현 완료. 알림 연동 및 스케줄 자동 복원 작업 중.

#### 휴식 기간에 따른 관계 상태

| 휴식 기간 | 관계 상태 | 설명 | 재등록 방식 |
|----------|----------|------|------------|
| ~30일 | `expired` | 수강권 만료 유예 | 갱신 알림 → 간편 재등록 |
| **30일+** | `past` | 이전 학생 | **레슨 요청 필요** |

> **2개월 휴식 = `past` 상태** → 선생님이 스케줄 여유 확인 후 수강권 제안

```mermaid
sequenceDiagram
    autonumber
    participant S as 🎓 학생/학부모
    participant App as 📱 Lesson App
    participant Push as 🔔 푸시 알림
    participant T as 🎻 이전 선생님

    Note over S,T: 🔄 시나리오: 2개월 휴식 후 재등록<br/>(관계 상태: past)

    S->>App: 앱 실행 → "선생님 찾기"
    App-->>S: 검색 옵션

    Note over App: 🔍 검색 옵션<br/>├── 이전 선생님 (레슨 이력 있음) ✅<br/>├── 학원 선생님 (학원 등록 시) ✅<br/>└── 새 선생님 검색 ❌ 불가

    S->>App: "이전 선생님" 선택
    App-->>S: 과거 레슨 이력 목록

    Note over App: 📋 이전 선생님 목록<br/>├── 김바이올린 선생님 (2024.03~2024.12)<br/>│   이전 스케줄: 토 15:00<br/>└── 박피아노 선생님 (2023.01~2023.06)

    S->>App: 김바이올린 선생님 선택
    App-->>S: 선생님 프로필 + 레슨 요청 버튼

    Note over S,T: 📱 Phase 1: 학생이 레슨 요청 (4단계 중 1)

    S->>App: "레슨 요청" 탭
    App-->>S: 요청 입력 폼

    Note over App: 메시지 (선택): "다시 레슨 받고 싶습니다"<br/>희망 시작: 다음 주<br/>이전 스케줄: 토 15:00 [유지하기]

    S->>App: 요청 작성 → 전송

    App->>Push: 선생님에게 알림
    Push->>T: "🔔 레슨 요청 도착\n김민수 학생 (2개월 만에 복귀)"

    Note over S,T: ⏱️ Phase 2: 선생님 응답 (4단계 중 2)

    T->>App: 알림 탭 → 요청 확인
    App-->>T: 학생 정보 + 이전 레슨 기록

    Note over App: 📋 김민수 학생<br/>├── 이전: 2024.03~12 (24회)<br/>├── 이전 스케줄: 토 15:00 (매주)<br/>├── 희망: 이전 스케줄 유지<br/>└── 💬 "다시 레슨 받고 싶습니다"

    alt 수강권 제안
        T->>App: "수강권 제안" 버튼
        App-->>T: 수강권 템플릿 선택 화면

        T->>App: 8회권 선택 → 제안 발송

        App->>Push: 학생에게 알림
        Push->>S: "🎉 수강권 제안 도착!\n8회권 (38만원)"

        Note over S,T: 💳 Phase 3: 학생 결제 (4단계 중 3)

        S->>App: 제안 확인 → 입금 완료
        S->>App: "입금 완료" 버튼 탭

        App->>Push: 선생님에게 알림
        Push->>T: "💰 김민수 입금 알림"

        Note over S,T: ⭐ Phase 4: 입금 확인 = 발급 (1탭!)

        T->>App: "입금 확인" 버튼 탭 (1번만!)

        App->>App: 🔄 자동 처리 시작
        Note over App: 1. 수강권 발급 (8회)<br/>2. 관계 active 전환<br/>3. 스케줄 확인 카드 생성

        App->>Push: 완료 알림 (양쪽)
        Push->>S: "✅ 수강권 발급!\n레슨 시간을 확정해주세요"
        Push->>T: "✅ 김민수 수강권 발급 완료"

        Note over S,T: 📅 Phase 5: 학생 스케줄 확인 (1탭!)

        S->>App: 앱 열기
        App-->>S: 스케줄 확인 카드 표시

        Note over App: ┌───────────────────────┐<br/>│ 🎉 수강권 발급 완료!   │<br/>│ 8회권 · 바이올린      │<br/>│                       │<br/>│ ⭐ 이전 스케줄로 예약? │<br/>│ 토 15:00 (매주)       │<br/>│ [이 시간으로 예약]    │<br/>│ [다른 시간 선택]      │<br/>└───────────────────────┘

        S->>App: "이 시간으로 예약" 탭 (1번!)
        App->>App: 스케줄 확정

        App->>Push: 스케줄 확정 알림
        Push->>T: "📅 김민수 스케줄 확정\n토 15:00 (매주)"

        Note over S,T: ✅ 핵심: 학생이 명시적 확인!<br/>이전 스케줄 추천 + 학생 동의 후 확정

    else 정중히 거절
        T->>App: "정중히 거절" 버튼
        App-->>T: 거절 사유 선택

        T->>App: "현재 스케줄 꽉 참" 선택 → 전송

        App->>Push: 학생에게 알림
        Push->>S: "김선생님: 현재 스케줄이 어렵습니다"

        App-->>S: 다른 선생님 찾기 옵션 제시
    end

    opt 스케줄 변경 필요 시
        S->>App: "다른 시간으로 변경" 탭
        App-->>S: 선생님 가용 시간 표시
        S->>App: 새 시간 선택 (예: 일 14:00)
        App->>Push: 선생님에게 변경 요청
        T->>App: 승인
    end

    Note over App: ✅ 해결: 레슨 요청 → 수강권 제안 → 발급 + 스케줄 복원<br/>이전 스케줄 자동 적용으로 선택 부담 제거
```

#### 휴식 후 재등록 플로우 요약 (5단계)

| # | 주체 | 액션 | 앱 미사용 |
|:-:|:----:|------|----------|
| 1 | S | 레슨 요청 | 연락처 찾아서 카톡 |
| 2 | T | 수강권 제안 | 카톡으로 비용 안내 |
| 3 | S | 수락 + 입금 | 입금 |
| 4 | T | 입금 확인 → 수강권 발급 | 확인 |
| 5 | S | **스케줄 확인** (이전 시간 추천) | 스케줄 등록 |
| | **5단계** | | **4단계** |

> **핵심 개선**: 이전 스케줄 추천 + 학생 명시적 확인!

#### 이전 선생님 재연결: 왜 "레슨 요청"인가?

> ⚠️ **신규 QR 연결**과 다름: 이전 선생님은 체험이 이미 끝났으므로 수강권 제안이 필요
>
> **갱신 알림(expired)과 다름**: 30일+ 휴식 시 선생님 스케줄이 바뀌었을 수 있음

| 항목 | 설명 |
|------|------|
| **버튼** | "레슨 요청" (신규 QR과 달리 버튼 필요) |
| **이유** | 선생님이 스케줄 여유 확인 후 수강권 제안해야 함 |
| **학생 액션** | 희망 시작일, 이전 스케줄 유지 여부, 메시지 |
| **선생님 액션** | 수강권 제안 또는 정중히 거절 |
| **결과** | 수강권 발급 + **이전 스케줄 자동 복원** |

#### 갱신 vs 휴식 후 재등록 비교

| 구분 | 갱신 (expired) | 휴식 후 재등록 (past) |
|------|---------------|---------------------|
| 휴식 기간 | ~30일 | 30일+ |
| 시작 주체 | **시스템 자동** | **학생 요청** |
| 선생님 확인 | 불필요 | **필요** (스케줄 여유) |
| 스케줄 | 자동 유지 | **자동 복원** (변경 가능) |
| 단계 수 | 3단계 | **4단계** |

## 5. 기존 정기레슨 → 앱 전환

> ⚠️ **이미 정기레슨 진행 중인 경우**: 체험 없이 바로 수강권 발급

기존에 앱 없이 정기레슨을 진행하다가 앱으로 전환하는 경우입니다.
이미 선생님과 학생 간의 신뢰가 형성되어 있으므로 **체험 단계 없이** 바로 수강권 발급으로 진행합니다.

#### 앱 전환이 필요한 상황

| 상황 | 예시 |
|------|------|
| 선생님이 앱 도입 | "이제 레슨앱으로 관리할게요" |
| 학생이 앱 추천 | "이 앱 쓰면 잔여 횟수 확인 편해요" |
| 기록 관리 필요 | "레슨 노트를 남기고 싶어요" |

#### 앱 전환 vs 신규 등록 비교

| 구분 | 신규 등록 | 앱 전환 |
|------|----------|--------|
| 관계 | 처음 만남 | **이미 형성됨** |
| 체험 | 필요 | **불필요** |
| 스케줄 | 체험 시간 기준 | **현재 스케줄 입력** |
| 단계 수 | 5단계 | **3단계** |

#### 앱 전환 플로우 요약 (3단계)

| # | 주체 | 액션 | 설명 |
|:-:|:----:|------|------|
| 1 | S | QR 스캔 → 연결 | 자동 연결 |
| 2 | T | 수강권 등록 | 현재 잔여 횟수 입력 |
| 3 | T | 스케줄 등록 | 현재 레슨 시간 입력 |
| | **3단계** | | 체험 없이 바로 전환 |

> **핵심**: 이미 신뢰 관계 + 결제 완료 상태이므로 체험/결제 단계 스킵!

#### "결제 완료로 발급" 옵션

> 기존 정기레슨에서 이미 결제가 완료된 상태이므로, 입금 확인 단계 없이 바로 발급

├─────────────────────────────────────┤

│  │ 잔여 횟수: [  6  ] 회             ││  ← 현재 남은 횟수 입력

│  └─────────────────────────────────┘│
│                                     │

#### 앱 전환 시 주의사항

| 항목 | 설명 |
|------|------|
| **잔여 횟수 정확히** | 현재 남은 횟수를 정확히 입력 (양측 혼란 방지) |
| **기존 스케줄 유지** | 갑자기 변경하지 않고 현재 시간 그대로 입력 |
| **레슨 노트 시작점** | 전환 시점부터 노트 축적 시작 (과거 기록은 없음) |
| **학생에게 안내** | "잔여 횟수 확인 가능해요" 등 앱 장점 설명 |

#### 앱 전환 vs 다른 시나리오 비교

| 시나리오 | 체험 | 결제 | 스케줄 | 단계 |
|----------|:----:|:----:|:------:|:----:|
| **신규 등록** | ✅ | ✅ | 체험 시간 자동 | 5 |
| **휴식 후 재등록** | ❌ | ✅ | 이전 스케줄 복원 | 4 |
| **앱 전환** | ❌ | ❌ (완료) | 현재 스케줄 입력 | **3** |
| **갱신** | ❌ | ✅ | 유지 | 3 |

## 6. 연결 방식 비교

| 구분 | 앱 미사용 | 앱 사용 | 개선 |
|------|----------|--------|------|
| **신규 선생님** | 외부 플랫폼 → 카톡 연락 | 외부 플랫폼 → **QR 스캔 = 자동 연결** | 제로 탭 연결 |
| **이전 선생님** | 연락처 찾기 → 다시 연락 | **앱에서 이력 검색 → 재연결** | 🔥 간편한 재연결 |
| **학원 레슨** | 전화 → 학원 배정 | 앱에서 **선생님 직접 선택** | 선택권 + 투명성 |
| **연결 관리** | 연락처로만 관리 | 앱에서 **관계 상태 확인** | 명확한 관계 |

#### QR/URL 연결 원칙

| 시나리오 | 연결 방식 | 이유 |
|----------|----------|------|
| **개인 선생님 QR** | 스캔 = 자동 연결 | 체험 후 대면 상황, 동의 명확 |
| **개인 선생님 URL** | 클릭 + 가입 = 자동 연결 | 카톡으로 이미 상담 완료 |
| **학원 QR** | 스캔 → 선생님 선택 → 체험 신청 | 선생님 미정, 선택 필요 |
