## 1. 개요

레슨 상세 화면의 과제(이번 주 연습) 탭 UI를 단순화한다.
유튜브의 좋아요 버튼처럼 직관적이고, 한눈에 파악할 수 있는 UI로 변경한다.

**핵심 변경**: 색상 코딩·유형 뱃지 제거, 좋아요 토글화, 완료 표시 단순화

## 2. 변경 사항

### 2.1 제거 항목

| 요소 | 현재 | 변경 | 이유 |
|------|------|------|------|
| 우선순위 색상 (🔴🟡🟢) | 3색 분류 + 그룹 헤더 | **제거** | 색상 의미 전달 안 됨 |
| 우선순위 그룹핑 | 필수/추천/도전 섹션 분리 | **단일 리스트** | 단순화 |
| 유형 뱃지 | 레퍼토리/테크닉/이론/직접입력 뱃지 | **제거** | 제목만으로 충분 |
| 우선순위 dot (요약 바) | 🔴3 🟡2 🟢1 카운터 | **제거** | 색상 제거에 따름 |
| 취소선 | ~~완료 텍스트~~ | **제거** | 회색 처리로 충분 |

### 2.2 변경 항목

| 요소 | 현재 | 변경 |
|------|------|------|
| 좋아요 (❤️) | 한 번 누르면 취소 불가 + 완료 시에만 표시 | **토글** (ON/OFF, 언제든 가능) |
| 좋아요 아이콘 | ❤️ (filled heart, red) | 👍 (thumb up, primary color) |
| 좋아요 시각 차이 (§7.133) | OS color emoji 16↔20px (모호) | **LikeStamp pill** — outline ↔ filled stamp + 텍스트 라벨 |
| 완료 표시 | 취소선 + 녹색 테두리 + dimmed 텍스트 | **회색 텍스트만** (체크 아이콘 유지) |
| 카드 테두리 | 완료 시 녹색 | **완료 시 변경 없음** (체크로 구분) |

### 2.3 유지 항목

| 요소 | 이유 |
|------|------|
| 요약 바 (진행률 + N/Total 완료) | 직관적, 유용 |
| 체크박스 (원형) | 완료 토글 필수 |
| 제목 + 설명 | 과제 내용 필수 |
| 연습 횟수 (N회) | 유용한 정보 |
| 선생님: 과제 추가/수정 버튼 | 기능 필수 |

## 3. UI 설계

### 3.1 요약 바 (변경 후)

```
┌──────────────────────────────────────────┐
│  [72%]  이번 주 연습                       │
│  ⭕     5 / 7 완료                        │
└──────────────────────────────────────────┘
```
- 우선순위 dot 카운터 제거
- 진행률 + 완료 수만 표시

### 3.2 과제 카드 (변경 후)

**미완료 상태:**
```
┌──────────────────────────────────────────┐
│  ○  Canon in D - A섹션                    │
│     메트로놈 60으로 정확하게                 │
│                                    👍    │
└──────────────────────────────────────────┘
```

**완료 상태 (좋아요 없음):**
```
┌──────────────────────────────────────────┐
│  ✅  Canon in D - A섹션        2회        │
│     메트로놈 60으로 정확하게                 │
│                                    👍    │
└──────────────────────────────────────────┘
```
- 텍스트 색상: `AppColors.textTertiaryLight` (dimmed)
- 취소선 없음, 카드 테두리 변경 없음

**완료 + 좋아요 ON:**
```
┌──────────────────────────────────────────┐
│  ✅  Canon in D - A섹션        2회        │
│     메트로놈 60으로 정확하게                 │
│                                    👍🔵 │
└──────────────────────────────────────────┘
```
- 👍 아이콘이 primary 색상으로 filled

### 3.3 좋아요 토글 동작 (§7.133 — LikeStamp 도장 메타포)

> 위치: `core/widgets/notebook/like_stamp.dart`
> 적용: `practice_items_section.dart` (선생님 토글 + 학생 read-only) + `weekly_practice_widget.dart` (학생 측 read-only)

**시각 시그널 (이중 인지)**:
- **OFF (선생님 토글)**: `Icons.thumb_up_alt_outlined` (14px, `AppColors.inkTertiary`) + 라벨 "좋아요" + transparent bg + `AppColors.inkQuaternary` 1px border. pill 모양.
- **ON (선생님 + 학생 read-only)**: `Icons.thumb_up_alt` filled (14px, `AppColors.paper`) + 라벨 "좋음" + `AppColors.paperAccent` solid bg + 동색 border. **잉크 도장 찍힘** 메타포.

**동작**:
- **선생님만** 좋아요 버튼 표시 (학생은 ON 결과만 확인, OFF는 비표시)
- 완료 여부와 **무관하게** 항상 표시 (선생님 측)
- 탭: ON → OFF, OFF → ON (토글)
- 학생 뷰: 좋아요가 ON이면 동일 stamp pill 표시 (탭 불가, `onTap == null`)

**거절된 대안**:
- 👍 emoji 16↔20px 크기 차이 — OS color emoji가 OFF에서도 컬러풀하게 렌더되어 "이미 좋아요됨" 오인. 차이 강도 부족.
- icon-only 토글 (텍스트 없음) — 학생 측 read-only 의미 모호.

**접근성**:
- `Semantics(button: true, toggled: isLiked, label: '좋아요'/'좋음')` 부여로 스크린리더 지원.
- 색맹·약시 대응: 모양(outline/filled) + 색(회색/잉크) + 텍스트("좋아요"/"좋음") 3중 시그널.

## 6. 과제 편집 UX

### 6.1 유사 서비스 분석 결과

| 카테고리 | 편집 가능 | "편집됨" 표시 | 편집 이력 |
|----------|:--------:|:----------:|:-------:|
| Google Classroom | 항상 | ❌ | ❌ |
| Seesaw | 항상 | ❌ | ❌ |
| Khan Academy | 제한적 (날짜/그룹만) | ❌ | ❌ |
| Better Practice (음악) | 항상 | ❌ | ❌ |
| Practice Space (음악) | 항상 | ❌ | ❌ |
| Slack/Teams (메신저) | 항상 | ✅ "(edited)" | ❌ |

**핵심 차이**: 메신저는 동등한 관계(peer-to-peer)라 "편집됨" 표시가 신뢰를 위해 필요하지만, 교육/레슨 앱은 선생님이 권위자(authoritative)이므로 학생은 "지금 과제가 무엇인지"만 알면 됨.

### 6.2 채택 방향

| 항목 | 결정 | 근거 |
|------|------|------|
| 편집 가능 여부 | **항상 가능** (제한 없음) | 음악 레슨 앱 표준. 선생님이 주중 수정 필수 |
| "편집됨" 뱃지 | **표시하지 않음** | 교육 앱 어디에서도 표시 안 함. 불필요한 노이즈 |
| 편집 이력 | **구현하지 않음** | 1:1 레슨 맥락에서 과도한 기능 |
| 편집 알림 | **보내지 않음** | 알림 피로 방지. 앱 열면 최신 버전 표시 |
| 완료 과제 편집 | **허용 + 소프트 경고** | "학생이 이미 연습한 과제입니다" 안내 |
| `updatedAt` 표시 | **미세하게 표시** (선택) | 학생 카드에 "수정됨" 대신 날짜만 |

### 6.3 편집 가능 필드

| 필드 | 편집 가능 | 비고 |
|------|:--------:|------|
| 제목 | ✅ | 곡명/구간 변경 |
| 설명 (메모) | ✅ | 연습 지시 변경 |
| 레퍼토리/섹션 연결 | ❌ | 삭제 후 재생성 |
| 완료 상태 | 학생만 | 선생님은 좋아요만 |
| 연습 횟수 | 학생만 | 자동 추적 |

### 6.4 완료 과제 편집 시 동작

```
선생님이 학생이 완료(✅) 표시한 과제를 수정하려 할 때:
1. EditPracticeItemSheet 열림
2. 상단에 info 배너: "학생이 이미 연습한 과제입니다"
3. 수정 가능 (차단하지 않음)
4. 저장 시 완료 상태 유지 (리셋하지 않음)
```
