# 레슨 취소/변경 플로우

> 마지막 업데이트: 2026-02-06

레슨 취소, 보강, 노쇼, 정기 시간 변경 시나리오를 다룹니다.

👉 [전체 플로우 인덱스](flow_with_app.md)

---

## 시퀀스 다이어그램

```mermaid
sequenceDiagram
    autonumber
    participant S as 🎓 학생/학부모
    participant App as 📱 Lesson App
    participant Push as 🔔 푸시 알림
    participant T as 🎻 선생님

    Note over S,T: ❌ 시나리오 A: 학생 측 취소

    S->>App: 레슨 상세 → "취소/변경" 탭
    App-->>S: 취소 정책 안내

    Note over App: - D-2 이전: 무료 취소<br/>- D-1: 보강 1회 차감<br/>- 당일: 회차 차감

    S->>App: "보강으로 변경" 선택
    App-->>S: 보강 가능 시간 표시

    S->>App: 다음 주 화요일 17:00 선택

    App->>Push: 선생님에게 알림
    Push->>T: "🔄 레슨 변경 요청\n토 15:00 → 화 17:00"

    T->>App: 승인

    App->>App: 원래 레슨 취소 + 보강 등록
    App->>Push: 확정 알림 (양쪽)

    Note over App: ✅ 해결: 보강 자동 관리<br/>추적 누락 없음

    Note over S,T: ❌ 시나리오 B: 선생님 측 취소

    T->>App: 레슨 상세 → "취소" 탭
    App-->>T: 취소 사유 선택

    T->>App: "개인 사정" 선택 → 보강 시간 제안
    App-->>T: 캘린더에서 대체 시간 선택

    T->>App: 다음 주 일요일 14:00 제안

    App->>Push: 학생에게 알림
    Push->>S: "📅 레슨 변경 안내\n토 15:00 → 일 14:00"

    S->>App: 수락/다른 시간 요청

    Note over App: ✅ 해결: 대체 시간 즉시 제안<br/>학생 불만 최소화

    Note over S,T: ⚠️ 시나리오 C: 당일 노쇼

    Note over App: 레슨 시작 10분 전

    App->>Push: 레슨 임박 알림 (양쪽)
    Push->>S: "⏰ 10분 후 레슨 시작"
    Push->>T: "⏰ 10분 후 김민수 레슨"

    Note over T: 레슨 시간 + 15분

    T->>App: "학생 미도착" 버튼

    App->>Push: 학생에게 확인
    Push->>S: "❓ 오늘 레슨에 오시나요?"

    alt 응답 없음 (5분)
        App->>App: 노쇼 처리 (정책에 따라)
        App->>Push: 노쇼 처리 알림
        Push->>S: "❌ 노쇼 처리됨 (잔여 9→8)"
        Push->>T: "❌ 노쇼 처리 완료"
    else 연락 옴
        S->>App: "죄송해요, 30분 늦어요"
        App->>Push: 선생님에게 전달
        Push->>T: "학생 30분 지각 예정"
    end

    Note over App: ✅ 해결: 명확한 노쇼 정책<br/>어색한 대화 없이 자동 처리

    Note over S,T: 🔄 시나리오 D: 정기 시간 변경

    S->>App: 선생님 연결 → "레슨 시간 변경"
    App-->>S: 변경 요청 화면

    S->>App: "다음 주부터 15:00 → 16:00"

    App->>Push: 선생님에게 요청
    Push->>T: "🔄 정기 시간 변경 요청\n15:00 → 16:00"

    T->>App: 16:00 가능 여부 확인

    alt 가능
        T->>App: 승인
        App->>App: 이후 모든 레슨 일괄 변경
        App->>Push: 확정 알림
    else 불가
        T->>App: 대안 제시 (16:30, 17:00)
        App->>Push: 학생에게 대안 전달
    end

    Note over App: ✅ 해결: 일괄 변경<br/>수동으로 하나씩 변경 불필요
```

## 개선 효과 비교

| 시나리오 | 앱 미사용 | 앱 사용 | 개선율 |
|----------|----------|--------|:------:|
| 학생 취소 | 메시지 핑퐁 | **1-2클릭** | 🔥 90% |
| 보강 관리 | 수동 추적 | **자동 관리** | 🔥 100% |
| 선생님 취소 | 어색한 알림 | **앱 자동 안내** | 🔥 100% |
| 노쇼 처리 | 즉흥 대응 | **정책 기반 자동** | 🔥 100% |
| 시간 변경 | 모든 일정 수동 | **일괄 변경** | 🔥 100% |
