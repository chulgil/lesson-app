# 연습 유형 통합 스펙

> Last updated: 2026-03-08
> Issue: #89

## 1. 개요

학생-선생님 화면의 연습 유형 불일치를 해소한다.
현재 학생은 레퍼토리만, 선생님은 4가지 유형(repertoire/technique/theory/custom)을 사용한다.
**옵션 A 채택**: 선생님도 레퍼토리 기반으로 단순화한다.

---

## 2. 현재 불일치

| 영역 | 학생 화면 | 선생님 화면 |
|------|----------|------------|
| 연습 분류 | 레퍼토리 → 섹션 | 4유형 (레퍼토리/테크닉/이론/커스텀) |
| 과제 추가 | 레퍼토리 + 섹션 추가 | 유형 선택 → 내용 입력 |
| UI 복잡도 | 단순 | 복잡 (유형 뱃지 + 색상 코딩) |

---

## 3. 변경 방향

### 3.1 선생님 과제 추가 시트 단순화

**변경 전** (`AddPracticeItemSheet`):
```
유형 선택: [레퍼토리] [테크닉] [이론] [직접입력]
↓
(유형별 다른 폼)
↓
우선순위 선택: [필수] [추천] [도전]
```

**변경 후**:
```
레퍼토리 선택 (or 새 레퍼토리 생성)
↓
섹션/곡 이름 + 범위
↓
메모 (선택)
```

- 테크닉/이론/커스텀 유형 제거
- 모든 과제는 레퍼토리 기반
- "스케일 연습", "이론 복습" 같은 것도 레퍼토리로 관리
  - 예: 레퍼토리 "기초 연습" → 섹션 "G Major 스케일 3옥타브"
  - 예: 레퍼토리 "이론" → 섹션 "음정 퀴즈 복습"
- 우선순위 선택도 제거 (Phase 1에서 UI 숨김 결정)

### 3.2 과제 목록 표시

**변경 전**: 유형별 뱃지 + 우선순위 색상 그룹
**변경 후**: 단순 체크리스트 (Phase 1 과제 UI 단순화와 동일)

```
┌──────────────────────────────────────────┐
│  [72%]  이번 주 연습    5/7 완료          │
├──────────────────────────────────────────┤
│  ○  Canon in D - A섹션                    │
│     메트로놈 60으로 정확하게                 │
│  ○  G Major 스케일 3옥타브                 │
│     4분음표 = 80                          │
│  ✅  음정 퀴즈 복습                 1회     │
└──────────────────────────────────────────┘
```

## 4. 코드 변경

### 4.1 변경 파일

| 파일 | 변경 내용 |
|------|----------|
| `add_practice_item_sheet.dart` | 유형 선택 제거, 레퍼토리 기반만 유지 |
| `edit_practice_item_sheet.dart` | 유형 필드 제거 |
| `practice_item.dart` | `PracticeType` 유지 (하위호환), 기본값을 `repertoire`로 |
| `practice_items_section.dart` | Phase 1에서 이미 뱃지 제거됨 |

### 4.2 PracticeType enum 처리

```dart
// 코드에 유지 (기존 데이터 호환)
// 새로 생성되는 과제는 모두 PracticeType.repertoire
// UI에서는 유형을 표시하지 않음
```

### 4.3 AddPracticeItemSheet 변경

**현재 구조:**
1. 유형 선택 탭 (4개)
2. 유형별 다른 폼
3. 우선순위 선택
4. 저장

**변경 후:**
1. 레퍼토리 선택 (기존 or 새 생성)
2. 곡명 + 범위 (마디/줄)
3. 메모 (선택)
4. 저장

---

## 5. 마이그레이션

- 기존 technique/theory/custom 데이터는 그대로 유지
- UI에서 유형 뱃지를 숨기므로 사용자에게 영향 없음
- 새로 생성하는 과제만 repertoire 유형으로 고정
