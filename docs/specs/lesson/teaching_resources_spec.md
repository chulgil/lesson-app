## 1. 개요

### 1.1 배경

선생님은 학생에게 학습 자료(참고 연주, 유튜브 영상, 연습 포인트 녹음 등)를 공유하고 싶지만,
현재는 카카오톡 등 외부 메신저에 의존해야 한다. 자료가 채팅에 묻히고, 학생별 자료 관리가 불가능하다.

### 1.2 솔루션

**선생님 자료 라이브러리** + **레슨/과제에 자료 첨부** 시스템

세 가지 유형의 학습 자료를 통합 관리:
1. **선생님 녹음** — 모범 연주, 구간별 시범
2. **유튜브 링크** — 참고 영상 (타임스탬프 지정 가능)
3. **외부 링크** — 악보 PDF, 이론 자료 등

### 1.3 유사 서비스 분석

| 서비스 | 자료 라이브러리 | 유튜브 통합 | 자료 첨부 방식 |
|--------|:--------------:|:----------:|:-------------:|
| Practice Space | ✅ (오디오/비디오/PDF) | ✅ (링크 첨부) | 과제에 직접 첨부 |
| Tonara | ✅ (과제 템플릿) | ✅ (하이퍼링크) | 과제에 첨부 |
| Better Practice | ✅ (악보/비디오/백킹트랙) | ✅ (링크) | 과제에 첨부 |
| SmartMusic | ✅ (10만곡+ 라이브러리) | ⚠️ (비디오 과제) | 과제에 첨부 |
| **Lessonaza** | **설계 중** | **설계 중** | **과제 + 레슨노트** |

**핵심 패턴**: 모든 성공 앱은 자료를 **과제에 인라인 첨부**한다. 별도 채팅이 아니라 과제 맥락에서 자료를 본다.

## 2. 시스템 구조

### 2.1 전체 아키텍처

```
┌─────────────────────────────────────────────────────────┐
│                    선생님 자료 라이브러리                    │
│                                                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐              │
│  │ 🎵 녹음   │  │ 🎬 유튜브 │  │ 🔗 링크   │              │
│  │ 모범 연주  │  │ 참고 영상  │  │ 악보/자료  │              │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘              │
│       │             │             │                     │
│       └─────────┬───┘─────────────┘                     │
│                 ▼                                       │
│         TeachingResource                                │
│                 │                                       │
│    ┌────────────┼────────────┐                          │
│    ▼            ▼            ▼                          │
│ PracticeItem  Lesson     레퍼토리                        │
│ (과제 첨부)   (노트 첨부)  (곡별 자료)                     │
└─────────────────────────────────────────────────────────┘
```

### 2.2 자료 유형

| 유형 | 아이콘 | 설명 | 저장 |
|------|:------:|------|------|
| `teacherRecording` | 🎵 | 선생님 모범 연주/시범 녹음 | 서버 업로드 (M4A) |
| `youtube` | 🎬 | 유튜브 영상 링크 (타임스탬프 지원) | URL만 저장 |
| `externalLink` | 🔗 | 외부 링크 (악보 PDF, 이론 사이트 등) | URL만 저장 |

## 3. 사용 플로우

### 3.1 선생님: 자료 라이브러리 관리

```
프로필 탭 → [내 학습 자료] (또는 별도 탭)
  │
  ├── 📂 전체 자료 목록 (최신순)
  │    ├── 🎵 바흐 미뉴엣 3번 - 느린 템포 시범   [바이올린]
  │    ├── 🎬 힐러리 한 - 바흐 파르티타 연주       [바이올린]
  │    ├── 🎵 음계 연습법 - G Major               [공통]
  │    └── 🔗 음악 이론 기초 (PDF)                [공통]
  │
  ├── 🔍 검색 (제목, 태그, 악기)
  │
  └── [+ 자료 추가]
       ├── [🎵 녹음하기] → 녹음 화면
       ├── [🎬 유튜브 링크] → URL 입력 + 타임스탬프
       └── [🔗 링크 추가] → URL + 제목 입력
```

### 3.2 선생님: 과제에 자료 첨부

```
과제 추가/수정 화면
  │
  ├── 제목: "비발디 1악장 카덴차"
  ├── 설명: "느린 템포에서 정확하게"
  │
  ├── 📎 학습 자료 (0개)                    [+ 첨부]
  │    └── [+ 첨부] 탭 시:
  │         ├── [라이브러리에서 선택] → 기존 자료 목록
  │         ├── [🎵 새로 녹음] → 바로 녹음
  │         ├── [🎬 유튜브 링크] → URL 입력
  │         └── [🔗 링크 추가] → URL 입력
  │
  └── [저장]
```

### 3.6 학생: 자료 재생

**선생님 녹음 재생**: 기존 `RecordingPlayerSheet` 재사용
- 파형 표시, 속도 조절, A-B 구간 반복 지원

**유튜브 재생**:
- 탭 시 유튜브 앱 또는 인앱 브라우저로 열기
- 타임스탬프 지정 시 해당 시점부터 재생 (`?t=92`)
- 구간 종료 시점은 안내 텍스트로만 표시 (유튜브 API 제약)

**외부 링크**: 인앱 브라우저 또는 외부 브라우저로 열기

## 4. 데이터 모델

### 4.1 TeachingResource (핵심 엔티티)

```dart
class TeachingResource {
  final String id;
  final String teacherId;
  final TeachingResourceType type;
  final String title;
  final String? description;      // 학생에게 표시할 메모
  final String? instrument;       // 악기 태그
  final List<String> tags;        // 자유 태그

  // Type-specific fields
  final String? audioUrl;         // teacherRecording: 서버 URL
  final int? audioDurationSeconds;
  final String? youtubeUrl;       // youtube: 전체 URL
  final String? youtubeVideoId;   // youtube: 영상 ID (추출)
  final String? youtubeThumbnail; // youtube: 썸네일 URL (자동)
  final int? youtubeStartSeconds; // youtube: 시작 타임스탬프
  final int? youtubeEndSeconds;   // youtube: 종료 타임스탬프
  final String? externalUrl;      // externalLink: URL

  final DateTime createdAt;
  final DateTime? updatedAt;
}

enum TeachingResourceType {
  teacherRecording, // 선생님 녹음
  youtube,          // 유튜브 링크
  externalLink,     // 외부 링크
}
```

## 5. 레퍼토리 연동

### 5.1 곡별 자료 관리

레퍼토리(곡)에 자료를 연결하면, 해당 곡이 포함된 과제에 자동으로 자료가 표시:

```
레퍼토리: "비발디 A단조 협주곡"
  ├── 섹션: 1악장
  │    ├── 🎵 선생님 시범 (전체)
  │    └── 🎬 힐러리 한 연주 (1:32~2:05)
  ├── 섹션: 2악장
  │    └── 🎵 선생님 시범 (느린 템포)
  └── 섹션: 3악장
       └── (자료 없음)
```

### 5.2 자료 상속

과제에 레퍼토리/섹션이 연결된 경우:
- **자동 표시**: 해당 섹션의 자료가 과제 카드에 자동 표시
- **추가 첨부**: 선생님이 과제별로 추가 자료 첨부 가능
- **우선순위**: 과제 직접 첨부 > 섹션 자료 > 레퍼토리 자료

## 6. 선생님 편의 기능

### 6.1 자료 재사용 (템플릿)

자료 라이브러리에 한 번 저장하면 **여러 학생의 과제에 반복 첨부** 가능:

```
"음계 연습법 - G Major" 녹음
  → 학생 A 과제에 첨부
  → 학생 B 과제에 첨부
  → 학생 C 과제에 첨부
  (같은 녹음, 업로드 1회)
```

### 6.2 빠른 첨부

과제 추가 시 최근 사용한 자료 3개를 상단에 표시:

```
📎 학습 자료 추가
  ├── ⏱️ 최근 사용
  │    ├── 🎵 음계 연습법 (어제 사용)
  │    ├── 🎬 보잉 테크닉 영상 (3일 전)
  │    └── 🎵 비발디 시범 (1주 전)
  │
  └── 📂 전체 라이브러리
```

### 6.3 유튜브 URL 자동 파싱

URL 붙여넣기 시 자동으로:
- 영상 제목 추출 (oEmbed API)
- 썸네일 URL 생성
- 영상 길이 표시
- 타임스탬프 파라미터 파싱 (`?t=92` → 시작: 1:32)
