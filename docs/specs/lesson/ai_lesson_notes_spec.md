## 1. 개요

### 1.1 배경

현재 선생님은 레슨 후 피드백/핵심포인트/연습팁을 **수동 타이핑**으로 작성해야 한다.
레슨 시간(30~60분) 동안의 지도 내용을 기억에 의존하여 사후 작성하면 누락이 많다.

**핵심 문제**: 레슨하면서 노트를 작성할 수 없고, 레슨 후 기억에 의존하면 정확도가 떨어진다.

### 1.2 솔루션

레슨 중 **자동 녹음** → AI **음성→텍스트 변환** → **구조화된 레슨 노트 자동 생성**

이 기능은 어떤 음악 레슨 앱에서도 제공하지 않는 **차별화 기능**이다.

### 1.3 유사 서비스 분석

| 서비스 | 유형 | AI 노트 | 음악 레슨 적용 가능성 |
|--------|------|:-------:|:-------------------:|
| Otter.ai | 회의 녹음 | 실시간 전사 + 요약 + 액션 아이템 | HIGH |
| Fireflies.ai | 회의 녹음 | Super Summary + 200+ 미니앱 | HIGH |
| Notion AI | 노트 | DB 항목 자동 요약 | MEDIUM |
| Tonara | 음악 레슨 | 녹음 비교(음정/리듬) — 노트 없음 | LOW |
| SmartMusic | 음악 교육 | AI 음정/리듬 피드백 — 노트 없음 | LOW |
| Practice Space | 음악 레슨 | 없음 | — |

**결론**: Otter.ai/Fireflies.ai의 "회의→구조화 노트" 패턴을 음악 레슨에 최초 적용.

## 2. 사용 플로우

### 2.1 선생님 플로우

```
레슨 시작
  ├── 레슨 상세 화면 상단: [🎙️ AI 노트] 버튼 탭
  ├── "레슨 중 대화를 녹음하여 노트를 자동 작성합니다" 안내
  ├── [녹음 시작] → 🔴 녹음 인디케이터 (화면 상단 고정)
  │
  ├── ── 레슨 진행 (30~60분) ──
  │    "오늘은 비발디 1악장 카덴차 부분을 봤는데요..."
  │    "활 잡는 자세가 많이 좋아졌어요..."
  │    "다음 시간까지 메트로놈 72에서 10회 반복해오세요..."
  │
  ├── [녹음 종료] 또는 레슨 완료 처리 시 자동 종료
  │
  ├── "AI 노트를 생성하고 있습니다..." (로딩, 30초~2분)
  │
  └── AI 결과 미리보기
       ├── 📋 피드백: "활 잡는 자세가 많이 좋아졌습니다..."
       ├── 🎯 핵심 포인트: ["카덴차 음정 정확도", "보잉 방향 전환"]
       ├── 💡 연습 팁: "메트로놈 72 템포에서 카덴차 구간 10회 반복..."
       ├── 📝 과제 제안: ["비발디 1악장 카덴차 반복", "보잉 연습 15분"]
       │
       ├── [수정] → 각 항목 인라인 편집
       └── [저장] → 레슨 노트에 반영
```

### 2.2 학생 플로우 (변경 없음)

학생은 기존처럼 레슨 상세에서 피드백/핵심포인트/연습팁을 **읽기만** 한다.
AI가 생성했든 선생님이 직접 작성했든 학생 입장에서는 동일한 UI.

## 3. 기술 구조

### 3.1 아키텍처

```
[Flutter App]                    [Backend]                    [AI Service]
     │                               │                            │
     ├── 녹음 시작 (로컬 M4A)         │                            │
     ├── 녹음 종료                    │                            │
     ├── 오디오 업로드 ──────────────→ │                            │
     │                               ├── 오디오 → STT ──────────→ │
     │                               │                            ├── Whisper 전사
     │                               │                            ├── GPT 구조화
     │                               │ ←── 구조화 노트 ──────────── │
     │ ←── 결과 반환 ──────────────── │                            │
     ├── 미리보기 표시                 │                            │
     ├── 수정/저장                    │                            │
     └── 오디오 파일 삭제              ├── 오디오 파일 삭제           │
```

### 3.2 AI 파이프라인

**Step 1: Speech-to-Text (Whisper)**
- 입력: M4A 오디오 (최대 60분)
- 출력: 타임스탬프 포함 전사 텍스트
- 모델: OpenAI Whisper API (`whisper-1`)
- 언어: Korean (ko)

**Step 2: 구조화 (GPT)**
- 입력: 전사 텍스트 + 레슨 메타데이터 (곡목, 악기, 학생 레벨)
- 출력: 구조화된 JSON
- 모델: GPT-4o-mini (비용 효율)

**프롬프트 설계:**
```
당신은 음악 레슨 노트 작성 전문가입니다.
아래는 {instrument} 레슨의 녹취록입니다.
학생: {studentName} ({level})
곡목: {pieces}

이 녹취록을 바탕으로 다음 항목을 작성하세요:
1. feedback: 레슨 전체 피드백 (2-3문장, 긍정적 + 개선점)
2. keyPoints: 핵심 포인트 (3-5개, 짧은 문장)
3. practiceTips: 구체적 연습 방법 (메트로놈 템포, 반복 횟수 포함)
4. suggestedAssignments: 과제 제안 (2-4개, 제목 + 간단 설명)

JSON 형식으로 응답하세요.
```

**출력 JSON:**
```json
{
  "feedback": "활 잡는 자세가 많이 좋아졌습니다. 비발디 1악장 카덴차 부분의 음정이 불안정하니 천천히 반복 연습해오세요.",
  "keyPoints": [
    "카덴차 음정 정확도",
    "보잉 방향 전환 시 끊김 제거",
    "가보트 리듬 안정화"
  ],
  "practiceTips": "메트로놈 72 템포에서 카덴차 구간 10회 반복 후, 템포를 4씩 올려보세요.",
  "suggestedAssignments": [
    {"title": "비발디 1악장 카덴차", "description": "느린 템포(72)에서 정확한 음정으로 10회 반복"},
    {"title": "가보트 리듬 연습", "description": "메트로놈 없이 리듬 카운팅 후 메트로놈과 합주"}
  ]
}
```

### 3.3 녹음 포맷

| 항목 | 값 |
|------|-----|
| 포맷 | M4A (AAC-LC) |
| 비트레이트 | 64 kbps (음성 최적화, 음악 녹음보다 낮음) |
| 샘플레이트 | 44100 Hz |
| 채널 | Mono |
| 최대 길이 | 60분 |
| 예상 파일 크기 | ~30MB/60분 |

### 3.4 비용 추정

| 항목 | 단가 | 60분 레슨 기준 |
|------|------|:-------------:|
| Whisper API | $0.006/min | $0.36 |
| GPT-4o-mini | ~$0.15/1M tokens | ~$0.01 |
| **합계** | | **~$0.37/레슨** |

월 20레슨 기준: **~$7.40/월** (합리적 비용)

### 4.4 과제 자동 추가

AI가 제안한 과제 중 선생님이 체크한 항목은 **이번 주 연습(PracticeItem)**에 자동 추가:
- `type: PracticeType.repertoire`
- `priority: PracticePriority.should` (기본)
- `title`, `description`: AI 제안 값

## 5. 데이터 모델

### 5.1 LessonRecording (새 엔티티)

```dart
class LessonRecording {
  final String id;
  final String lessonId;
  final String teacherId;
  final String localPath;        // 임시 로컬 경로
  final int durationSeconds;
  final LessonRecordingStatus status;
  final String? transcription;   // STT 결과
  final AiLessonNote? aiNote;    // AI 구조화 결과
  final DateTime createdAt;
}

enum LessonRecordingStatus {
  recording,      // 녹음 중
  uploading,      // 서버 업로드 중
  transcribing,   // STT 처리 중
  structuring,    // GPT 구조화 중
  completed,      // 완료 (결과 준비됨)
  failed,         // 실패
}
```

### 5.2 AiLessonNote (AI 결과)

```dart
class AiLessonNote {
  final String feedback;
  final List<String> keyPoints;
  final String practiceTips;
  final List<SuggestedAssignment> suggestedAssignments;
}

class SuggestedAssignment {
  final String title;
  final String description;
  final bool selected;  // 선생님이 체크했는지
}
```

## 6. 구현 Phase

### Phase 1: 코어 (MVP)
- [ ] 레슨 중 녹음 (로컬 M4A, 최대 60분)
- [ ] 녹음 중 인디케이터 UI
- [ ] 오디오 업로드 → Whisper STT
- [ ] GPT 구조화 → 미리보기 UI
- [ ] 수정 후 레슨 노트에 저장
- [ ] 오디오 파일 삭제 (로컬 + 서버)

### Phase 2: 향상
- [ ] 백그라운드 녹음 (앱 전환 시 유지)
- [ ] 실시간 전사 미리보기 (Whisper Streaming)
- [ ] 과제 자동 추가 (체크한 제안 → PracticeItem)
- [ ] 이전 레슨 노트 참조 (GPT 컨텍스트에 포함)

### Phase 3: 고도화
- [ ] 음악 구간 감지 (연주 vs 대화 분리)
- [ ] 다국어 지원 (영어 레슨)
- [ ] 학부모 알림 (레슨 노트 자동 공유)

## 7. 제약사항 및 고려사항

### 7.1 개인정보

- 녹음 시 **명시적 동의** 필요 (첫 사용 시 안내 + 동의)
- 오디오 파일은 STT 처리 후 **즉시 삭제** (서버 저장 안 함)
- 전사 텍스트도 GPT 처리 후 삭제 (구조화된 노트만 저장)

### 7.2 기술적 제약

- iOS 백그라운드 녹음: `AVAudioSession` 설정 필요
- 60분 오디오 업로드: 청크 업로드 또는 압축 필요
- 네트워크 오프라인: 로컬 저장 후 연결 시 업로드

### 7.3 백엔드 의존

- Whisper API + GPT API 호출: 백엔드 서버 필요
- Phase 1은 **백엔드 구현 후** 프론트 연동
