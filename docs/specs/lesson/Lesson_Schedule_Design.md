# 레슨 스케줄 조절 - 상세 설계

> 작성일: 2024-12-22
> 상태: 설계 완료 (구현 대기)

---

## 1. 개요

### 목표
선생님과 학생 간의 레슨 스케줄을 **기분 좋고 효율적으로** 관리하는 시스템

### 핵심 원칙
- **심플함**: 음악인은 IT에 관심이 적으므로 최소한의 조작으로 완료
- **유연함**: 고정/유동 스케줄 모두 지원
- **자동화**: 반복 일정, 알림, 리마인더 자동 처리

---

## 2. 스케줄 유형

### 2.1 체험레슨

| 항목 | 설명 |
|------|------|
| 특징 | 불특정 시간, 선생님이 일부러 시간을 내서 진행 |
| 목적 | 정규레슨 전 상호 적합성 확인 |
| 빈도 | 1회성 |

### 2.2 정규레슨

| 항목 | 설명 |
|------|------|
| 특징 | 고정 요일/시간에 매주 반복 |
| 목적 | 지속적인 레슨 진행 |
| 권장 | 고정 시간 유지 (안정적인 학습 루틴) |

### 2.3 유동레슨 (정규의 변형)

| 항목 | 설명 |
|------|------|
| 특징 | 정규레슨이지만 매주 시간이 유동적 |
| 대상 | 스케줄이 불규칙한 학생/선생님 |
| 방식 | 매주 가용 시간 중 선택 |

## 3. 가용 시간 관리 (선생님)

### 3.1 설정 방식 (혼용)

```
[주간 패턴]
- 매주 반복되는 가용 시간 설정
- 예: 월/수/금 14:00~18:00, 토 10:00~16:00

[날짜별 직접 입력]
- 특정 날짜에 추가 가용 시간 설정
- 예: 12/28(토) 09:00~12:00 추가 오픈
- 예: 12/25(수) 휴무 설정
```

### 3.2 데이터 모델

```
TeacherAvailability {
  id: UUID
  teacher_id: UUID

  // 주간 패턴
  weekly_pattern: [
    { day_of_week: 1, start_time: "14:00", end_time: "18:00" },
    { day_of_week: 3, start_time: "14:00", end_time: "18:00" },
    { day_of_week: 5, start_time: "14:00", end_time: "18:00" },
    { day_of_week: 6, start_time: "10:00", end_time: "16:00" }
  ]

  // 날짜별 예외
  date_overrides: [
    { date: "2024-12-28", start_time: "09:00", end_time: "12:00", type: "add" },
    { date: "2024-12-25", type: "blocked" }
  ]
}
```

## 4. 체험레슨 플로우

### 4.1 신청 경로 (2가지)

#### A. 앱 내 검색 → 신청
```
학생 → 선생님 검색 → 프로필 확인 → 체험레슨 신청
```

#### B. 선생님 링크 공유 → 신청
```
선생님 → 개인 예약 링크 복사 → SNS/카톡 공유
학생 → 링크 클릭 → 앱 설치/로그인 → 체험레슨 신청
```

## 6. 변경/취소 정책

### 6.1 정책 설정 (선생님별)

선생님이 개인 정책 설정 가능:

```
┌─────────────────────────────────────────────────┐
│  변경/취소 정책 설정                              │
├─────────────────────────────────────────────────┤
│                                                 │
│  [변경 가능 기한]                                │
│  ○ 24시간 전까지                                │
│  ● 48시간 전까지                                │
│  ○ 72시간 전까지                                │
│  ○ 1주일 전까지                                 │
│                                                 │
│  [취소 시 정책]                                  │
│  ○ 무료 취소                                    │
│  ● 1회 차감                                     │
│  ○ 수강료 50% 차감                              │
│                                                 │
│  [당일 취소 정책]                                │
│  ○ 허용 (패널티 없음)                            │
│  ● 1회 차감                                     │
│  ○ 허용 안 함                                   │
│                                                 │
│  [메시지] (학생에게 표시)                         │
│  ┌─────────────────────────────────────────┐   │
│  │ 48시간 전까지 변경/취소가 가능합니다.      │   │
│  │ 당일 취소 시 1회가 차감됩니다.            │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│                          [저장]                 │
└─────────────────────────────────────────────────┘
```

### 6.2 데이터 모델

```
TeacherPolicy {
  id: UUID
  teacher_id: UUID

  // 변경 정책
  change_deadline_hours: 48       // 변경 가능 기한 (시간)

  // 취소 정책
  cancel_penalty_type: "deduct_one"  // none, deduct_one, deduct_percent
  cancel_penalty_percent: null       // deduct_percent인 경우 사용

  // 당일 취소
  same_day_cancel_allowed: true
  same_day_penalty_type: "deduct_one"

  // 학생에게 표시할 메시지
  policy_message: "48시간 전까지 변경/취소가 가능합니다..."
}
```

## 7. 알림 시스템

### 7.1 알림 유형

| 이벤트 | 수신자 | 알림 채널 | 타이밍 |

CREATE TABLE lesson_booking (
