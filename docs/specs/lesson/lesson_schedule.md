## 개요

체험레슨 신청/승인 및 정규레슨 등록 시스템. 고정 스케줄 권장.

---

## 스케줄 유형

| 유형 | 설명 | 권장 |
|------|------|------|
| 체험레슨 | 불특정 시간, 선생님이 시간을 내서 진행 | - |
| 정규레슨 (고정) | 매주 같은 요일/시간 | ⭐ 권장 |
| 정규레슨 (유동) | 매주 가능한 시간 협의 | - |

---

## 체험레슨 플로우

```
선생님 가용시간 등록 → 학생 신청 → 선생님 승인 → 알림 발송
```

### 신청 폼 필드

| 필드 | 필수 | 설명 | 디폴트 값 |
|------|------|------|-----------|
| 날짜/시간 | O | 선생님 가용시간 중 선택 | - |
| 레슨 목표 | O | 취미/입시/전공 | 취미 (기존 정보 있으면 유지) |
| 악기 경험 | O | 처음/1년미만/1-3년/3년이상 | StudentLevel 매핑 |
| 메시지 | X | 선생님께 전달할 메시지 | - |

### StudentLevel → ExperienceLevel 매핑

| StudentLevel | ExperienceLevel |
|--------------|-----------------|
| beginner (입문) | beginner (1년 미만) |
| elementary (초급) | beginner (1년 미만) |
| intermediate (중급) | some (1-3년) |
| advanced (고급) | experienced (3년 이상) |

## 예약 상태

| 상태 | 설명 | 학생 액션 | 선생님 액션 |
|------|------|----------|------------|

| completed | 레슨 완료 | - | - |
| cancelled | 취소됨 | - | - |
| rejected | 거절됨 | - | - |

## 5주차 정책 (월 4회 기준 정기레슨)

> 결정일: 2025-01-28
> 배경: 월 4회 기준 정기레슨에서 한 달에 5주가 있는 경우 처리 방안

### 문제 상황

주 1회 정기레슨(월 4회 기준)에서 특정 요일이 5번 있는 달 발생

| 2025년 예시 | 화요일 횟수 |
|-------------|------------|
| 4월 | 5회 (1, 8, 15, 22, 29) |
| 7월 | 5회 (1, 8, 15, 22, 29) |
| 9월 | 5회 (2, 9, 16, 23, 30) |
| 12월 | 5회 (2, 9, 16, 23, 30) |

### 정책 결정

| 항목 | 결정 |
|------|------|
| **기본 정책** | 5주차 자동 휴강 |
| **선생님별 설정** | 가능 (개별 정책 선택) |
| **결제** | 항상 4회분 고정 |

### 선생님 설정 옵션

```
FifthWeekPolicy:
├── skip (기본값)     → 5주차 자동 휴강
├── optional          → 학생 선택 (진행/휴강)
├── credit            → 진행 후 다음달 이월
└── always            → 항상 진행 (5회 결제)
```

| 정책 | 설명 | 결제 |
|------|------|------|
| **skip** | 5주차는 자동으로 휴강 표시 | 4회 고정 |
| **optional** | 5주차에 학생이 선택 (진행/휴강) | 4회 + 선택시 추가 |
| **credit** | 5주차 진행 → 다음달 크레딧 적립 | 4회 고정, 크레딧 차감 |
| **always** | 5주차도 항상 진행 | 5회 결제 |

### 캘린더 표시 (skip 정책 예시)

```
┌─────────────────────────────────┐
│ 7월 2025 (화요일 5회)           │
├─────────────────────────────────┤
│  1일 (화) │ 🎻 레슨 (1/4)       │
│  8일 (화) │ 🎻 레슨 (2/4)       │
│ 15일 (화) │ 🎻 레슨 (3/4)       │
│ 22일 (화) │ 🎻 레슨 (4/4)       │
│ 29일 (화) │ 😴 휴강 (5주차)     │ ← 자동 표시
└─────────────────────────────────┘
```

### 학생 안내 문구 (자동 생성)

```
📅 7월 레슨 안내
- 레슨일: 매주 화요일
- 이번 달: 4회 진행 (1, 8, 15, 22일)
- 29일(화): 5주차 휴강
- 결제금액: ₩200,000 (4회)
```

### 데이터 모델

```dart
enum FifthWeekPolicy {
  skip,      // 5주차 자동 휴강 (기본값)
  optional,  // 학생 선택
  credit,    // 다음달 이월
  always,    // 항상 진행
}

class RegularLessonSettings {
  final int sessionsPerMonth;        // 기본 4
  final FifthWeekPolicy fifthWeek;   // 기본 skip
  final String? customNotice;        // 선택적 안내 문구
  final DayOfWeek lessonDay;         // 레슨 요일
  final TimeOfDay lessonTime;        // 레슨 시간
}
```

### 자동 스케줄 생성 로직

```
1. 해당 월의 레슨 요일 날짜 목록 추출
2. 목록 개수 확인
   - 4개: 전체 레슨으로 표시
   - 5개: fifthWeekPolicy에 따라 처리
     - skip: 5번째 날짜를 휴강으로 표시
     - optional: 5번째 날짜를 '선택' 상태로
     - credit: 5번째 날짜를 레슨으로, 크레딧 +1
     - always: 전체 5개 레슨으로 표시
3. 캘린더 및 결제 정보 반영
```

## 스케줄 변경 요청 플로우

```
[선생님 컨펌 상태]
  ↓
학생: "변경 요청" 클릭
  ↓
새로운 날짜/시간 선택
  ↓
[변경 요청 중] 상태
- 기존 스케줄 유지 (선생님 승인 전까지)
- 선생님에게 알림 발송
  ↓
선생님: 변경 승인 또는 거절
  ↓
승인 시: 새 스케줄로 변경
거절 시: 기존 스케줄 유지
```
