# 레슨 스케줄 시스템 스펙

> 작성일: 2025-12-25
> 상태: ✅ 화면 구현 완료, 라우터 연결 필요
> 엔티티 스키마: [lesson_schedule.md](../../schema/entities/lesson_schedule.md)

---

## 개요

체험레슨 신청/승인 및 정규레슨 등록 시스템. 고정 스케줄 권장.

---

## 스케줄 유형

| 유형 | 설명 | 수강권 타입 | 권장 |
|------|------|:----------:|:----:|
| 체험레슨 | 불특정 시간, 선생님이 시간을 내서 진행 | trial | - |
| 정규레슨 (고정) | 매주 같은 요일/시간 고정 | monthly | ⭐ 권장 |
| 회차권 레슨 (유동) | 매 레슨마다 시간 협의 | package | - |

### 🆕 정기레슨 vs 회차권 스케줄링 비교

> 결정일: 2026-01-25

| 구분 | 정기레슨 (월정액) | 회차권 (패키지) |
|------|-----------------|----------------|
| **레슨 일정** | ✅ 고정 (매주 같은 요일/시간) | 🔄 유동 (매번 협의) |
| **예약 주체** | 최초 설정 → 자동 생성 | 선생님 제안 → 학생 선택 |
| **스케줄 관리** | 변경 요청만 | 매 레슨 예약 필요 |
| **적합 대상** | 장기/정기 수강생 | 불규칙 일정 수강생 |
| **billingType** | `monthly` | `perPackage` |
| **5주차 정책** | ✅ 적용 | ❌ 해당 없음 |

#### 정기레슨 (월정액) 플로우

```
[최초 설정] ─────────────────────────────────────────▶ [자동 스케줄]
     │                                                    │
     ▼                                                    ▼
┌──────────────┐                                  ┌──────────────┐
│ 요일: 화요일  │                                  │ 2/4 14:00 ✅ │
│ 시간: 14:00  │  ──▶ 매월 자동 생성 ──▶           │ 2/11 14:00 ✅ │
│ 레슨: 60분   │                                  │ 2/18 14:00 ✅ │
│ 결제일: 27일 │                                  │ 2/25 14:00 ✅ │
└──────────────┘                                  └──────────────┘
                                                         │
                                                         ├── 결제 확인 전
                                                         │   └── ⚠️ 미입금 경고 표시
                                                         │
                                                         ├── 일정 변경 필요 시
                                                         │   └── [변경 요청] 사용
                                                         │
                                                         └── 5주차 달
                                                             └── 정책에 따라 처리
```

#### 월정액 결제 + 스케줄 워크플로우

> 자동결제 없음 → 스케줄 생성 + 결제 알림 방식

```
[매월 결제일 기준]
     │
     ├── 1. 스케줄 자동 생성 (4개)
     │
     ├── 2. 학생/학부모에게 결제 요청 알림
     │
     ├── 3. 선생님: 입금 확인 시 "결제 확인" 처리
     │         │
     │         └── 미입금 시: ⚠️ 경고 표시 (레슨 기록은 가능)
     │
     └── 4. 레슨 진행
```

| 케이스 | 미입금 처리 |
|--------|-----------|
| 선생님 매칭됨 | 경고 표시, 레슨 가능 |
| 학생 수기관리 | 경고 표시, 레슨 가능 |
| 학원 모드 | 학원 정책에 따름 |

→ 상세: [subscription_system_spec.md](../subscription/subscription_system_spec.md#월정액-결제--스케줄-워크플로우)

#### 회차권 (패키지) 플로우

```
[레슨 완료] ──▶ [선생님 알림] ──▶ [시간 제안] ──▶ [학생 선택] ──▶ [예약 확정]
     │              │               │               │              │
     ▼              ▼               ▼               ▼              ▼
 잔여 횟수      "다음 레슨       ┌─────────┐    학생이        레슨 일정
   확인        예약해주세요"    │ 2/10 14:00│   선택           캘린더에
                              │ 2/11 16:00│                   표시
                              │ 2/12 10:00│
                              └─────────┘
```

#### 회차권 예약 상세 플로우

1. **레슨 완료 시** 잔여 횟수 확인
2. **1회 이상 남음** → 선생님에게 "다음 레슨 시간 제안" 알림
3. **선생님** → 가용 시간 3~5개 제안
4. **학생** → 제안된 시간 중 선택 또는 다른 시간 요청
5. **확정** → 양측에 예약 확정 알림

```
┌─────────────────────────────────────────────────────┐

│  가용 시간 선택 (최대 5개)                           │
│  ┌─────────────────────────────────────────────┐   │
│  │ ☑ 2/10(월) 14:00                            │   │
│  │ ☑ 2/11(화) 16:00                            │   │
│  │ ☑ 2/12(수) 10:00                            │   │
│  │ ☐ 2/13(목) 15:00                            │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  메시지 (선택):                                      │
│  ┌─────────────────────────────────────────────┐   │
│  │ 다음 레슨 가능 시간입니다. 선택해주세요!      │   │

## 체험레슨 플로우

```
선생님 가용시간 등록 → 학생 신청 → 선생님 승인 → 알림 발송
```

### 신청 폼 필드

| 필드 | 필수 | 설명 | 디폴트 값 |
|------|------|------|-----------|
| 날짜/시간 | O | 선생님 가용시간 중 선택 | - |
| 레슨 목표 | O | 취미/입시/전공 | 취미 (기존 정보 있으면 유지) |
| 악기 경험 | O | 처음/1년미만/1-3년/3년이상 | StudentLevel 매핑 |
| 메시지 | X | 선생님께 전달할 메시지 | - |

### StudentLevel → ExperienceLevel 매핑

| StudentLevel | ExperienceLevel |
|--------------|-----------------|
| beginner (입문) | beginner (1년 미만) |
| elementary (초급) | beginner (1년 미만) |
| intermediate (중급) | some (1-3년) |
| advanced (고급) | experienced (3년 이상) |

## 5주차 정책 (월 4회 기준 정기레슨)

> 결정일: 2025-01-28
> 배경: 월 4회 기준 정기레슨에서 한 달에 5주가 있는 경우 처리 방안

### 문제 상황

주 1회 정기레슨(월 4회 기준)에서 특정 요일이 5번 있는 달 발생

| 2025년 예시 | 화요일 횟수 |
|-------------|------------|
| 4월 | 5회 (1, 8, 15, 22, 29) |
| 7월 | 5회 (1, 8, 15, 22, 29) |
| 9월 | 5회 (2, 9, 16, 23, 30) |
| 12월 | 5회 (2, 9, 16, 23, 30) |

### 정책 결정

| 항목 | 결정 |
|------|------|
| **기본 정책** | 5주차 자동 휴강 |
| **선생님별 설정** | 가능 (개별 정책 선택) |
| **결제** | 항상 4회분 고정 |

### FifthWeekPolicy

| 정책 | 설명 | 결제 |
|------|------|------|
| **skip** (기본값) | 5주차는 자동으로 휴강 표시 | 4회 고정 |
| **optional** | 5주차에 학생이 선택 (진행/휴강) | 4회 + 선택시 추가 |
| **credit** | 5주차 진행 → 다음달 크레딧 적립 | 4회 고정, 크레딧 차감 |
| **always** | 5주차도 항상 진행 | 5회 결제 |

→ 엔티티 정의: [lesson_schedule.md](../../schema/entities/lesson_schedule.md#fifthweekpolicy-5주차-정책)

### 캘린더 표시 (skip 정책 예시)

```
┌─────────────────────────────────┐
│ 7월 2025 (화요일 5회)           │
├─────────────────────────────────┤
│  1일 (화) │ 🎻 레슨 (1/4)       │
│  8일 (화) │ 🎻 레슨 (2/4)       │
│ 15일 (화) │ 🎻 레슨 (3/4)       │
│ 22일 (화) │ 🎻 레슨 (4/4)       │
│ 29일 (화) │ 😴 휴강 (5주차)     │ ← 자동 표시
└─────────────────────────────────┘
```

### 학생 안내 문구 (자동 생성)

```
📅 7월 레슨 안내
- 레슨일: 매주 화요일
- 이번 달: 4회 진행 (1, 8, 15, 22일)
- 29일(화): 5주차 휴강
- 결제금액: ₩200,000 (4회)
```

### 선생님 설정 UI

```
┌─────────────────────────────────┐
│ 정기레슨 설정                    │
├─────────────────────────────────┤
│ 월 레슨 횟수: [4회 ▼]           │
├─────────────────────────────────┤
│ 5주차 정책:                      │
│ ○ 자동 휴강 (기본)              │ ← 선택됨
│ ○ 학생 선택                     │
│ ○ 크레딧 이월                   │
│ ○ 항상 진행 (5회 결제)          │
├─────────────────────────────────┤
│ 안내 문구 (선택):               │
│ ┌─────────────────────────────┐ │
│ │ 5주차는 휴강입니다.         │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

### 자동 스케줄 생성 로직

```
1. 해당 월의 레슨 요일 날짜 목록 추출
2. 목록 개수 확인
   - 4개: 전체 레슨으로 표시
   - 5개: fifthWeekPolicy에 따라 처리
     - skip: 5번째 날짜를 휴강으로 표시
     - optional: 5번째 날짜를 '선택' 상태로
     - credit: 5번째 날짜를 레슨으로, 크레딧 +1
     - always: 전체 5개 레슨으로 표시
3. 캘린더 및 결제 정보 반영
```

## 노쇼(No-Show) 정책 시스템

> 작성일: 2026-01-27
> 참조: [flow_with_app.md](./flow_with_app.md) - 섹션 5 시나리오 C

### 노쇼 정의

레슨 시작 시간이 지났는데 학생이 연락 없이 나타나지 않은 상황

### 노쇼 감지 플로우

```
레슨 시작 10분 전
    │
    ├── 양쪽에 "레슨 임박" 알림
    │
    ▼
레슨 시작 시간
    │
    ├── 선생님 출석 체크 (선생님 앱)
    │         │
    │         ├── "학생 출석" → 정상 진행
    │         │
    │         └── "학생 미출석" 선택
    │               │
    │               ▼
    │         학생에게 확인 알림 전송
    │         "❓ 오늘 레슨에 오시나요?"
    │               │
    │               ├── 5분 내 응답 있음
    │               │     ├── "지각 중" → 대기
    │               │     └── "못 갑니다" → 취소 플로우
    │               │
    │               └── 5분 내 응답 없음
    │                     │
    │                     ▼
    │               [노쇼 자동 처리]
    │
    └── 레슨 종료 시간
          │
          └── 미완료 레슨 자동 노쇼 처리
```

### 노쇼 정책 (NoShowPolicy)

> 선생님이 설정, 학생에게 사전 안내

| 정책 | 설명 | 회차권 처리 | 월정액 처리 |
|------|------|-----------|-----------|
| **deductCredit** (기본값) | 회차 차감 | 잔여 -1 | 해당 월 레슨 -1 |
| **halfCredit** | 0.5회 차감 | 잔여 -0.5 | - (월정액 미지원) |
| **noDeduction** | 차감 없음 (관대) | 차감 없음 | 차감 없음 |
| **reschedule** | 보강으로 전환 | 보강 +1 추가 | 보강 +1 추가 |

### 노쇼 알림

| 시점 | 수신자 | 내용 |
|------|--------|------|
| 레슨 시작 시간 + 5분 | 학생 | "❓ 오늘 레슨에 오시나요?" |
| 노쇼 처리 시 | 학생 | "❌ 노쇼 처리됨 (잔여 9→8)" |
| 노쇼 처리 시 | 선생님 | "❌ 노쇼 처리 완료" |

### 노쇼 예외 상황

| 상황 | 처리 |
|------|------|
| 학생이 지각 알림 보냄 | 노쇼 처리 취소, 지각으로 기록 |
| 선생님이 직접 출석 처리 | 노쇼 처리 취소 |
| 사전 취소 (D-2 이전) | 정상 취소로 처리 |

## 보강(Makeup Lesson) 추적 시스템

> 작성일: 2026-01-27
> 참조: [flow_with_app.md](./flow_with_app.md) - 섹션 5 시나리오 A, B

### 보강 발생 조건

| 조건 | 보강 생성 | 설명 |
|------|:--------:|------|
| 학생 취소 (D-1) | ⚠️ 선택 | 정책에 따라 보강 가능 |
| 학생 취소 (당일) | ❌ | 회차 차감 (보강 없음) |
| 선생님 취소 | ✅ 필수 | 항상 보강 제공 |
| 노쇼 (reschedule 정책) | ✅ | 정책에 따라 보강 |
| 휴강 (5주차 등) | ❌ | 보강 아님, 정상 휴강 |

### 보강 상태 (MakeupStatus)

| 상태 | 설명 |
|------|------|
| `pending` | 보강 발생, 시간 미정 |
| `scheduled` | 보강 시간 확정 |
| `completed` | 보강 완료 |
| `expired` | 보강 기한 만료 (30일) |
| `waived` | 선생님이 면제 처리 |

### 보강 플로우

```
[보강 발생]
    │
    ├── 자동: 보강 잔여 +1 표시
    │
    ├── 선생님 앱: "보강 1회 적립됨" 알림
    │
    └── 학생 앱: "보강 1회 적립됨" 알림
         │
         ▼
[보강 예약]
    │
    ├── 학생: 레슨 화면 → "보강 예약" 버튼
    │         │
    │         └── 선생님 가용 시간 선택
    │               │
    │               ▼
    │         선생님에게 요청 알림
    │               │
    │               ├── 승인 → 보강 일정 확정
    │               │

## 정기 레슨 일괄 시간 변경

> 작성일: 2026-01-27
> 참조: [flow_with_app.md](./flow_with_app.md) - 섹션 5 시나리오 D

### 사용 시나리오

- 학생 학원 스케줄 변경으로 매주 레슨 시간 변경 필요
- 선생님 스케줄 변경으로 해당 학생 레슨 시간 이동

### 일괄 변경 플로우

```
학생 → 선생님 연결 → "레슨 시간 변경"
    │
    ▼
┌─────────────────────────────────────┐
│ 📅 정기 레슨 시간 변경               │
├─────────────────────────────────────┤
│ 현재: 매주 토요일 15:00             │
├─────────────────────────────────────┤
│ 변경 방식:                          │
│ ○ 이번 주만 변경 (1회성)            │
│ ● 앞으로 모든 레슨 변경 (일괄)      │ ← 선택
├─────────────────────────────────────┤
│ 희망 시간:                          │
│ ┌─────────────────────────────────┐ │
│ │ ○ 토요일 16:00                  │ │
│ │ ○ 토요일 17:00                  │ │
│ │ ○ 일요일 14:00                  │ │
│ │ ○ 다른 시간 요청                │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [변경 요청 보내기]                   │
└─────────────────────────────────────┘
    │
    ▼
선생님에게 알림: "🔄 레슨 시간 변경 요청"
    │
    ▼
┌─────────────────────────────────────┐
│ 📅 레슨 시간 변경 요청 (선생님)      │
├─────────────────────────────────────┤
│ 학생: 김서연                         │
│ 요청: 토요일 15:00 → 16:00          │
│ 적용: 이후 모든 레슨                 │
├─────────────────────────────────────┤
│ 16:00 가용 여부: ✅ 가능            │
├─────────────────────────────────────┤
│ [승인]     [다른 시간 제안]          │
└─────────────────────────────────────┘
    │
    ├── 승인 → 모든 미래 레슨 일괄 변경
    │         │
    │         ├── 기존 예약들 시간 업데이트
    │         ├── 정기 레슨 설정 변경
    │         └── 양쪽에 확정 알림
    │
    └── 대안 제시 → 학생에게 대안 전달
              │
              └── 학생 선택 → 위 과정 반복
```

### 일괄 변경 시 처리

| 항목 | 처리 방식 |
|------|----------|
| 정기 레슨 설정 (RegularLessonSettings) | `dayOfWeek`, `startTime` 업데이트 |
| 이미 생성된 미래 레슨들 | 시간 일괄 변경 |
| 완료된 과거 레슨 | 변경 없음 |
| 가용 시간 충돌 | 선생님 확인 후 조정 |

### 일괄 변경 알림

| 시점 | 수신자 | 내용 |
|------|--------|------|
| 요청 시 | 선생님 | "🔄 정기 레슨 시간 변경 요청" |
| 승인 시 | 양쪽 | "✅ 정기 레슨 시간이 변경되었습니다" |
| 거절 시 | 학생 | "❌ 요청한 시간이 불가능합니다" |
| 대안 제시 | 학생 | "📅 다른 시간을 제안받았습니다" |

## 레슨 장소

> 작성일: 2025-01-25

레슨은 다양한 장소에서 진행될 수 있으며, 학생 앱에서 장소 정보가 표시됩니다.

### 장소 유형 (LocationType)

| 유형 | 설명 | 표시 예시 |
|------|------|----------|
| academyRoom | 학원 레슨실 | 🏫 음악학원 301호 |
| teacherStudio | 선생님 스튜디오 | 🏠 남부터미널 우드브릿지 |
| studentHome | 학생 집 방문 | 🚗 학생 집 방문 |
| externalPlace | 외부 장소 (대여 연습실 등) | 📍 뮤직홀 연습실 |
| online | 온라인 (Zoom, FaceTime 등) | 💻 온라인 (Zoom) |

### 장소 결정 시나리오

| 시나리오 | 장소 유형 | 설명 |
|----------|----------|------|
| 선생님 스튜디오로 방문 | teacherStudio | 학생이 선생님 장소로 이동 |
| 선생님이 학생 집 방문 | studentHome | 선생님이 학생 집으로 이동 |
| 학원 레슨 | academyRoom | 학원 소속 레슨실 사용 |
| 외부 연습실 대여 | externalPlace | 양측이 외부 장소에서 만남 |
| 온라인 레슨 | online | 화상 플랫폼으로 진행 |
