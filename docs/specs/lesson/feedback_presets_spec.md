# 레슨노트 피드백 프리셋 스펙

> 이슈: [#122](https://github.com/chulgil/lesson-app/issues/122)
> 작성일: 2026-03-11
> 상태: 구현 완료

---

## 1. 개요

레슨 노트 작성 시 자주 사용하는 피드백 문구를 프리셋 칩으로 제공하여 입력 효율을 높인다.

---

## 2. UI 설계

### 2.1 프리셋 칩 영역

LessonNoteEditor 텍스트 필드 위에 프리셋 칩 행 표시:

```
[+프리셋] [음정 주의] [리듬 좋음] [활 주법] [자세 교정] [진도 우수]
┌──────────────────────────────────┐
│ 레슨 피드백을 작성하세요...        │
│                                  │
└──────────────────────────────────┘
```

- 칩 터치 시 텍스트 필드 커서 위치에 삽입
- 이미 입력된 텍스트가 있으면 줄바꿈 후 삽입
- 수평 스크롤 가능한 칩 행

### 2.2 기본 프리셋 목록

| 카테고리 | 프리셋 |
|----------|--------|
| 테크닉 | 음정 주의, 리듬 좋음, 활 주법 연습, 자세 교정 |
| 평가 | 진도 우수, 많이 향상됨, 복습 필요 |
| 과제 | 천천히 연습, 메트로놈 사용, 녹음 후 비교 |
