## 2. Phase 1: 학생 홈 가이드 + 선생님 연결 (#124)

### 2.1 학생용 GettingStartedCard
- 3단계 체크리스트: 선생님 연결 → 프로필 완성 → 첫 레슨 확인
- myConnectionsProvider / studentBookingsProvider watch
- 모든 단계 완료 시 자동 숨김

### 2.2 MyConnections 도움말
- 바텀시트: 초대코드/QR스캔/검색 3가지 연결 방법 안내
- 각 항목 탭 시 해당 화면으로 이동

### 2.3 연결 상태 배지
- 활성: 녹색 "연결됨" 배지
- 비활성: 회색 "해제됨" 배지 + 시각적 dimming

### 2.4 이전 선생님 섹션
- "연결된 선생님 (N명)" / "이전 선생님 (N명)" 분리
- "다시 연결" 버튼 → reactivateConnection()

## 3. Phase 2: 레슨노트 UX (#125)

### 3.1 학생 메모 위치 변경
- 기존: 피드백 → 포인트 → 팁 → **메모** (4번째)
- 변경: 피드백 → **메모** → 포인트 → 팁 (2번째)
- 학생 뷰(isTeacher==false)에서만 적용

### 3.2 학생 메모 타임라인 포함
- 검색 필터에 studentNote 추가
- 노트 카드에 "내 메모" 섹션 표시 (2줄 축약)

### 3.3 과제 설명 확장
- maxLines: 2 → 5

### 3.4 피드백 날짜 포맷
- 기존: `3월 11일`
- 변경: `2026.03.11`
