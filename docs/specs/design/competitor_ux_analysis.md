## 2. 핵심 UX 패턴 분석

### 2.1 대시보드 정보 아키텍처

**경쟁 앱 패턴**:
```
┌─────────────────────────────────────────────┐
│ [오늘의 핵심 숫자]                          │  ← 한눈에 파악
│  레슨 3회 | 미수금 2명 | 연습 5일           │
├─────────────────────────────────────────────┤
│ [즉시 액션이 필요한 항목]                   │  ← 빨간/주황 하이라이트
│  ⚠️ 결제 기한 D-3                           │
│  ⚠️ 미완료 과제 2개                         │
├─────────────────────────────────────────────┤
│ [오늘의 일정]                               │  ← 시간순 정렬
│  14:00 김민수 | 15:00 박철수               │
└─────────────────────────────────────────────┘
```

**개선 포인트**:
- **정보 우선순위**: 긴급한 정보 > 오늘의 정보 > 통계
- **액션 유도**: "즉시 처리" 섹션으로 긴급 항목 분리
- **숫자 강조**: 핵심 메트릭은 큰 폰트로 한눈에

### 2.2 연습 동기 부여 (게이미피케이션)

**Tonara 패턴**:
| 요소 | 설명 | 효과 |
|------|------|------|
| 포인트 시스템 | 연습 시간 × 포인트 | 68% 연습 시간 증가 |
| 리더보드 | 주간/월간 순위 | 경쟁심 자극 |
| 스티커/배지 | 과제 완료 시 획득 | 성취감 |
| 스트릭 | 연속 연습 일수 | 습관 형성 |
| 레벨 업 | 누적 연습 기반 | 장기 목표 |

**개선 포인트**:
```
현재 우리 앱: 스트릭만 있음 (🔥 12일)

추가 필요:
1. 주간 연습 목표 달성 배지
2. 악기별 레벨 시스템 (초급 → 중급 → 고급)
3. 선생님 칭찬 스티커 (레슨 후 지급)
4. 월간 연습왕 순위 (선택적 참여)
```

### 2.3 실시간 연습 타이머

**My Music Staff 패턴**:
```
┌─────────────────────────────────────────────┐
│ 🎵 연습 중: 모차르트 소나타 1악장           │
│                                             │
│           ⏱️ 12:34                          │  ← 상단 알림바에 상시 표시
│                                             │
│    [ ⏸️ 일시정지 ]  [ ⏹️ 완료 ]            │
│                                             │
│ 💡 앱을 나가도 타이머가 계속됩니다          │
└─────────────────────────────────────────────┘
```

**개선 포인트**:
- 현재: 연습 완료 후 시간 수동 입력
- 개선: 실시간 타이머 + 자동 기록
- 알림바 위젯으로 앱 전환 중에도 타이머 표시

### 2.5 3자 소통 완성

## 5. UX 원칙 추가 사항

### 5.1 정보 우선순위 원칙

```
1순위: 긴급 - 즉시 액션 필요 (빨강/주황)
       예: 미수금 D+, 예약 승인 대기

2순위: 오늘 - 당일 해야 할 일
       예: 오늘의 레슨, 오늘의 과제

3순위: 트렌드 - 진행 현황
       예: 스트릭, 이번주 연습, 이번달 레슨

4순위: 도구 - 필요시 접근
       예: 메트로놈, 튜너, 녹음
```

### 5.2 동기 부여 원칙

```
1. 즉각적 보상: 과제 완료 → 즉시 포인트/애니메이션
2. 진행 시각화: 목표 대비 현재 상태 프로그레스바
3. 사회적 인정: 선생님 칭찬, 순위 (선택적)
4. 연속성 강조: 스트릭, 연속 달성 배지
```

### 5.3 3자 소통 원칙

```
1. 투명성: 학부모가 자녀 현황 실시간 확인 가능
2. 적절한 분리: 학생 개인 메모 ≠ 학부모 공유 내용
3. 알림 최적화: 역할별 알림 내용/빈도 차별화
4. 쉬운 연락: 1탭으로 선생님 연락 가능
```
