# 역할별 화면 통합 설계서

> 작성일: 2026-01-24
> 상태: 설계 완료
> 연관 스펙: [student_class_system.md](../student/student_class_system.md), [parent_system.md](../user/parent_system.md), [subscription_system_spec.md](../subscription/subscription_system_spec.md)

## 개요

이 문서는 레슨 앱의 모든 화면을 **역할(Role)** 기준으로 정리한 통합 설계서입니다.
학원/개인레슨, 수강권, 3자 관계(선생님-학생-학부모)가 각 역할의 화면에서 어떻게 표현되는지 정의합니다.

---

## 플랫폼 구분

| 플랫폼 | 역할 | 설명 |
|--------|------|------|
| **앱 (iOS/Android)** | 선생님 | 레슨/학생 관리, 개인레슨 수강권 발급 |
| **앱 (iOS/Android)** | 학생 | 연습, 레슨 확인, 과제 수행 |
| **앱 (iOS/Android)** | 학부모 | 자녀 모니터링, 결제 관리 |
| **웹** | 학원 매니저 | 학원 운영, 강사/학생 관리, 수강권 발급 |

> **Note**: 이 문서는 **앱** 화면만 다룹니다. 웹 관리자 화면은 별도 스펙으로 관리됩니다.

## 4. 공통 컴포넌트

### 4.1 컨텍스트 배지

모든 화면에서 일관되게 사용하는 컨텍스트 배지입니다.

| 배지 | 의미 | 사용 위치 |
|------|------|----------|
| 🏫 학원명 | 학원 소속 | 학생 목록, 레슨 일정, 수강권 |
| 👤 개인레슨 | 선생님 직접 연결 | 학생 목록, 레슨 일정, 수강권 |
| 💻 온라인 | 온라인 레슨 | 레슨 장소, 레슨 일정 |
| 🎟️ N회 | 회차제 수강권 | 수강권 현황 |
| 📅 월정액 | 기간제 수강권 | 수강권 현황 |
| 🆓 체험 | 체험 레슨 | 수강권 현황, 학생 목록 |

### 4.2 수강권 상태 표시

| 상태 | 표시 | 색상 |
|------|------|------|
| 정상 | 잔여 N회 / 총 N회 | 기본색 |
| 임박 (잔여 2회 이하) | ⚠️ 잔여 N회 | 주황색 |
| 만료 임박 (D-7 이내) | ⚠️ D-N | 주황색 |
| 만료됨 | ❌ 만료됨 | 빨간색 |
| 미결제 | ⚠️ 미수금 | 빨간색 |

### 4.3 알림 우선순위

| 우선순위 | 알림 종류 | 표시 방식 |
|----------|----------|----------|
| 1 (긴급) | 결제 기한 D-day, 미수금 | 빨간 배지 + 상단 고정 |
| 2 (높음) | 결제 요청, 수강권 임박 | 주황 배지 |
| 3 (보통) | 새 과제, 레슨 변경 | 기본 알림 |
| 4 (낮음) | 연습 완료, 스트릭 달성 | 선택적 알림 |
