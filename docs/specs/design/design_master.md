## 1. Overview

이 문서는 Lessonaza 앱의 디자인 시스템 전체를 하나의 마스터 문서로 통합한 것입니다. UX 원칙, 디자인 토큰, 화면 설계, 경쟁사 분석을 포함합니다.

**타겟 사용자**: 음악 선생님, 학생, 학부모 (IT 친숙도 낮음, 다양한 연령대)

**설계 철학**: "음악인은 IT에 관심이 적으므로 최대한 심플하면서 효율적으로"

**3가지 황금 원칙**:

| 원칙 | 설명 | 예시 |
|------|------|------|
| **1. 원클릭** | 핵심 작업은 한 번의 탭으로 완료 | 연습 완료 체크, 좋아요 |

| **3. 얕은 뎁스** | 메뉴 진입 최대 2단계 | 홈 -> 상세 (끝) |

**플랫폼 구분**:

| 플랫폼 | 역할 | 설명 |
|--------|------|------|
| **앱 (iOS/Android)** | 선생님 | 레슨/학생 관리, 개인레슨 수강권 발급 |

## 2. UX Guidelines

### 2.1 Core Principles

#### "생각없이 사용" 원칙 (Don't Make Me Think)

| 법칙 | 설명 | 적용 |
|------|------|------|
| **Hick's Law** | 선택지가 많을수록 결정 시간 증가 | 옵션 3~4개로 제한, 템플릿 제공 |
| **Fitts's Law** | 타겟이 크고 가까울수록 빠른 선택 | CTA 버튼 크게, 엄지 영역 배치 |
| **Miller's Law** | 단기 기억 용량 7+-2개 | 한 화면 정보 7개 이하 |

**실천 지침**:

| 원칙 | 잘못된 예 | 올바른 예 |
|------|----------|----------|
| **기본값 제공** | 모든 옵션 비어있음 | 추천 값 미리 선택 |
| **토글 최소화** | 칩 뷰 <-> 블록 뷰 토글 | 단일 뷰만 제공 |
| **선택지 숨김** | 모든 옵션 펼쳐서 표시 | 고급 설정 접기식 |
| **역방향 처리** | 전체 수동 선택 | 기본 체크 + 예외만 해제 |
| **빈 상태 대응** | "데이터 없음" 만 표시 | 대안 제시, 다음 행동 안내 |
| **스마트 추천** | 모든 옵션 동등 표시 | 추천/최근 하이라이트 |

#### 사용자 관점 원칙

| 원칙 | 설명 | 예시 |
|------|------|------|
| **과제 집중** | 현재 사용자의 목표와 무관한 요소 배제 | 연습 기록 중 결제 배너 X |
| **맥락 존중** | 사용자의 현재 흐름을 방해하지 않음 | 레슨 예약 중 팝업 X |
| **비즈니스 자연 통합** | 수익화 요소도 자연스럽게 녹임 | 유료 기능은 필요 시점에 안내 |

#### 사용자 언어 사용

| 피해야 할 표현 | 권장 표현 | 이유 |
|----------------|----------|------|
| 내림차순/오름차순 | 최신순/오래된순/이름순 | 정렬 의도가 명확함 |
| 동기화 | 새로고침, 불러오기 | 일상 언어 |
| 렌더링 | 표시, 보기 | 기술 용어 회피 |
| NULL, undefined | 미입력, 없음 | 에러 메시지 명확화 |
| 인스턴스, 엔티티 | 레슨, 학생, 과제 | 도메인 언어 사용 |

#### 일관된 UI 경험

| 요소 | 일관성 규칙 |
|------|------------|
| **헤더** | 모든 화면 동일 높이/스타일 |
| **하단 탭** | 위치/아이콘/라벨 고정 |
| **카드 레이아웃** | 동일한 패딩/마진/그림자 |
| **버튼 스타일** | Primary/Secondary 구분 명확 |
| **색상 의미** | 녹색=성공, 빨간색=경고, 회색=비활성 |

#### 정보 우선순위 원칙

```
1순위: 긴급 (빨강/주황) - 즉시 액션 필요
       예: 미수금 D+, 예약 승인 대기, 결제 기한

2순위: 오늘 - 당일 해야 할 일
       예: 오늘의 레슨, 오늘의 과제

3순위: 트렌드 - 진행 현황/통계
       예: 스트릭, 이번주 연습, 이번달 레슨

4순위: 도구 - 필요시 접근
       예: 메트로놈, 튜너, 녹음
```

**홈 화면 레이아웃 원칙**:

| 영역 | 내용 | 이유 |
|------|------|------|
| **상단** | 핵심 숫자 (오늘 레슨, 미수금, 완료율) | 한눈에 현황 파악 |
| **중상단** | 즉시 확인 필요 섹션 | 긴급 항목 놓치지 않도록 |
| **중앙** | 캘린더 + 오늘의 일정 | 핵심 정보 |
| **하단** | 빠른 도구 | 필요시 접근 |

**긴급 표시 규칙**:

| 긴급도 | 색상 | 표시 | 예시 |
|--------|------|------|------|
| **긴급** | 빨강 | D+ (기한 초과) | 미수금 D+3 |
| **경고** | 주황 | D-7 이내 | 결제 기한 D-5 |
| **주의** | 노랑 | 임박 상태 | 수강권 2회 남음 |
| **정상** | 기본색 | - | 일반 상태 |

#### 동기 부여 원칙 (게이미피케이션)

| 요소 | 현재 | 개선 목표 | 우선순위 |
|------|------|----------|----------|
| **스트릭** | 있음 (12일) | 유지 | - |
| **포인트** | 없음 | 연습/과제 완료 시 획득 | Phase 2 |
| **레벨** | 없음 | 악기별 초급->중급->고급 | Phase 2 |
| **배지** | 없음 | 주간 목표 달성 시 | Phase 3 |
| **리더보드** | 없음 | 선택적 참여 | Phase 3 |

**즉각적 피드백 원칙**:
- 과제 완료 시: 탭 -> 체크 + 애니메이션 + "+30 pt" 표시 (0.5초 후 사라짐) + 토스트

**진행 시각화 원칙**:

| 항목 | 표시 방식 |
|------|----------|
| 과제 진행 | [2/4 완료] 또는 프로그레스바 |
| 주간 연습 | 5/7일 + 프로그레스바 |
| 수강권 | 5/8회 + 프로그레스바 + 만료일 |
| 연습 목표 | 2h 30m / 5h + 프로그레스바 |

### 2.2 Navigation Patterns

**뎁스 최소화**:
```
목표: 모든 핵심 기능은 2탭 이내 도달

좋은 예:
홈 -> 학생 상세 (끝)
홈 -> 레슨 상세 (끝)

나쁜 예:
홈 -> 학생 목록 -> 학생 상세 -> 레슨 탭 -> 레슨 상세
```

**메인 탭 구성**:

| 역할 | 탭 1 | 탭 2 | 탭 3 | 탭 4 |
|------|------|------|------|------|
| **선생님** | 홈 | 스케줄 | 학생 | 프로필 |
| **학생** | 홈 | 스케줄 | 연습 | 프로필 |
| **학부모** | 대시보드 | 수강권 | 결제 | 설정 |

**메뉴 배치 원칙**:

| 빈도 | 기능 예시 | 배치 |
|------|----------|------|
| **매일** | 연습 체크, 레슨 확인, 학생 목록 | 메인 탭, 홈 대시보드 |
| **주 1회** | 레슨 기록 작성, 과제 등록 | 상세 화면 내 |
| **월 1회** | 결제 확인, 통계 확인 | 별도 탭 또는 설정 |
| **가끔** | 프로필 수정, 알림 설정 | 설정 메뉴 |

**네비게이션 상세**:

선생님 앱:
```
BottomNavigation:
+-- 홈 (home)                    <- 대시보드 형태 (캘린더 없음)
|   +-- 핵심 통계 (오늘 레슨, 미수금, 이번 달)
|   +-- 즉시 확인 필요 (레슨 요청, 입금 확인)
|   +-- 오늘의 레슨 목록
+-- 스케줄 (schedule)
|   +-- 뷰 선택 (전체/주간/일간)
|   +-- 캘린더 뷰
|   +-- 레슨 상세
|   +-- 레슨 노트
+-- 학생 (students)
|   +-- 학생 목록 (학원별/개인레슨 필터)
|   +-- 학생 상세 (수강권, 학부모 정보, 레슨 장소)
|   +-- 수강권 발급 (개인레슨)
+-- 프로필 (profile)
    +-- 내 프로필 (프로필 상세, 가용 시간, 레슨 정책)
    +-- 설정 (알림, 다크모드, 녹음 관리)
    +-- 지원 (도움말, 피드백, 앱 정보)
    +-- 계정 (약관, 로그아웃)
```

학생 앱:
```
BottomNavigation:
+-- 홈 (home)
|   +-- 오늘 할일
|   +-- 수강권 현황
|   +-- 빠른 도구
+-- 스케줄 (schedule)
|   +-- 뷰 선택 (전체/주간/일간)
|   +-- 레슨 캘린더
|   +-- 레슨 상세 / 레슨 노트
|   +-- 수강권 상세
|   +-- 레슨 장소
+-- 연습 (practice)
|   +-- 연습 캘린더
|   +-- 레퍼토리 / 섹션 상세
|   +-- 녹음
+-- 프로필 (profile)
    +-- 내 정보
    +-- 설정
```

학부모 앱:
```
ProfileSelector -> BottomNavigation:
+-- 대시보드 (dashboard)
|   +-- 자녀 선택 / 현황 요약 / 알림 목록

|   +-- 자녀별 수강권 / 이용 내역
```

### 2.3 Interaction Patterns

**원클릭 액션**:
```
연습 항목:
  탭 = 즉시 완료 체크/해제
  확인 다이얼로그 불필요
  저장 버튼 불필요
  즉시 반영 + 토스트 피드백
```

**스와이프 액션**:
- 좌 스와이프: 삭제 (빨간색)
- 우 스와이프: 완료/보관 (녹색)
- 사용처: 과제 목록, 알림 목록, 레슨 일정

**길게 누르기**:
- 순서 변경 (드래그), 컨텍스트 메뉴 열기, 다중 선택 모드 진입
- 주의: 대안 접근 방식도 함께 제공 (... 메뉴)

**피드백 패턴**:

| 액션 | 피드백 방식 |
|------|------------|
| 저장 성공 | 하단 토스트 "저장되었습니다" |
| 삭제 성공 | 하단 토스트 "삭제되었습니다" + 되돌리기 |
| 에러 발생 | 하단 토스트 (빨간색) + 재시도 버튼 |
| 로딩 중 | 버튼 내 스피너 또는 Shimmer |

**시간 선택 UI 패턴**:

| 원칙 | 설명 |
|------|------|
| **단일 뷰** | 학생용은 칩 버튼만 (토글 제거) |
| **가용 시간만** | 예약 불가 시간은 숨김 |
| **스마트 추천** | 평소 레슨 시간에 별 표시 |
| **빈 상태 대응** | 대안 날짜 자동 제안 |

학생/학부모용 (칩 버튼):
```
+-------------------------------------+
|  < 2/18(화) >                       |
|------------------------------------- |
|  예약 가능한 시간                     |
|                                      |
|  [15:00]  [* 16:00]   <- 평소 시간   |
|  [17:00]  [18:00]                    |
|                                      |
|  16:00 (60분)                        |
|  김선생님 / 수강권 5/8회              |
|                                      |
|  [예약하기]                           |
+--------------------------------------+
```

칩 스타일:

|------|------|--------|--------|
| 기본 | #FFFAF5 | #E0E0E0 | #333 |
| 호버 | #FFF5EB | Secondary | #333 |
| 선택 | Primary | Primary | #FFF |

### 2.4 Role-Specific UX

#### 역할별 화면 재사용 원칙

```
동일한 화면 컴포넌트를 역할에 따라 다르게 표시
- 레이아웃: 동일
- 데이터: 역할별 필터링
- 텍스트: 역할별 라벨 변경
- 액션: 역할별 권한에 따라 활성화/비활성화
```

선생님 <-> 학부모 화면 (관찰자 역할 동일):

| 화면 | 선생님 | 학부모 | 재사용 방식 |
|------|--------|--------|------------|
| 학생 목록 | 내 학생들 | 내 자녀들 | 타이틀만 변경 |
| 연습 현황 | 학생 연습 현황 | 자녀 연습 현황 | 타이틀만 변경 |
| 레슨 일정 | 학생별 레슨 일정 | 자녀별 레슨 일정 | 타이틀만 변경 |
| 과제 목록 | 학생 과제 현황 | 자녀 과제 현황 | 타이틀만 변경 |

역할별 차이점:

| 구분 | 선생님 | 학부모 | 학생 |
|------|--------|--------|------|
| **데이터 권한** | 읽기/쓰기 | 읽기 전용 | 본인 데이터 읽기/쓰기 |
| **과제 관리** | 생성/수정 | 열람만 | 완료 체크 |
| **결제 관리** | 청구서 발행 | 결제 수행 | 열람만 |
| **피드백** | 작성 가능 | 열람만 | 열람만 |

읽기 전용 모드: 눈 아이콘 표시, 체크박스 비활성화 (회색), 탭해도 반응 없음

#### 역할별 기본 설정

| 설정 항목 | 선생님 | 학생 | 학부모 |
|----------|--------|------|--------|
| 캘린더 뷰 | 주간 | 주간 | 주간 |
| 알림 시간 | 레슨 1시간 전 | 연습 리마인더 오후 6시 | 자녀 활동 요약 오후 9시 |

**잔여 횟수 경고**:

| 조건 | 색상 | 표시 |
|------|------|------|
| <= 50% | 기본 | (경고 없음) |
| <= 25% | 노랑 | "N회 남음" |
| <= 2회 | 주황 | "2회 남음 - 연장을 고려해주세요" |
| = 1회 | 빨강 | "마지막 1회!" |

**변경/취소 횟수 경고**:

| 조건 | 색상 | 표시 | 액션 |
|------|------|------|------|
| >= 2회 남음 | 기본 | "변경: N/M회" | 자유 변경 |

| = 0회 | 빨강 | "[X] 변경 불가" | 버튼 비활성화 |

**만료일 경고**:

| 조건 | 색상 | 표시 |
|------|------|------|
| > 7일 | 기본 | "만료: M/D" |
| <= 7일 | 노랑 | "[!] 7일 후 만료" |

| 만료 | 회색 | "만료됨" |

**레슨 장소 안내**: 지도 영역 + 주소/층/호/레슨실 + [주소 복사][길찾기][전화하기] + 메모
