## 1. 문제 정의

E2E 감사 정성 입증: 가입 흐름의 첫 단계 = SMS 3분 타이머 마찰. v3 spec §1 자체에서 "전화인증이 첫 단계 → 진입 마찰 큼" 으로 인식했으나 미구현.

### 1.1 현재 결함

| # | 문제 | 영향 |
|---|---|---|
| 1 | SSO 직후 즉시 전화인증 강제 | SMS 인증번호 입력 3분 = 가입 직후 최대 마찰 지점 |
| 2 | 약관 동의가 별도 화면 | SSO + 약관 + 전화인증 = 3단계 누적 마찰 |
| 3 | 전화인증 미완료 시 모든 기능 차단 | 가입~D 단계 자유 사용 불가 → "한 번 보고 그만" |
| 4 | 학부모 측 신뢰 신호 부재 | 인증된 선생님과 미인증 선생님 구분 불가 |

### 1.2 영향 범위 (펀넬)

A 단계 이탈 1순위 (가입 직후 3분 내). 카톡 채널(이미 가입됨)·네이버 카페·숨고(약관만) 대비 진입 마찰 최대.

### 1.3 정량 추정

- SSO → 홈 진입 평균 시간: 현재 추정 180초+ (SMS 타이머 포함)
- 가입 후 24h 내 이탈률: 현재 추정 40%+ (SMS 입력 단계 이탈 다수)

## 2. 설계 원칙

> **"가입은 60초 안에. 전화인증은 신뢰·법 요건이 필요한 시점에만."**

| 원칙 | 의미 |
|---|---|
| 즉시 진입 (성인 역할) | 선생님·학부모는 SSO → 약관 → B 단계 → 홈. 전화인증은 가입 흐름 밖 |
| 학생은 가입 시 인증 | 학생 직접 가입은 만 14세 검증을 위해 SSO 직후 전화인증 필수 |
| 보상 유도 (선생님) | 전화인증 = "인증 선생님 배지" 보상 (Phase C 선택 퀘스트) |
| 신뢰 게이트 (선생님 E3) | 첫 수강권 발급 직전 전화인증 강제. 학부모 신뢰 보호 |
| 학부모 신호 | 인증 배지가 학부모에게 시각적으로 표시 → 자연스러운 인증 유도 |
| 약관 통합 | SSO 직후 화면에 약관 체크박스 통합. 필수 2개(서비스·개인정보) + 마케팅 별도 1개 |

### 2.1 역할별 차등 근거

| 역할 | SSO 직후 전화인증 | 근거 |
|---|---|---|
| **선생님** | 분리 (E3 게이트) | 거의 성인. 학부모 신뢰는 결제 시점(E3)에 필요 |
| **학부모** | 분리 (필요 시 결제 시점) | 성인 가정. 결제·자녀 관리에 인증이 필요한 시점에 별도 게이트 |
| **학생 (직접 가입)** | **필수** | SSO만으로 만 14세 검증 불가. 정보통신망법 제31조 대응 — 통신사 본인인증으로 연령 자동 검증 |
| **학생 (자녀 프로필)** | 해당 없음 | 학부모 계정 하위로 가입 — 학부모가 만 14세 미만 자녀 대신 동의 |

### 2.2 만 14세 검증 메커니즘

- **전화인증 = 통신사 본인인증 = 주민번호 기반 → 연령 자동 검증**
- 정보통신서비스 제공자가 만 14세 미만 회원가입 시 법정대리인 동의 필요(정보통신망법 제31조)
- 자녀 프로필 방식과 결합: 만 14세 미만은 자녀 프로필(학부모 대리), 만 14세 이상은 직접 SSO + 전화인증
- 전화인증이 통과되면 만 14세 이상임이 통신사 측에서 검증된 상태로 진입

### 2.3 약관 통합의 법적 제약

> "1탭" 은 별도 화면 분리를 제거한다는 의미이며, 한 체크박스로 모든 동의를 묶는 것은 **불가**.

| 동의 항목 | 필수/선택 | 별도 동의 의무 |
|---|---|---|
| 서비스 이용약관 | 필수 | 한 묶음 가능 |
| 개인정보 처리방침 | 필수 | 한 묶음 가능 (개인정보보호법 §22 — 명시적 동의 필요) |
| 마케팅 정보 수신 | 선택 | **별도 체크박스 필수** (정보통신망법 제50조) |

→ "약관 통합" = SSO 직후 화면에 체크박스 2개(필수 묶음 + 마케팅) 노출. 별도 페이지 분리 제거.

                                                              ▼

                                                              │
                                                              ▼ Phase C 선택 퀘스트

### 3.2 학생 직접 가입 흐름 (v3.1)

```
[A 단계 — 만 14세 검증 필수]

                                      │ 약관 통합 동의 (필수 1탭 + 마케팅 별도 1탭)
                                      ▼
                              역할 선택 ("학생으로 시작하기")
                                      │
                                      ▼

                                      │              (통신사 본인인증 = 주민번호 = 연령 자동)
                                      │

                            │ 만 14세 이상       │ 만 14세 미만
                            ▼                   ▼
                       이름·악기            "자녀 프로필로 가입해주세요"
                            │              (학부모 안내 화면 — 가입 차단)
                            ▼
                         홈 진입
```

### 3.3 자녀 프로필 흐름 (변경 없음)

학부모 계정 하위로 만 14세 미만 자녀 프로필 생성. 자녀는 직접 SSO·전화인증 없이 학부모 계정에서 활동.

### 3.4 학생 직접 가입 — PASS 통합 전 임시 안전망 (2026-06-02)

통신사 본인인증(PASS) 통합 전까지 학생 직접 가입은 만 14세 검증 메커니즘이 부재한다. 따라서 본 통합이 완료될 때까지 학생 직접 가입은 **임시 안전망 화면**(`StudentSignupBlockedScreen`)으로 안내된다.

```
역할 선택 "학생으로 시작하기"
        │
        ▼
[임시 안전망 — PASS 통합 전]
"학생 직접 가입은 준비 중이에요"
        │
   ┌────┴────┐
   ▼         ▼
부모님 계정     선생님 초대코드
(역할 재선택)   (학생 초대 흐름)
```

| 항목 | 안전망 (현재) | PASS 통합 후 |
|---|---|---|
| 라우트 | `/student/onboarding/signup-blocked` | `/student/onboarding/phone-verification` |
| 학생 직접 가입 | 차단 + 안내 | §3.2 흐름 (전화인증 → 14세 분기) |
| 만 14세 미만 | 자녀 프로필 안내 (수동) | PASS 결과 기반 자동 분기 |
| 학부모 전환 CTA | 제공 | 옵션 |

PASS 통합 완료 시 본 안전망은 §3.2 의 전화인증 화면으로 교체되며, 만 14세 미만 사용자는 통신사 본인인증 결과 기반으로 자녀 프로필 안내 화면으로 분기된다.

### 3.5 기존 흐름 (v1) 와 비교

| 단계 | v1 (현재) | v3.1 (제안) |
|---|---|---|
| SSO 직후 | 약관 화면 (별도 페이지) | 약관 체크박스 통합 (SSO 결과 화면) |
| 선생님·학부모 다음 단계 | 전화인증 (SMS 3분) | 이름·악기 (B 단계) — 전화인증 분리 |

## 4. 게이트 정책

### 4.1 인증 없이 가능한 행동 (선생님·학부모)

| 행동 | 인증 필요? |
|---|---|
| 홈 진입·탐색 | 불필요 |
| 가용시간 설정 | 불필요 |
| 학생 초대 (D 단계) | 불필요 |
| 첫 레슨 등록 | 불필요 |
| 프로필 편집 | 불필요 |

### 4.2 인증 필요한 행동 (선생님)

| 행동 | 인증 필요? | 게이트 시점 |
|---|---|---|
| 첫 수강권 발급 (E3 진입) | **필수** | "발급" 버튼 탭 시 인증 모달 |
| 수강권 제안 송신 (E1) | 선택 (정책 결정) | 본 스펙: **선택** (E3 까지만 강제) |
| 입금 확인 (E3) | 필수 (E3 게이트 통과 후 자동) | 별도 게이트 없음 |

### 4.3 학생 직접 가입 게이트

| 행동 | 인증 필요? | 게이트 시점 |
|---|---|---|
| 가입 진입 (역할 선택 = 학생) | **필수** | 역할 선택 직후 — 만 14세 검증 |
| 만 14세 미만 진입 시 | 가입 차단 | 자녀 프로필 안내 화면으로 라우팅 |

### 4.4 학부모 게이트 (참고)

| 행동 | 인증 필요? | 비고 |
|---|---|---|
| 가입 진입 | 불필요 | 성인 가정 |
| 결제 (수강권 입금 확인 — 부모 측) | 향후 정책 결정 | 결제 게이트웨이 PG 본인인증으로 대체 가능 |

### 4.3 게이트 UX

E3 진입 직전 미인증 시:

```
┌────────────────────────────────────────┐
│                                        │
│   수강권 발급에는 전화인증이 필요해요    │
│                                        │
│  학부모가 신뢰할 수 있는 선생님임을      │
│  확인하기 위해 본인 인증이 필요합니다.   │
│                                        │
│  인증 완료 시:                          │
│  · 인증 선생님 배지                     │
│  · 학부모 화면에서 신뢰 표시            │
│                                        │
│  ┌──────────────────────────────┐      │
│  │       지금 인증하기            │      │
│  └──────────────────────────────┘      │
│                                        │
│  [나중에 — 수강권 발급 보류]            │
└────────────────────────────────────────┘
```

"나중에" 선택 시 수강권 제안은 `paymentRequested` 상태로 유지되나 발급 단계 불가.

## 5. 백엔드 영향

### 5.1 User 엔티티 확장

| 필드 | 타입 | 기본 | 설명 |
|---|---|---|---|
| `phoneVerifiedAt` | `DateTime?` | `null` | 전화인증 완료 시각 |
| `phoneNumber` | `String?` | `null` | 인증된 전화번호 (E.164 형식) |

기존 가입 흐름에서 강제로 받던 전화번호는 `null` 허용으로 전환. 마이그레이션 시 기존 가입자는 `phoneVerifiedAt` 을 가입일로 backfill.

### 5.2 약관 동의 처리

| 필드 | 타입 | 설명 |
|---|---|---|
| `User.termsAcceptedAt` | `DateTime` | 서비스 이용약관 + 개인정보 처리방침 동의 시각 (필수 묶음) |
| `User.marketingConsentAt` | `DateTime?` | 마케팅 정보 수신 동의 시각 (선택, 별도 동의) |

SSO 결과 화면에서 체크박스로 즉시 기록. 별도 페이지 분리는 제거하지만, 마케팅 동의는 정보통신망법 제50조에 따라 별도 체크박스로 표시.

### 5.3 게이트 미들웨어

```python
# E3 진입 시점 (수강권 발급 직전) — 선생님 한정
def require_phone_verification_for_subscription_issue(user: User):
    if user.role != UserRole.teacher:
        return  # 학생·학부모는 다른 게이트 적용
    if user.phone_verified_at is None:
        raise PhoneVerificationRequired(
            message="수강권 발급에는 전화인증이 필요해요",
            action="phone_verification_modal",
        )


# 학생 직접 가입 (역할 선택 직후) — 만 14세 검증
def require_phone_verification_for_student_signup(user: User):
    if user.phone_verified_at is None:
        raise PhoneVerificationRequired(
            message="가입을 위해 본인 인증이 필요해요",
            action="student_signup_phone_screen",
        )
    # 만 14세 미만 진입 차단은 통신사 본인인증 결과 (생년월일) 로 판정
    if user.is_under_14():
        raise UnderAgeBlocked(
            message="만 14세 미만은 자녀 프로필로 가입해주세요",
            action="parent_signup_guide_screen",
        )
```

### 5.4 학부모 측 표시

학부모가 선생님 프로필을 조회할 때:

```dart
// FE
if (teacher.phoneVerifiedAt != null) {
  VerifiedTeacherBadge();  // 체크 아이콘 + "인증 선생님" 라벨
}
```

학생/학부모 검색 결과·프로필·수강권 제안 화면 모두에 배지 노출.

### 5.5 메트릭 이벤트

| 이벤트 | 트리거 | 페이로드 |
|---|---|---|
| `auth.sso_completed` | SSO 콜백 완료 | `userId`, `provider`, `timestamp` |
| `auth.home_entered` | 홈 첫 진입 | `userId`, `timeSinceSSO` |
| `auth.phone_verification_gate_shown` | E3 진입 시 게이트 노출 | `userId`, `subscriptionId` |
| `auth.phone_verification_completed` | 전화인증 완료 | `userId`, `trigger`(quest/gate) |

## 6. 측정 기준

|---|---|---|
| SSO → 홈 진입 평균 시간 | `auth.home_entered.timeSinceSSO` 중앙값 | < 60초 |
