# 학부모 로그인 플로우 스펙

> 작성일: 2025-12-27
> 브레인스토밍 결과 정리

## 결정 사항 요약

| 항목 | 결정 |
|------|------|
| 역할 선택 위치 | 로그인 화면에 별도 학부모 버튼 |
| 학부모 버튼 디자인 | "학부모이신가요?" 텍스트 링크 |
| 신규 학부모 온보딩 | 즉시 초대 코드 입력 화면 |
| 초대 코드 없는 경우 | 로그인 허용, 빈 홈 화면 표시 |
| 다중 역할 지원 | 인앱 역할 전환기 제공 |
| 역할 전환기 위치 | 프로필 탭 상단 (데이터 있는 역할만 표시) |

## 플로우 다이어그램

```
[로그인 화면]
     │
     ├─── [소셜 로그인 버튼들]
     │         │
     │         └─── 로그인 성공 ───→ [역할 선택 다이얼로그]
     │                                    │
     │                                    ├─── 선생님 선택 → /home
     │                                    └─── 학생 선택 → /student-home
     │
     └─── "학부모이신가요?" 텍스트 링크
               │
               └─── 탭 ───→ [소셜 로그인] ───→ [초대 코드 입력 화면]
                                                      │
                                                      ├─── 코드 입력 → 자녀 연결 → /parent-home
                                                      └─── "코드가 없어도 괜찮아요" → /parent-home (빈 화면)
```

## 상세 스펙

### 1. 로그인 화면 수정

**위치**: 소셜 로그인 버튼들 하단

```
[Google 로그인]
[Apple 로그인]

"학부모이신가요?"  ← 텍스트 링크 (밑줄, 회색 계열)
```

**동작**:
- 탭 시 학부모 로그인 모드로 전환
- 소셜 로그인 진행 (동일한 소셜 로그인 사용)
- 로그인 성공 후 초대 코드 입력 화면으로 이동

### 2. 초대 코드 입력 화면

**새 화면**: `ParentInviteCodeScreen`

**UI 구성**:
```
[뒤로가기]

👨‍👩‍👧 학부모 등록

자녀의 선생님으로부터 받은
초대 코드를 입력해주세요

[______________________]  ← 초대 코드 입력 필드

[코드 확인하기]  ← Primary 버튼

─────────────────────────

"코드가 없어도 괜찮아요"  ← 텍스트 링크
나중에 프로필에서 자녀를 등록할 수 있습니다
```

**동작**:
- 코드 입력 후 확인 → 자녀 연결 → /parent-home
- "코드가 없어도 괜찮아요" 탭 → /parent-home (빈 화면)

### 3. 다중 역할 지원

**프로필 탭 상단 역할 전환기**:
- 현재 사용자가 데이터를 가진 역할만 표시
- 예: 선생님+학부모 데이터 있으면 두 역할만 표시
- 세그먼트 컨트롤 또는 탭 형태

```
프로필 화면 상단:
┌─────────────────────────────────────┐
│  [👩‍🏫 선생님]  [👨‍👩‍👧 학부모]        │  ← 데이터 있는 역할만
└─────────────────────────────────────┘
```

### 4. 빈 학부모 홈 화면

초대 코드 없이 진입한 경우:

```
┌─────────────────────────────────────┐
│                                     │
│         👨‍👩‍👧                        │
│                                     │
│    자녀를 등록해주세요              │
│                                     │
│  선생님으로부터 받은 초대 코드로    │
│  자녀를 등록하면 레슨 정보와        │
│  연습 현황을 확인할 수 있습니다.    │
│                                     │
│     [초대 코드 입력하기]            │
│                                     │
└─────────────────────────────────────┘
```

## 구현 순서

1. 로그인 화면에 "학부모이신가요?" 링크 추가
2. 학부모 로그인 모드 상태 관리
3. 초대 코드 입력 화면 생성
4. 빈 학부모 홈 화면 상태 처리
5. 프로필 탭 역할 전환기 구현
