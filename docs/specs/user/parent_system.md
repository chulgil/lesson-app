## 개요

학생의 학부모가 레슨 관리에 참여할 수 있는 시스템입니다.
선생님-학부모-학생 간의 효율적인 소통과 결제/과제 관리를 지원합니다.

### 학원 컨텍스트

학부모는 다음 상황에서 활동할 수 있습니다:

| 컨텍스트 | 설명 |
|----------|------|
| **개인 레슨** | 선생님 ↔ 학부모 직접 연결 |
| **학원 레슨** | 학원 ↔ 학부모 연결, 강사는 학원 통해 접근 |
| **복합 상황** | 자녀가 개인+학원 동시 레슨 시 각각 관리 |

> 학원 컨텍스트에서는 결제가 학원으로 이루어지며, 데이터 소유권은 학원에 있습니다.
> 자세한 내용: [3자 관계 설계](../lesson/three_party_relationship_spec.md), [구독 시스템](../subscription/subscription_system_spec.md)

## 2. 학부모 등록

### 2.1 등록 방식 (Q1:D)

학생 또는 선생님이 학부모를 초대할 수 있습니다.

```
┌────────────────────────────────────────────────────────┐
│                   학부모 초대 방식                      │
├────────────────────────────────────────────────────────┤
│                                                        │
│  방식 1: 학생이 초대                                   │
│  ┌──────────┐     초대링크      ┌──────────┐          │
│  │   학생   │ ─────────────────► │  학부모  │          │
│  └──────────┘                   └──────────┘          │
│                                                        │
│  방식 2: 선생님이 초대                                 │
│  ┌──────────┐     초대링크      ┌──────────┐          │
│  │  선생님  │ ─────────────────► │  학부모  │          │
│  └──────────┘                   └──────────┘          │
│                                                        │
│  초대 프로세스:                                        │
│  1. 초대자가 학부모 연락처(이메일/전화) 입력           │
│  2. 초대 링크 전송 (SMS/이메일)                        │
│  3. 학부모가 링크 클릭 → 회원가입/로그인               │
│  4. 자녀와 연결 완료                                   │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 2.2 연령별 계정 구조 (Q2:D)

**핵심 원칙**: 만 14세 미만 학생은 **회원가입 없이** 부모 계정의 "자녀 프로필"로만 존재합니다.
이를 통해 개인정보보호법상 법정대리인 동의 절차가 불필요해집니다.

| 연령 구분 | 계정 구조 | 학부모 연결 | 비고 |
|----------|----------|------------|------|
| **만 14세 미만** | 회원가입 ❌ (자녀 프로필) | 필수 (부모 계정에 포함) | 개인정보 수집 최소화 |
| **만 14세 이상** | 학생 계정 가입 가능 | 선택적 연동 | 본인 동의로 가입 |
| **성인 (18+)** | 학생 계정 단독 | 선택적 | 독립적으로 결제 가능 |

```
┌─────────────────────────────────────────────────────────┐
│                    연령별 플로우                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  만 14세 미만 (자녀 프로필 방식):                       │
│  ┌────────┐                ┌────────┐   초대   ┌────────┐
│  │ 부모   │ ── 프로필 ──► │자녀    │ ◄───────│ 선생님 │
│  │ 계정   │    포함       │프로필  │         │        │
│  └────────┘                └────────┘         └────────┘
│      ↑                         │                        │
│  회원가입                  회원가입 ❌                  │
│                           (개인정보 최소 수집)          │
│                                                         │
│  만 14세 이상 (본인 계정 가능):                         │
│  ┌────────┐   연결   ┌────────┐                        │
│  │  학생  │ ◄───────►│ 학부모 │  ← 선택적 연동         │
│  │ (계정) │  선택적  │(선택적)│     (읽기 전용)        │
│  └────────┘          └────────┘                        │
│                                                         │
│  성인 (독립):                                           │
│  ┌────────┐   결제   ┌────────┐                        │
│  │  학생  │ ────────►│ 선생님 │  ← 학부모 불필요       │
│  │ (성인) │  직접    │        │                        │
│  └────────┘          └────────┘                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.3 만 14세 미만 자녀 프로필 시스템

> **법적 근거**: 개인정보보호법 제22조의2에 따라 만 14세 미만 아동의 개인정보 수집 시
> 법정대리인 동의가 필수입니다. 자녀 프로필 방식은 회원가입 없이 최소 정보만 저장하여
> 이 요건을 우회합니다.

#### 2.3.1 자녀 프로필 구조

```

#### 2.3.4 만 14세 도달 시 전환

만 14세가 되어도 자녀 프로필로 **계속 사용 가능**합니다.
원하는 경우에만 본인 계정으로 전환할 수 있습니다.

```
┌─────────────────────────────────────────────────────────┐
│                만 14세 도달 시 처리                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  옵션 A: 그대로 유지 (기본)                             │
│  ┌────────────────────────────────────────────────┐    │
│  │  자녀 프로필로 계속 사용                        │    │
│  │  - 부모 계정에서 프로필 전환                    │    │
│  │  - 기존 데이터 그대로 유지                      │    │
│  │  - 부모가 계속 관리                             │    │
│  └────────────────────────────────────────────────┘    │
│                                                         │
│  옵션 B: 본인 계정으로 전환 (선택)                      │
│  ┌────────────────────────────────────────────────┐    │
│  │  1. 학생이 본인 이메일로 회원가입               │    │
│  │  2. 기존 자녀 프로필 데이터 → 본인 계정으로 이전│    │
│  │  3. 부모 계정과 연동 (읽기 전용) 선택 가능      │    │
│  │  4. 이전 완료 후 자녀 프로필 삭제               │    │
│  └────────────────────────────────────────────────┘    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.4 휴대폰 없는 학생 처리

어린 학생 중 휴대폰이 없는 경우를 위한 접근 방식입니다.

| 방식 | 설명 | 적합한 상황 |
|------|------|------------|
| **부모 기기 공유** | 부모 휴대폰에서 프로필 전환하여 사용 | 외출 시, 어린 초등학생 |
| **태블릿/iPad 사용** | 가정 내 태블릿에서 앱 사용 | 집에서 연습할 때 |
| **복합 사용** | 집에서는 태블릿, 외출 시 부모 폰 | 가장 권장 |

```
┌─────────────────────────────────────────────────────────┐
│              휴대폰 없는 학생 사용 시나리오              │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  집에서 연습:                                           │
│  ┌──────────┐      ┌──────────┐                        │
│  │  iPad    │ ──►  │ 자녀     │  연습 기록             │
│  │ (가정용) │      │ 프로필   │  과제 확인             │
│  └──────────┘      └──────────┘                        │
│                                                         │
│  외출/레슨실:                                           │
│  ┌──────────┐      ┌──────────┐                        │
│  │ 부모     │ ──►  │ 자녀     │  레슨 노트 확인        │
│  │ 휴대폰   │      │ 프로필   │  과제 확인             │
│  └──────────┘      └──────────┘                        │
│                                                         │
│  동기화:                                                │
│  - 모든 기기에서 동일한 데이터 접근                     │
│  - 부모 계정 로그인 → 자녀 프로필 선택으로 통일        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.5 이중 역할 처리 (학부모이자 학생인 경우)

성인이 본인도 레슨을 받으면서 자녀도 관리하는 경우의 처리 방식입니다.
**하나의 계정**에서 역할을 전환하여 사용합니다.

#### 2.5.1 시나리오

```
예시: 박지영 (35세)
- 본인: 바이올린 레슨 수강 (성인 취미반)
- 자녀1: 김민수 (12세) - 피아노 레슨
- 자녀2: 김민지 (9세) - 바이올린 레슨
- 자녀3: 김민호 (6세) - 레슨 계획 없음 (연습만)

### 2.6 미연결 자녀 기능

선생님과 연결되지 않은 자녀도 일부 기능을 사용할 수 있습니다.
레슨 계획이 없거나, 아직 선생님을 찾지 못한 경우를 지원합니다.

#### 2.6.1 사용 가능 기능

| 기능 | 미연결 자녀 | 연결된 자녀 | 비고 |
|------|:-----------:|:-----------:|------|
| **연습 기록** | O | O | 날짜별 연습 시간 기록 |

| **연습 스트릭** | O | O | 연속 연습일 추적 |
| **레퍼토리 등록** | O | O | 본인이 직접 등록 |
| **레슨 노트** | X | O | 선생님 작성 |
| **과제 관리** | X | O | 선생님 할당 |
| **녹음 피드백** | X | O | 선생님 피드백 |
| **결제 관리** | X | O | 수강료 청구/결제 |
