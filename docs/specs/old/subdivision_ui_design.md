# Metronome Subdivision UI Design

> 작성일: 2025-01-17

## 개요

메트로놈 서브디비전(subdivision) 기능 UI 설계. 다양한 리듬 패턴을 제공하여 연습 효과를 높임.

---

## 1. 서브디비전 패턴 종류 (12개)

### 기본 패턴 (Basic)

| # | 패턴명 | 영문 | 비트당 분할 | 시각 표현 |
|---|--------|------|------------|----------|
| 1 | 기본 (4분음표) | Quarter | 1 | `●` |
| 2 | 8분음표 | Eighth | 2 | `● ○` |
| 3 | 셋잇단음 (3연음) | Triplet | 3 | `● ○ ○` |
| 4 | 16분음표 | Sixteenth | 4 | `● ○ ○ ○` |

### 고급 패턴 (Advanced)

| # | 패턴명 | 영문 | 비트당 분할 | 시각 표현 |
|---|--------|------|------------|----------|
| 5 | 5연음 | Quintuplet | 5 | `● ○ ○ ○ ○` |
| 6 | 6연음 | Sextuplet | 6 | `● ○ ○ ○ ○ ○` |
| 7 | 7연음 | Septuplet | 7 | `● ○ ○ ○ ○ ○ ○` |

### 특수 패턴 (Special)

| # | 패턴명 | 영문 | 설명 | 시각 표현 |
|---|--------|------|------|----------|
| 8 | 점8분음표 | Dotted Eighth | 긴-짧 (3:1) | `●―○` |
| 9 | 스윙 | Swing | 긴-짧 (2:1) | `●~○` |
| 10 | 셔플 | Shuffle | 3연음 기반 스윙 | `●_○` |
| 11 | 2+3 클라베 | 3-2 Clave | 라틴 리듬 | `● ○ ● ○ ○` |
| 12 | 3+2 클라베 | 2-3 Clave | 라틴 리듬 | `● ○ ○ ● ○` |

## 4. 인터랙션 설계

### 4.1 패턴 선택 흐름

```
1. 메인 화면에서 기본 4개 패턴 중 선택 (한 번의 탭)
2. "더보기" 탭 → 전체 12개 패턴 모달
3. 모달에서 선택 → 자동 닫힘, 메인 화면 반영
```

| 비트 타입 | 사운드 | 볼륨 |
|----------|--------|------|
| 메인 비트 (●) | click_high.wav | 100% |
| 서브디비전 (○) | click_low.wav | 70% |
| 악센트 (첫 박) | accent.wav | 100% |

### 4.3 햅틱 피드백

## 5. 데이터 모델

### 5.1 Subdivision Enum

```dart
enum Subdivision {
  // Basic
  quarter(1, '기본', 'Quarter'),
  eighth(2, '8분음표', 'Eighth'),
  triplet(3, '셋잇단음', 'Triplet'),
  sixteenth(4, '16분음표', 'Sixteenth'),

  // Advanced
  quintuplet(5, '5연음', 'Quintuplet'),
  sextuplet(6, '6연음', 'Sextuplet'),
  septuplet(7, '7연음', 'Septuplet'),

  // Special (custom timing ratios)
  dottedEighth(-1, '점8분', 'Dotted Eighth'),
  swing(-2, '스윙', 'Swing'),
  shuffle(-3, '셔플', 'Shuffle'),
  clave32(-4, '3-2 클라베', '3-2 Clave'),
  clave23(-5, '2-3 클라베', '2-3 Clave');

  const Subdivision(this.divisionsPerBeat, this.koreanName, this.englishName);

  final int divisionsPerBeat; // -1 이하는 특수 패턴
  final String koreanName;
  final String englishName;
}
```

## 9. 기술적 고려사항

### 9.1 metronome 패키지 한계

현재 `metronome` 패키지는 **서브디비전을 지원하지 않음**.

**해결 방안:**
1. 패키지 Fork하여 수정
2. BPM 조작으로 우회 (예: 120 BPM + triplet = 360 subdivisions/min)
3. 네이티브 엔진 직접 구현 (이전 시도한 방식)

### 9.2 BPM 조작 방식

```dart
// 예: 120 BPM에서 triplet
// 실제 재생 BPM = 120 * 3 = 360
// 3번째 틱마다 메인 비트로 표시

final actualBpm = settings.bpm * subdivision.divisionsPerBeat;
final isMainBeat = (tickCount % subdivision.divisionsPerBeat) == 0;
```

### 9.3 특수 패턴 타이밍

스윙/셔플은 불균등 분할:
```dart
// Swing (2:1 ratio)
// Beat: ●~~~~~~○
// Timing: 66% - 33%

// Shuffle (triplet-based swing)
// Beat: ●____○
// Timing: 67% - 33% (2/3 - 1/3)
```

## 10. 결론

서브디비전 기능은 메트로놈의 핵심 고급 기능으로, Phase별로 구현하여 점진적으로 완성도를 높입니다.

**MVP (Phase 1)**에서는 기본 4개 패턴(기본, 8분, 3연음, 16분)을 먼저 구현하고, 사용자 피드백을 받아 고급/특수 패턴을 추가합니다.
