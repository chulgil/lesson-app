# 레슨 타입 분석

음악 레슨 앱에서 지원하는 4가지 레슨 타입의 장단점과 목적을 정리한 문서입니다.

---

## 개요

| 레슨 타입 | 영문명 | 핵심 특징 |
|----------|--------|----------|
| 정기레슨 | Regular Lesson | 매주/격주 고정 시간, 장기 계약 |
| 회차별 레슨 | Per-Session Lesson | 선결제 회차권, 유연한 스케줄 |
| 1회 레슨 | One-Time Lesson | 단발성, 특정 목적 |
| 체험 레슨 | Trial Lesson | 첫 만남, 상호 평가 |

---

## 1. 정기레슨 (Regular Lesson)

### 정의
매주 또는 격주로 **고정된 요일/시간**에 진행하는 레슨. 월 단위로 수강료를 결제하며, 장기적인 학습 관계를 전제로 함.

### 선생님 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **수입 안정성** | 매월 예측 가능한 고정 수입 확보 |
| **스케줄 예측** | 주간 일정 계획이 용이함 |
| **학생 이해도** | 장기간 지도로 학생의 성향, 장단점 파악 가능 |
| **커리큘럼 설계** | 체계적인 장기 학습 계획 수립 가능 |
| **관계 구축** | 학생/학부모와 신뢰 관계 형성 |

#### 단점
| 항목 | 설명 |
|------|------|
| **유연성 부족** | 고정 시간 변경이 어려움 |
| **빈 슬롯 리스크** | 학생 이탈 시 해당 시간대 공백 발생 |
| **수업료 부담** | 학생 결석 시에도 월 수업료 기준으로 정산 |
| **새 학생 진입 장벽** | 원하는 시간대가 이미 예약된 경우 다수 |

### 학생 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **일관된 학습** | 정기적인 피드백으로 꾸준한 성장 |
| **루틴 형성** | 연습 습관 정착에 유리 |
| **수업료 할인** | 1회성 대비 저렴한 단가 |
| **예약 불필요** | 매번 예약하는 번거로움 없음 |
| **진도 연속성** | 선생님이 학생 상태를 계속 파악 |

#### 단점
| 항목 | 설명 |
|------|------|
| **스케줄 구속** | 고정 시간 엄수 필요 |
| **결석 페널티** | 개인 사정으로 결석해도 수업료 환불 어려움 |
| **초기 부담** | 선생님과 맞지 않아도 계약 기간 지속 |
| **취소 부담** | 중도 해지 시 위약금 발생 가능 |

### 적합한 상황
- 장기적 실력 향상이 목표인 학생
- 안정적 수입이 필요한 전업 강사
- 어린 학생 (루틴이 중요한 경우)
- 입시/대회 준비생

### 관련 정책
- **5주차 정책**: 월 4회 기준 정기레슨에서 5주차 처리 방안 → [레슨 스케줄 시스템 스펙](./lesson_schedule.md#5주차-정책-월-4회-기준-정기레슨)

## 2. 회차별 레슨 (Per-Session Lesson)

### 정의
**N회 분량의 레슨권**을 선구매하고, 유효기간 내에 자유롭게 예약하여 수강하는 방식. 정기레슨의 안정성과 1회 레슨의 유연성을 결합.

### 선생님 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **선수금 확보** | 회차권 판매로 미리 수입 확보 |
| **노쇼 리스크 감소** | 이미 결제한 회차이므로 취소율 낮음 |
| **유연한 스케줄** | 고정 시간 없이 빈 슬롯에 배치 가능 |
| **다양한 학생층** | 바쁜 직장인, 학생 등 유치 가능 |

#### 단점
| 항목 | 설명 |
|------|------|
| **수입 불규칙** | 월별 수입 변동 가능 |
| **스케줄 관리** | 여러 학생의 유동적 예약 조율 필요 |
| **연속성 부족** | 불규칙한 수업으로 학습 효과 감소 우려 |
| **환불 이슈** | 미사용 회차 환불 정책 필요 |

### 학생 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **유연한 스케줄** | 내 일정에 맞춰 예약 가능 |
| **부담 감소** | 바쁜 주는 쉬고, 여유 있을 때 집중 |
| **단가 절약** | 1회 레슨보다 저렴 (보통 5~10% 할인) |
| **선생님 테스트** | 첫 회차로 맞는지 확인 후 추가 구매 결정 |

#### 단점
| 항목 | 설명 |
|------|------|
| **유효기간** | 기한 내 미사용 시 소멸 리스크 |
| **예약 경쟁** | 인기 시간대 예약 어려움 |
| **학습 연속성** | 불규칙 수강 시 진도 유지 어려움 |
| **선결제 부담** | 한 번에 여러 회차 금액 지불 |

### 적합한 상황
- 스케줄이 불규칙한 직장인/대학생
- 취미로 여유롭게 배우고 싶은 학생
- 정기레슨 전 단계로 테스트 원하는 경우
- 방학/휴가 기간 집중 수강

## 3. 1회 레슨 (One-Time Lesson)

### 정의
**단발성** 레슨으로, 지속적인 관계를 전제하지 않음. 특정 곡 연주, 급한 교정, 마스터클래스 등 목적형 수업.

### 선생님 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **높은 단가** | 정기레슨 대비 프리미엄 요금 책정 가능 |
| **빈 시간 활용** | 비어있는 슬롯 수익화 |
| **다양한 경험** | 다양한 수준/스타일의 학생 접촉 |
| **전문성 어필** | 특정 분야 전문가로 포지셔닝 가능 |

#### 단점
| 항목 | 설명 |
|------|------|
| **수입 불안정** | 예측 불가능한 수요 |
| **준비 부담** | 학생 정보 없이 수업 준비 어려움 |
| **피드백 한계** | 장기 성장 관찰 불가 |
| **노쇼 리스크** | 첫 만남이라 취소 가능성 높음 |

### 학생 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **부담 없음** | 장기 계약 없이 필요할 때만 수강 |
| **전문 피드백** | 특정 주제에 대한 집중 지도 |
| **다양한 선생님** | 여러 전문가에게 배울 기회 |
| **즉각적 해결** | 급한 문제 (발표회, 오디션) 대응 |

#### 단점
| 항목 | 설명 |
|------|------|
| **높은 단가** | 회차권/정기레슨 대비 비쌈 |
| **연속성 없음** | 체계적 학습 어려움 |
| **선생님 이해도** | 선생님이 내 상태를 모른 채 시작 |
| **예약 어려움** | 좋은 선생님은 정기학생 우선 배정 |

### 적합한 상황
- 발표회/오디션/콩쿠르 직전 마무리 점검
- 특정 테크닉이나 곡에 대한 컨설팅
- 타 지역/해외 거주자의 방문 수업
- 마스터클래스/워크샵 형태의 그룹 레슨

## 4. 체험 레슨 (Trial Lesson)

### 정의
정규 등록 전 **첫 만남** 수업. 선생님과 학생이 서로를 평가하고, 레슨 스타일/방향성을 확인하는 상호 탐색 기회.

### 선생님 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **학생 스크리닝** | 장기 지도할 학생인지 미리 판단 |
| **신뢰 구축** | 전문성을 보여줄 첫인상 기회 |
| **전환율 확보** | 체험 → 정규 전환으로 안정적 학생 확보 |
| **홍보 효과** | 만족한 체험생이 입소문 형성 |

#### 단점
| 항목 | 설명 |
|------|------|
| **낮은 단가** | 무료 또는 할인 제공으로 수익 감소 |
| **노쇼 리스크** | 무료/저가라 취소 가능성 높음 |
| **시간 투자** | 전환 안 되면 순수 손실 |
| **기대 관리** | 체험과 정규의 차이 설명 필요 |

### 학생 관점

#### 장점
| 항목 | 설명 |
|------|------|
| **리스크 최소화** | 적은 비용으로 선생님 평가 가능 |
| **분위기 파악** | 레슨실, 수업 방식 미리 경험 |
| **질문 기회** | 수업료, 진도, 목표 등 상담 가능 |
| **비교 기회** | 여러 선생님 체험 후 선택 |

#### 단점
| 항목 | 설명 |
|------|------|
| **제한된 내용** | 30분 내외로 깊이 있는 수업 어려움 |
| **판매 압박** | 체험 후 등록 권유 받을 수 있음 |
| **대기 시간** | 인기 선생님은 체험 예약도 어려움 |
| **진정성 의문** | 체험용으로 꾸민 수업일 가능성 |

### 적합한 상황
- 처음 악기를 배우는 입문자
- 선생님을 바꾸려는 기존 학습자
- 자녀의 음악 교육을 고려하는 학부모
- 오랜 공백 후 레슨 재개를 고민하는 경우

### 분석 인사이트

1. **체험 레슨은 필수**
   - 대부분의 서비스가 체험/첫 레슨 할인 제공
   - 전환율이 핵심 KPI

2. **회차권이 대세**
   - 유연성을 원하는 현대 학습자 니즈 반영
   - 플랫폼 입장에서도 선결제로 리스크 감소

3. **정기레슨의 부활**
   - 구독 경제 트렌드로 월정액 모델 인기
   - "매주 N회" 형태로 정기+회차 하이브리드

4. **1회 레슨은 프리미엄 포지션**
   - 마스터클래스, 전문 컨설팅 형태로 고단가 가능
   - 신규 유입 채널로 활용

## 레슨앱 적용 방안

### 권장 구조

```
체험 레슨 (Entry Point)
    ↓
회차별 레슨 (테스트 기간)
    ↓
정기 레슨 (장기 관계)
    ↑
1회 레슨 (특수 목적) ←── 기존 학생도 필요 시 이용
```

### 가격 정책 예시

| 레슨 타입 | 기준가 | 비고 |
|----------|--------|------|
| 체험 레슨 | 무료 ~ 50% 할인 | 30분, 선생님 재량 |
| 1회 레슨 | 100% (기준가) | 60분 기준 |
| 회차권 (4회) | 90% × 4 | 2개월 유효 |
| 회차권 (8회) | 85% × 8 | 4개월 유효 |
| 정기레슨 (월) | 80% × 4 | 주 1회 기준, 자동결제 |

### 전환 유도 전략

| 단계 | 전략 | 구현 방안 |
|------|------|----------|
| 체험 → 회차권 | 첫 구매 할인 | 체험 후 24시간 내 구매 시 추가 10% 할인 |
| 회차권 → 정기 | 연속성 강조 | "3개월 연속 수강 시 정기레슨 단가 적용" |
| 정기 유지 | 로열티 보상 | 6개월/1년 장기 등록 추가 혜택 |
| 이탈 방지 | 알림 시스템 | 회차 소진 임박 / 유효기간 만료 알림 |

## 결론

### 레슨 타입별 핵심 가치

| 레슨 타입 | 선생님 핵심 가치 | 학생 핵심 가치 |
|----------|------------------|----------------|
| 정기레슨 | 수입 안정성 | 체계적 학습 |
| 회차별 레슨 | 선수금 확보 | 유연한 스케줄 |
| 1회 레슨 | 프리미엄 단가 | 즉각적 해결 |
| 체험 레슨 | 신규 학생 유입 | 리스크 최소화 |

### 앱 개발 우선순위

1. **필수 (MVP)**: 체험 레슨, 정기 레슨
2. **Phase 2**: 회차별 레슨 (유효기간, 예약 시스템)
3. **Phase 3**: 1회 레슨 (마켓플레이스 형태)
