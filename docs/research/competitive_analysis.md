## 1. 시장 개요

음악 레슨 및 연습 관리 앱 시장은 크게 3가지 유형으로 나뉩니다:

| 유형 | 설명 | 대표 서비스 |
|------|------|------------|
| **AI 학습형** | 연주를 듣고 실시간 피드백 제공 | Tonara, Trala, Violy |
| **연습 관리형** | 연습 기록, 시간 추적, 목표 설정 | Modacity, Andante, Practice Space |
| **스튜디오 관리형** | 일정, 결제, 학생 관리 중심 | My Music Staff, Teachworks, Duet |

**우리 앱의 포지션**: 연습 관리형 + 선생님-학생 협업 기능

## 2. 주요 경쟁 서비스 분석

### 2.1 Tonara (토나라)

> **유형**: AI 학습형 + 선생님-학생 연동
> **가격**: $4.99/월
> **플랫폼**: iOS, Android, Web

#### 주요 기능
- AI 실시간 연주 분석 (음정, 리듬, 템포, 유창성)
- 선생님이 과제 생성 → 학생이 연습 → AI가 평가
- 녹음 비교 기능 (선생님 시범 vs 학생 연주)
- 인앱 메시징, 스티커/이모지 동기부여
- Sony, Universal, Disney 악보 파트너십

#### 장점
- ✅ 선생님-학생 실시간 연동
- ✅ AI 기반 객관적 평가
- ✅ 게이미피케이션 (포인트, 리더보드)
- ✅ 유명 악보 라이브러리

#### 단점
- ❌ **AI 분석에 집중 → 연습 일지/계획 기능 부족**
- ❌ **선생님 레슨 일지 기능 미흡**
- ❌ 월 구독료 필요
- ❌ 한국어 미지원

**출처**: [Tonara 공식](https://www.tonara.com/), [The Strad Review](https://www.thestrad.com/accessories/the-tonara-teaching-and-practice-app/8477.article)

---

### 2.2 Modacity (모다시티)

> **유형**: 개인 연습 관리형
> **가격**: 무료 / Premium $8.99/월
> **플랫폼**: iOS, Android

#### 주요 기능
- 연습 시간 자동 추적
- 연습 플레이리스트 생성
- 녹음 및 재생 (템포 조절 -16x ~ 16x)
- 과학적 연습법 가이드 (한 가지씩 개선)
- 내장 메트로놈 & 드론 (30-500 BPM)

#### 장점
- ✅ 상세한 연습 통계 및 히스토리
- ✅ 녹음/재생 기능 우수
- ✅ 무료 버전 기능 충실
- ✅ 다양한 악기 지원

#### 단점
- ❌ **선생님-학생 연동 기능 없음** (개인 사용 전용)
- ❌ **레슨 일정 관리 없음**
- ❌ 녹음 파일 외부 내보내기 불가
- ❌ 한국어 미지원

**출처**: [Modacity 공식](https://www.modacity.co/), [App Store](https://apps.apple.com/us/app/modacity-pro-music-practice/id1351617981)

### 2.3 Practice Space

> **유형**: 선생님-학생 협업형
> **가격**: 요금제 문의
> **플랫폼**: iOS, Android, Web

#### 주요 기능
- 선생님 → 학생 과제 전송
- 오디오/비디오/악보/링크 첨부 가능
- 학생 연습 로그 확인
- Practice Streaks, Gems 등 보상 시스템
- 단계별 목표 설정

#### 장점
- ✅ **선생님-학생 양방향 소통**
- ✅ 다양한 자료 첨부 (동영상, 악보)
- ✅ 연습 로그 시각화
- ✅ 동기부여 요소 (스트릭, 보상)

#### 단점
- ❌ **주간 레슨 일정 관리 기능 부족**
- ❌ **선생님 레슨 피드백 템플릿 없음**
- ❌ 한국어 미지원
- ❌ 가격 정보 불투명

**출처**: [Practice Space 공식](https://www.practicespaceapp.com/)

### 2.4 MyTractice (마이트랙티스)

> **유형**: 선생님 평가 + 학생 연습 통합형
> **가격**: 요금제 문의
> **플랫폼**: Web

#### 주요 기능
- 학생 평가 및 채점 도구
- 연습 플래너 및 추적
- Post-Practice 기능 (연습 후 상세 분석)
- 24/7 선생님-학생 메시징
- 레슨 준비를 위한 인사이트 제공

#### 장점
- ✅ **선생님을 위한 평가/채점 기능**
- ✅ 학생 연습 세션 상세 분석
- ✅ 실시간 평가 및 메시징

#### 단점
- ❌ **모바일 앱 없음 (웹 전용)**
- ❌ **레슨 일정 관리 기능 미흡**
- ❌ 연습 템플릿 기능 부재
- ❌ 한국어 미지원

**출처**: [MyTractice 공식](https://www.mytractice.com/)

## 4. 시장 갭 분석 (우리가 채울 수 있는 단점)

### 4.1 확실히 채울 수 있는 갭

| 갭 | 설명 | 우리 솔루션 |
|----|------|------------|
| 🎯 **레퍼토리 템플릿** | 선생님이 만든 커리큘럼을 학생이 복제하여 연습 계획 수립 | 템플릿 복제 → 체크리스트 방식 |
| 🎯 **한국어 지원** | 모든 경쟁사 영어 전용 | 네이티브 한국어 UI/UX |
| 🎯 **심플한 연습 일지** | 기존 앱들 입력 복잡 | "했다/안했다" 체크 + 짧은 메모 |
| 🎯 **주간 레슨 일정** | 스튜디오 관리 앱은 과도, 연습 앱은 부재 | 심플한 주간 시간표 |
| 🎯 **악보 마스터 연동** | 악보 등록 후 간편 참조 | 악보명 입력 → 자동 완성/표시 |
| 🎯 **음악 용어 자동완성** | 음악 용어 매번 수동 입력 | 용어 DB → 자동 완성 |

### 4.2 부분적으로 채울 수 있는 갭

| 갭 | 경쟁사 현황 | 우리 접근법 |
|----|------------|------------|
| 연습 통계 시각화 | Modacity가 강점 | MVP에서는 기본 통계, 추후 확장 |
| AI 연주 분석 | Tonara/Trala 강점 | 초기에는 미포함, 추후 검토 |
| 녹음/재생 | Modacity/Tonara 강점 | 선택적 기능으로 검토 |

### 4.3 채우기 어려운 갭

| 갭 | 이유 |
|----|------|
| AI 실시간 연주 분석 | 고도의 기술력 및 투자 필요 |
| 대형 악보 라이브러리 | 저작권 및 파트너십 필요 |
| 결제/청구 시스템 | 스튜디오 관리 앱 영역 (차별화 불필요) |

## 5. 차별화 전략 제안

### 5.1 핵심 차별화 포인트

```
┌─────────────────────────────────────────────────────────┐
│  "선생님이 만든 레퍼토리 템플릿 → 학생이 복제 → 체크 방식 연습"  │
│                                                         │
│  ✓ 연습할 시간도 부족한 학생 → 최소 입력                   │
│  ✓ 선생님 레슨 일지 → 학생 연습 계획 자동 연동              │
│  ✓ 음악 용어/악보 자동완성 → 빠른 기록                     │
└─────────────────────────────────────────────────────────┘
```

### 5.2 타겟 사용자

| 사용자 | 페인 포인트 | 우리 솔루션 |
|--------|------------|------------|
| **바이올린 학생** | 연습 기록 귀찮음, 뭘 연습해야 할지 모름 | 템플릿 체크 방식, 선생님 피드백 확인 |
| **음악 선생님** | 학생 연습 현황 파악 어려움 | 주간 연습 현황 한눈에 확인 |
| **IT 비친화 음악인** | 복잡한 앱 거부감 | 극도로 심플한 UI |

### 5.3 MVP 기능 우선순위

| 우선순위 | 기능 | 근거 |
|:--------:|------|------|
| P0 | 간편 로그인 (Google/Kakao) | 진입 장벽 최소화 |
| P0 | 선생님-학생 연결 | 핵심 가치 |
| P0 | 레퍼토리 템플릿 → 연습 체크 | 핵심 차별화 |
| P1 | 주간 레슨 일정 | 기본 관리 기능 |
| P1 | 선생님 레슨 피드백 | 양방향 소통 |
| P2 | 악보 마스터 연동 | 편의 기능 |
| P2 | 음악 용어 자동완성 | 편의 기능 |
| P3 | 연습 통계/차트 | 동기부여 |

## 6. 결론

### 채울 수 있는 시장 갭 ✅

1. **한국어 네이티브 지원** - 경쟁사 전무
2. **레퍼토리 템플릿 기반 연습 관리** - 차별화된 접근법
3. **극도로 심플한 UX** - 음악인 특성 반영
4. **선생님 레슨 일지 ↔ 학생 연습 계획 연동** - 유기적 워크플로우

### 진입 장벽 ⚠️

1. AI 연주 분석 기능은 초기에 포함하지 않는 것이 현실적
2. 대형 악보 라이브러리는 자체 구축 필요
3. 사용자 획득을 위한 마케팅 전략 필요 (음악 학원, 개인 레슨 시장)

### 추천 다음 단계

1. [requirement.md](./requirement.md)의 기능 목록을 기반으로 **상세 기능 명세서** 작성
2. **와이어프레임/UI 목업** 제작
3. **기술 스택 선정** (Flutter/React Native for 모바일, Next.js for 웹)
4. **MVP 개발 일정** 수립
