## 1. Practice Space

### 가격 구조

| 플랜 | 월간 | 연간 (월 환산) | 할인율 |
|------|------|---------------|--------|
| **Plus** (기본) | $15.99 | $13.33 | 16% |
| **Unlimited** (무제한 교사) | $84.99 | $70.83 | 16% |

### 추가 교사 요금 (Plus 플랜)

| 결제 주기 | 추가 교사당 |
|----------|------------|
| 월간 | $6.95/월 |
| 연간 | $5.79/월 |

### 포함 기능 (모든 유료 플랜)
- 무제한 학생 계정
- 무제한 저장 공간
- 미디어 및 과제 라이브러리
- 연습 및 진도 추적
- 학생 동기부여 도구 (게이미피케이션)
- 무료 설정 상담 및 지원

### 과금 특징
- **선생님만 결제**, 학생은 완전 무료
- 연간 결제 시 약 2개월분 할인 (16%)
- 학원/스튜디오용 Unlimited 플랜으로 규모 확장 대응
- 학생 수 무제한 → 성장해도 추가 비용 없음

### 비즈니스 모델 분석
```
수익 = (기본 교사 수 × $15.99) + (추가 교사 × $6.95)

예시: 5명 교사 스튜디오
- 월간: $15.99 + ($6.95 × 4) = $43.79/월
- Unlimited: $84.99/월 (5명 이상이면 유리)
```

## 2. My Music Staff

### 가격 구조

| 항목 | 가격 |
|------|------|
| 기본 요금 | $14.95/월 |
| 추가 교사 | $4.95/월/명 |
| 연간 결제 | $149.50/년 ($12.46/월, 17% 할인) |

### 무료 체험
- 30일 전체 기능 무료 체험
- 신용카드 정보 불필요

### 포함 기능
- 학생 관리 (무제한)
- 레슨 스케줄링
- 청구서 발행 및 결제 추적
- 온라인 결제 수락 (Stripe 연동)
- 이메일/SMS 알림
- 연습 로그
- 맞춤 웹사이트

### 과금 특징
- **웹 기반** 서비스 (앱 없음, 웹앱으로 접근)
- 온라인 결제 수수료 별도 (Stripe 2.9% + $0.30)
- 학원 규모에 따라 추가 교사 요금
- 올인원 스튜디오 관리에 초점

### 비즈니스 모델 분석
```
수익 = $14.95 + (추가 교사 × $4.95) + (결제 수수료 간접)

예시: 3명 교사 스튜디오
- 월간: $14.95 + ($4.95 × 2) = $24.85/월
```

### 포함 기능 (Pro)
- 무제한 학생

전환율 예측: 5명 이상 학생 보유 교사 → 유료 전환

## 6. 스튜디오메이트

### 가격 구조

| 항목 | 내용 |
|------|------|
| 공개 가격 | **비공개** (문의 필요) |
| 과금 방식 | 지점/기능 기반 (추정) |
| 무료 체험 | 있음 (기간 미상) |

### 추정 가격대
- 국내 SaaS 시장 기준 월 3~10만원대 추정
- 지점 수, 회원 수, 기능에 따라 변동
- 대형 프랜차이즈 별도 협의

### 과금 특징
- B2B 영업 중심 (가격 협상)
- 기능별 모듈 추가 방식
- 피트니스 산업 특화로 음악 학원에는 불필요한 기능 포함

## 과금 모델 유형 분석

### 1. 교사 기준 과금 (Per-Seat)
```
Practice Space, My Music Staff
- 장점: 예측 가능한 수익, 팀 확장 시 수익 증가
- 단점: 개인 교사에게 비용 부담, 추가 교사 저항
```

### 2. 학생 수 기준 과금
```
TuneKey, Tonara
- 장점: 성장에 비례한 과금, 공정한 느낌
- 단점: 학생 수 관리 복잡, 이탈 시 수익 감소
```

### 3. 기능 기반 티어
```
Fons, 스튜디오메이트
- 장점: 업셀 기회, 다양한 고객층 대응
- 단점: 복잡한 가격표, 선택 피로
```

### 4. 프리미엄 (Freemium)
```
TuneKey, Fons
- 장점: 진입 장벽 낮음, 바이럴 성장
- 단점: 전환율 의존, 무료 사용자 지원 비용
```

## lesson-app 가격 정책 제안

### 권장 모델: **프리미엄 + 교사 기준**

| 플랜 | 가격 | 대상 |
|------|------|------|
| **Free** | ₩0 | 학생 5명 이하 |
| **Basic** | ₩9,900/월 | 개인 교사 (무제한 학생) |
| **Pro** | ₩19,900/월 | 고급 기능 (리포트, 다중 위치) |
| **Studio** | ₩49,900/월 | 학원 (무제한 교사) |

### 근거

1. **한국 시장 특성**
   - 해외 앱 대비 50-70% 가격 (환율 감안)
   - 월 1만원대가 개인 교사 심리적 한계선
   - 스튜디오메이트 대비 음악 특화로 가치 차별화

2. **경쟁 우위**
   - Practice Space ($15.99) 대비 저렴 + 한국어
   - TuneKey ($9.99) 수준의 진입 가격
   - 스튜디오메이트 대비 음악 레슨 전용 기능

3. **성장 전략**
   ```
   Phase 1: 무료로 사용자 확보 (1년)
   Phase 2: 프리미엄 모델 도입
   Phase 3: 학원/스튜디오 B2B 확장
   ```

### 학생/학부모 앱
- **완전 무료** (Practice Space, TuneKey와 동일)
- 선생님 유료 구독 시 학생에게 전체 기능 제공

## 핵심 인사이트

### 1. 학생 무료는 업계 표준
모든 경쟁사가 학생 앱을 무료로 제공. 선생님 결제가 핵심.

### 2. 월 $10-15가 개인 교사 적정 가격대
TuneKey $9.99, Tonara $9, Practice Space $15.99

### 3. 연간 결제 할인 필수
15-20% 할인으로 연간 결제 유도 → 이탈 방지, 현금흐름 개선

### 4. 무료 플랜 필요성
TuneKey 성공 사례: 5명 무료 → 자연스러운 유료 전환

### 5. 학원용 별도 플랜
Practice Space Unlimited, Fons Business처럼 규모 고객 별도 대응
