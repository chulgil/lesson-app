## 🎯 분석 목적

**음악 학원/레슨 시장에서 스튜디오메이트가 대안으로 사용되는 현상 분석**

현재 음악 레슨 전용 스케줄 관리 앱이 부족하여, 많은 음악 학원과 레슨 선생님들이 피트니스용 앱인 스튜디오메이트를 대안으로 사용하고 있습니다. 이 문서는 스튜디오메이트의 기능을 분석하여 lesson-app이 음악 레슨에 특화된 더 나은 솔루션을 제공하기 위한 참고 자료입니다.

## 회원용 앱 기능

### 1. 수업 예약 시스템

| 기능 | 설명 |
|------|------|
| 실시간 예약 | 언제 어디서나 모바일로 수업 예약 |

- 보유 수강권 목록 조회

## 🎵 음악 레슨 시장에서의 스튜디오메이트 사용 현황

### 왜 음악 선생님들이 스튜디오메이트를 사용하는가?

**시장 상황:**
- 한국에서 음악 레슨 전용 스케줄 관리 앱이 **거의 없음**
- 해외 앱(Practice Space, My Music Staff 등)은 **영어 전용** + **해외 결제**
- 기존 음악 앱들은 **연습 도구** 중심이지 **스튜디오 운영** 기능 부족
- 스튜디오메이트는 **한국어** + **국내 결제** + **검증된 안정성**

**음악 선생님들의 니즈:**
| 니즈 | 스튜디오메이트로 해결 | 아쉬운 점 |
|------|---------------------|----------|
| 레슨 예약 관리 | ✅ 예약/취소/변경 | 1:1 레슨 특화 기능 부족 |
| 수강료 관리 | ✅ 수강권 판매/관리 | 입금확인 2단계 없음 |
| 학생 관리 | ✅ 회원 목록/이력 | 레벨/악기별 관리 없음 |
| 스케줄 공유 | ✅ 앱으로 실시간 확인 | 레슨 노트 기능 없음 |
| 학부모 소통 | △ 알림만 가능 | 학부모 전용 기능 없음 |
| 연습 과제 관리 | ❌ 없음 | 레퍼토리/과제 기능 필요 |
| 연습 도구 | ❌ 없음 | 메트로놈/튜너/녹음 필요 |

### 음악 레슨에 스튜디오메이트를 적용할 때의 한계

#### 1. 수업 형태의 차이

| 구분 | 피트니스 (스튜디오메이트 설계) | 음악 레슨 (실제 니즈) |
|------|----------------------------|---------------------|
| 수업 형태 | 그룹 수업 중심 | **1:1 개인 레슨** 중심 |
| 정원 개념 | 6~10명 정원 | 1명 (개인) 또는 2~3명 (그룹) |
| 예약 방식 | 빈 자리에 예약 | **선생님과 시간 조율** |
| 대기 예약 | 의미 있음 | 거의 의미 없음 |
| 수업 길이 | 50분~1시간 고정 | 30분/45분/1시간 **유동적** |

#### 2. 레슨 기록의 차이

| 구분 | 피트니스 | 음악 레슨 |
|------|---------|----------|
| 기록 내용 | 출석 여부만 | **레슨 노트**, 배운 곡, 숙제 |
| 진도 관리 | 없음 | 곡별 진도, 테크닉 레벨 |
| 녹음/영상 | 불필요 | **레슨 중 녹음** 필수 |
| 과제 | 없음 | **연습 과제** (곡, 구간, 횟수) |

#### 3. 학부모 연동의 차이

| 구분 | 피트니스 | 음악 레슨 |
|------|---------|----------|
| 대상 연령 | 성인 중심 | **어린이/청소년** 많음 |
| 보호자 역할 | 거의 없음 | **학부모 소통 필수** |
| 연습 확인 | 불필요 | 학부모가 **집에서 연습 확인** |
| 결제 주체 | 본인 | **학부모** |

#### 4. 연습 도구의 부재

음악 레슨에 필수적인 도구가 스튜디오메이트에는 없음:
- ❌ 메트로놈
- ❌ 튜너
- ❌ 녹음 기능
- ❌ 연습 기록
- ❌ 레퍼토리 관리

### 스튜디오메이트에서 가져올 기능 (우선순위)

#### 높음 (Phase 2에 구현 고려)
1. **매출 리포트** - 월별/학생별 수입 분석
2. **알림 시스템 강화** - 레슨 리마인더, 수강료 알림
3. **운영 설정** - 레슨 가능 시간대 설정

#### 중간 (Phase 3 이후)
4. **다지점 관리** - 여러 레슨 장소 (학원, 출장, 온라인)
5. **강사 관리** - 학원에서 여러 선생님 관리 시

#### 낮음 (필요시)
6. **대기 예약** - 그룹 레슨 시에만 의미
7. **체크인** - 학원 규모가 클 때만 필요

### 타겟 사용자 시나리오

#### 시나리오 1: 개인 레슨 선생님 (주 타겟)

**현재 (스튜디오메이트 사용 시):**
```
1. 스튜디오메이트로 레슨 예약 관리
2. 카카오톡으로 학부모 소통
3. 엑셀/메모장으로 레슨 기록
4. 별도 앱으로 메트로놈/튜너
5. 음성 녹음 앱으로 레슨 녹음
```

**lesson-app 사용 시:**
```
1. lesson-app 하나로 모든 것 해결
   - 레슨 예약/캘린더
   - 수강료 관리
   - 레슨 노트 + 녹음
   - 연습 과제 + 메트로놈/튜너
   - 학부모 앱으로 자동 공유
```

#### 시나리오 2: 소규모 음악 학원

**현재:**
```
- 스튜디오메이트로 예약 관리
- 학원 자체 시스템으로 학생 관리
- 선생님마다 다른 방식으로 레슨 기록
```

**lesson-app 사용 시:**
```
- 통합된 레슨 관리 시스템
- 선생님별 학생 배정
- 일관된 레슨 기록 형식
- 학부모 앱으로 투명한 소통
```

## 💡 결론 및 시사점

### 스튜디오메이트가 음악 시장에서 쓰이는 이유

1. **대안 부재**: 한국어 지원 음악 레슨 관리 앱이 없음
2. **검증된 안정성**: 100만+ 다운로드, 오랜 운영 경험
3. **핵심 기능 충족**: 예약/수강료 관리는 잘 됨
4. **학습 비용**: 이미 익숙해진 사용자들

### lesson-app이 가져가야 할 것

**스튜디오메이트의 강점:**
- 직관적인 캘린더 UI
- 안정적인 예약/취소 시스템
- 실시간 알림
- 수강권 관리 유연성

**lesson-app만의 강점으로 승부:**
- 🎵 레슨 노트 + 녹음 (핵심)
- 🎵 연습 과제 관리 (핵심)
- 🎵 메트로놈/튜너/녹음 도구 (핵심)
- 👨‍👩‍👧 학부모 연동 (핵심)
- 📊 연습 현황 리포트

### 예상 전환 시나리오

```
현재 스튜디오메이트 사용 중인 음악 선생님
    ↓
lesson-app 발견 (앱스토어, 입소문)
    ↓
"어? 음악 레슨 전용이네? 레슨 노트도 되고 학부모 앱도 있네?"

기존 스튜디오메이트와 병행 사용 (테스트)
    ↓
"연습 과제 관리가 너무 편하다. 학부모 반응도 좋다."
    ↓
lesson-app으로 완전 전환
```
