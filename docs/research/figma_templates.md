## 사용 방법

### 1. 템플릿 복사하기

1. 위 링크 클릭 → Figma Community 페이지 열기
2. **"Open in Figma"** 버튼 클릭
3. 내 Drafts에 복사본 생성됨

### 2. 필요한 화면 가져오기

1. 복사된 템플릿에서 필요한 화면 선택
2. `Ctrl/Cmd + C` 복사
3. 내 프로젝트 파일에서 `Ctrl/Cmd + V` 붙여넣기

### 3. 커스터마이징

- 색상: 프로젝트 컬러로 변경
- 텍스트: 한글로 수정
- 레이아웃: 레슨 앱에 맞게 조정
