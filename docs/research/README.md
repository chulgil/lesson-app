## 앱별 요약

### Tonara (서비스 종료)

| 항목 | 내용 |
|------|------|
| 회사 | 이스라엘 스타트업 (2008~2023) |
| 투자 | $9.75M (Baidu 포함) |
| 핵심 기능 | AI 연주 분석, Compare Recording 특허 |
| 종료일 | 2023년 12월 8일 |
| 참고 포인트 | AI 피드백, 게이미피케이션 |

### Practice Space

| 항목 | 내용 |
|------|------|
| 앱 구조 | 선생님/학생 앱 **분리** |
| 가격 | 선생님 $15.99/월, 학생 무료 |
| 핵심 기능 | 과제 관리, 게이미피케이션 (젬, 스트릭) |
| 한계 | 한국어 미지원, 수강료/캘린더 없음 |
| 참고 포인트 | 게이미피케이션 시스템 설계 |

### 스튜디오메이트

| 항목 | 내용 |
|------|------|
| 앱 구조 | 관리자/회원 앱 **분리** |
| 타겟 | 필라테스, 요가, PT |
| 핵심 기능 | 예약 시스템, 수강권 관리, 매출 리포트 |
| 특이점 | **음악 학원에서 대안으로 많이 사용** |
| 참고 포인트 | 예약 UI, 수강권 관리, 알림 시스템 |

## lesson-app 차별화 포인트

### vs Tonara (종료됨)
- Tonara: AI 연주 분석 중심
- **lesson-app**: 레슨 운영 전체 (일정, 결제, 노트) + 연습 도구

### vs Practice Space
- Practice Space: 연습 동기부여 + 과제 관리, **영어 전용**
- **lesson-app**: 한국어 + 수강료 관리 + 캘린더 + 학부모 앱

### vs 스튜디오메이트
- 스튜디오메이트: 피트니스용, 그룹 수업 중심
- **lesson-app**: 음악 1:1 레슨 특화 + 레슨 노트/녹음 + 연습 도구

## 핵심 인사이트

### 시장 기회
```
한국어 지원 + 음악 레슨 전용 + 스케줄 관리 = 시장 공백
```

### lesson-app 핵심 가치
| 영역 | 기능 |
|------|------|
| 스케줄 | 레슨 캘린더 (월/주), 예약 관리 |
| 결제 | 수강료 관리, 2단계 입금확인 |
| 레슨 | 레슨 노트, 녹음 첨부 |
| 연습 | 메트로놈, 튜너, 녹음 재생 |
| 과제 | 레퍼토리, 구간 설정, 연습 횟수 |
| 소통 | 학부모 앱, 연습 현황 공유 |

### 마케팅 메시지
> **"피트니스 앱으로 음악 레슨 관리하고 계셨나요?"**
>
> lesson-app은 음악 선생님을 위해 만들어졌습니다.
