## 선생님 기능

### 1. 학생 관리

**My Students 탭:**
- 개별 학생 관리
- 학생 그룹 관리
- 메시지 관리
- 진도 로그 열람

### 2. 과제 및 레슨 생성

**레슨 구성:**
- 빈 레슨 새로 생성 ("Create from Scratch")
- 이전 레슨 복사 ("Copy from Last Lesson")
- 레슨 노트 작성
- 연습 목표 설정

**과제 첨부 가능 항목:**
| 유형 | 설명 |
|------|------|
| 이미지 | 악보 사진, 손 모양 등 |
| PDF | 악보, 교재 |
| 비디오 | 시범 영상 (최대 5분) |
| 오디오 | 반주 음원, 예시 녹음 |
| 링크 | YouTube, 웹 자료 |
| 라이브러리 첨부 | 저장된 자료 재사용 |

> 파일 용량 제한: 1GB, 비디오 직접 녹화: 5분

### 3. 미디어 및 과제 라이브러리

- 자주 사용하는 자료 저장
- 태그 시스템으로 정리
- 여러 학생에게 재사용
- 웹/모바일 양쪽에서 접근
- 대량 업로드 지원

**저장 가능 항목:**
- 선생님 듀엣 영상
- 작곡가 이미지
- 악보 PDF
- YouTube 링크
- 자주 쓰는 과제 템플릿

### 4. 대시보드 (Practice Space 2.0)

- 학생들의 최근 보상 현황
- 스튜디오 리더보드
- 학생 비디오 피드
- 빠른 피드백 전송

### 5. 진도 추적

| 추적 항목 | 설명 |
|-----------|------|
| 연습 시간 | 일별/주별/월별 |
| 과제 완료율 | 각 과제별 진행 상황 |
| 목표 달성률 | 설정 목표 대비 실제 |
| 스트릭 | 연속 연습 일수 |

### 6. 비디오 피드

- 학생 연습 영상 실시간 확인
- 영상에 코멘트 달기
- 좋아요로 빠른 격려
- 보충 레슨 전송

## 학생 기능

### 1. 과제 확인 및 연습

- 선생님이 보낸 레슨/과제 확인
- 첨부된 영상/PDF/링크 열람
- 연습 목표 확인

### 2. 연습 도구

| 도구 | 설명 |
|------|------|
| Practice Timer | 연습 시간 측정 |
| Metronome | 내장 메트로놈 |
| Video Recording | 연습 영상 녹화 |

### 3. 피드백 시스템

- 연습 영상을 선생님에게 전송
- 영상에 코멘트 작성
- 선생님 피드백 확인
- 채팅으로 질문

### 4. 진도 기록

- 일일 연습 시간 로깅
- 과제 완료 체크
- 연습 노트 작성

## 게이미피케이션 시스템

### 1. Practice Points (연습 포인트)

**획득 방식:**
- 목표 달성 시 100 포인트
- 목표의 %만큼 비례 지급
- 10분 목표 vs 60분 목표 = 동일한 100점 (공평한 시스템)

**설계 의도:**
> "초보자든 고급자든, 짧은 목표든 긴 목표든 공평하게 보상받을 수 있도록 설계"

### 2. Gems (젬)

**획득 방법:**
| 활동 | 젬 |
|------|-----|
| 리더보드 1위 | 50젬 (기본값) |
| 리더보드 2위 | 30젬 |
| 리더보드 3위 | 20젬 |
| 스트릭 달성 | 보너스 젬 |

**사용처 (인앱 상점):**
- 아바타 구매
- 배경화면 구매
- 파워업 아이템

### 3. Practice Streaks (연습 스트릭)

**스트릭 보상:**
| 연속 일수 | 보상 |
|-----------|------|
| 7일 | 뱃지 + 젬 |
| 30일 | 뱃지 + 젬 + 인증서 |
| 50일 | 뱃지 + 젬 + 인증서 |
| 100일 | 뱃지 + 젬 + 인증서 |
| 반년 (182일) | 뱃지 + 젬 + 인증서 |
| 1년 (365일) | 뱃지 + 젬 + 인증서 |

### 4. Leaderboard (리더보드)

- 스튜디오 내 학생들만 참여
- **매주 일요일 리셋**
- 주간 포인트 순위 경쟁
- 선생님이 1~3위 젬 보상 설정 가능

### 5. In-Studio Rewards

선생님이 직접 상점에 상품 추가 가능:
- "선생님과 듀엣 연주권"
- "좋아하는 곡 선택권"
- "간식 선물" 등

### 6. 아바타 & 커스터마이징

- 다양한 아바타 캐릭터
- 배경화면 선택
- 젬으로 구매

## 사용자 평가

### 장점

> "과제와 목표를 명확하게 전달할 수 있고, 시범 영상도 포함할 수 있어요. 학생들이 인앱 보상 시스템에 매우 동기부여됩니다."

> "계속 업데이트되는 리더보드와 젬/아바타 덕분에 아이들이 연습에 대한 불평이 줄었어요!"

> "Duolingo에서 영감받은 게이미피케이션이 연습을 게임처럼 만들어줍니다."

### 단점

- 메트로놈이 200 BPM 이상에서 불안정
- 앱 잠시 나갔다 오면 연습 기록이 삭제되는 버그 (일부 보고)
- 가격이 점점 인상되는 추세
- 연습 시간/날짜 수정 기능 초기에 부재 (현재는 추가됨)

### 각 앱의 포지셔닝

**Practice Space:**
- 연습 동기부여 + 과제 관리에 특화
- 게이미피케이션 중심
- 레슨 운영(일정, 결제)은 다루지 않음

**lesson-app:**
- 레슨 운영 전체 관리 (일정, 결제, 노트)
- 고급 연습 도구 내장 (메트로놈, 튜너)
- 선생님-학생-학부모 통합 플랫폼
