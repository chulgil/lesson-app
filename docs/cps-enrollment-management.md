# CPS: 학생관리 → 수강관리 전환

> 작성일: 2026-04-16
> 버전: 1.0
> 상태: 확정

---

## Context (맥락)

### 도메인

음악 레슨 앱. 한 선생님이 같은 학생에게 여러 과목을 가르칠 수 있음.

```
박선생 →
    학원     이민석 (바이올린)   ← 수강 1
    개인레슨  이민석 (피아노)    ← 수강 2
```

### 현재 구현

| 항목 | 현재 상태 |
|------|----------|
| 탭 이름 | "내 학생들" |
| 목록 단위 | StudentWithMembership (수강 단위) — 같은 학생 2행 |
| 상세 진입 | 탭한 행의 멤버십 기준으로 악기/스케줄 표시 |
| 수강권 | 해당 멤버십의 수강권 카드 |
| 레슨 노트 | 학생 전체 (멤버십 필터링 없음) |
| 수강 이력 | 학생 전체 (멤버십 필터링 없음) |

### 데이터 모델 (기존)

```
Student (1) ──→ (N) ClassMembership ──→ (N) Subscription
                     │
                     ├── lessonClassId (학원/개인)
                     ├── instrument (악기)
                     └── status (active/trial/terminated)
```

### 결정 사항 (사용자 확인 완료)

| 질문 | 답변 |
|------|------|
| 탭 시 어떤 과목? | **A. 탭한 행의 과목만** |
| 목록 단위? | **B. 수강 단위** (동일 학생 복수 행) |
| 탭 이름? | **"수강관리"** |

---

## Problem (문제)

### 핵심 문제

> **목록은 수강 단위(멤버십별)인데, 상세 화면은 학생 단위로 보여져서 데이터 범위가 불일치한다.**

### 세부 문제

#### P-1. 레슨 노트가 멤버십으로 필터링 안 됨

선생님이 "이민석 바이올린" 행을 탭했는데, 상세에서 피아노 레슨 노트도 섞여서 나옴.

#### P-2. 수강 이력이 멤버십으로 필터링 안 됨

바이올린 수강권 이력을 보고 싶은데 피아노 이력도 함께 표시.

#### P-3. 용어 불일치

목록은 수강 단위인데 탭 이름이 "내 학생들" → 사용자 혼란.

#### P-4. 수강권 종료 후 이력 접근

수강권이 만료되어도 레슨 진행 이력은 볼 수 있어야 함. 현재 만료된 멤버십은 목록에서 숨겨질 수 있음.

---

## Solution (솔루션)

### 솔루션 개요

**"수강관리" 탭으로 전환.** 목록 단위 = 멤버십(수강), 상세 화면 = 해당 멤버십 범위로 필터링. 수강권 종료 후에도 이력 조회 가능.

### 핵심 변경

| 항목 | AS-IS | TO-BE |
|------|-------|-------|
| 탭 이름 | "내 학생들" | **"수강관리"** |
| 상세 진입 파라미터 | studentId | **studentId + membershipId** |
| 수강권 표시 | 학생의 모든 수강권 | **해당 멤버십의 마지막 수강권 1개** |
| 레슨 노트 | 학생 전체 | **해당 멤버십(악기)의 노트만** |
| 수강 이력 | 학생 전체 | **해당 멤버십의 수강권 이력만** |
| 만료 멤버십 | 숨김 가능 | **"이전 수강" 그룹으로 표시** |

### 수강 상세 화면 구조

```
[수강관리] > 이민석 (바이올린) 탭
┌─────────────────────────────────────┐
│  이민석                              │
│  학원 · 바이올린 · 중급              │  ← 학생 정보 + 멤버십 컨텍스트
├─────────────────────────────────────┤
│  [정보]  [레슨노트]  [수강이력]      │  ← 3탭 (기존 유지)
├─────────────────────────────────────┤
│                                     │
│  정보 탭:                            │
│    기본 정보 (이름, 연락처)          │
│    ★ 현재 수강권 (마지막 1개)        │
│    ┌─ 바이올린 8회 패키지 ─────────┐│
│    │  ██████░░  5/8회  D-25        ││
│    │  [상세 →]                      ││
│    └───────────────────────────────┘│
│                                     │
│  레슨노트 탭:                        │
│    ★ 바이올린 레슨 노트만 표시       │
│    (피아노 노트는 피아노 행에서)      │
│                                     │
│  수강이력 탭:                        │
│    ★ 바이올린 수강권 이력만          │
│    현재: 8회 패키지 (5/8)           │
│    이전: 4회 패키지 (4/4 완료)       │
│                                     │
└─────────────────────────────────────┘
```

### 수강관리 목록 구조

```
수강관리
├── 학원 (3명)
│   ├── 이민석  바이올린 중급  화 15:00  [활성]  5/8회
│   ├── 이서연  피아노  초급  화 16:00  [활성]  3/4회
│   └── 박지훈  피아노  입문  수 14:00  [체험]
│
├── 개인레슨 (2명)
│   ├── 이민석  피아노  중급  금 17:00  [활성]  2/4회  ← 같은 학생
│   └── 강서윤  바이올린  고급  토 10:00  [활성]  6/8회
│
└── 이전 수강 (1명)                    ← 만료된 멤버십
    └── 정다은  바이올린  초급  [만료]  4/4회 완료
```

### 필터링 기준

| 데이터 | 필터 키 | 로직 |
|--------|---------|------|
| 수강권 | membershipId | 해당 멤버십의 수강권만, 최신 1개 카드 표시 |
| 레슨 노트 | instrument (from membership) | 해당 악기의 레슨 노트만 |
| 수강 이력 | membershipId | 해당 멤버십의 과거+현재 수강권 전체 |
| 스케줄 변경 | subscriptionId (from membership) | 해당 수강권의 변경 이력만 |

### 기술적 제약/결정

| 결정 | 근거 |
|------|------|
| 상세 진입 시 membershipId 필수 전달 | 수강 단위 필터링의 기준 |
| 만료 멤버십도 목록에 표시 | "이전 수강" 그룹으로 분리, 이력 접근 보장 |
| 레슨 노트 필터는 instrument 기반 | membershipId가 바뀌어도 같은 악기면 이력 연속 |
| 수강권 카드는 마지막 1개만 | 이력은 별도 탭에서 전체 조회 |

### 벤치마크

| 서비스 | 목록 단위 | 참고 |
|--------|----------|------|
| **네이버 예약** | 예약 건별 | 같은 고객 여러 예약 = 여러 행 |
| **스튜디오메이트** | 회원 단위 | 1명 1행, 수강권은 상세에서 |
| **My Music Staff** | 학생 단위 | 1명 1행, 과목은 상세 탭 |

→ 우리는 **네이버 예약 스타일** (수강 건별) 채택. 음악 레슨은 과목별로 완전히 다른 교육이므로 분리가 자연스러움.

### 범위 밖

| 제외 | 이유 |
|------|------|
| 학생 프로필 편집 | 수강관리와 별개 (설정에서) |
| 과목 간 데이터 통합 뷰 | 복잡도 증가, 실제 필요성 낮음 |
| 학생 검색/필터 변경 | 기존 유지 |
