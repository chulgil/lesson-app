# 선생님 피드백 세션

> 날짜: 2026-01-26
> 대상: 레슨 선생님

---

## 앱 소개

**lesson-app**은 음악 레슨 선생님의 **관리 부담을 줄이고**, 학생/학부모와의 **소통을 간편하게** 만드는 앱입니다.

### 핵심 가치

| 문제 | 해결 |
|------|------|
| 카톡으로 일정 조율 (5-10회 메시지) | **다중 옵션 제안 → 1회로 확정** |
| 매월 수동 스케줄 등록 | **정기 레슨 자동 생성** |
| 수강료 독촉 어색함 | **앱 자동 알림** |
| 잔여 횟수 기억/메모 | **앱에서 자동 관리** |
| 레슨 기록 흩어짐 | **인앱 노트 + 녹음** |

### 3. 정기 레슨 등록 (다중 옵션 제안)

> 📄 상세: [Multi_Option_Schedule_Spec.md](../specs/lesson/Multi_Option_Schedule_Spec.md) Part B

```
"토요일 2시 어때요?" → "안돼요" → "3시는요?" → "그것도..." → 반복
```

### 4. 수강권 발급 및 결제 관리

> 📄 상세: [subscription_system_spec.md](../specs/subscription/subscription_system_spec.md) 섹션 5.7

**현재 방식**:
- 입금 확인 → 수기 메모 "김민수 4회"
- 잔여 횟수는 선생님만 알고 있음
- 학생이 "몇 회 남았어요?" 문의

**앱 사용 시**:
- 입금 확인 → 앱에서 수강권 발급
- 학생도 잔여 횟수 실시간 확인
- 결제 안내/리마인더 자동 발송

#### 결제 상태 옵션

| 옵션 | 설명 |
|------|------|
| 결제 완료 (계좌이체) | 이미 입금 확인됨 |
| 결제 완료 (현금) | 현금 수령 완료 |
| 결제 완료 (카드) | 카드 결제 완료 |
| **미수금** | 나중에 받을 예정 |

- [ ] 미수금 기능이 필요한가요?
- [ ] 결제 안내 자동 알림이 도움되나요?
- [ ] 결제 리마인더 (D-3)가 필요한가요?
