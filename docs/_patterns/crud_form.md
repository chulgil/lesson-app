## 1. 개요

데이터의 생성(Create), 조회(Read), 수정(Update), 삭제(Delete)를 위한 표준 폼 패턴.
레퍼토리, 섹션, 학생 등 대부분의 엔티티에 적용.

---

## 2. 진입점

### 2.1 추가 진입

| 위치 | UI | 동작 |
|------|-----|------|
| 헤더 우측 | + 아이콘 버튼 | 추가 바텀시트 열기 |
| 빈 상태 | "추가하기" 버튼 | 추가 바텀시트 열기 |
| FAB | + 플로팅 버튼 | 추가 바텀시트 열기 |

※ 우선순위 규칙: 헤더 + 버튼이 있는 화면에서는 동일한 엔티티의 하단/바텀시트 트리거를 추가로 노출하지 않는다.
  (예: 학생 상세에서 `레슨 추가`를 헤더에 노출하면 하단 고정 + 레이블은 제거.)

### 2.2 편집 진입

| 위치 | UI | 동작 |
|------|-----|------|
| 리스트 아이템 | 롱프레스 | 컨텍스트 메뉴 표시 |
| 상세 화면 | 편집 아이콘 버튼 | 편집 바텀시트 열기 |
| 스와이프 | 우측 스와이프 | 편집 바텀시트 열기 |

### 2.3 삭제 진입

| 위치 | UI | 동작 |
|------|-----|------|
| 컨텍스트 메뉴 | "삭제" 항목 | 삭제 확인 다이얼로그 |
| 상세 화면 | 삭제 아이콘 버튼 | 삭제 확인 다이얼로그 |
| 스와이프 | 좌측 스와이프 | 삭제 확인 다이얼로그 |

## 3. 폼 구조

### 3.1 추가/편집 바텀시트

```
┌─────────────────────────────────────────────┐
│  ───────                                    │
├─────────────────────────────────────────────┤
│  [취소]       {엔티티} 추가         [저장]  │  ← 헤더
├─────────────────────────────────────────────┤
│                                             │
│  필드 라벨 *                                │  ← 필수 필드
│  ┌─────────────────────────────────────┐    │
│  │ 플레이스홀더                        │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  선택 필드                                  │  ← 선택 필드
│  ┌─────────────────────────────────────┐    │
│  │ 플레이스홀더                        │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  ...추가 필드들...                          │
│                                             │
└─────────────────────────────────────────────┘
```

---

## 4. 필드 타입별 가이드

| 필드 타입 | 컴포넌트 | 용도 |
|----------|----------|------|
| 텍스트 | `form_field` | 이름, 설명, 메모 |
| 숫자 | `form_field` (숫자 키보드) | 횟수, 수량 |
| 날짜 | `date_range_picker` | 기간 설정 |
| 선택 | `measure_picker`, 드롭다운 | 마디, 카테고리 |
| 토글 | `repeat_toggle`, 스위치 | 반복, 활성화 |

---

## 5. 버튼 상태

### 5.1 저장 버튼

| 상태 | 조건 | 스타일 |
|------|------|--------|
| 비활성 | 필수 필드 미입력 | disabled |
| 활성 | 모든 필수 필드 입력 | primary |
| 로딩 | 저장 중 | 스피너 + "저장 중..." |

### 5.2 취소 버튼

| 상태 | 동작 |
|------|------|
| 변경 없음 | 바로 시트 닫기 |
| 변경 있음 | 저장 확인 다이얼로그 표시 |

---

## 6. 유효성 검사

### 6.1 실시간 검증

```
필드 입력 중:
- 포커스 해제 시 검증
- 에러 시 에러 메시지 표시
- 유효 시 체크 아이콘 표시
```

### 6.2 제출 검증

```
저장 버튼 탭:
1. 모든 필드 검증
2. 첫 번째 에러 필드로 스크롤
3. 에러 메시지 표시
4. 모두 유효하면 저장 진행
```

---

## 7. 에러 처리

| 에러 유형 | 표시 방법 |
|----------|----------|
| 필드 에러 | 필드 하단 에러 메시지 (빨간색) |
| 중복 에러 | 스낵바 + 해당 필드 하이라이트 |
| 서버 에러 | 스낵바 "저장에 실패했습니다" |
| 네트워크 에러 | 스낵바 "연결을 확인해주세요" |

---

## 8. 저장 흐름

```
[저장] 탭
    ↓
유효성 검사
    ↓ (실패)
에러 표시 ← ─ ─ ─
    ↓ (성공)
로딩 상태
    ↓
API 호출 (또는 로컬 저장)
    ↓ (실패)
에러 스낵바 → 폼 유지 ← ─
    ↓ (성공)
성공 스낵바
    ↓
시트 닫기
    ↓
리스트 갱신
```

---

## 9. 삭제 흐름

```
[삭제] 탭
    ↓
확인 다이얼로그
    ↓ (취소)
다이얼로그 닫기 ← ─ ─
    ↓ (확인)
로딩 상태
    ↓
삭제 실행
    ↓ (실패)
에러 스낵바 ← ─ ─
    ↓ (성공)
성공 스낵바 "{이름} 삭제됨"
    ↓
리스트에서 제거 (애니메이션)
```

---

## 10. 편집 모드 차이

| 항목 | 추가 모드 | 편집 모드 |
|------|----------|----------|
| 제목 | "{엔티티} 추가" | "{엔티티} 편집" |
| 초기값 | 빈 값 | 기존 데이터 |
| 저장 버튼 | "추가" 또는 "저장" | "저장" |
| 삭제 버튼 | 없음 | 있음 (하단 또는 메뉴) |

---

## 11. 키보드 대응

| 상황 | 동작 |
|------|------|
| 키보드 표시 | 시트 높이 자동 조절 |
| 포커스 필드 | 뷰포트 내 스크롤 |
| 완료 버튼 | 다음 필드로 이동 또는 키보드 닫기 |
