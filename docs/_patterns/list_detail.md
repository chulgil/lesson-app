## 1. 개요

리스트 화면에서 아이템을 선택하면 상세 화면으로 이동하는 마스터-디테일 패턴.
대부분의 데이터 탐색 UI에 적용.

---

## 2. 기본 구조

### 2.1 리스트 화면 (마스터)

```
┌─────────────────────────────────────────────┐
│  ←  페이지 제목                       [+]   │  ← 헤더
├─────────────────────────────────────────────┤
│  [🔍 검색...]                               │  ← 검색바 (선택)
├─────────────────────────────────────────────┤
│  ┌─────────────────────────────────────┐    │
│  │  아이템 1                     [>]   │    │  ← 리스트 아이템
│  └─────────────────────────────────────┘    │
│  ┌─────────────────────────────────────┐    │
│  │  아이템 2                     [>]   │    │
│  └─────────────────────────────────────┘    │
│  ┌─────────────────────────────────────┐    │
│  │  아이템 3                     [>]   │    │
│  └─────────────────────────────────────┘    │
│                  ...                        │
└─────────────────────────────────────────────┘
```

### 2.2 상세 화면 (디테일)

```
┌─────────────────────────────────────────────┐
│  ←  아이템 제목                    [편집]   │  ← 헤더
├─────────────────────────────────────────────┤
│                                             │
│  섹션 1                                     │
│  ┌─────────────────────────────────────┐    │
│  │  상세 정보 1                        │    │
│  │  상세 정보 2                        │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  섹션 2                                     │
│  ┌─────────────────────────────────────┐    │
│  │  관련 리스트 (중첩)                 │    │
│  └─────────────────────────────────────┘    │
│                                             │
└─────────────────────────────────────────────┘
```

## 3. 네비게이션 흐름

```
리스트 화면
    │
    ├── 아이템 탭 ──→ 상세 화면
    │                   │
    │                   ├── ← 뒤로가기 ──→ 리스트 화면
    │                   │
    │                   ├── 편집 ──→ 편집 시트
    │                   │              │
    │                   │              └── 저장/취소 ──→ 상세 화면
    │                   │
    │                   └── 삭제 ──→ 확인 다이얼로그
    │                                  │
    │                                  └── 확인 ──→ 리스트 화면
    │
    └── + 버튼 ──→ 추가 시트
                    │
                    └── 저장 ──→ 리스트 화면 (새 아이템 표시)
```

## 4. 리스트 화면 요소

### 4.1 헤더

| 요소 | 위치 | 동작 |
|------|------|------|
| 뒤로가기 | 좌측 | 이전 화면으로 |
| 제목 | 중앙 | - |
| 추가 버튼 | 우측 | 추가 시트 열기 |
| 더보기 | 우측 | 정렬/필터 옵션 |

### 4.2 검색/필터 (선택)

| 유형 | UI | 용도 |
|------|-----|------|
| 검색바 | 텍스트 입력 | 이름 검색 |
| 세그먼트 | 탭 버튼 | 카테고리 필터 |
| 날짜 필터 | 날짜 선택 | 기간 필터 |

### 4.3 리스트 아이템

→ `components/list_card` 참조

### 4.4 빈 상태

→ `components/empty_state` 참조

## 5. 상세 화면 요소

### 5.1 헤더

| 요소 | 위치 | 동작 |
|------|------|------|
| 뒤로가기 | 좌측 | 리스트로 돌아가기 |
| 제목 | 중앙 | 아이템 이름 |
| 편집 | 우측 | 편집 시트 열기 |
| 더보기 | 우측 | 삭제, 공유 등 |
| 추가 | 헤더 우측 + | 하위 엔티티 추가 액션은 헤더가 우선. 동일 액션 바디 중복 금지 |

### 5.2 콘텐츠 섹션

```
┌─────────────────────────────────────────────┐
│  섹션 제목                                  │
├─────────────────────────────────────────────┤
│  라벨         값                            │
│  라벨         값                            │
│  라벨         값                            │
└─────────────────────────────────────────────┘
```

### 5.3 중첩 리스트

상세 화면 내에 하위 아이템 리스트:

```
┌─────────────────────────────────────────────┐
│  하위 항목 (3)                        [+]   │
├─────────────────────────────────────────────┤
│  ┌─────────────────────────────────────┐    │
│  │  하위 아이템 1                      │    │
│  └─────────────────────────────────────┘    │
│  ┌─────────────────────────────────────┐    │
│  │  하위 아이템 2                      │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

## 6. 데이터 갱신

### 6.1 리스트 → 상세 이동 시

```dart
// 아이템 ID로 상세 데이터 로드
onTap: () => context.push('/items/${item.id}')
```

### 6.2 상세에서 편집 후

```dart
// 편집 완료 시 상세 화면 갱신
onSaved: () {
  ref.invalidate(itemDetailProvider(id));
}
```

### 6.3 상세에서 삭제 후

```dart
// 삭제 완료 시 리스트로 돌아가기
onDeleted: () {
  ref.invalidate(itemListProvider);
  context.pop();
}
```

## 7. 스크롤 동작

### 7.1 리스트

| 동작 | 효과 |
|------|------|
| 스크롤 다운 | 추가 아이템 로드 (무한 스크롤) |
| 당겨서 새로고침 | 리스트 갱신 |

### 7.2 상세

| 동작 | 효과 |
|------|------|
| 스크롤 다운 | 콘텐츠 스크롤 |
| 헤더 축소 | 스크롤 시 헤더 축소 (선택) |

## 8. 전환 애니메이션

| 전환 | 애니메이션 |
|------|------------|
| 리스트 → 상세 | 오른쪽에서 슬라이드 인 |
| 상세 → 리스트 | 왼쪽으로 슬라이드 아웃 |
| 시트 열기 | 아래에서 슬라이드 업 |
| 시트 닫기 | 아래로 슬라이드 다운 |

## 9. 계층 구조

깊은 중첩의 경우:

```
레퍼토리 리스트
    └── 레퍼토리 상세
            └── 섹션 리스트 (중첩)
                    └── 섹션 상세
                            └── 녹음 리스트 (중첩)
```

| 레벨 | 예시 | 뒤로가기 대상 |
|------|------|--------------|
| 1 | 레퍼토리 리스트 | 탭 홈 |
| 2 | 레퍼토리 상세 | 레퍼토리 리스트 |
| 3 | 섹션 상세 | 레퍼토리 상세 |
