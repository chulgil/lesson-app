## 1. 개요

날짜 기반으로 데이터의 활성/비활성, 표시/숨김을 결정하는 패턴.
레퍼토리 활성 기간, 과제 기간 등에 적용.

---

## 2. 기본 개념

### 2.1 활성 기간

```
          시작일                    종료일
             │                         │
 ──────────┼─────────────────────────┼──────────
   비활성   │        활성 기간        │  비활성
             │                         │
```

### 2.2 날짜 상태

| 상태 | 조건 | 설명 |
|------|------|------|
| 시작 전 | 오늘 < 시작일 | 아직 활성화 안됨 |
| 활성 | 시작일 ≤ 오늘 ≤ 종료일 | 현재 활성 상태 |
| 종료됨 | 오늘 > 종료일 | 기간 만료 |
| 무제한 | 종료일 = null | 종료일 없음 |

---

## 3. 레퍼토리/섹션 적용

### 3.1 연습 화면 필터링

```
오늘 날짜: 2026-01-15

레퍼토리 A: 2026-01-01 ~ 2026-01-31  → ✓ 표시
레퍼토리 B: 2026-01-01 ~ 2026-01-10  → ✕ 숨김 (종료됨)
레퍼토리 C: 2026-02-01 ~ 2026-02-28  → ✕ 숨김 (시작 전)
레퍼토리 D: 2026-01-01 ~ null        → ✓ 표시 (무제한)
```

### 3.2 일별 연습 기록

```
2026-01-15 선택:
  - 해당 날짜에 활성인 레퍼토리/섹션만 표시
  - 해당 날짜의 완료 상태 표시

2026-01-10 선택 (과거):
  - 해당 날짜에 활성이었던 레퍼토리/섹션 표시
  - 해당 날짜의 완료 상태 표시 (읽기 전용)
```

## 4. UI 표시

### 4.1 활성 상태 표시

| 상태 | 표시 | 색상 |
|------|------|------|
| 활성 | (표시 없음) | 기본 |
| 시작 전 | "1/20 시작" | `color.text.tertiary` |
| 종료됨 | "종료됨" | `color.text.disabled` |
| 곧 종료 | "3일 남음" | `color.warning` |

### 4.2 리스트에서 종료된 항목

```
┌─────────────────────────────────────────────┐
│  ○ 라폴리아 (2~3줄)               활성      │  ← 활성 (정상)
└─────────────────────────────────────────────┘
┌─────────────────────────────────────────────┐
│  ○ 미뉴에트                     종료됨     │  ← 종료됨 (희미하게)
└─────────────────────────────────────────────┘
```

## 5. 날짜 선택 제약

### 5.1 레퍼토리 기간

| 필드 | 제약 |
|------|------|
| 시작일 | 과거 선택 가능 (기록용) |
| 종료일 | 시작일 이후만 선택 가능 |
| 종료일 | "제한 없음" 옵션 제공 |

### 5.2 섹션 기간 (부모 제약)

```
레퍼토리: 2026-01-01 ~ 2026-01-31

섹션 시작일: 2026-01-01 이후만 선택 가능
섹션 종료일: 2026-01-31 이전만 선택 가능
             또는 레퍼토리 종료일 자동 상속
```

---

## 6. 과거 날짜 조회

### 6.1 일별 연습 기록

```
2026-01-10 (과거) 선택:
  ┌─────────────────────────────────────────┐
  │  ✓ 라폴리아 (2~3줄)              완료   │  ← 그날 완료함
  │  ○ 미뉴에트                      미완료 │  ← 그날 안함
  └─────────────────────────────────────────┘

  → 편집 불가 (읽기 전용)
```

### 6.2 녹음 필터

```
섹션 상세 화면:

  녹음 필터: [전체] [이번 주] [당일]

  당일 선택 (2026-01-10):
    - 2026-01-10에 녹음된 파일만 표시

  이번 주 선택:
    - 해당 날짜가 포함된 주 (월~일) 녹음 표시
```

## 7. 기간 연장/변경

### 7.1 종료일 연장

```
현재: 2026-01-15
원래 종료일: 2026-01-10 (이미 지남)

→ 종료일을 2026-01-31로 연장
→ 항목이 다시 활성화됨
```

### 7.2 기간 변경 시 데이터 처리

```
기존: 2026-01-01 ~ 2026-01-31
변경: 2026-01-15 ~ 2026-01-31

→ 2026-01-01~14의 기록은 유지됨
→ 해당 날짜 조회 시 기록 표시됨
→ 오늘(1/16) 연습 화면에서는 정상 표시
```

## 8. 보관 처리

### 8.1 자동 보관

```
종료일로부터 30일 경과 시:
  - 자동으로 "보관됨" 상태로 전환
  - 기본 리스트에서 숨김
  - "보관함"에서 조회 가능
```

### 8.2 수동 보관

```
컨텍스트 메뉴:
  - "보관하기" 옵션
  - 활성 상태에서도 보관 가능
  - 보관 해제 가능
```

## 9. 날짜 표시 형식

| 상황 | 형식 | 예시 |
|------|------|------|
| 같은 연도 | MM.DD | 01.15 |
| 다른 연도 | YYYY.MM.DD | 2025.12.31 |
| 기간 표시 | MM.DD ~ MM.DD | 01.01 ~ 01.31 |
| 상대 표시 | 오늘, 어제, 3일 전 | 오늘 |
