# 빈 상태 컴포넌트

> ID: `components/empty_state`
> 버전: 1.0
> 소스: 공통 위젯

<!-- @defines: components/empty_state -->
<!-- @uses: tokens/colors, tokens/typography, tokens/spacing, tokens/icons -->

---

## 1. 개요

리스트나 화면에 데이터가 없을 때 표시하는 안내 컴포넌트.
사용자에게 다음 행동을 유도하는 CTA 포함.

---

## 2. 구조

```
┌─────────────────────────────────────────────┐
│                                             │
│                                             │
│              [일러스트/아이콘]               │
│                                             │
│               제목 텍스트                   │
│                                             │
│          설명 메시지 (선택)                 │
│                                             │
│            [  액션 버튼  ]                  │
│                                             │
│                                             │
└─────────────────────────────────────────────┘
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `icon` | `IconData?` | - | null | 아이콘 (일러스트 대신) |
| `illustration` | `Widget?` | - | null | 커스텀 일러스트 |
| `title` | `String` | ✓ | - | 제목 텍스트 |
| `message` | `String?` | - | null | 설명 메시지 |
| `actionLabel` | `String?` | - | null | 액션 버튼 텍스트 |
| `onAction` | `VoidCallback?` | - | null | 액션 버튼 콜백 |
| `compact` | `bool` | - | false | 컴팩트 모드 |

---

## 4. 스타일

| 요소 | 스타일 |
|------|--------|
| 아이콘 크기 | `icon.2xl` (64px) |
| 아이콘 색상 | `color.text.tertiary` |
| 제목 | `type.heading.small`, `color.text.primary` |
| 메시지 | `type.body.medium`, `color.text.secondary` |
| 간격 (아이콘-제목) | `space.4` (16px) |
| 간격 (제목-메시지) | `space.2` (8px) |
| 간격 (메시지-버튼) | `space.6` (24px) |
| 정렬 | 모두 중앙 정렬 |

---

## 5. 변형

### 5.1 전체 화면 빈 상태

페이지 전체가 빈 경우:

```
┌─────────────────────────────────────────────┐
│                                             │
│                                             │
│                                             │
│                  📝                         │
│                                             │
│          등록된 레퍼토리가 없습니다          │
│                                             │
│       연습할 곡을 추가하고                  │
│       연습 기록을 관리해보세요              │
│                                             │
│         [  레퍼토리 추가  ]                 │
│                                             │
│                                             │
│                                             │
└─────────────────────────────────────────────┘
```

### 5.2 섹션 빈 상태

카드나 섹션 내부가 빈 경우:

```
┌─────────────────────────────────────────────┐
│  오늘의 연습                                │
├─────────────────────────────────────────────┤
│                                             │
│        오늘 연습할 항목이 없습니다          │
│                                             │
│           [  연습 추가  ]                   │
│                                             │
└─────────────────────────────────────────────┘
```

### 5.3 컴팩트 빈 상태

리스트 아이템 영역이 빈 경우:

```
┌─────────────────────────────────────────────┐
│  📭 녹음이 없습니다                         │
└─────────────────────────────────────────────┘
```

## 6. 도메인별 메시지

### 연습

| 상황 | 제목 | 메시지 |
|------|------|--------|
| 레퍼토리 없음 | "등록된 레퍼토리가 없습니다" | "연습할 곡을 추가해보세요" |
| 섹션 없음 | "등록된 섹션이 없습니다" | "연습할 구간을 추가해보세요" |
| 오늘 연습 없음 | "오늘 연습할 항목이 없습니다" | null |
| 녹음 없음 | "녹음이 없습니다" | "연습을 녹음해보세요" |

### 레슨

| 상황 | 제목 | 메시지 |
|------|------|--------|
| 레슨 없음 | "예정된 레슨이 없습니다" | null |
| 학생 없음 | "등록된 학생이 없습니다" | "학생을 초대해보세요" |

### 검색

| 상황 | 제목 | 메시지 |
|------|------|--------|
| 검색 결과 없음 | "검색 결과가 없습니다" | "다른 검색어로 시도해보세요" |
