# 리스트 카드 컴포넌트

> ID: `components/list_card`
> 버전: 1.0
> 소스: `features/*/presentation/widgets/`

## 1. 개요

리스트 아이템을 표시하는 카드 컴포넌트.
레퍼토리, 섹션, 학생, 레슨 등 다양한 리스트에 사용.

---

## 2. 기본 구조

### 2.1 단일 줄

```
┌─────────────────────────────────────────────┐
│  [아이콘]  제목 텍스트              [액션]  │
└─────────────────────────────────────────────┘
```

### 2.2 두 줄

```
┌─────────────────────────────────────────────┐
│  [아이콘]  제목 텍스트              [액션]  │
│           부제목/설명                       │
└─────────────────────────────────────────────┘
```

### 2.3 세 줄 (확장)

```
┌─────────────────────────────────────────────┐
│  [아이콘]  제목 텍스트              [액션]  │
│           부제목                            │
│           추가 정보 | 메타데이터           │
└─────────────────────────────────────────────┘
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `title` | `String` | ✓ | - | 제목 텍스트 |
| `subtitle` | `String?` | - | null | 부제목 |
| `description` | `String?` | - | null | 추가 설명 |
| `leading` | `Widget?` | - | null | 좌측 아이콘/이미지 |
| `trailing` | `Widget?` | - | null | 우측 액션/상태 |
| `onTap` | `VoidCallback?` | - | null | 탭 콜백 |
| `onLongPress` | `VoidCallback?` | - | null | 롱프레스 콜백 |
| `isSelected` | `bool` | - | false | 선택 상태 |
| `isEnabled` | `bool` | - | true | 활성화 상태 |

---

## 4. 크기

| 유형 | 높이 | 용도 |
|------|------|------|
| 단일 줄 | `height.listItem` (56px) | 간단한 리스트 |
| 두 줄 | `height.listItem.large` (72px) | 제목+부제목 |
| 확장 | 자동 | 상세 정보 포함 |

---

## 5. 스타일

| 요소 | 스타일 |
|------|--------|
| 배경 | `color.surface` |
| 패딩 | `space.4` (16px) |
| 테두리 라디우스 | `radius.medium` (8px) |
| 그림자 | elevation 1 (미세한 그림자) |
| 제목 | `type.body.large`, `color.text.primary` |
| 부제목 | `type.body.medium`, `color.text.secondary` |
| 설명 | `type.body.small`, `color.text.tertiary` |

---

## 6. 상태별 스타일

| 상태 | 배경 | 테두리 |
|------|------|--------|
| 기본 | `color.surface` | 없음 |
| 눌림 | `color.surface.secondary` | 없음 |
| 선택됨 | `color.primary.light` (10%) | `color.primary` (1px) |
| 비활성 | `color.surface` (50%) | 없음 |

## 7. Leading 변형

### 7.1 아이콘

```
│  [○]  연습 항목...                          │
```

### 7.2 체크박스

```
│  [✓]  완료된 항목...                        │
```

### 7.3 아바타

```
│  [👤]  학생 이름...                         │
```

### 7.4 섬네일

```
│  [🖼️]  레퍼토리 이름...                     │
```


## 9. 연습 리스트 특화

### 9.1 연습 완료 상태

```
┌─────────────────────────────────────────────┐
│  ✓  라폴리아 (2~3줄)               🔁      │  ← 완료 + 반복
│      스즈키 6권                            │
└─────────────────────────────────────────────┘
┌─────────────────────────────────────────────┐
│  ⭐ 미뉴에트 G장조                  3/5     │  ← 과제 + 횟수
│      바흐 미뉴에트                          │
└─────────────────────────────────────────────┘
```

| 아이콘 | 의미 |
|--------|------|
| ○ | 미완료 (일반) |
| ✓ | 완료 |
| ⭐ | 과제 (미완료) |
| ★ | 과제 (완료) |
| 🔁 | 매일 반복 |
| n/m | 횟수 반복 (진행/목표) |

## 10. 스와이프 액션

```
│  [삭제]  │  카드 내용...                    │  ← 좌로 스와이프
│          │  카드 내용...           │ [편집] │  ← 우로 스와이프
```

| 액션 | 배경색 | 아이콘 |
|------|--------|--------|
| 삭제 | `color.error` | 🗑️ |
| 편집 | `color.primary` | ✏️ |
| 보관 | `color.warning` | 📦 |
