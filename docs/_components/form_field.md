# 폼 필드 컴포넌트

> ID: `components/form_field`
> 버전: 1.0
> 소스: Material TextField + 커스텀 스타일

<!-- @defines: components/form_field -->
<!-- @uses: tokens/colors, tokens/typography, tokens/spacing -->

---

## 1. 개요

텍스트 입력을 위한 기본 폼 필드 컴포넌트.
라벨, 힌트, 에러 메시지, 접두사/접미사를 지원.

---

## 2. 구조

### 2.1 기본 구조

```
┌─────────────────────────────────────────────┐
│  라벨 텍스트 *                               │  ← 라벨 (필수 표시)
│  ┌─────────────────────────────────────┐    │
│  │ 플레이스홀더 텍스트                  │    │  ← 입력 필드
│  └─────────────────────────────────────┘    │
│  보조 텍스트                                │  ← 힌트 또는 에러
└─────────────────────────────────────────────┘
```

### 2.2 접두사/접미사

```
┌─────────────────────────────────────────────┐
│  ┌─────────────────────────────────────┐    │
│  │ [🔍] 검색어 입력...            [✕] │    │
│  └─────────────────────────────────────┘    │
└─────────────────────────────────────────────┘
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `label` | `String?` | - | null | 라벨 텍스트 |
| `hint` | `String?` | - | null | 플레이스홀더 |
| `value` | `String` | - | "" | 현재 값 |
| `errorText` | `String?` | - | null | 에러 메시지 |
| `helperText` | `String?` | - | null | 보조 텍스트 |
| `isRequired` | `bool` | - | false | 필수 입력 표시 |
| `isEnabled` | `bool` | - | true | 활성화 상태 |
| `isReadOnly` | `bool` | - | false | 읽기 전용 |
| `maxLength` | `int?` | - | null | 최대 글자 수 |
| `maxLines` | `int` | - | 1 | 최대 줄 수 |
| `keyboardType` | `TextInputType` | - | text | 키보드 유형 |
| `prefixIcon` | `Widget?` | - | null | 접두사 아이콘 |
| `suffixIcon` | `Widget?` | - | null | 접미사 아이콘 |
| `onChanged` | `Function(String)` | - | null | 값 변경 콜백 |
| `onSubmitted` | `Function(String)` | - | null | 제출 콜백 |

---

## 4. 상태별 스타일

| 상태 | 테두리 | 라벨 | 배경 |
|------|--------|------|------|
| 기본 | `color.border` | `color.text.secondary` | `color.surface` |
| 포커스 | `color.primary` (2px) | `color.primary` | `color.surface` |
| 에러 | `color.error` | `color.error` | `color.surface` |
| 비활성 | `color.border` (50%) | `color.text.disabled` | `color.surface.secondary` |
| 읽기전용 | 없음 | `color.text.secondary` | `color.surface.secondary` |

---

## 5. 크기

| 요소 | 값 |
|------|-----|
| 높이 (단일 줄) | `height.input` (48px) |
| 높이 (멀티 줄) | 자동 (min 48px) |
| 패딩 | `space.4` (16px) |
| 테두리 라디우스 | `radius.medium` (8px) |
| 라벨 폰트 | `type.body.small` |
| 입력 폰트 | `type.body.large` |
| 보조 텍스트 폰트 | `type.caption` |

---

## 6. 라벨 동작

| 상태 | 라벨 위치 |
|------|----------|
| 빈 상태 + 포커스 없음 | 필드 내부 (플레이스홀더처럼) |
| 포커스 또는 값 있음 | 필드 상단 (작은 크기) |

---

## 7. 글자 수 표시

`maxLength` 설정 시:

```
┌─────────────────────────────────────────────┐
│  │ 메모 내용 입력...                    │    │
│  └─────────────────────────────────────┘    │
│                                   45/200    │  ← 현재/최대
└─────────────────────────────────────────────┘
```

---

## 8. 유효성 시각 피드백

| 상태 | 표시 |
|------|------|
| 유효 | 초록색 체크 아이콘 (접미사) |
| 경고 | 주황색 느낌표 + helperText |
| 에러 | 빨간색 테두리 + errorText |

---

## 사용처

<!-- @used-by: 모든 폼 스펙 -->

- 레퍼토리 추가/편집: 제목 입력
- 섹션 추가/편집: 별칭 입력
- 레슨 노트: 메모 입력
- 검색: 검색어 입력
