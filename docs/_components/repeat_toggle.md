> 버전: 1.0
> 소스: `features/practice/presentation/widgets/`

## 1. 개요

연습 반복 설정을 위한 토글 및 횟수 입력 컴포넌트.
매일 반복 또는 횟수 기반 반복을 설정.

---

## 2. 구조

### 2.1 반복 토글

```
┌─────────────────────────────────────────────┐
│  🔁 반복 연습                    [토글 ON]   │
└─────────────────────────────────────────────┘
```

### 2.2 반복 유형 선택 (토글 ON 시 표시)

```
┌─────────────────────────────────────────────┐
│  반복 유형                                   │
│  ┌──────────────┐  ┌──────────────┐        │
│  │  🔁 매일      │  │  🔢 횟수     │        │  ← 세그먼트 버튼
│  └──────────────┘  └──────────────┘        │
└─────────────────────────────────────────────┘
```

### 2.3 횟수 입력 (횟수 선택 시)

```
┌─────────────────────────────────────────────┐
│  반복 횟수                                   │
│  ┌─────┐                                    │
│  │  5  │ 회                                 │
│  └─────┘                                    │
└─────────────────────────────────────────────┘
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `isEnabled` | `bool` | - | false | 반복 활성화 여부 |
| `repeatType` | `RepeatType` | - | daily | 반복 유형 |
| `repeatCount` | `int?` | - | null | 반복 횟수 (횟수 유형일 때) |
| `onEnabledChanged` | `Function(bool)` | ✓ | - | 토글 변경 콜백 |
| `onTypeChanged` | `Function(RepeatType)` | ✓ | - | 유형 변경 콜백 |
| `onCountChanged` | `Function(int)` | ✓ | - | 횟수 변경 콜백 |

---

## 4. RepeatType Enum

```dart
enum RepeatType {
  daily,   // 매일 반복
  count,   // 횟수 기반 반복
}
```

## 5. 상태별 스타일

### 토글

| 상태 | 배경 | 아이콘 |
|------|------|--------|
| OFF | `color.surface.secondary` | `color.text.tertiary` |
| ON | `color.primary` | 흰색 |

### 세그먼트 버튼

| 상태 | 배경 | 텍스트 |
|------|------|--------|
| 미선택 | 투명 | `color.text.secondary` |
| 선택됨 | `color.primary.light` | `color.primary.dark` |

## 6. 횟수 입력 필드

| 요소 | 스타일 |
|------|--------|
| 컨테이너 | 64px 너비, `height.input`, `radius.medium` |
| 입력 | 숫자만, 중앙 정렬, `type.heading.medium` |
| 단위 | "회", `type.body.medium`, `color.text.secondary` |

---

## 7. 리스트 아이템 표시

연습 리스트에서의 반복 상태 표시:

| 유형 | 표시 | 예시 |
|------|------|------|
| 반복 없음 | - | (표시 없음) |
| 매일 반복 | 🔁 아이콘 | 🔁 |
| 횟수 반복 | 진행/목표 | 2/5 |

```
┌─────────────────────────────────────────────┐
│  ○ 라폴리아 1~2줄          🔁              │  ← 매일 반복
│  ○ 라폴리아 3~4줄          3/5             │  ← 5회 중 3회 완료
│  ✓ 미뉴에트 전체                           │  ← 반복 없음, 완료
└─────────────────────────────────────────────┘
```

## 8. 발바닥 스탬프 UI

횟수 반복 시 상세 화면에서:

```
┌─────────────────────────────────────────────┐
│  오늘의 연습 (5회 반복)                      │
│                                             │
│  🐾 🐾 🐾 ○ ○                              │  ← 3회 완료
│                                             │
│  [     연습 완료     ]                      │
└─────────────────────────────────────────────┘
```

| 상태 | 아이콘 | 색상 |
|------|--------|------|
| 완료 | 🐾 (발바닥) | `color.cat.accent` |
| 미완료 | ○ | `color.border` |
