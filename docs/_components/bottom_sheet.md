# 바텀 시트 컴포넌트

> ID: `components/bottom_sheet`
> 버전: 1.0
> 소스: Material BottomSheet + 커스텀 스타일

<!-- @defines: components/bottom_sheet -->
<!-- @uses: tokens/colors, tokens/typography, tokens/spacing -->

---

## 1. 개요

화면 하단에서 올라오는 모달 시트 컴포넌트.
추가/편집 폼, 선택 피커, 상세 정보 등에 사용.

---

## 2. 구조

### 2.1 기본 구조

```
┌─────────────────────────────────────────────┐
│  ─────── (드래그 핸들)                       │
├─────────────────────────────────────────────┤
│  시트 제목                           [닫기]  │  ← 헤더 (선택적)
├─────────────────────────────────────────────┤
│                                             │
│              콘텐츠 영역                     │
│                                             │
├─────────────────────────────────────────────┤
│  [     액션 버튼     ]                      │  ← 푸터 (선택적)
└─────────────────────────────────────────────┘
   Safe Area Bottom
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `title` | `String?` | - | null | 헤더 제목 |
| `showHandle` | `bool` | - | true | 드래그 핸들 표시 |
| `showCloseButton` | `bool` | - | false | 닫기 버튼 표시 |
| `isDismissible` | `bool` | - | true | 외부 탭으로 닫기 |
| `enableDrag` | `bool` | - | true | 드래그로 닫기 |
| `isScrollable` | `bool` | - | false | 콘텐츠 스크롤 |
| `initialHeight` | `double` | - | 0.5 | 초기 높이 (화면 비율) |
| `maxHeight` | `double` | - | 0.9 | 최대 높이 (화면 비율) |
| `child` | `Widget` | ✓ | - | 콘텐츠 위젯 |
| `footer` | `Widget?` | - | null | 푸터 위젯 |

---

## 4. 스타일

| 요소 | 스타일 |
|------|--------|
| 배경 | `color.surface` |
| 상단 라디우스 | `radius.xlarge` (16px) |
| 드래그 핸들 | 32×4px, `color.border`, `radius.round` |
| 헤더 높이 | `height.header` (56px) |
| 헤더 패딩 | `space.4` (16px) |
| 콘텐츠 패딩 | `space.4` (16px) |
| 푸터 패딩 | `space.4` (16px) + Safe Area |
| 오버레이 | 검정 50% 투명도 |

---

## 5. 헤더 변형

### 5.1 제목만

```
├─────────────────────────────────────────────┤
│  섹션 추가                                   │
├─────────────────────────────────────────────┤
```

### 5.2 제목 + 닫기

```
├─────────────────────────────────────────────┤
│  섹션 편집                            [✕]   │
├─────────────────────────────────────────────┤
```

### 5.3 제목 + 액션

```
├─────────────────────────────────────────────┤
│  [취소]     섹션 추가              [저장]   │
├─────────────────────────────────────────────┤
```

---

## 6. 높이 동작

| 유형 | 초기 높이 | 최대 높이 | 동작 |
|------|----------|----------|------|
| 고정 | 콘텐츠에 맞춤 | - | 드래그 비활성 |
| 스크롤 | 50% | 90% | 드래그로 확장/축소 |
| 풀스크린 | 90% | 90% | 거의 전체 화면 |

---

## 7. 인터랙션

1. 오버레이 탭 → 시트 닫힘 (isDismissible=true)
2. 핸들 드래그 다운 → 시트 닫힘
3. 핸들 드래그 업 → 시트 확장 (maxHeight까지)
4. 닫기 버튼 탭 → 시트 닫힘

---

## 8. 애니메이션

| 동작 | 시간 | 곡선 |
|------|------|------|
| 열기 | 300ms | easeOutCubic |
| 닫기 | 250ms | easeInCubic |
| 높이 변경 | 200ms | easeOut |
