# 확인 다이얼로그 컴포넌트

> ID: `components/confirm_dialog`
> 버전: 1.0
> 소스: Material AlertDialog + 커스텀 스타일

<!-- @defines: components/confirm_dialog -->
<!-- @uses: tokens/colors, tokens/typography, tokens/spacing, components/submit_button -->

---

## 1. 개요

사용자에게 확인을 요청하는 모달 다이얼로그.
삭제, 취소, 나가기 등 중요한 액션 전에 표시.

> 용어 규칙(UX): `취소` 라벨은 **액션 취소**(요청/제안/변경 철회)일 때만 사용하고,
> 단순 오버레이 닫기에는 `닫기`를 사용한다.

---

## 2. 구조

```
         ┌─────────────────────────────┐
         │                             │
         │      [아이콘 (선택)]         │
         │                             │
         │         제목 텍스트          │
         │                             │
         │     설명 메시지 텍스트       │
         │     (여러 줄 가능)           │
         │                             │
         ├─────────────────────────────┤
         │  [취소]          [확인]     │
         └─────────────────────────────┘
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `title` | `String` | ✓ | - | 제목 텍스트 |
| `message` | `String` | ✓ | - | 설명 메시지 |
| `icon` | `IconData?` | - | null | 상단 아이콘 |
| `iconColor` | `Color?` | - | null | 아이콘 색상 |
| `confirmLabel` | `String` | - | "확인" | 확인 버튼 텍스트 |
| `cancelLabel` | `String` | - | `null` | 보조 버튼 텍스트 (`취소`는 액션 취소, `닫기`는 종료 전용) |
| `confirmVariant` | `ButtonVariant` | - | primary | 확인 버튼 스타일 |
| `isDismissible` | `bool` | - | true | 외부 탭으로 닫기 |
| `onConfirm` | `VoidCallback` | ✓ | - | 확인 콜백 |
| `onCancel` | `VoidCallback?` | - | null | 취소 콜백 |

---

## 4. 스타일

| 요소 | 스타일 |
|------|--------|
| 배경 | `color.surface` |
| 라디우스 | `radius.large` (12px) |
| 패딩 | `space.6` (24px) |
| 최대 너비 | 280px |
| 아이콘 크기 | `icon.xl` (48px) |
| 제목 | `type.heading.medium`, `color.text.primary`, 중앙 정렬 |
| 메시지 | `type.body.medium`, `color.text.secondary`, 중앙 정렬 |
| 버튼 영역 | `space.4` (16px) 상단 간격 |

## 5. 변형

### 5.1 기본 확인

```
         ┌─────────────────────────────┐
         │                             │
         │        변경 사항 저장        │
         │                             │
         │   저장하지 않은 변경 사항이   │
         │   있습니다. 저장하시겠습니까? │
         │                             │
         ├─────────────────────────────┤
         │  [취소]          [저장]     │
         └─────────────────────────────┘
```

### 5.2 삭제 경고

```
         ┌─────────────────────────────┐
         │                             │
         │           [🗑️]              │
         │                             │
         │        섹션 삭제            │
         │                             │
         │   '라폴리아 1~2줄'을         │
         │   삭제하시겠습니까?          │
         │   이 작업은 취소할 수 없습니다.│
         │                             │
         ├─────────────────────────────┤
         │  [취소]          [삭제]     │  ← 삭제 버튼: danger
         └─────────────────────────────┘
```

### 5.3 정보 안내

```
         ┌─────────────────────────────┐
         │                             │
         │           [ℹ️]              │
         │                             │
         │        녹음 공유 안내        │
         │                             │
         │   대표 녹음을 선생님과       │
         │   공유할 수 있습니다.        │
         │                             │
         ├─────────────────────────────┤
         │  [나중에]        [공유하기]  │
         └─────────────────────────────┘
```

### 5.4 닫기 전용(단일 액션)

```
         ┌─────────────────────────────┐
         │                             │
         │           [ℹ️]              │
         │                             │
         │       알림 상세 보기        │
         │                             │
         │   변경이 불가한 히스토리를     │
         │   보여주는 안내입니다.        │
         │                             │
         ├─────────────────────────────┤
         │         [닫기]              │
         └─────────────────────────────┘
```

## 6. 버튼 배치

| 유형 | 배치 |
|------|------|
| 2개 버튼 | 가로 배치 (취소 왼쪽, 확인 오른쪽) |
| 1개 버튼 | 전체 너비 |
| 3개 버튼 | 세로 배치 |

---

## 7. 버튼 스타일 가이드

| 상황 | 확인 버튼 | 취소 버튼 |
|------|----------|----------|
| 일반 확인 | `primary` | `ghost` |
| 삭제 | `danger` | `secondary` |
| 저장 | `primary` | `ghost` |
| 안내 | `primary` | `ghost` |
| 닫기 전용 | `primary` | - |

---

## 8. 애니메이션

| 동작 | 효과 |
|------|------|
| 열기 | 페이드인 + 스케일업 (0.9→1.0) |
| 닫기 | 페이드아웃 |
| 시간 | 200ms |

---

## 9. 오버레이

| 요소 | 스타일 |
|------|--------|
| 배경 | 검정 50% 투명도 |
| 탭 동작 | isDismissible=true면 닫기 |
