# Swipe Action

> 버전: 1.0  
> 최종 업데이트: 2026-05-31

리스트 행에서 반복 관리 액션을 숨겨두고, 오른쪽 스와이프로 액션 버튼을 드러내는 공통 패턴이다.

## 사용 원칙

- 리스트 행의 주요 정보는 항상 먼저 보이고, 보조 관리 액션은 오른쪽 스와이프로 노출한다.
- 한 행의 스와이프 액션은 1~2개를 기본으로 한다. 3개 이상이면 상세 화면 또는 메뉴로 분리한다.
- 삭제 같은 파괴적 액션은 `paperAccent` 배경을 사용한다.
- 편집 같은 일반 액션은 `ink` 배경을 사용한다.
- 같은 화면 안에서 행별 trailing 아이콘 버튼과 스와이프 액션을 혼용하지 않는다.
- 삭제 후 행이 속한 그룹이 비어도 그룹 헤더는 유지하고, 상태를 `휴무`처럼 비활성 라벨로 표시한다.

## 구조

```text
┌────────────────────────────────────┐
│ 09:00 - 18:00                      │  기본 상태
└────────────────────────────────────┘

┌────────┬────────┬──────────────────┐
│ 편집   │ 삭제   │ 09:00 - 18:00    │  오른쪽 스와이프 후
└────────┴────────┴──────────────────┘
```

## Props

| 이름 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| `child` | `Widget` | O | - | 이동되는 리스트 행 본문 |
| `actions` | `List<SwipeAction>` | O | - | 왼쪽에 노출할 액션 |
| `actionWidth` | `double` | X | `72` | 액션 버튼 너비 |

## 상태

| 상태 | 동작 |
|------|------|
| 기본 | 본문만 표시 |
| 오른쪽 스와이프 | 왼쪽에 액션 버튼 표시, 본문은 오른쪽으로 이동 |
| 왼쪽 스와이프 | 액션 버튼 닫힘 |
| 액션 탭 | 액션 닫힘 후 콜백 실행 |

## 구현

- Flutter 공통 위젯은 `frontend/lib/core/widgets/swipe_action_tile.dart`를 사용한다.
- production UI 문구는 `AppStrings`를 사용한다.
- raw color, raw spacing, raw typography를 쓰지 않는다.
