## 1. 개요

마디(measure) 또는 줄(line) 번호를 선택하는 컴포넌트.
섹션의 시작/끝 범위를 지정할 때 사용.

---

## 2. 구조

### 2.1 트리거 버튼

```
┌─────────────────────────────────┐
│  [시작 마디]        ▼           │  ← 탭하면 피커 시트 열림
└─────────────────────────────────┘
```

| 요소 | 스타일 |
|------|--------|
| 컨테이너 | `height.input` (48px), `radius.medium`, `color.surface` 배경 |
| 텍스트 | `type.body.large`, `color.text.primary` |
| 드롭다운 아이콘 | `icon.sm` (20px), `color.text.secondary` |
| 테두리 | 1px, `color.border` |

### 2.2 피커 바텀시트

```
┌─────────────────────────────────┐
│  ───────  (드래그 핸들)          │
├─────────────────────────────────┤
│                                 │
│    ┌───┐ ┌───┐ ┌───┐ ┌───┐    │
│    │ 1 │ │ 2 │ │ 3 │ │ 4 │    │  ← 숫자 그리드
│    └───┘ └───┘ └───┘ └───┘    │
│    ┌───┐ ┌───┐ ┌───┐ ┌───┐    │
│    │ 5 │ │ 6 │ │ 7 │ │ 8 │    │
│    └───┘ └───┘ └───┘ └───┘    │
│           ...                   │
│                                 │
├─────────────────────────────────┤
│  [     확인     ]               │
└─────────────────────────────────┘
```

---

## 3. Props

| 속성 | 타입 | 필수 | 기본값 | 설명 |
|------|------|:----:|--------|------|
| `value` | `int?` | - | null | 현재 선택된 값 |
| `min` | `int` | - | 1 | 최소값 |
| `max` | `int` | ✓ | - | 최대값 |
| `label` | `String` | - | "선택" | 라벨 텍스트 |
| `unit` | `String` | - | "마디" | 단위 텍스트 (마디/줄) |
| `onChanged` | `Function(int)` | ✓ | - | 값 변경 콜백 |

---

## 4. 상태

| 상태 | 버튼 스타일 | 설명 |
|------|-------------|------|
| 기본 | `color.surface` 배경 | 값 미선택 |
| 선택됨 | `color.surface` 배경, 값 표시 | 값 선택됨 |
| 비활성 | `color.surface.secondary` 배경, 50% 투명도 | 선택 불가 |

---

## 5. 그리드 아이템 스타일

| 상태 | 배경 | 텍스트 |
|------|------|--------|
| 기본 | 투명 | `color.text.primary` |
| 선택됨 | `color.primary` | 흰색 |
| 범위 외 | - | `color.text.disabled` |

---

## 6. 인터랙션

1. 버튼 탭 → 바텀시트 열림
2. 숫자 탭 → 해당 값 선택 (하이라이트)
3. 확인 버튼 탭 → 값 적용, 시트 닫힘
4. 외부 탭/드래그 다운 → 시트 닫힘 (값 미적용)

---

## 7. 유효성 검사

- 시작 마디 ≤ 끝 마디 (범위 선택 시)
- 값이 min~max 범위 내
