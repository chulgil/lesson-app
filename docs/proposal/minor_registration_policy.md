# 미성년자 회원가입 정책 Q&A

> 브레인스토밍 일자: 2025-12-27

## 배경

음악 레슨 앱의 주요 사용자인 학생 중 상당수가 미성년자(특히 만 14세 미만)이며, 일부는 휴대폰이 없는 경우도 있음. 이에 대한 법적 요건과 사용자 경험을 고려한 정책 수립이 필요.

## 조사 결과

### 한국 법적 요건

| 연령 | 요건 | 근거 |
|------|------|------|
| **만 14세 미만** | 법정대리인(부모) 동의 **필수** | 개인정보보호법 제22조의2 |
| 만 14세 이상 | 본인 동의 가능 | - |
| 위반 시 | 5천만원 이하 과태료 | - |

### 경쟁사 해결 방식

| 앱 | 최소 연령 | 해결 방식 |
|-----|---------|----------|
| Yousician | 13세 | 부모 동의 → 패밀리 플랜으로 관리 |
| Tonara | 13세 | 부모가 구독 완료 → 학생 계정 생성 |
| Simply Piano | 별도 제한 없음 | 패밀리 플랜 (5명) - 부모가 프로필 생성 |
| 클래스팅 | 제한 없음 | 학생 코드 발급 → 이메일 없이 가입 |

## 결정 사항

### Q1. 학생 계정 생성 방식

**결정: A. 프로필 방식**

- 학부모 계정 하위에 "자녀 프로필"로 존재
- 만 14세 미만 학생은 별도 회원가입 없음
- 개인정보 수집을 최소화하여 법적 이슈 회피

### Q2. 휴대폰 없는 학생 처리

**결정: A + B (부모 기기 공유 + 태블릿/iPad 지원)**

- 집에서는 태블릿/iPad로 연습
- 외출 시 부모 휴대폰에서 프로필 전환하여 사용

### Q3. 부모-자녀 계정 연동 범위

**결정: D. 연령별 차등**

| 연령 | 부모 권한 |
|------|----------|
| 만 14세 미만 | 완전 연동 (자녀 프로필 = 부모 계정 일부) |
| 만 14세 이상 | 읽기 전용 (선택적 연동) |

### Q4. 본인인증 방식

**결정: 해당 없음 (만 14세 미만)**

- 만 14세 미만: 회원가입 없이 프로필로 사용 → 본인인증 불필요
- 만 14세 이상: 본인 회원가입 시 이메일 인증

### Q5-Q7. 프로필 방식 상세

**결정: 만 14세 미만은 부모 계정 프로필로 사용**

- 부모가 로그인 → 자녀 프로필 전환 → 사용
- 자녀 개인정보를 별도 수집하지 않음
- 법정대리인 동의 절차 자체가 불필요

### Q8. 자녀 프로필에 저장할 정보

**결정: B. 기본 정보**

| 정보 | 저장 여부 | 용도 |
|------|----------|------|
| 이름/닉네임 | ✅ | 선생님이 구분 |
| 생년(년도만) | ✅ | 연령 확인 (만 14세 판단) |
| 악기 | ✅ | 레슨 유형 |
| 레벨 | ✅ | 실력 수준 |
| 연습 기록 | ✅ | 핵심 기능 |
| 레슨 노트 | ✅ | 핵심 기능 |

> **참고**: 주민등록번호, 상세 생년월일, 주소 등 민감 정보는 수집하지 않음

### Q9. 선생님-학생 연결

**결정: C. 양방향**

| 방향 | 흐름 |
|------|------|
| 선생님 → 부모 | 선생님이 부모 이메일/전화로 초대 → 부모가 수락 후 자녀 프로필 연결 |
| 부모 → 선생님 | 부모가 선생님 검색 또는 초대 코드 입력 → 자녀 프로필과 연결 요청 |

### Q10. 만 14세 도달 시 전환

**결정: B. 그대로 유지**

- 만 14세가 되어도 부모 계정 프로필로 계속 사용 가능
- 원하면 본인 계정으로 전환 가능 (선택적)
- 기존 연습 기록, 레슨 노트 등 데이터 이전 지원

## 사용자 시나리오

### 시나리오 1: 만 10세 학생 (휴대폰 없음)

```
1. 부모가 학부모 계정으로 회원가입
2. 부모가 자녀 프로필 생성 (이름, 생년, 악기)
3. 선생님이 부모에게 초대 → 자녀 프로필과 연결
4. 부모 휴대폰 또는 가정 태블릿에서:
   - 부모 로그인 → 자녀 프로필 전환 → 연습/과제 확인
5. 만 14세 도달 후에도 동일하게 사용 가능
   (원하면 본인 계정 생성하여 독립)
```

### 시나리오 2: 만 16세 학생 (휴대폰 있음)

```
1. 학생이 본인 이메일로 학생 계정 회원가입
2. 선생님과 직접 연결
3. (선택) 부모 계정과 연동하여 부모도 진도 확인 가능
```

### 시나리오 3: 만 14세 학생 (기존 자녀 프로필 사용 중)

```
1. 만 14세 도달
2. 선택지:
   A. 그대로 부모 계정 프로필로 계속 사용
   B. 본인 계정 생성 → 기존 데이터 이전 → 독립
```

## 구현 시 고려사항

### 1. 프로필 전환 UX

```dart
// 부모 계정 로그인 후 프로필 선택 화면
- 부모 본인 (학부모 모드)
- 김민수 (자녀 1)
- 김민지 (자녀 2)
```

### 2. 연령 확인 로직

```dart
// 생년만 저장하므로 년도 기준으로 판단
bool isUnder14(int birthYear) {
  final currentYear = DateTime.now().year;
  return (currentYear - birthYear) < 14;
}
```

### 3. 데이터 구조

```dart
// 학부모 계정
class ParentAccount {
  String id;
  String email;
  String name;
  List<ChildProfile> children;  // 자녀 프로필 목록
}

// 자녀 프로필 (회원 아님)
class ChildProfile {
  String id;

  int birthYear;           // 년도만 저장
  String instrument;
  StudentLevel level;
  String? connectedTeacherId;

```
