# Smart Recording Q&A Session

> 작성일: 2025-12-31

## 배경

사용자가 녹음 시작 후 악기/악보 준비하는 동안 발생하는 불필요한 무음 구간을 자동으로 제거하는 기능 요청.

## 경쟁사 조사

| 앱 | 플랫폼 | 기능 | 방식 |
|---|---|---|---|
| Skipping Silence Recorder | Android | 실시간 스킵 | 녹음 시 제거 |
| Apple Voice Memos | iOS | 재생 시 스킵 | 저장 시 미적용 |
| HT Professional Recorder | iOS | 자동 스킵 | 녹음 시 제거 |
| Cleanvoice AI | Web | AI 제거 | 후처리 |

**인사이트**: 실시간 스킵 vs 후처리 두 가지 접근 방식 존재

---

## Q&A

### Q1. 무음 구간 처리 방식

| 옵션 | 설명 |
|---|---|
| A. 실시간 스킵 | 녹음하면서 바로 제외, 원본 없음 |
| **B. 자동 트리밍** | 녹음 완료 후 자동 트림, 원본 보존 가능 |
| C. 마커 표시 | 무음 구간에 마커만 표시 |

**결정**: **B. 자동 트리밍**

### Q2. 트리밍 적용 범위

| 옵션 | 설명 |
|---|---|
| A. 앞부분만 | 시작 전 준비 시간만 제거 |
| **B. 앞뒤 모두** | 시작 전 + 종료 후 여운 제거 |
| C. 전체 구간 | 중간 무음도 모두 제거 |

**결정**: **B. 앞뒤 모두** (중간 무음은 음악적 휴식일 수 있어 유지)

### Q3. 임계값 설정

| 옵션 | 설명 |
|---|---|
| A. 0.30 (30%) | 보수적 |
| B. 0.40 (40%) | 고정값 |
| **C. 사용자 조절** | 슬라이더로 조절 가능 |

**결정**: **C. 사용자 조절 가능 슬라이더** (기본값 40%)

### Q4. 사용자 피드백 UI

| 옵션 | 설명 |
|---|---|
| A. 자동 무음 | 별도 UI 없음 |
| B. 트림 미리보기 | 완료 후 결과 표시 |
| C. 실시간 표시 | 녹음 중 상태 표시 |

**결정**: **B+C 조합**
- 녹음 중: "대기 중... (연주를 시작하세요)" 상태 표시
- 녹음 후: "앞 X초 / 뒤 Y초 트림됨 [복구]" 결과 표시

### Q5. 기능 이름

| 옵션 | 이름 |
|---|---|
| A | 스마트 녹음 |
| B | 자동 트림 |
| C | 무음 스킵 |
| D | 연습 녹음 모드 |

**결정**: **스마트 녹음**

## 결정 요약

|------|------|
| 처리 방식 | 자동 트리밍 (후처리) |
