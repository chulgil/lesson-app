# 레슨 요청 리스트 & 상세 화면 UX 개선 PAD

> 작성일: 2026-03-29
> Grill Me: 17개 질문, 4개 디자인 가지 탐색 완료

---

## 문제 정의

선생님이 레슨 요청 리스트를 볼 때 실제 판단 순서는 **학원 여부 → 긴급도 → 체험/정규 → 희망 일시 → 학생 정보**이지만, 현재 UI는 학생 정보(이름·악기·레벨)가 가장 눈에 띄고 긴급도와 희망 일시가 표시되지 않아 판단 순서와 정보 배치가 어긋나 있다.

상세 화면은 리스트와 거의 동일한 정보를 반복 표시하고 있어, 체험 학생의 메시지나 정규 학생의 레슨 이력 같은 **의사결정에 필요한 추가 정보**가 부족하다.

---

## 솔루션 개요

리스트 아이템을 선생님의 판단 순서에 맞게 재배치하고, 상세 화면 상단 프로필 카드를 레슨 타입별(체험/정규)로 분기하여 각각에 맞는 정보를 강조한다.

---

## 유저 스토리

### 리스트 화면

- 선생님으로서 리스트를 훑으면 **학원 요청인지 개인 요청인지** 한눈에 구분할 수 있다
- 선생님으로서 **체험 레슨 요청**이 시각적으로 구분되어 신규 학생 유치 기회를 놓치지 않는다
- 선생님으로서 요청이 **얼마나 오래 전에 왔는지** 바로 보여서 긴급한 것부터 처리할 수 있다
- 선생님으로서 **학생이 희망하는 1순위 시간**을 리스트에서 바로 볼 수 있어 상세 화면에 들어가기 전에 대략적 판단이 가능하다

### 상세 화면

- 선생님으로서 **체험 학생의 메시지**가 크게 보여서 처음 만나는 학생의 요구사항을 파악할 수 있다
- 선생님으로서 **정규 학생의 레슨 이력 요약**(총 레슨 횟수, 연습 빈도)이 보여서 학생 상태를 파악하고 수락/거절을 결정할 수 있다
- 선생님으로서 AppBar에서 **체험/정규 타입**이 바로 보여서 어떤 요청인지 혼동하지 않는다

## 수용 기준

### 리스트 아이템 (RequestListItem)

- [ ] 1줄: 학원 뱃지(🏫 또는 "개인레슨") + 레슨 타입(체험/정규/재수강) + 경과 시간("3일 전")
- [ ] 2줄: 학생 이름 · 악기 · 레벨
- [ ] 3줄: 1순위 희망 시간 + "외 N건" (희망 시간이 1개면 "외 N건" 생략)
- [ ] 아바타에 학원 요청이면 🏫 오버레이 뱃지 표시
- [ ] 경과 시간이 5일 이상이면 빨간색으로 강조 (7일 만료 기준)
- [ ] 상태칩은 기존 위치(우측) 유지

### 상세 화면 AppBar

- [ ] AppBar 타이틀 좌측에 레슨 타입 뱃지 표시 (예: [체험] 요청 상세)

### 상세 화면 프로필 카드 — 체험 레슨

- [ ] 학생 기본 정보 (이름, 악기, 레벨, 목표)
- [ ] 학생 메시지를 카드 내에 크게 표시 (말풍선 또는 인용 블록 스타일)
- [ ] 학원 경유 시 학원명 표시

### 상세 화면 프로필 카드 — 정규 레슨

- [ ] 학생 기본 정보 (이름, 악기, 레벨, 목표)
- [ ] 이력 요약 1줄: "레슨 N회 · 연습 주N회" (Student 엔티티의 totalLessons, practiceRate 사용)
- [ ] 학생 메시지는 이력 아래에 작게 표시 (있는 경우만)
- [ ] 재수강(isReturningStudent)이면 "재수강" 뱃지 표시

### 기존 유지 (변경 없음)

- [ ] CurrentRequestBox (시간 슬롯 선택 + 수락/역제안) 변경 없음
- [ ] RequestHistoryChat (이벤트 타임라인) 변경 없음
- [ ] SuggestAlternativeScreen (스케줄 대조) 변경 없음

## 구현 결정 사항

### 학생 이력 데이터 접근

Student 엔티티에 이미 `totalLessons`, `practiceRate`, `practiceStatus` 필드가 존재한다. RequestDetailScreen에서 students 도메인의 Provider를 직접 참조하여 학생 정보를 조회한다. 별도 API 없이 기존 `studentByIdProvider` 등을 활용.

### 타입별 프로필 카드 분기

`request.type`이 `trial`이면 체험용 카드, 그 외(`regular`, `package`)면 정규용 카드를 렌더링한다. 분기는 ProfileCard 위젯 내부에서 처리.

### 경과 시간 표시

`request.createdAt`에서 현재 시각까지의 차이를 계산하여 상대 시간으로 표시한다 ("2시간 전", "3일 전"). `core/utils/date_format_utils.dart`에 기존 유틸이 있으면 활용, 없으면 추가.

### 학원 뱃지

아바타 위젯에 `academyId != null`일 때 우하단에 작은 🏫 아이콘을 오버레이한다. 기존 아바타 위젯을 확장하거나 `Stack` + `Positioned`로 구현.
