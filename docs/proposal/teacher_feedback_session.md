# 레슨나자(Lessonaza) - 선생님 피드백 세션 자료

> 작성일: 2026-03-06
> 목적: 음악 선생님에게 앱을 소개하고, 실제 업무와의 적합성에 대해 피드백을 받기 위한 자료

---

## 📋 Part 1: 앱 소개

### 레슨나자는 이런 앱입니다

> **"레슨나자는 음악 선생님의 비서 앱입니다."**
>
> 레슨 스케줄, 학생 관리, 레슨 기록, 수강료 확인까지 — 지금 수첩이나 카톡으로 하고 계신 일을
> 하나의 앱에서 깔끔하게 정리해 드립니다.

비유하자면, **네이버 예약**이 식당 예약을 편하게 해주듯이,
레슨나자는 **음악 레슨의 예약·기록·관리**를 편하게 해주는 앱입니다.

---

### 선생님이 겪는 5가지 불편함, 이렇게 해결합니다

#### 불편함 1: 레슨 스케줄 관리가 복잡해요

> "카톡으로 시간 조율하고, 캘린더에 옮기고, 변경되면 또 연락하고..."

| 지금 (Before) | 앱 사용 후 (After) |
|:---|:---|
| 카톡으로 학생마다 개별 연락 | 앱에서 가능한 시간을 설정해두면, 학생이 직접 예약 |
| 변경/취소 시 대화 내용 뒤져야 함 | 앱에서 한눈에 일정 확인, 자동 알림 |
| 수첩·달력·카톡 3군데 따로 관리 | 하나의 캘린더에서 모든 레슨 관리 |

**비유**: 지금은 식당 전화 예약처럼 하나하나 직접 받고 계신 거고, 앱을 쓰면 네이버 예약처럼 자동으로 잡히는 겁니다.

---

#### 불편함 2: 학생이 지난 2년간 뭘 배웠는지 기록이 없어요

> "작년에 뭐 했더라... 기억이 안 나요"

| 지금 (Before) | 앱 사용 후 (After) |
|:---|:---|
| 머릿속 기억에 의존 | 레슨 노트가 날짜별로 자동 저장 |
| 학부모가 물어보면 기억 더듬기 | 타임라인으로 성장 과정을 한눈에 |
| 학생이 바뀌면 인수인계 불가 | 레슨 기록이 앱에 남아 다음 선생님도 참고 가능 |

**비유**: 병원의 진료 기록부처럼, 학생의 "레슨 기록부"가 자동으로 쌓입니다.

---

#### 불편함 3: 학부모에게 보여줄 근거가 없어요

> "우리 애가 잘하고 있는 건가요?" 라는 질문에 말로만 설명

| 지금 (Before) | 앱 사용 후 (After) |
|:---|:---|
| "잘하고 있어요"라고 말로만 전달 | 학부모 앱에서 레슨 내용·연습 기록을 직접 확인 |
| 발표회 전에야 실력 확인 | 연습 현황과 레퍼토리 진도를 실시간 공유 |
| 수강료 인상할 때 근거 부족 | 성장 데이터로 객관적 설명 가능 |

**비유**: 학교 알림장이 학부모에게 자동으로 가는 것과 같습니다. 선생님이 따로 보내지 않아도 됩니다.

---

#### 불편함 4: 수강료 관리가 번거로워요

> "이 학생 이번 달 입금했나? 몇 회 남았지?"

| 지금 (Before) | 앱 사용 후 (After) |
|:---|:---|
| 엑셀이나 수첩에 수기 기록 | 수강권 N회 남음이 자동 표시 |
| 입금 확인을 일일이 통장 조회 | 결제 확인 버튼 한 번으로 기록 완료 |
| 만료·잔여 회수 계산 실수 | 앱이 자동 계산, 만료 전 알림 |

**비유**: 커피숍 스탬프 카드처럼, 레슨할 때마다 자동으로 1회씩 차감됩니다.

> 참고: 실제 돈의 이동(계좌이체, 현금 등)은 기존 방식 그대로 하시면 됩니다.
> 앱은 **"받았다/안 받았다"를 기록**하는 역할만 합니다.

---

#### 불편함 5: 학생 연습 현황을 모르겠어요

> "이번 주에 연습 했어? 안 했어?"

| 지금 (Before) | 앱 사용 후 (After) |
|:---|:---|
| 레슨 시간에 물어봐야 알 수 있음 | 학생의 연습 기록이 실시간으로 보임 |
| 연습 안 한 학생을 레슨 시작 후 파악 | 레슨 전에 연습 현황 미리 확인 |
| 뭘 연습했는지 구체적으로 모름 | 어떤 곡을 몇 분 연습했는지 확인 가능 |

**비유**: 학생의 "연습 출석부"를 선생님이 언제든 열어볼 수 있습니다.

---

### 주요 화면 소개 (선생님 앱 기준)

선생님 앱은 아래 4개 탭으로 구성되어 있습니다.

| 탭 | 역할 | 핵심 기능 |
|:---|:---|:---|
| **홈** | 오늘의 대시보드 | 오늘 레슨 목록, 다가오는 일정, 알림 |
| **스케줄** | 레슨 일정 관리 | 주간/월간 캘린더, 가용 시간 설정, 예약 관리 |
| **학생** | 학생 정보 관리 | 학생 목록, 수강권 현황, 레슨 기록 |
| **프로필** | 내 정보 관리 | 선생님 소개, 레슨 장소, 정책 설정 |

---

### 학생앱 / 학부모앱은?

- **학생앱**: 레슨 스케줄 확인, 연습 기록(체크리스트 방식), 녹음, 메트로놈/튜너 도구를 사용할 수 있습니다.
- **학부모앱**: 자녀의 레슨 일정, 연습 현황, 레슨 노트를 확인할 수 있습니다. (보기 전용)

## 📝 Part 2: 피드백 체크포인트

> 아래 항목들에 대해 선생님의 의견을 듣고 싶습니다.
> "현재 설계"를 읽어보시고, 질문에 답변해 주세요.

---

### 핵심 확인사항 (반드시 확인이 필요한 항목)

#### 1. 레슨 스케줄 관리 흐름

**현재 설계**:
- 선생님이 "가용 시간 슬롯"을 미리 설정합니다 (예: 월요일 14:00~20:00)
- 학생이 가용 시간 중에서 원하는 시간을 선택하여 예약합니다
- 선생님이 예약을 확인(확정) 또는 거절할 수 있습니다
- 정기 레슨의 경우, 한 번 설정하면 매주 같은 시간에 자동 반복됩니다

**질문**:
- [ ] 이 흐름이 실제 레슨 잡는 방식과 비슷한가요?
- [ ] 학생이 직접 시간을 선택하는 것이 괜찮은가요, 아니면 선생님이 지정해 주는 편이 더 현실적인가요?
- [ ] 정기 레슨 외에 비정기(보충) 레슨은 어떻게 잡으시나요?

---

#### 2. 수강권/결제 확인 프로세스

**현재 설계**:
- 수강권은 "회당제"(8회, 12회 등)와 "월정액" 두 가지 유형을 지원합니다
- 실제 결제(계좌이체, 현금)는 앱 밖에서 진행합니다
- 선생님이 앱에서 "입금 확인" 버튼을 누르면 수강권이 활성화됩니다
- 레슨이 진행될 때마다 잔여 회수가 자동으로 1회 차감됩니다
- 수강권이 3회 이하로 남으면 선생님과 학생 모두에게 알림이 갑니다

**질문**:
- [ ] 회당제와 월정액 외에 다른 수강료 체계가 있나요? (예: 분기제, 학기제 등)
- [ ] "입금 확인" 방식이 현실적인가요? 더 편한 방식이 있을까요?
- [ ] 수강권 만료 기준은 어떻게 하시나요? (기간 만료? 회수 소진?)

---

#### 3. 학생 정보 관리

**현재 설계**:
- 학생 프로필: 이름, 악기, 레슨 시작일, 현재 레퍼토리
- 레슨 기록: 날짜별 레슨 노트 (피드백, 주요 포인트, 연습 팁)
- 수강권 현황: 잔여 회수, 만료일
- 연습 현황: 이번 주 연습 기록 요약
- 학부모 연결: 학부모가 별도 앱으로 연습/레슨 현황 확인

**질문**:
- [ ] 학생 정보에 빠진 항목이 있나요? (예: 레벨, 목표, 특이사항 등)
- [ ] 학생마다 레슨 요금이 다른 경우가 있나요? (경력, 레벨에 따라)
- [ ] 그룹 레슨 학생과 개인 레슨 학생을 구분해서 관리하시나요?

---

#### 4. 취소/변경/노쇼 정책

**현재 설계**:
- 레슨 24시간 전까지 무료 취소 가능
- 24시간 이내 취소 시 1회 차감 (선생님 설정에 따라 변경 가능)
- 노쇼(무단 결석) 시 1회 차감
- 보충 레슨은 선생님이 별도 일정을 잡아 진행

**질문**:
- [ ] 위 정책이 현재 운영하시는 방식과 맞나요?
- [ ] 취소 기준 시간(24시간)이 적절한가요?
- [ ] 노쇼 시 어떻게 처리하시나요? (차감? 경고? 보충?)
- [ ] 선생님 사정으로 취소하는 경우는 어떻게 하시나요?

---

### 편의성 확인사항 (있으면 좋은 기능)

#### 5. 레슨 노트 작성

**현재 설계**:
- 레슨 후 간단한 노트를 작성합니다 (3~5분 소요 목표)
- 3가지 영역: ① 오늘의 피드백, ② 잘한 포인트, ③ 다음 주 연습 팁
- 자주 쓰는 음악 용어는 자동완성으로 빠르게 입력
- 작성한 노트는 학생과 학부모에게 자동 공유

**질문**:
- [ ] 레슨 후 노트를 쓰는 것이 부담스러울까요?
- [ ] 3가지 영역(피드백/잘한 점/연습 팁) 구분이 괜찮은가요?
- [ ] 지금도 레슨 기록을 남기시나요? 어떤 방식으로?
- [ ] 노트에 사진(악보, 보잉 표시 등)을 첨부하는 기능이 필요한가요?

---

#### 6. 학부모 정보 공유

**현재 설계**:
- 학부모는 별도 앱에서 다음을 확인할 수 있습니다:
  - 레슨 일정 및 출석 현황
  - 선생님이 작성한 레슨 노트
  - 자녀의 연습 기록 (얼마나 연습했는지)
  - 수강권 잔여 회수

**질문**:
- [ ] 학부모에게 이 정도 정보가 적절한가요? (너무 많거나 부족한가요?)
- [ ] 학부모와 앱으로 소통하는 것에 대해 학부모들이 호응할까요?
- [ ] 성인 학생의 경우 학부모 연동이 불필요하겠죠?

---

#### 7. 알림 설정

**현재 설계**:
- 레슨 1시간 전 리마인더 (학생에게)
- 수강권 잔여 3회 이하 알림 (선생님 + 학생)
- 학생이 연습 기록을 올리면 선생님에게 알림
- 레슨 노트가 작성되면 학생/학부모에게 알림

**질문**:
- [ ] 알림이 너무 자주 오면 꺼버리실 수 있는데, 이 정도 빈도가 괜찮을까요?
- [ ] 추가로 필요한 알림이 있나요? (예: 숙제 미완료 알림, 결제 기한 알림 등)
- [ ] 알림을 받고 싶은 시간대가 있나요? (예: 밤 10시 이후 무음)

---

### 비즈니스 확인사항

#### 8. 수강료 체계

**현재 설계**:
- 회당제: N회 묶음 (예: 8회 320,000원 → 회당 40,000원)
- 월정액: 월 고정 금액 (예: 월 200,000원, 주 1회)
- 할인: 장기 등록 시 할인율 설정 가능 (예: 12회 등록 시 10% 할인)
- 보너스: 특정 조건 시 보너스 레슨 추가 (예: 5주차 보너스 1회)

**질문**:
- [ ] 선생님이 실제로 쓰시는 수강료 체계는 무엇인가요?
- [ ] 할인 기능이 실제로 필요한가요?
- [ ] 보너스 레슨(무료 추가)을 운영하시나요?
- [ ] 형제 할인, 재등록 할인 같은 것도 있나요?

---

#### 9. 다른 선생님 추천 가능성

**질문**:
- [ ] 이런 앱이 있다면 주변 선생님께 추천하실 의향이 있으신가요?
- [ ] 추천하시기 어렵다면, 어떤 기능이 있어야 추천하시겠어요?
- [ ] 선생님들끼리 모이는 커뮤니티(오프라인/온라인)가 있나요?

## 💡 Part 3: 시장 진입 전략 & 수익 모델 제안

### 3.1 시장 현황

#### 국내 음악 레슨 시장의 특성

| 특성 | 설명 |
|:---|:---|
| 시장 구조 | 소규모 개인 레슨 + 중소 음악학원 위주 |
| 관리 방식 | 대부분 수기(수첩) + 카카오톡 + 엑셀 |
| IT 도입도 | 매우 낮음 — 전용 관리 앱 사용률 극히 낮음 |
| 경쟁 환경 | 한국어 지원 음악 레슨 관리 앱이 사실상 없음 |

#### 경쟁사 분석 요약

| 서비스 | 유형 | 강점 | 약점 |
|:---|:---|:---|:---|
| **Practice Space** | 선생님-학생 협업 | 과제 전송, 연습 추적 | 일정 관리 부족, 한국어 미지원, $16/월 |
| **My Music Staff** | 스튜디오 관리 | 결제/일정/출석 올인원 | 연습 추적 없음, 웹 전용, 한국어 미지원 |
| **Modacity** | 개인 연습 관리 | 상세한 연습 통계 | 선생님 연동 없음, 한국어 미지원 |
| **스튜디오메이트** | 학원 운영 관리 | 국내 서비스, B2B | 음악 특화 아님, 가격 비공개, 개인 선생님 부적합 |

#### 레슨나자의 차별점

1. **한국어 네이티브** — 국내에 한국어로 된 음악 레슨 관리 앱이 없습니다
2. **선생님 + 연습 통합** — 스케줄 관리(My Music Staff)와 연습 관리(Modacity)를 하나로
3. **극도로 심플한 UX** — 음악인의 IT 친숙도를 고려한 "3초 내 원하는 화면" 원칙
4. **레퍼토리 템플릿** — 선생님이 만든 커리큘럼을 학생이 바로 연습 체크리스트로 활용
