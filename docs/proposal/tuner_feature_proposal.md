# 튜너(Tuner) 기능 제안서

> 작성일: 2025-01-04
> 상태: 초안 - 사용자 피드백 대기

---

## 1. 개요

### 1.1 목적
레슨 앱에 튜너 기능을 추가하여 학생들의 연습 효율성을 높이고,
선생님과 학생 간의 음정 관련 피드백을 개선합니다.

### 1.2 타겟 사용자
| 사용자 | 니즈 |
|--------|------|
| 음악 학생 | 연습 전 빠른 튜닝, 음정 훈련 |
| 음악 선생님 | 레슨 중 학생 악기 튜닝 확인, 교육 도구 |
| 학부모 | 자녀의 튜닝 습관 확인 (선택적) |

### 2.2 Tonal Energy Tuner 상세 분석 (음악 전공생 표준)

**핵심 기능:**
- 원형 12음계 인디케이터 (색상 구분)
- 이명동음 표시 (B/Cb, C#/Db)
- 옥타브 표시 (C5)
- 기준 주파수 조절 (430-450Hz)
- 조옮김 (Transposition)
- Temperament (음률) 설정
- Sustain/Vibrato 감지
- 음정 분석 그래프

### 2.2 핵심 기능 트렌드
1. **크로마틱 튜너** - 모든 악기 지원 (필수)
2. **자동 감지** - 음 자동 인식 (Auto mode)
3. **시각적 피드백** - 직관적 바늘/색상 표시
4. **메트로놈 통합** - 튜닝 후 바로 연습
5. **정확도** - ±0.5~1 cent 수준

#### 원형 인디케이터 상세 (색상 구분)

```
        12음계 원형 배치 (Tonal Energy 스타일)

              ┌───┐
           ┌──┤ C ├──┐
          B   └───┘   C#
         ┌┴┐  ╱───╲  ┌┴─┐
         │ │ │     │ │Db│    ← 이명동음 표시 (설정 시)
        Bb └┘│ 🐱  │ └──┘ D
        ┌──┐ │-0.0¢│ ┌──┐
        │A │ │ ⚪  │ │D#│    ← cent 원형 게이지
        └──┘ └─────┘ └Eb┘
        Ab            E
           G#     F
              F#

    색상 구분:
    • 자연음 (C,D,E,F,G,A,B): 연한 파랑/청록
    • 반음 (C#,D#,F#,G#,A#): 연한 녹색/민트
    • 활성화 음: 진한 색상 + 테두리 강조
    • 정확 시: 연두색 발광
```

#### 중앙 영역 상세 (고양이 + cent 게이지)

```
    ┌─────────────────┐
    │     ╭───╮       │
    │     │🐱 │       │    ← 고양이 캐릭터
    │     ╰───╯       │
    │                 │
    │    -0.0 ¢       │    ← cent 수치
    │                 │
    │   ┌─────────┐   │
    │   │ ◄─│─► │   │    ← 원형 게이지 (flat/sharp)
    │   └─────────┘   │
    └─────────────────┘

    게이지 색상:
    • 중앙 (정확): 연두색
    • 왼쪽 (Flat): 빨강/주황
    • 오른쪽 (Sharp): 빨강/주황
```

#### 애니메이션 시퀀스 (확정)

```
1. 대기 상태
   - 고양이: 기본 표정
   - 12음계: 투명회색으로 원형 배치
   - 원: 단순 투명 테두리선

2. 음 감지 시
   - 고양이 얼굴에서 "♪ 음표 모양" 생성
   - 해당 음 위치로 음표가 날아감 (애니메이션)
   - 목표 음표: 투명회색 → 진한회색으로 변화

3. 튜닝 정확 시 (Perfect)
   - 음표가 도달하며 해당 음이 "발광" 효과
   - 연두색 글로우(glow) 애니메이션
   - 고양이 표정: 기쁨 + 말풍선 "완벽해옹!"

4. 튜닝 부정확 시 (Flat/Sharp)
   - 음표가 해당 음 근처에서 멈춤
   - 화살표 표시: ↑ (Sharp) 또는 ↓ (Flat)
   - 고양이 말풍선: "조금 더 높여봐옹~ ↑" / "낮춰봐옹~ ↓"
```

#### 비주얼 요소 상세

| 요소 | 디자인 | 비고 |
|------|--------|------|
| **날아가는 음표** | ♪ 모양 | 고양이에서 발사 |
| **원 테두리** | 단순 투명선 | 미니멀 스타일 |
| **정확 시 효과** | 발광 (glow) | 연두색 글로우 |
| **오차 표시** | ↑↓ 화살표 | 음표 옆에 표시 |

```
     정확한 튜닝 시:           부정확할 때 (Flat):

           A ✨                     A
          /glow\                   / \
     G#  (발광!) B             G#  ↓  B
      │   🐱   │                │  🐱  │
     F#        C#              F#      C#

     "완벽해옹!"               "조금 높여봐옹~ ↑"
```

#### 고양이 표정 & 말풍선

| 상태 | 표정 | 말풍선 |
|------|------|--------|
| 대기 | 😺 평온 | - |
| 감지중 | 🐱 집중 | "음..." |
| 낮음 (Flat) | 😿 슬픔 | "더 높여봐옹~" |
| 높음 (Sharp) | 😾 놀람 | "조금 낮춰봐옹~" |
| 정확 (Perfect) | 😻 기쁨 | "완벽해옹!" |

#### 기준 주파수 설정 상세
```
기본값: A4 = 440Hz

프리셋:
• 440Hz (국제 표준)
• 441Hz
• 442Hz (유럽/한국 오케스트라 일반)
• 443Hz

범위: 430-450Hz (0.1Hz 단위 조절)
용도: 바로크 음악(415Hz), 오케스트라별 차이 대응
```

#### 조옮김 (Transposition) 설정 상세
```
Concert Pitch (실음):
• C (기본 - 피아노, 바이올린, 플루트 등)

조옮김 악기:
• Bb (클라리넷, 트럼펫, 소프라노 색소폰)
• Eb (알토 색소폰, 바리톤 색소폰)
• F (호른)
• A (클라리넷 A관)

동작: 악보 기준 음 ↔ 실음 자동 변환
예시: Bb 설정 시, 악보 C → 튜너에서 Bb로 표시
```

#### 이명동음 표시 설정
```
설정 옵션:
• 단일 표시 (기본): C# 또는 Db 하나만
• 병기 표시: C#/Db 함께 표시

자동 선택 기준 (단일 표시 시):
• 샤프 우선: C# D# F# G# A#
• 조성 기반: 설정된 조성에 따라 자동 선택
```

## 5. 사용자 시나리오

### 5.1 학생 연습 시나리오 (업데이트)
```
1. 학생이 연습 화면 진입
2. 하단 [튜너] 탭 선택 (또는 위로 스와이프)
3. 고양이 주변에 원형 12음계 표시됨
4. 악기 연주 → 고양이에서 털이 해당 음으로 날아감
5. 튜닝 정확 → 연두색 연결 + "완벽해옹!"
6. 하단 [메트로놈] 탭으로 전환 → 바로 연습 시작
```

### 5.2 일반 사용 시나리오
```
1. 메트로놈 사용 중 튜닝 필요
2. 위로 스와이프 → 메트로놈 인디케이터 숨김
3. 자동으로 튜너 모드 활성화
4. 빠른 튜닝 후 다시 아래로 스와이프
5. 메트로놈 복귀
```
