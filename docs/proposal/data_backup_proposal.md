# 녹음 데이터 백업 전략 제안서

> 작성일: 2026-01-03
> 대상: 프로덕트 오너 / 기획자

## 요약

앱 재설치 시 녹음 파일과 Hive DB가 초기화되는 문제를 해결하기 위한 백업 전략을 제안합니다.

---

## 현재 문제

### 사용자 시나리오

```
👩‍🎓 "앱을 지우고 다시 깔았더니 3개월간 녹음한 연습 파일이 전부 사라졌어요!"
```

| 상황 | 결과 | 사용자 영향 |
|------|------|-----------|
| 앱 삭제 후 재설치 | 모든 데이터 손실 | 🔴 심각 |
| 새 기기로 이동 | 데이터 이전 불가 | 🔴 심각 |
| 저장공간 부족으로 삭제 | 데이터 손실 | 🔴 심각 |

---

## 경쟁사 분석 결과

### 음악 앱들의 백업 전략

| 앱 유형 | 예시 | 전략 | 앱 삭제 후 |
|---------|------|------|-----------|
| **구독 기반** | Yousician, Simply Piano | 서버 동기화 | ✅ 완전 복원 |
| **프리미엄** | forScore | iCloud + 수동 백업 | ✅ 완전 복원 |
| **기본 앱** | Voice Memos | iCloud 자동 | ✅ 완전 복원 |
| **레슨 앱** | 우리 앱 (현재) | 로컬만 | ❌ 손실 |

### 핵심 인사이트

1. **모든 경쟁사가 클라우드 백업 제공** - 업계 표준
2. **forScore 모델이 우리에게 적합** - 사용자 클라우드(iCloud/Google Drive) 활용
3. **서버 없이도 구현 가능** - 클라우드 API만 사용

## 제안 옵션

### 옵션 A: 클라우드 백업 (권장 ⭐)

```
┌─────────────────────────────────────────┐
│          사용자 클라우드 활용             │
├─────────────────────────────────────────┤
│                                         │
│   iOS 사용자    │    Android 사용자     │
│       ↓        │         ↓            │
│   ☁️ iCloud    │   ☁️ Google Drive    │
│                                         │
│   • 자동 백업 옵션                       │
│   • 앱 삭제 후 복원 가능                  │
│   • 기기 간 동기화                        │
│   • 서버 비용 없음                        │
│                                         │
└─────────────────────────────────────────┘
```

| 항목 | 내용 |
|------|------|
| **개발 기간** | 1-2주 |

| **복잡도** | 중간 |
| **사용자 경험** | 우수 |

| 항목 | 내용 |

| **복잡도** | 낮음 |
| **사용자 경험** | 보통 |

## 권장 접근법

### 단계적 구현

```
Phase 1 (즉시) ──────────────────────────────
│
├── Files 앱 노출 (iOS)
│   └── 30분 작업, Info.plist 설정만
│
├── ZIP 백업/복원
│   └── 1-2일, 수동 백업 기능
│
└── 결과: 최소한의 백업 수단 확보

Phase 2 (1-2주) ─────────────────────────────
│
├── iCloud 자동 백업 (iOS)
│   └── 설정에서 켜면 자동 동기화
│
├── Google Drive 백업 (Android)
│   └── Google 로그인 후 자동
│
└── 결과: 앱 재설치 후 자동 복원

Phase 3 (향후) ──────────────────────────────
│
├── 백엔드 서버 구축
├── 계정 시스템
├── 선생님/학부모 공유 기능
│
└── 결과: 완전한 클라우드 동기화
```

## 의사결정 필요 사항

### Q1. 클라우드 백업 범위

어떤 데이터까지 백업할까요?

| 옵션 | 설명 |
|------|------|
| A | 녹음 파일만 |
| B | 녹음 + 연습 기록 |
| C | 모든 데이터 (녹음, 기록, 설정) |

**권장**: C (모든 데이터) - 완전한 복원 경험

### Q2. 자동 백업 기본값

자동 백업을 기본으로 켤까요?

| 옵션 | 설명 |
|------|------|
| A | 기본 OFF - 사용자가 켜야 함 |
| B | 기본 ON - 옵트아웃 방식 |
| C | 첫 녹음 시 물어보기 |

**권장**: C (첫 녹음 시) - 사용자 인지 + 높은 채택률

### Q3. 클라우드 용량 초과 시

iCloud/Google Drive 용량이 부족할 때?

| 옵션 | 설명 |
|------|------|
| A | 에러 표시만 |
| B | 오래된 백업 자동 삭제 |
| C | 중요 녹음만 백업 (대표 녹음) |

**권장**: A + 안내 메시지 - 사용자 데이터 존중
