## 2. 현재 구현 상태 분석

### 2.1 모델 구조
```
PracticeRepertoire (레퍼토리)
├── id, studentId, name, description
├── startDate, endDate (활성 기간)
├── sections: List<PracticeSection>
└── 통계: completionRate, totalPracticeCount, totalPracticeSeconds

PracticeSection (섹션/구간)
├── id, repertoireId, pieceName
├── startMeasure, endMeasure, sectionName
├── isCompleted, isRepeat
├── practiceCount, totalPracticeSeconds
├── recordings: List<PracticeRecording>
└── dailyStatuses: List<DailyPracticeStatus>

DailyPracticeStatus (일자별 완료)
├── id, sectionId, date
├── isCompleted, completedAt
└── dateOnly (날짜 비교용)

PracticeRecording (녹음)
├── id, sectionId, filePath
├── durationSeconds, bpm
├── isRepresentative
└── createdAt
```

### 2.2 구현된 CRUD 기능
| 대상 | 생성 | 조회 | 수정 | 삭제 | UI 노출 |
|------|:----:|:----:|:----:|:----:|:-------:|
| Repertoire | ✅ | ✅ | ✅ | ✅ | ✅ 모두 구현 |
| Section | ✅ | ✅ | ✅ | ✅ | ✅ 모두 구현 |
| Recording | ✅ | ✅ | - | ✅ | ✅ 삭제 구현 |
| DailyStatus | 자동 | ✅ | 토글 | - | ✅ 캘린더 연동 |

### 2.3 추가 기능
- ✅ `toggleSectionComplete`: 전체 완료 토글
- ✅ `toggleDailyCompletion`: 일자별 완료 토글
- ✅ `toggleSectionRepeat`: 반복 설정 토글
- ✅ `incrementPracticeCount`: 연습 횟수/시간 증가
- ✅ `setRepresentativeRecording`: 대표 녹음 설정

### 6.1 Q3. 연습노트 상세 설계

**사용자 요구사항:**
- 섹션 상세 화면 상단 제목 밑에 최근 연습노트 미리보기
- 터치 시 전체 연습노트 리스트로 화면 전환
- 날짜별 연습노트 추가 가능

**UI 플로우:**
```
[섹션 상세 화면]
├── 제목: "바흐 파르티타 1~8 마디"
├── 최근 연습노트 미리보기 (1줄) ← 터치 시 노트 리스트로 이동
│   └── "2026-01-03: 왼손 4번 손가락 음정 주의..."
├── 연습 통계
├── 녹음 목록
└── ...

[연습노트 리스트 화면] ← 새 화면
├── 헤더: "바흐 파르티타 1~8 마디 연습노트"
├── + 버튼: 새 노트 추가
└── 날짜별 노트 목록 (최신순)
    ├── 2026-01-03: "왼손 4번 손가락 음정 주의..."
    ├── 2026-01-02: "템포 80에서 연습 시작..."
    └── 2026-01-01: "첫 연습, 운지법 확인..."
```

| **Q4. 연습 목표** | D | 일일(시간+섹션) + 주간(시간+일수), 알림+스트릭+뱃지 | 🔴 높음 |
| **Q5. 아카이브** | B | 수동 아카이브 + 최종 삭제 | 🟡 중간 |
| **Q8. 통계 리포트** | B,C | 주간 + 월간 리포트 + 그래프 | 🟡 중간 |

### 7.2 구현 안함

| 기능 | 결정 | 이유 |
|------|:----:|------|
| Q2. 마스터리 등급 | A | 복잡도 대비 효과 낮음 |
| Q6. 선생님 녹음 비교 | A | Phase 2+ 이후 검토 |
| Q7. 가이드 연습 세션 | A | 자유 연습 선호 |

### 7.3 구현 순서 제안

```
Phase 1: 기본 기능 (2-3일)
├── Q1. 섹션 정렬 옵션 (이름순/마디순/최근순)
├── Q5. 레퍼토리 아카이브 (수동 + 최종삭제)
└── Quick Wins (완료율 시각화, 빈 상태 개선)

Phase 2: 연습노트 (2-3일)
├── PracticeNote 모델 추가
├── 섹션 상세 화면에 미리보기 추가
├── 연습노트 리스트 화면 신규
└── CRUD 기능

Phase 3: 연습 목표 (3-4일)
├── PracticeGoal 모델 추가
├── 목표 설정 화면
├── 홈 화면 목표 위젯
├── 스트릭 연계 로직
└── 목표 달성 알림

Phase 4: 통계 리포트 (2-3일)
├── 주간 리포트 화면
├── 월간 리포트 화면
└── 그래프 시각화

Phase 5: 드래그앤드롭 (1-2일)
└── 섹션 순서 수동 변경
```

### 7.4 새로 필요한 모델

```dart
/// 연습노트
class PracticeNote {
  final String id;
  final String sectionId;
  final String content;      // 텍스트 내용
  final DateTime createdAt;  // 작성 시간 (시간별 구분용)
  final DateTime? updatedAt;
}

/// 연습 목표
class PracticeGoal {
  final String id;
  final String studentId;

  // 일일 목표
  final int? dailyTimeMinutes;     // 일일 연습 시간 (분)
  final int? dailySectionCount;    // 일일 완료 섹션 수

  // 주간 목표
  final int? weeklyTimeMinutes;    // 주간 연습 시간 (분)
  final int? weeklyDayCount;       // 주간 연습 일수

  final DateTime createdAt;
  final DateTime? updatedAt;
}
```
