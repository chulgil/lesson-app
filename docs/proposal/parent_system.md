# 학부모 시스템 Q&A 세션

> 작성일: 2025-12-27
> 스펙 문서: `specs/parent_system.md`

## 배경

학생의 경우 학부모 액터가 추가되어 프로젝트 전반적인 재설계가 필요합니다.

### 주요 관계 변경
- 선생님 → 학부모: 수강료 청구
- 선생님 → 학생: 과제 부여
- 학부모: 여러 자녀 과제 현황 한눈에 확인 (선생님 뷰와 유사)

## Q&A 세션

### Q1. 학부모 등록 방식

**질문**: 학부모는 어떻게 시스템에 등록되나요?

| 옵션 | 설명 |
|------|------|
| A | 학부모가 직접 가입 후 자녀 연결 요청 |
| B | 선생님이 학부모 연락처 입력 → 초대 |
| C | 학생이 학부모 초대 링크 전송 |
| **D** | **학생 또는 선생님 모두 초대 가능** |

**결정**: **D** - 학생 또는 선생님이 학부모를 초대할 수 있음

---

### Q2. 연령별 계정 구조

**질문**: 학생 연령에 따른 학부모 연결 정책은?

| 옵션 | 설명 |
|------|------|
| A | 미성년자만 학부모 연결 필수, 성인은 단독 계정 |
| B | 모든 연령 학부모 연결 선택, 결제만 분리 |
| C | 미성년자 학부모 필수 + 성인 선택적 연결 |
| **D** | **모두 지원 (미성년자 필수, 성인 독립, 선택적 연결)** |

**결정**: **D** - 유연한 연령 기반 정책

---

### Q3. 학부모-자녀 관계

**질문**: 한 학부모가 여러 자녀를 관리할 수 있나요?

| 옵션 | 설명 |
|------|------|
| A | 1:1 (학부모 1명 = 자녀 1명) |
| B | 1:N (학부모 1명 = 여러 자녀) |
| C | N:N (여러 학부모 = 여러 자녀) |
| **D** | **현재 1:N, 추후 N:N 확장** |

**결정**: **D** - 1 학부모가 여러 자녀 관리, 추후 N:N 확장

---

### Q4. 결제 청구 대상

**질문**: 수강료 청구는 누구에게 하나요?

| 옵션 | 설명 |
|------|------|
| A | 항상 학부모 |
| B | 항상 학생 |
| C | 학생 연령에 따라 자동 결정 |
| **D** | **기본 학부모, 선생님이 변경 가능** |

**결정**: **D** - 기본값 학부모, 선생님이 청구 대상 변경 가능

---

### Q5. 과제/숙제 알림 대상

**질문**: 과제 알림은 누구에게 먼저 가나요?

| 옵션 | 설명 |
|------|------|
| A | 학부모에게만 |
| B | 학생에게만 |
| C | 학생 + 학부모 동시 |
| **D** | **학생 먼저, 미완료 시 학부모에게 알림** |

**결정**: **D** - 2단계 알림 (학생 1차 → 미완료 시 학부모 2차)

---

### Q6. 학부모 열람 범위

**질문**: 학부모가 볼 수 있는 자녀 정보의 범위는?

| 옵션 | 설명 |
|------|------|
| A | 모든 정보 열람 가능 |
| B | 결제/일정만, 과제/연습은 요약 |
| **C** | **선생님이 열람 범위 설정** |
| D | 학생이 공개 범위 선택 |

**결정**: **C** - 선생님이 학생별로 학부모 열람 범위 설정

---

### Q7. 채팅 채널 구조

**질문**: 선생님-학생-학부모 채팅은 어떻게 구성하나요?

| 옵션 | 설명 |
|------|------|
| A | 3자 통합 채팅방 |
| **B** | **분리 (선생님↔학생, 선생님↔학부모)** |
| C | 기본 분리, 필요시 3자 방 생성 |
| D | 학생 연령에 따라 자동 결정 |

**결정**: **B** - 선생님-학생, 선생님-학부모 채팅 분리

---

### Q8. 학부모 대시보드 범위

**질문**: 학부모 대시보드에서 볼 수 있는 정보의 범위는?

| 옵션 | 설명 |
|------|------|
| A | 일정/결제만 (최소) |
| B | 일정/결제/과제현황 (기본) |
| **C** | **거의 모든 정보 (레슨노트 작성 제외)** |
| D | 선생님과 동일 |

**결정**: **C** - 선생님 수준의 열람, 작성 권한 없음

---

### Q9. 리뷰 작성 권한

**질문**: 선생님 리뷰는 누가 작성할 수 있나요?

| 옵션 | 설명 |
|------|------|
| A | 학생만 |
| B | 학부모만 |
| **C** | **학부모, 학생 모두 가능** |
| D | 결제자만 |

**결정**: **C** - 학부모와 학생 모두 리뷰 작성 가능 (각 1개씩)

---

### Q10. 학부모 알림 종류

**질문**: 학부모에게 어떤 알림을 보내나요?

| 옵션 | 설명 |
|------|------|
| A | 결제만 |
| B | 결제 + 일정 변경 |
| C | 결제 + 일정 + 과제 미완료 |
| **D** | **학부모가 알림 종류 선택 가능** |

**결정**: **D** - 결제 알림 필수, 나머지는 학부모가 선택

---

### Q11. 학부모 리포트

**질문**: 학부모에게 정기 리포트를 제공하나요?

| 옵션 | 설명 |
|------|------|
| A | 리포트 없음, 앱에서 직접 확인 |
| B | 월간 요약 리포트만 |
| C | 주간 + 월간 리포트 |
| **D** | **주간 간략 + 월간 상세 리포트** |

**결정**: **D** - 주간 간략 요약 + 월간 상세 리포트
