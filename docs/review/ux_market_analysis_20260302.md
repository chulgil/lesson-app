## 1. 핵심 플로우 UX 검증

### 1.1 선생님 핵심 여정 (탭 수 분석)

| 여정 | 경로 | 최소 탭 | 평가 |
|------|------|:-------:|:----:|
| 오늘 레슨 확인 | 앱 열기 → 홈 대시보드 | **0탭** | 우수 |
| 레슨 추가 (홈에서) | 홈 → 레슨추가 → 폼 작성 → 저장 | **10탭** | 개선 필요 |
| 레슨 추가 (학생 상세에서) | 학생상세 → FAB → 폼(학생 자동선택) | **4~5탭** | 양호 |
| 레슨 노트 작성 | 홈 레슨카드 → 상세 → 노트 입력 | **1탭+타이핑** | 우수 |
| 과제 배정 | 레슨상세 → 과제탭 → 추가 → 폼 작성 | **4탭** | 양호 |
| 수강권 발급 | 학생탭 → 학생선택 → 수강권 발급 | **3탭** | 양호 |
| 미수금 확인 | 홈 대시보드 즉시 확인 | **0탭** | 우수 |

#### 선생님 홈 대시보드 구성

- **핵심 숫자 3개**: 오늘 레슨 / 미수금 / 이번 달 완료
- **즉시 확인 필요 섹션** (조건부 표시): 레슨 요청 N건, 예약 승인 N건, 입금 확인 N건
- **오늘의 레슨 목록** + [레슨 추가] 버튼

#### 레슨 생성 폼 (AddLessonScreen)

단일 스크롤 폼 (탭/단계 없음):
1. 학생 선택 (바텀시트) → 2탭
2. 날짜 선택 (피커) → 2탭
3. 시간 선택 (피커) → 2탭
4. 레슨 시간 (프리셋 칩 30/45/60/90분) → 1탭
5. 정기 레슨 (토글 + 요일) → 선택적
6. 레슨 내용 (곡명, 메모) → 타이핑
7. 알림 설정 (토글 + 시간) → 선택적
8. 저장 → 1탭

진입 경로별 최적화:
- 학생 상세 → FAB: `studentId` 자동 주입 (학생 선택 2탭 절감)
- 스케줄 탭 → [+]: `preselectedDate`, `preselectedHour` 지원

#### 레슨 상세 (LessonDetailScreen) 3탭 구조

| 탭 | 선생님이 할 수 있는 것 |
|-----|---------------------|
| 레슨 노트 (기본) | 피드백 인라인 편집, 주요 포인트 추가, 연습 팁 추가 |
| 녹음 | 녹음 시작/중지 FAB, 녹음 파일 목록, AI 요약 카드 |
| 과제 | 연습 추가 (유형/우선순위/레퍼토리/구간), 완료 체크, 좋아요 |

### 1.2 학생 핵심 여정 (매일 반복 루프)

| 여정 | 경로 | 최소 탭 | 평가 |
|------|------|:-------:|:----:|
| 다음 레슨 확인 | 앱 열기 → 홈 카드 | **0탭** | 우수 |
| 연습 시작 | 연습탭 → 섹션 탭 | **2탭** | 우수 |
| 메트로놈 켜기 | 중앙 버튼 탭 (어디서든) | **1탭** | 우수 |
| 녹음 시작/종료 | 섹션 상세 인라인 | **2탭** | 우수 |
| 연습 완료 체크 | 연습탭 리스트 체크박스 | **1탭** | 우수 |
| **전체 루프** | 앱→연습→메트로놈→녹음→완료 | **6탭** | **우수** |

#### 학생 홈 네비게이션

```
[홈] [스케줄] [메트로놈(중앙)] [연습] [프로필]
```

- 중앙 버튼: 탭 → 메트로놈 / 길게 누름 → 튜너
- 연습탭: 주간 캘린더 + 날짜별 레퍼토리/섹션 목록 (섹션 직접 탭 가능)

#### 녹음 플로우 (SectionDetailScreen 인라인)

```
섹션 상세 → [녹음 시작] 탭 → 녹음 중 → [정지] 탭
→ 자동 저장 + 연습 횟수 자동 증가 + 스마트 트리밍(무음 제거)
```

별도 화면 이동 없이 인라인으로 완료.

### 1.3 UX 강점

- **학생 매일 반복 루프 6탭** — 연습 도구 앱 대비 매우 효율적
- **홈 대시보드 "즉시 확인 필요"** — 선생님 액션 아이템 집중 표시
- **메트로놈 SectionDetailScreen 하단바 상시 노출** — 0탭 제어
- **학생 상세 → 레슨 추가 시 컨텍스트 자동 주입**
- **수강권 미니배지** — 학생 카드에서 한 눈에 상태 확인
- **원샷 UX 적용** — 과제 배정 → 학생 연습장 자동 등록

### 1.4 UX 병목점 (개선 필요)

| 병목 | 현재 상태 | 개선 제안 |
|------|----------|----------|
| 홈에서 레슨 추가 10탭 | 모든 필드 수동 입력 | 스케줄탭 캘린더에서 날짜/시간 자동 주입 |
| 메트로놈/튜너 중앙 버튼 구분 | 탭=메트로놈, 롱프레스=튜너 (시각적 안내 없음) | 아이콘 라벨 또는 온보딩 힌트 |
| 섹션 완료 버튼 스크롤 최하단 | 매일 반복 액션에 스크롤 필요 | 상단 고정 또는 플로팅 버튼 |
| PracticeRepertoireScreen | StudentPracticeTab과 기능 중복 (데드 코드) | 정리 필요 |
| 홈 대시보드 연습 통계 | 하드코딩 Mock 데이터 | 실 데이터 연동 필요 |

## 2. 핵심 가치 제안

### 2.1 앱 포지셔닝

> **"음악 선생님과 학생이 레슨 외 잡일(메시지, 결제 독촉, 수동 기록)에서 해방되어 음악에만 집중할 수 있는 한국형 레슨 협업 플랫폼"**

### 2.2 3자 생태계 설계

```
학생 (앱의 주인) ←→ 선생님 (초대됨) ←→ 학부모 (모니터링)
                         ↑
                      학원 (관리자)
```

대부분의 경쟁사가 **선생님 중심**인데, lesson-app은 **학생이 주인**. 선생님이 바뀌어도 학생의 레슨 기록 보존.

### 2.3 5가지 핵심 차별화

| 차별점 | 설명 | 경쟁사 현황 |
|--------|------|-----------|
| 양방향 초대 모델 | 선생님/학생 어느 쪽이든 QR/URL로 초대 | 한쪽 방향만 |
| 일정 조율 제로화 | 가용 시간 오픈 → 원클릭 선택 (카톡 핑퐁 제거) | 수동 메시지 |
| 수강권 투명성 | 양쪽 실시간 잔여 횟수 확인 (결제 독촉 부담 제거) | 선생님 메모 의존 |
| 레슨 노트 공동 소유 | 선생님+학생 공동 열람, 선생님 변경 시 데이터 보존 | 선생님만 보유 |
| 한국어 네이티브 | 한국어 UI + 한국 결제 문화 반영 | 전원 영어 |

## 7. 결론

### UX 관점
- **학생 매일 반복 루프 (6탭)**: 매우 잘 설계됨. 경쟁사 대비 우수
- **선생님 핵심 플로우**: 홈 대시보드 우수, 레슨 추가 개선 여지 있음
- **원샷 UX 원칙 잘 적용됨**: 과제 배정 → 학생 연습장 자동 등록 등

### 시장 관점
- **한국 음악 레슨 관리 앱 시장은 사실상 공백** — 선점 기회
- **"레슨 관리 + 연습 도구 통합"은 전 세계 유일한 포지셔닝**
- Tonara 불안정성, TakeLessons 폐업이 기회 요인

### 최우선 과제 (권장 순서)
1. 수익 모델 스펙 문서 작성 (`docs/specs/business/`)
2. 백엔드 MVP 착수 (FastAPI + 핵심 API)
3. 홈→레슨추가 UX 최적화 (캘린더 컨텍스트 자동 주입)
