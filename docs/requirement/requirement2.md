선생님이 과제를 주는 부분의 레파토리 섹션입력 부분에서는 범위유형이 전체로 좁혀집니다. 중복해서 섹션을 입력할수 없으며 줄과 마디입력은 메모로 입력가능합니다. 학생이 알람을 받고 이 섹션을 가져올때 메모는 김선생님 메모란이 활성화되어서 고정 표기됩니다. 김선생님과의 링크가 끊기게되면 메모가 사라집니다.
  다른선생님이 같은 섹션에 메모를 남기게 되어도  채팅히스토리처럼 날짜: 김선생님 (아래 노트 메시지 표기) 하나의 필드에 시간대로 표시됩니다. 연습노트와 같이 선생님별 최근 메모 하나만 표기됩니다. 이메모는 레슨노트로 표기됩니다.  선생님 과제의 경우 리스트에 과제로 표시되고 대표녹음의 경우 선생님 과제만 대표녹음으로
  지정가능합니다. 다른 일반 섹션의 경우 대표녹음이 자동으로 선택되지 않습니다. 따라서 공유도 되지 않습니다. 완료시 대표녹음이 선생님께 공유됩니다.는 과제에 한해서 입니다. 이렇게 설계된 이유는 향후 공유될때 파일이 커져서 공간확보의 어려움을 해소하기 위함압니다.
