## 프로젝트 개요

### 목표
바이올린(음악) 실력 향상을 위한 헬퍼 앱

### 핵심 가치
- **데일리 루틴 관리**: 음악 전문 레슨 및 연습 일지를 통해 효율적 연습 지원
- **체계적인 관리**: 연습일지를 통해 과거 연습 기반 향후 계획 수립

### 타겟 사용자

| 역할 | 설명 |
|------|------|
| **학생** | 연습 기록 관리, 연습 루틴 추적 (앱의 주인) |
| **선생님** | 학생 관리, 레슨 피드백, 진도 확인 (학생 공간에 초대됨) |

### 플랫폼
- iOS, Android (Flutter)
- 음악인은 IT에 관심이 적으므로 **최대한 심플하면서 효율적**으로

## 핵심 아키텍처: 양방향 초대 모델

> **설계 철학**: 학생 중심 + 선생님 도구 양립

| 관점 | 앱의 역할 | 초대 방식 |
|------|----------|----------|
| **학생 관점** | 내 연습 관리 앱 | 학생이 선생님을 QR/URL로 초대 |
| **선생님 관점** | 학생 관리 앱 | 선생님이 학생을 QR/URL로 초대 |

### 사용 시나리오

| 시나리오 | 설명 |
|----------|------|
| A. 선생님 앱 사용 | 상호 연결 (피드백 즉시 반영) |
| B. 선생님 앱 미사용 | 학생이 최소 정보 입력 (이름, 악기, 요일) |
| C. 독학 | 선생님 없이 연습 기록만 관리 |
| D. 학생관리 | 학생 기록만 관리 |

## 기능 요구사항

### 1. 인증
- Google/Kakao 소셜 로그인
- 첫 로그인 시 역할 선택 (선생님/학생)

### 2. 선생님 기능
- 대시보드: 오늘 레슨, 학생 목록
- 학생 관리: CRUD, 레벨 설정, 검색/필터
- 레슨 캘린더: 월/주 뷰, 레슨 CRUD
- 레슨 기록: 노트 작성, 녹음, 연습 과제
- 수강료 관리: 2단계 입금확인 → [상세 스펙](specs/payment_system.md)
- 레퍼토리 관리: 책/곡 > 섹션 구조
- 설정: 레슨 가능 시간

### 3. 학생 기능
- 대시보드: 다음 레슨, 연습 현황
- 레슨 일정 보기
- 선생님 피드백 보기
- 연습 관리: 체크박스, 스트릭 → [상세 스펙](specs/practice_system.md)
- 메트로놈: 인앱 메트로놈, 녹음 연동 → [상세 스펙](specs/metronome_system.md)

### 4. 레슨 스케줄
- 체험레슨 신청/승인
- 정규레슨 등록 (고정/유동)
- 스케줄 변경 요청 → [상세 스펙](specs/lesson_schedule.md)

## 핵심 의사결정

### 데이터 소유권

| 데이터 | 소유권 | 접근 권한 |
|--------|--------|----------|
| 연습 기록 | 학생 | 학생: 읽기/쓰기, 선생님: 읽기 |
| 레슨 노트 | 선생님 | 선생님: 읽기/쓰기, 학생: 읽기 |
| 과제 | 학생 | 선생님: 제안, 학생: 수락/관리 |

### 멀티코치 지원
한 학생이 여러 선생님과 연결 가능 (예: 바이올린 + 화성학)

### 초대 방식
- QR 코드: 대면 레슨 시 스캔
- URL 링크: 메시지/카카오톡 공유
- 앱 내 검색: 선생님 프로필 검색

## 경쟁사 분석 요약

| 경쟁사 약점 | 본 앱의 해결책 |
|-------------|--------------|
| 교사 중심 or 학생 중심 택일 | 양방향 초대 모델 |
| 스케줄과 연습일지 분리 | 레슨에서 바로 연습일지 접근 |
| 영어 UI만 | 네이티브 한글 UI |
| 해외 결제만 | 카카오페이/토스 연동 예정 |
| 교사 없으면 앱 사용 불가 | 외부 선생님 등록 + 독학 모드 |
