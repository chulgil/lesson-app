# Frontend Verify — Playwright 스크린샷 기반 회귀 검증

> autopus `auto verify` 패턴 흡수 (2026-04-23).
> 목적: UI 변경이 의도한 화면만 바꿨는지, 다른 화면을 깨뜨리지 않았는지를 **시각적으로** 확인. 타입체크/단위테스트는 "코드가 컴파일됨" 만 보장한다.
> 보완: 플러그인 `ux-consistency-check` 스킬과 병행 (스킬은 플러그인 업데이트 시 덮어씀, 이 규칙은 프로젝트/글로벌 영속).

## 적용 범위

프론트엔드 변경이 포함된 커밋:
- `frontend/lib/**/*.dart`
- `web/src/**/*.{ts,tsx,vue,svelte}`
- 스타일 파일 (`.css`, `.scss`, theme 토큰)
- 라우터/레이아웃 파일

백엔드만 변경, 데이터 마이그레이션, 문서 변경 → 이 규칙 비적용.

## 검증 흐름

### autopus 사용 시

```bash
# 변경된 프론트엔드 파일 자동 감지 → Playwright 스크린샷 생성 → diff 리포트
auto verify

# 자동 수정 없이 리포트만
auto verify --report-only

# 모바일 뷰포트로 검증
auto verify --viewport mobile
```

기본값: `--fix true` — 쉬운 CSS 회귀(여백, 색상)는 자동 수정 시도 후 스크린샷 재촬영.

### autopus 미사용 환경

수동 3단 검증:

1. **변경 경로 확인**: `git diff --name-only` 에서 프론트엔드 파일 식별
2. **영향 화면 매핑**: 각 파일 → 어느 화면에 사용되는지 수동 조사 (grep 으로 import 체인 추적)
3. **실기 확인**: 개발 서버 띄우고 영향 화면 + 공통 레이아웃 2~3개를 직접 확인

3단계는 CLAUDE.md 상위 지침("UI 변경은 브라우저에서 실기 확인") 과 일치.

## 뷰포트 커버리지

한 번의 검증에 최소 2개 뷰포트:
- 기본: `desktop` (1440x900)
- 모바일: `mobile` (375x667) — 반응형 깨짐 자주 발생

tablet 은 태블릿 전용 레이아웃 변경 시에만.

## 리포트 판독

Playwright diff 이미지에서:
- **빨간 박스** = 레이아웃 변형 (의도적 or 회귀)
- **노란 박스** = 색상/타이포그래피 변화
- **파란 박스** = 새로 나타난 요소

모든 박스는 **의도한 변경인지 설명**할 수 있어야 한다. 설명 불가능한 박스 = 회귀.

## 실패 처리

- **의도한 변경인데 스냅샷이 오래됨** → 스냅샷 업데이트 후 재실행
- **의도하지 않은 회귀** → 수정 후 재검증. 스냅샷 업데이트로 은폐 금지.
- **flaky (애니메이션/폰트 로딩)** → wait 조건 추가하거나 해당 영역 마스킹, 스냅샷 자체는 유지.

## 금지

- 스크린샷 테스트 실패 → 실패 이유 확인 없이 스냅샷 재생성 (회귀 은폐)
- 프론트엔드 커밋에 이 규칙 적용 누락 → 단위 테스트만 통과했다고 PR 제출
- 의도한 변경을 모두 "자동 수정" 에 맡기기 → 자동 수정은 단순 회귀만, 의도한 변경은 수동 반영

## 트리거 시점

| 시점 | 실행 |
|---|---|
| 프론트엔드 변경 커밋 전 | `auto verify --report-only` |
| PR 생성 시 | CI 에 `auto verify` 게이트 연결 |
| 디자인 시스템 변경 (theme/tokens) | 전체 앱 스크린샷 재촬영 (범위 넓음, ultra 모드) |
| 레이아웃 리팩토링 | PR 설명에 before/after 이미지 첨부 |

## 상위 규칙과의 관계

- [adaptive-quality.md](./adaptive-quality.md): frontend 변경은 기본 balanced, 디자인 시스템 변경은 ultra.
- [verification.md](./verification.md): 스크린샷 diff 는 "실제 실행 결과" 증거로 인정.
- 플러그인 `ux-consistency-check` 스킬: 원칙은 이 규칙, 실행은 스킬/autopus 로.
