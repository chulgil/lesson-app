# 이슈: 오디오 라이프사이클 백그라운드 정합성

**우선순위:** 높음  
**상태:** 완료

## 대상

- 앱 전환 시 튜너 마이크가 유지되는 버그를 차단한다.
- `녹음 중이 아닌 상태`에서 앱 백그라운드 전환 시 마이크/튜너 스트림이 종료되도록 보장한다.
- `녹음 진행 중`일 때는 백그라운드에서도 녹음이 유지되도록 예외 처리한다.

## 실행 계획

1. `frontend/lib/main.dart`에 앱 생명주기 observer를 추가하여:
   - `paused/inactive/hidden`에서 `tunerProvider.onAppPaused()` 호출
   - `resumed`에서 수동 녹음이 없을 때 `tunerProvider.onAppResumed()` 호출
2. `flutter analyze` 및 핵심 테스트 실행으로 회귀 점검
3. 문제 반복 재현 시나리오에서 수동 점검(튜너 화면, 녹음 화면, 일반 화면 전환)

## 종료 조건

- 앱이 튜너/마이크 미사용 상태에서 백그라운드로 나갈 때 마이크가 깨어 있지 않아야 함
- 녹음 중에는 앱 전환 후에도 녹음이 유지되어야 함
- `main.dart` 라이프사이클 observer 및 관련 정책이 문서에 반영되어야 함
