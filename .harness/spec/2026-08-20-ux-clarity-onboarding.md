# UX Clarity — 첫 사용 이해 용이성 개선 (시장조사 기반)

> 작성: 2026-08-20 | 상태: Phase 5 진행 | 근거: 병렬 리서치 워크플로우 wf_0eefbc7b-e25 (한국 소비자 앱 3종 조사 + 경쟁 레슨관리 서비스 조사 + UX 이론 조사 + 선생님/학생 여정 코드 감사 2건)

## 1. 문제 정의

앱이 기능 풍부·복잡하여 신규 사용자(비테크 음악 선생님, 저연령 학생)가 "이 앱이 뭘 하는 앱인지, 어디서 시작하는지"를 파악하지 못한다. 감사 결과, 안내 장치(퀘스트·스포트라이트·코치마크·체크리스트)는 이미 만들어져 있으나 **배선이 끊겨 있거나 묻혀 있다**.

## 2. 리서치 결론 (설계 원칙)

| 원칙 | 근거 |
|------|------|
| 첫 실행 투어/캐러셀 금지 — 설명은 필요한 그 화면에 한 줄 | NN/g 70명 통제실험: 프런트로드 튜토리얼은 과업 성공률 무개선 + 체감 난이도 상승 |
| 빈 화면이 곧 사용법 (선행 행동 CTA) | NN/g empty-state, 레슨노트·배민 '텅' 패턴 |
| 한 화면 한 행동, 선택지 축소 | 토스 One-thing-per-page, Hick's Law, 오늘수거 3단계 문장 환원 |
| 활성화 이벤트 역산 설계 | 선생님=첫 학생+첫 레슨, 학생=첫 연습 기록, 학부모=자녀 연결+첫 레슨 기록 열람 |
| 용어는 사용자 언어로, 첫 노출 시 한 줄 풀이 | Userpilot 결과 중심 카피, 비테크 사용자는 기능명을 목표로 번역 못 함 |

## 3. 범위 (13건, 전부 FE-only)

UXC-1(프로필→가용시간 라우팅)은 origin/main에 이미 반영 확인(#P1-7) → 제외. 잔여 헤더 정합만 슬라이스 A에 포함.

### 슬라이스 A — 선생님 온보딩 플로우
- **UXC-4** 로그인 화면에 WHAT 1줄(가치제안) 추가, 첫 가용시간 화면에 WHY 부제 추가. AC: 신규 사용자가 로그인 화면에서 앱 용도를 1문장으로 읽을 수 있다. 가용시간 화면 진입 시 "왜 필요한지"가 본문에 보인다(죽은 코치마크 카피에만 존재 금지).
- **UXC-5** 카테고리 프리뷰 CTA 정리: [건너뛰기]/[시작하기]가 동일 동작 → 단일 CTA로 통합(같은 행동=하나의 CTA, ux-rules #16). AC: 동일 동작 버튼 2개가 사라진다.
- **UXC-7(일부)** 카테고리 프리뷰 타일 카피에 용어 한 줄 풀이(수강권 등). AC: '수강권' 첫 노출 지점에 풀이 존재.
- **UXC-8** 전화인증 뒤로가기 데드엔드: 온보딩 폼이 아닌 진입 전 화면(홈)으로 복귀. AC: 인증 화면에서 뒤로가기 시 온보딩 재진입 없음.
- **UXC-14** 로그인 '학부모 로그인' 경로가 remote에서 죽어 있으면 숨기거나 안내로 교체. AC: NO-OP 진입점 0.
- **UXC-1 잔여** OnboardingStepHeader 단계 수가 실제 여정과 일치(분야 자동스킵 시 헤더도 3단계).

### 슬라이스 B — 선생님 홈
- **UXC-2** NextMissionSpotlight 플래그 레이스 수정: `home_screen.dart:98` `_markQuestFirstShown()`이 첫 도착 즉시 기록 → `next_mission_spotlight.dart`는 값 null일 때만 렌더 → 스포트라이트가 플래시하거나 안 뜸. '첫 도착 타임스탬프'(QuestBoard 5분 윈도우용)와 'spotlight dismiss'(사용자 [시작]/[나중에] 탭)를 별도 플래그로 분리. AC: 신규 선생님 첫 홈 진입 시 스포트라이트가 안정적으로 노출되고, 버튼 탭으로만 소거된다. 기존 QuestBoard 5분 윈도우 동작 불변.
- **UXC-3** 죽은 코치마크 배선 제거 + WHY 카피 이식: `CoachMarkController.start()`가 프로덕션 경로에서 호출 0회(테스트만). home_screen의 코치마크 배선 제거, 카피('학생이 이 시간에 레슨을 예약할 수 있어요' 등)는 퀘스트 행 부제/해당 빈 상태로 이동. core/widgets/coach_mark 라이브러리 자체는 보존(surgical). AC: home_screen에서 CoachMark 관련 죽은 상태·리스너 제거, 카피는 사용자 도달 가능 위치에 존재.
- **UXC-6** 퀘스트보드 점진 공개: 현재 그룹 3-4행만 + '더 보기', 데이터 없는 통계 카드·Pro 분석 링크는 데이터 생기기 전 숨김. AC: 0학생 선생님 첫 홈의 상호작용 요소 수 감소(퀘스트 최대 12행 → 현재 그룹만).
- **UXC-7(일부)** 퀘스트 행 부제에 용어 풀이 적용.

### 슬라이스 C — 학생
- **UXC-9** 학생 대시보드 재배열: 연결(선생님) 없음 시 StudentGettingStartedCard(현재 14개 중 12번째)를 시간대 배너 직후로 승격, 데이터 없는 게이미피케이션 섹션(목표/미션/배지 등)은 연결·첫 레슨 이후 노출. AC: 신규 학생 첫 화면 상단에 체크리스트가 보인다.
- **UXC-10** '선생님 찾기' 라우트 단일화: `teacherSearch`(/search/teachers) vs `selectTeacher`(/schedule/teachers) 혼용. **결정 규칙**: 미연결 학생 CTA는 '발견(검색)' 화면으로 통일 — 두 라우트의 실제 화면 의미를 코드로 확인 후 미연결 문맥의 CTA를 하나로 통일. AC: 미연결 문맥의 '선생님 찾기' CTA가 전부 동일 라우트.
- **UXC-11** NextLessonCard 빈 상태 NO-OP 수정: 빈 상태에 실제 CTA(onTap→UXC-10 정식 라우트), error 분기를 빈 상태와 분리 렌더(C7). AC: 빈 상태 탭 시 이동, 네트워크 오류가 '레슨 없음'으로 위장하지 않음.
- **UXC-13** 학생 가입 3중 모순 해소: 역할카드 '초대 필요' 배지 → 차단 화면 → 그러나 초대코드 화면에 '코드 없이 시작하기' 존재. 차단 화면에 '코드 없이 체험 시작' 경로를 직접 노출해 1화면 단축, 역할카드 배지 문구 완화. AC: 코드 없는 신규 학생이 차단 화면에서 바로 체험 진입 가능.

### 슬라이스 D — 학부모
- **UXC-12** 학부모 대시보드 미연동 상태 정리: 죽은/중복 안내 문구를 단일 '자녀 연결' 카드로 통합. AC: 미연동 학부모 첫 화면에 행동 가능한 연결 CTA 1개.
