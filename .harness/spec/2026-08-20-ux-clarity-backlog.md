# UX Clarity 백로그 — 스타터 샘플·초대 role-skip·시작 안내 공유

> 작성: 2026-08-20 | 선행: #1287/PR#1288 (머지 완료) | 근거: wf_0eefbc7b-e25 리서치에서 "FE 단독 불가"로 보류했던 3건을 BE/FE 정찰로 재평가 — 전부 기존 인프라 재사용으로 FE-only 구현 가능 판정.

## 1. 정찰 근거 (재평가 이유)

| 보류 사유 (당시) | 정찰 결과 (현재) |
|---|---|
| 샘플 데이터 = BE seeds 필요 | seeds는 dev 전용이지만, 수기 학생(`POST /students` name만 필수) + 레슨 완료/노트 + 연습 기록의 **기존 API 조합**으로 교사 1인 스코프 샘플 생성 가능. 스키마 변경 불요 |
| 역할 인코딩 초대코드 = BE 필요 | 역할은 이미 **테이블로 인코딩**됨(학생 `Invite` / 학부모 `ParentInvitation`). 6자 코드 = 항상 학생 연결 → 딥링크 코드 보유 시 role_select 스킵은 FE 라우팅만으로 가능 |
| 알림톡 학부모 온보딩 = 인프라 | 카카오 비즈메시지 발송은 **범위 밖 유지**. FE 대체: 리서치의 "forwardable cheat sheet" — 교사가 시스템 공유(카톡)로 전달하는 시작 안내 메시지. share_plus·초대 템플릿(`app_strings.dart:6559-6577`) 기존재 |

## 2. 범위 (3건, 전부 FE-only)

### UXB-1 스타터 샘플 데이터 — 빈 캔버스 제거 (P1, M)

- **연구 근거**: Trello Welcome Board·Notion 프리필(온보딩 완료율 55% vs 업계 20-30%) — 데이터 기반 앱은 빈 껍데기로 가치 평가 불가.
- **동작**: 학생 0명 교사에게 옵트인 진입점("예시 데이터로 둘러보기") 노출 → 기존 리포지토리로 수기 학생 1명(명시적 예시 라벨) + 완료 레슨 1건(레슨 노트 포함, 과거 날짜) + 연습 기록 1건 생성 → 채워진 화면을 실제로 조작 가능.
- **정리 경로**: 생성된 엔티티 id를 사용자 스코프 로컬 키에 기록. 실제 학생 1명 이상 등록 시 "예시 데이터 정리" 1탭 CTA 노출(샘플 학생 삭제 = 기존 학생 삭제 플로우 재사용). id 유실 시에도 샘플은 일반 수기 학생이므로 수동 삭제 가능 (안전 저하 없음).
- **AC**: 옵트인 없이는 아무것도 생성되지 않는다 / 샘플임이 UI에서 항상 식별된다 / 정리 1탭 후 잔여 0 / 구독·차감 로직 오염 없음(무수강권 완료 경로 사용).
- **아키텍처**: `features/onboarding/domain/services/` 순수 서비스(리포 인터페이스 주입) + presentation provider — flutter-architecture.md Cross-Feature Service Wiring 준수.

### UXB-2 초대 딥링크 role-skip — 가입 단계 축소 (P1, M)

- **연구 근거**: 초대 기반 진입자는 초대자가 이미 앱을 설명함(NN/g) — 역할 질문은 낭비. Duolingo 지연 가입.
- **동작**: `lessonapp://invite/{6자}` 딥링크 보유 사용자가 로그인 후 역할 미확정이면 role_select·student_signup_blocked를 **스킵**하고 학생 초대코드 화면(코드 프리필)으로 직행. 화면 상단에 "초대를 받으셨네요 — 학생으로 시작합니다" 1줄 + 역할이 다르면 빠져나갈 수 있는 보조 링크(role_select로).
- **경계**: 코드 없는 일반 가입 흐름 불변. 기존 auth redirect 회귀 테스트 전부 유지.
- **AC**: 딥링크 신규 학생의 화면 수가 기존 대비 2화면 감소 / 보조 링크로 역할 변경 가능 / 코드 만료·무효 시 기존 에러 처리로 자연 낙하.

### UXB-3 시작 안내 공유 (알림톡 FE 대체) — 온보딩 책임 위임 (P2, S)

- **연구 근거**: My Music Staff·TutorBird "forwardable cheat sheet" — 교사가 학생·학부모의 온보딩 안내자가 되면 앱이 3역할을 직접 가르칠 필요가 없음.
- **동작**: 기존 초대 공유 메시지를 "시작 안내"로 강화 — 앱 한 줄 소개 + 시작 3단계(설치→코드 입력→선생님과 연결) + 코드 + 딥링크. 학부모 초대 생성 지점에 동일한 시스템 공유 CTA가 없으면 추가(있으면 문구만 정합).
- **AC**: 공유 메시지만 읽고 학생이 가입을 완료할 수 있는 정보가 전부 포함 / 신규 문자열 AppStrings / 알림톡 자동 발송은 비범위.

## 3. 비범위

카카오 비즈메시지(알림톡) 자동 발송 인프라, BE 스키마 변경(is_sample 등), Invite 테이블 확장, seeds 프로덕션화, 학부모 초대코드 신설(전화 기반 ParentInvitation 유지).
