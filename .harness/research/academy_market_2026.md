## TL;DR (소규모 음악학원 관점)

한국 소규모 음악학원의 운영 SaaS는 **(1) 예체능 특화 무료 솔루션 (온하이)** 과 **(2) 출결-알림 단일 기능 (출결버스/출결선생)** 두 가지가 실질 옵션이다. 보습학원용 올인원 (클비즈/캠스몬) 은 음악 1:1 레슨·횟수제 운영에 맞지 않고 비용·학습 부담이 커서 소규모는 채택 안 함. **음악학원 전용 + 강사 1-5명 규모 한국형 제품은 사실상 부재**. 글로벌 MyMusicStaff ($14.95/월) 가 강사 1명-소규모 스튜디오 모델로 운영되나 한국 미진출.

**겸직 학원장의 매일/매주 통점 (1인 운영 기준)**:
1. **수업 사이 1-2분 공백에 무통장입금 도착 알림 확인 + 입금자명 ↔ 학생명 매칭** — 미수금 추적이 가장 자주 발생하는 잡무
2. **강사 1-2명에 비율제 페이 (학생 N명 × 단가의 N%) 매달 수작업 계산** — 엑셀 + 출석 캘린더 교차 확인
3. **카톡 그룹방 + 1:1 톡 + 부모톡 + 학생톡 채널 폭증** — 본인이 강사이므로 레슨 중에도 답 못함 → 야간 몰아치기
4. **본인 휴가 / 갑작스러운 컨디션 난조 시 대체 불가** — 학생/부모에게 일정 변경 일괄 통보의 부담
5. **발표회·콩쿠르 시즌의 추가 비용 징수 + 곡목·시간 매칭** — 12월/6월만 폭증

Lessonaza 차별화 기회 (소규모 1인 운영 가설):
1. **무통장입금 매칭 자동화** (입금자명 fuzzy match 또는 가상계좌)
2. **비율제 강사 정산 자동화** (강사 1-5명, 비율 변수만 입력하면 매달 자동 산출)
3. **3자 채팅 채널 분리 + 답변 시간 명시** (영업 외 시간 알림 자동 안내)
4. **발표회 시즌 모드** (곡목·인원·발표회비를 한 화면에서 관리)
5. **현금영수증 자동 발급** (학원법 의무, 위반 시 100만원 과태료)

## 1. 경쟁사 매트릭스

### 1-3. 인접 시장 (학습 가능 패턴)

소규모 음악학원과 운영 패턴이 가장 가까운 곳은 **개인 PT 스튜디오 (트레이너 1-3명) / 필라테스 부티크 (강사 2-5명)**. 동일하게 **무통장입금 + 비율제 강사 + 예약 매칭** 패턴 공유.

| 서비스 | 학습 포인트 (소규모 PT/필라테스 → 소규모 음악학원 이전) |
|---|---|
| **바디코디 (Bodycodi)** | 4,000+ 시설 중 부티크 스튜디오 多. **강사 1-3명 PT샵에도 정산 자동화** 제공. 도입 후 평균 15-38% 매출 성장. → 음악학원 비율제 강사 정산에 동일 패턴 적용 가능 |
| **포인티 (Pointy)** | 회원 재등록 차별화 — "퍼스널 레포트". → 음악학원의 월별 진도 레포트 자동화 (학생 1명 = 부모 1명에게 매월 자동 발송) |
| **위시켓 필라테스 정산 시스템 사례** | 강사별 정산 요율 다른 문제, 수기 예약 중복 문제 → 강사 1-5명 음악학원과 동일 페인 |

### 1-4. 결제 / 입금 매칭

| 서비스 | 음악학원 활용 시 시사점 |
|---|---|
| **토스페이먼츠 (가상계좌 + 웹훅)** | 가상계좌 = 학생별 임시 계좌 → 입금자명 매칭 문제 자동 해결. 웹훅으로 실시간 매칭. **음악학원이 직접 도입은 진입장벽 高 (개발 필요)** → Lessonaza가 래핑하면 가치 |

## 2. 경영 페인포인트 Top 10 (소규모 / 1인 운영 기준)

> 학원장 = 겸직 강사가 **매일/매주** 마주치는 통점 우선 순위.
> 중·대형만의 문제 (다지점 마스터 스케줄, 본사 가맹 정산 등) 는 §2-별표 로 분리.

| 순위 | 페인포인트 | 빈도 | 현 Lessonaza 스펙 커버 | 보강 권장 |
|---|---|---|---|---|
| **1** | **무통장입금 미수금 / 입금자명 불일치 매칭** — 부모님이 입금 미루거나 입금자명이 다른 학생 이름으로 들어옴 → 학원장이 매일 통장 보고 손으로 매칭. 미입금 시 강사 페이는 다음 달로 밀림 | 매일 | 부분 (수강권 결제, 무통장 안내) | **가상계좌 / 입금 fuzzy match** (P0) |
| **2** | **카톡 채팅방 폭증 + 야간 응대** — 학원장이 본인이 레슨 중이라 즉답 불가. 부모 톡·학생 톡·그룹방·공지방 채널 분리 안 됨. 영업시간 외 답변 강요 | 매일 | 부분 (lesson_request 채팅) | **3자 분리 채널 + 답변 시간 명시 + 이벤트 메시지** (P0) |
| **3** | **비율제 강사 페이 계산** — 강사 1-2명이 학생 N명 × 단가의 N% 비율. 매달 출석부 + 엑셀 교차 확인. 출석 누락·취소·보강 처리 헷갈림 | 매월 (말일) | 부재 (추정) | **강사 정산 모듈 (출석 데이터 → 자동 산출)** (P0) |
| **4** | **현금영수증 / 영수증 발급 누락** — 학원법 의무 (위반 시 100만원 과태료). 부모가 요청해도 잊거나 양식 부재 | 매월 (수납 시점) | 부분 (영수증) | **현금영수증 자동 발급 + 매출 export** (P1) |
| **5** | **본인 (학원장) 휴가 / 컨디션 난조 대처** — 1인 운영은 대체 강사 없음. 학생 N명에게 일괄 일정 변경 통보 + 보강 일정 잡기 | 분기 1-2회 + 갑작스러운 컨디션 | 부분 (휴가/일정 변경) | **휴무 시 학생 일괄 통보 + 보강 일정 추천** (P1) |
| **6** | **학생 이탈 신호 감지** — 출석 저조, 부모 톡 답 늦어짐, 진도 정체 → 소규모는 학생 1명 이탈 = 매출 직격 | 주간 (모니터링) | 부분 (출석, 진도) | **이탈 위험 대시보드 (소규모는 학생별 카드 UI 권장)** (P1) |
| **7** | **발표회 / 콩쿠르 시즌 운영** — 12월/6월에 곡목·시간·발표회비 별도 징수. 부모 컴플레인 시즌 | 연 2회 (집중) | 부재 (추정) | **발표회 시즌 모드 (곡목·인원·발표회비 한 화면)** (P1) |
| **8** | **신규 학생 모객 (당근 / 네이버 플레이스 상담)** — 1인 운영은 상담 lead 응대 시간 부족. 상담→체험→등록 흐름 누락 | 주간 (신학기 집중) | 부재 (추정) | **상담 lead 관리 (체험 예약 → 등록 전환)** (P2) |
| **9** | **수업 사이 1-2분 공백 시 잡무** — 다음 학생 준비 + 입금 확인 + 부모 톡 답 + 보강 일정 조정이 모두 1-2분에 몰림 | 매 수업 사이 | 부분 | **"수업 사이 대시보드" — 1분 안에 처리할 일 카드** (P2) |
| **10** | **세무 (간이/일반과세, 부가세 신고, 종소세)** — 1인 운영은 세무사 의뢰 비용도 부담. 매출 데이터 export 형식 필요 | 연 2-4회 (분기·연말) | 부분 | **세무사 표준 양식 export (간이/일반 자동 판정)** (P2) |

### §2-별표. 대·중형 / 다강사만의 페인 (본 보고서 타겟 제외, 참고만)

- 강사 3명+ 의 이직 / 학생 데이터 인수인계 → 소규모(1-2 강사)는 학원장이 직접 인수
- 다지점 본사-지점 매출 정산 → 본 보고서 타겟 무관
- 입시반 깊이 (시창청음·화성학·콩쿠르 결과 누적) → 입시 전문 학원만의 영역
- 연습실 예약 heat map → 방 5+ 의 대형 학원만 필요

### 추가 (1차 조사에서 확인된 한국 음악학원 특이 페인)

- **강사 노무 분쟁 위험**: 3.3% 프리랜서로 계약했으나 실질 근로자성 인정되면 **퇴직금·4대보험 소급 부담 + 과태료**. 소규모 학원도 강사 2명 이상이면 위험. → SaaS가 계약 형태 가이드 + 근무 실태 기록 제공 가치

## 3. 한국 음악학원 시장 특이점

### 3-1. 결제 방식

검색 결과 + 추정:
- **무통장입금 의존도 高**: CMS 자동이체 도입 시 70-80% 자동 수금되나, **소형 음악학원은 CMS 도입률 낮음** (수수료·진입장벽)
- **카카오페이 송금 / 토스 송금 증가 추세** (개인 간 송금 무료)
- **현금 결제는 잔존**: 영수증 발급 의무로 인해 점차 감소
- 추정: 음악학원 결제 분포 — 무통장 50% / 카카오·토스 송금 30% / CMS·카드 15% / 현금 5%

### 3-2. 부모-학생-학원 3자 커뮤니케이션

- **카카오톡 의존도 매우 높음** — 오픈채팅방으로 학원-학부모 그룹방 운영하는 사례 다수
- 문제점:
  - 답변 가능 시간 분쟁 (밤·주말 메시지)
  - 개인정보 노출 (오픈채팅 익명 한계)
  - 공지·문의·결제 안내가 한 채널에 섞임
  - 강사 이직 시 채팅 히스토리 인수인계 불가
- **랑톡/함께학교** 같은 교육 전용 소통 플랫폼 등장하나 학원 도입은 미미

### 3-3. 발표회 시즌 (12월/6월)

- 음악학원 운영의 **가장 큰 비정기 부담**
- 일부 학원은 **목적이 비슷한 수강생끼리 팀 발표** 로 부담 분산
- 발표회비 별도 징수 → 무통장입금 매칭 부담 증가

### 3-4. 코로나 이후 줌 수업

- **음악학원은 줌 잔존도 낮음** (악기 음질·1:1 레슨 특성)
- MOOZ 같은 음악 특화 화상 플랫폼 존재하나 보조 용도
- 추정: 입시반·성인반은 일부 활용, 어린이 취미반은 거의 0

### 3-5. 음대 입시반 vs 일반 취미반 차이

| 구분 | 입시반 | 취미반 |
|---|---|---|
| 가격 | 월 30만~100만 | 월 15~25만 |
| 커리큘럼 | 시창청음 + 화성학 + 전공 실기 + 합주 + 음악사 (체계적) | 좋아하는 곡 중심, 유연 |
| 운영 부담 | 학생 데이터 깊이 (진도·실기 동영상) | 단순 (출석·진도 정도) |
| 대상 | 고등학생 中 | 성인·초중등 |
| SaaS 필요 기능 | 진도 추적 + 실기 영상 아카이브 + 입시 일정 관리 | 출석 + 수납 + 알림톡 |

전국 1,000개+ 실용음악학원 존재 (추정). 입시반 운영 학원은 **데이터 깊이 (학생별 곡목·실기 영상·콩쿠르 결과)** 가 차별화

### 3-6. 지역별 차이 (추정)

- **수도권 (강남·홍대)**: 입시반 비중 ↑, 가격 ↑ (월 20만+), 디지털 도입 적극
- **지방**: 취미반 + 어린이 비중 ↑, 가격 ↓ (월 15만), 무통장입금 의존 ↑, 디지털 도입 보수적

## 4. 디지털 전환 트렌드

### 4-1. 음악학원이 디지털 도입을 미루는 이유

1. **학원 고유 운영 방식과 충돌**: 1:1 레슨, 그룹 수업, 연주회 일정 등 특수 운영이 많아 기성 올인원 툴이 100% 맞지 않음
2. **학부모 앱 설치 거부감**: 일부 프로그램은 유아·초등 저학년 학부모는 익숙하나, 음악학원의 성인·중고등 수강생 비중 高 환경에서는 부담
3. **프로그램 유목민 문제**: 출결은 A, 결제는 B, 상담은 카톡 → 정보 분산 → "도입해도 효율 ↓" 경험 → 재도입 거부
4. **원장 1인 운영**: 학습 부담 + 새 시스템 셋업 시간 부재
5. **CMS 수수료**: 무통장입금이 무료라는 인식 (실제는 미수금 비용 발생)

### 4-2. 도입한 학원이 가장 가치를 느끼는 기능

검색 결과 후기 기반:
1. **자동 청구 + 미수금 가시화** (1순위) — "결산이 깔끔해짐", "수납률 개선"
2. **출결 알림 자동화** — 학부모 신뢰도 ↑ → 자연스러운 등록률 증가
3. **스케줄 관리 (수업 변경, 강사 조정)** — "클릭 몇 번으로 끝남"
4. **상담 기록 누적** — 학부모 응대 일관성

### 4-3. 도입 후 이탈하는 이유

1. 학원 특수성 미수용 (1:1 + 그룹 + 횟수제 혼재 처리 못함)
2. UI 복잡 (원장 1인 학습 부담)
3. 학부모 앱 설치율 저조 → 알림톡으로 회귀
4. "툴이 학원에 맞춰지지 않고 학원이 툴에 맞춰야 하는" 경험

## 5. Lessonaza 스펙 보강 권장 영역 (Top 5, 소규모 1인 운영 기준)

> "학원장 = 겸직 강사가 매일/매주 반복하는 흐름" 을 줄이는 기능에 집중.
> 다강사 운영·다지점·입시 전문 영역은 후순위.

### 5-1. **무통장입금 매칭 (입금자명 fuzzy match 우선, 가상계좌는 옵션)** — P0

- **근거**: 페인 1순위 (매일 발생), 한국 시장 특이점, 글로벌 Fons 도 결제 자동화가 핵심 가치
- **구현 방향 (소규모 1인 운영 우선)**:
  - **MVP**: 학원 계좌 등록 + 학원장이 입금 내역 사진/스크린샷 업로드 → Lessonaza 가 OCR + 학생명 fuzzy match 제안 → 학원장 1탭 확인
  - 점진: 토스페이먼츠 가상계좌 + 웹훅 (학원이 사업자 등록 안 한 경우 진입장벽 ↑ → 옵션 처리)
- **차별화**: 한국 음악학원 SaaS 중 가상계좌·입금 매칭 자동화 제공자 없음. 1인 학원장의 "통장 보고 손 매칭" 잡무 완전 제거

### 5-2. **3자 채팅 (학생-부모-학원) + 답변 시간 명시 + 이벤트 메시지** — P0

- **근거**: 페인 2순위 (매일, 야간 응대 부담). 학원장이 본인이 강사라 즉답 불가
- **구현 방향**:
  - 학원-부모-학생 채널 분리 (현재 카톡은 한 방에 다 섞임)
  - **영업시간 외 자동 안내 메시지** ("21시 이후 메시지는 익일 9시 이후 답변" 자동 발송)
  - 결제 안내·휴가 공지·진도 보고를 이벤트 메시지로 (반복 회화 제거)
  - 부모 톡과 학생 톡 분리 (학생은 진도, 부모는 결제)
- **차별화**: 이미 Lessonaza에 lesson_request 채팅 모델 있음 → 확장 용이. 1인 운영의 야간 응대 부담 직격 해결

### 5-3. **비율제 강사 정산 모듈 (강사 1-5명 특화)** — P0

- **근거**: 페인 3순위 (매월 말일 잡무), 노무 분쟁 위험, 바디코디 부티크 정산 자동화 학습
- **구현 방향 (소규모 특화)**:
  - 강사별 정산 룰 입력 (학생 N명 × 단가의 N%, 시급 N원, 월 고정 N원)
  - **출석 데이터 (취소·보강 포함) → 자동 정산 산출** → 학원장은 확인만
  - 3.3% 원천징수 vs 4대보험 가이드 (계약 형태 추천)
  - 학원장 본인이 강사인 경우 본인 페이도 자동 계산 (자기 회계 명확화)
- **차별화**: 음악학원 비율제 강사에 특화한 한국형 솔루션 부재. 강사 1-2명 소규모 학원에 정확히 fit

### 5-4. **현금영수증 자동 발급 + 매출 export** — P1

- **근거**: 페인 4순위 (학원법 의무, 위반 시 100만원 과태료). 1인 학원장이 가장 자주 잊는 항목
- **구현 방향**:
  - 모든 결제 등록 시 현금영수증 발급 여부 토글 (기본 ON)
  - 부모 전화번호 등록 → 국세청 현금영수증 자동 발급 API 연동
  - 분기·연말 매출 export (세무사 표준 양식)
  - 간이/일반과세 자동 판정 가이드
- **차별화**: 한국 학원 SaaS 중 현금영수증 자동 발급 통합 제공자 부재 (대부분 별도 발급)

### 5-5. **발표회 시즌 모드 (12월/6월 집중)** — P1

- **근거**: 페인 7순위 (연 2회 집중 부담), 음악학원 특이, 글로벌 MyMusicStaff "앙상블 관리"
- **구현 방향**:
  - 발표회 이벤트 생성 → 학생 매칭 → 곡목 등록 → 발표회비 별도 징수 (수강료와 분리)
  - 발표회 시즌 일시 일정 변경 일괄 처리 (보강 슬롯 자동 추천)
  - 콩쿠르 결과 기록 (학생별 누적, 마케팅 콘텐츠로도 재활용)
- **차별화**: 한국 어떤 SaaS도 음악 발표회를 직접 다루지 않음. 1인 학원장의 시즌 부담 직격

### 5-5+. (참고) 후순위 후보

- **이탈 위험 대시보드** (페인 6): 소규모는 학원장이 학생 N명 다 알기 때문에 우선순위 ↓. 그러나 학생 30+ 학원은 가치 ↑
- **휴무 시 학생 일괄 통보 + 보강 추천** (페인 5): 분기 1-2회 이벤트 — 기존 일정 변경 기능 확장으로 충분
- **상담 lead 관리** (페인 8): 신학기 집중 — 별도 모듈보다는 채팅 채널 + 등록 전환 토글로 가볍게
- **수업 사이 1분 대시보드** (페인 9): UX 단위 — 위 5개 모듈을 한 화면에 모은 "수업 사이 모드" 로 통합 가능
- **세무 export** (페인 10): 5-4 의 현금영수증 + 매출 export 와 통합

## 부록 A. 검증 가능 / 추정 표시

본 보고서 내 "추정:" 표시 항목 (검증 부족, 가설 단계):
- 결제 분포 비율 (3-1) — 무통장 50% / 송금 30% / CMS·카드 15% / 현금 5%
- 입시반·취미반 학원 수 (3-5)
- 지역별 차이 (3-6)
- 페인 빈도 ("매일", "매월", "분기 1-2회") — 1차 가설, 학원장 인터뷰로 검증 필요
- "강사 정산 모듈 부재" — Lessonaza 스펙 직접 확인 없이 추정. docs/specs 확인 필요
- 페인 7 (발표회 / 콩쿠르), 페인 9 (수업 사이 대시보드 UX 단위) Lessonaza 커버 여부 미확인. docs/specs/academy/ 또는 docs/specs/schedule/ 추가 확인 권장
- 타겟 "소규모 음악학원 = 강사 1-5명 / 학생 20-100명 / 방 2-5개" 정의 자체가 가설 — 실제 시장에서 이 규모가 가장 큰 segment 인지는 별도 시장 규모 조사 필요
